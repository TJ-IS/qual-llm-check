# Weighted order-dependent clustering and visualization of web navigation patterns

YongSeog Kim<sup>⁎</sup>

Business Information Systems Department, 3515 Old Main Hill, Utah State University, Logan, UT 84322, USA

Available online 19 April 2006

## Abstract

This study introduces a simple but effective visualization system that allows decision makers to easily identify groups of visitors with different sequential navigation patterns. In particular, navigation sequences of visitors are encoded as an order-dependent format so that early visited pages have more weights in the clustering process. Experimental results on a real-world dataset show that Markov state-transition diagrams with transition probabilities based on the proposed scheme can be very useful for developing Web marketing programs tailored to visitors' preferences and interests. © 2006 Elsevier B.V. All rights reserved.

Keywords: Clustering; Markov state-transition diagrams; Self-organizing map; Visualization

## 1. Introduction

Recently, identifying segments of Web users based on navigation and purchasing patterns becomes a very important research topic across multiple disciplines. This specific research theme has been evolved into Web mining [19] and one of the most successful applications of Web mining to personalized marketing is online recommendation system available in many online shops (e.g., Amazon.com). Many online vendors have already renovated their online shopping malls to provide individual visitors with dynamically personalized Web pages by predicting what pages the current visitor is likely to visit or what products she is more likely to purchase [14,15]. One of the most frequently used methods in Web usage mining is clustering. Formally, clustering is defined as the process of partitioning transaction records of customers into a fixed number of groups (or clusters) based on heuristic metrics such as intra-cluster compactness (how similar the elements of each cluster are) and inter-cluster separability (how dissimilar the clusters are). In general, clustering algorithms try to find a clustering where the elements within the same cluster are as similar as possible and the clusters are as dissimilar as possible. A good review of clustering can be found in [11].

Clustering analysis has been widely adopted for many different applications. For example, many marketing professionals [5] have used clustering methods for analyzing market structure and restricting their concerns to a group of customers who are most likely to buy their goods. In information system (IS) community, clustering methods have been applied for studying behaviors of online auction bidders [3], identifying segments of consumers [2], profiling Web usage [1], and data analysis in a data warehousing environment [7].

Many other studies from machine learning and data mining community have presented various algorithms to improve the service quality of Web servers and clients by predicting and prefetching next pages that a typical user will follow conditioned on past pages visited [4,6,18].

One of the main research goals of this study is to find an efficient way of representing Web users preferences and interests embedded in navigation records. This study presents and compares two approaches to representation of navigation patterns of visitors in Web traffic datasets: a boolean and a sequential order-dependent representation of navigation patterns. In a boolean representation of navigation patterns, the navigation sequence of a chosen visitor consists of two integer values, $^ { \ \mathfrak { s } } 1 ^ { \mathfrak { s } }$ for Web pages that a visitor visited and $" 0 "$ for other pages. However, in an order-dependent representation of navigation patterns, the resulting navigation sequence consists of integer values between $^ { \ \mathfrak { s } } 1 ^ { \mathfrak { s } }$ (for the page visited last) and $^ { 6 6 } P ^ { 9 }$ (for the page visited first among $^ { 6 6 } P ^ { \prime }$ pages available on the Web site). Therefore, in an orderdependent representation, Web pages that a visitor visited earlier will have more weights in the process of determining how similar two different navigation patterns are. While the boolean representation has been widely used in most studies [4,10], to authors best knowledge, no other studies have explicitly implemented a weighted order-dependent representation of navigation patterns and compared two methods.

This paper also intends to develop and introduce a visualization tool that enables decision makers to easily identify segments of visitors and understand key characteristics of each segment. As a first step, the proposed system uses Kohonen's Self-Organizing Map (SOM) [13] to divide visitors into subgroups based on their navigation patterns expressed in a weighted orderdependent format. Once clustering outputs from SOM are obtained, the proposed visualization tool takes its place. Although SOM has been preferred to other clustering algorithms because of its capability to visually present clustering outputs into two-dimensional maps, it has its own limitation. By default, SOM constructs a map for each dimension and, therefore, it cannot provide a comprehensive view of clusters of high dimensional datasets. Note that visualizing cluster structure of multi-variate datasets is a generic problem to all clustering algorithms, not a problem specific to SOM. The proposed visualization system combines multiple SOM maps into a single map and present it in a table format.

The proposed system also provides decision makers with an interactive way of exploring each cluster. For example, in the proposed system, decision makers select one cluster and obtain additional information such as the number of visitors, the most representative sequential navigation pattern, and centroid values of the chosen cluster. The proposed simple graphical user interface (GUI) enables users to easily move from one option to another by clicking a mouse button or selecting an option from the menu bar. Thus the proposed system intends to help decision makers develop an effective marketing programs tailored to individual clusters.

The remainder of this article is organized as follows. Section 2 introduces two different methods to represent visitors' navigation patterns. Cluster structures from two approaches on a simple artificial data are illustrated and compared. In Section 3, a short introduction to SOM as a clustering algorithm and its output is provided. Section 4 presents the overall structure of the research model and explains about datasets used in this study. Section 5 shows how different clustering outputs are when the dataset is preprocessed by boolean and order-dependent methods. It also presents how these cluster structures should be interpreted and understood. Section 6 introduces Markov state-transition diagrams based on two representation methods and illustrates how useful they are for effective decision making. Finally Section 7 addresses directions of future research and concludes the paper.

## 2. Web navigation patterns and representation

## 2.1. Boolean and weighted order-dependent methods

Recently, Web mining has gained much attentions of many practitioners and researchers. The main goal of Web mining is to identify interesting and useful usage patterns by applying data mining techniques to Web server log datasets [19]. A successful implementation of Web mining can help site administrators provide visitors with personalized Web pages, recommend associated products, improve site design, and develop tailored marketing messages. Another important area in Web mining is to identify and visualize visitor segments based on their navigation patterns. In fact, the success of a number of approaches to Web personalization and Web site optimization is closely related to the quality of original datasets and how to represent values in original datasets during the preprocessing. Therefore, it is critical to represent original datasets in such a way that clustering algorithms can find true structures of navigation patterns and identified clusters can truly reflect structures of original datasets.

Assuming that original datasets truly reflect visitors navigation patterns, this paper considers two possible ways of representing navigation patterns in Web traffic datasets: a boolean and a sequential order-dependent representation. Before introducing two representation methods, we first define few notations. A navigation sequence for a visitor n is denoted as $x _ { n }$ and a collection of N visitors' navigation patterns is denoted as ${ \vec { x } } .$ Note that an element n in $\overrightarrow { x }$ contains a complete list of Web pages that a visitor n visited. The length of $x _ { i }$ can be different from that of $x _ { j }$ where $i \neq j .$ Also assume that there are P Web pages (or page categories) on a specific Web site.

In a boolean representation of navigation patterns, Web pages that the navigator visited are marked as $^ { \mathfrak { s } } 1 ^ { \mathfrak { s } }$ and $" 0 "$ , otherwise. The boolean representation is the most common and easiest way to encode visitors' navigation patterns, and has been adopted in many previous researchers [4,10]. However, by considering all visits to Web pages equal, the boolean representation cannot truly reflects visitors' implicit preferences of a page $( p _ { i } )$ to another page $( p _ { j } )$ . Therefore, it is desirable to develop a new representation method to fully take into account of sequential visiting orders with weights and hence visitors' implicit interests. In this paper, an order-dependent representation method is proposed to overcome the limited representational power of a boolean representation.

In an order-dependent method, values of P, $P - 1 { , } . . . , 1$ are assigned to the first, $\operatorname { s e c o n d } , . . . ,$ and last visited pages. Therefore, in an order-dependent representation, similarity of navigation sequences over pages visited earlier is more important than similarity over pages visited later in determining how similar two different navigation patterns $x _ { i }$ and $x _ { j }$ are. For example, assume that a navigation pattern $x _ { 1 }$ consists of three different pages in the order of $p _ { 1 }  p _ { 3 }  p _ { 2 }$ . Let's also consider two other patterns, x $( p _ { 1 } \to p _ { 3 } \to p _ { 2 } )$ and $x _ { 3 }$ $( p _ { 3 } \to p _ { 1 } \to p _ { 2 } )$ . In an order-dependent representation, a pair of $( x _ { 1 } , x _ { 2 } )$ is considered closer than a pair of $( x _ { 1 }$ , $x _ { 3 } )$ . This is reasonable because visitors of $x _ { 1 }$ and $x _ { 2 }$ share the same interests in the contents of $p _ { 1 }$ and both visitors show the greatest preference by visiting $p _ { 1 }$ at the earliest time while visitors of $x _ { 1 }$ and $x _ { 3 }$ share interests in other pages with lower priority. However, two pairs will be treated to be equal in a boolean representation because all patterns consist of the same three pages.

## 2.2. Effects of representation methods on clustering

We now illustrate by providing a simple example that clustering results based on two methods can be very different in terms of the number of clusters and both visitors in each cluster. Suppose that a dataset keeps navigation patterns of six visitors $( N { = } 6 )$ on a Web site consisting of three pages $( P { = } 3 )$ . Each page is represented as $p _ { 1 } , p _ { 2 }$ , and $p _ { 3 }$ . Table 1 first shows navigation patterns of individual visitors and corresponding two representations of navigation patterns for a given visitor. For example, when visitor 1 visits three different pages in the order of $p _ { 1 }  p _ { 3 }  p _ { 2 } , $ , a boolean and an order dependent representation represents $x _ { 1 }$ as (1,1,1) and (3,1,2), respectively. Note that in both representation methods, the value of $" 0 "$ is assigned to pages that the user did not visit. Let us denote datasets obtained from a boolean and an order-dependent representation of original dataset as $\mathrm { D a t a } ^ { \mathrm { b o o l e a n } }$ and $\mathrm { D a t a } ^ { \mathrm { o r d e r } }$ respectively.

Although we can apply a clustering algorithm to $\mathrm { D a t a } ^ { \mathrm { b o o l e a n } }$ and $\mathrm { D a t a } ^ { \mathrm { o r d e r } }$ to form clusters, the given example in Table 1 is so simple that we can identify clusters without using clustering algorithms. For example, from Data<sup>boolean</sup>, four visitors (visitors 1, 2, 3, and 5) show the exactly same navigation sequences and hence all belong to the same cluster, say $c _ { 1 }$ . The other two visitors (visitor 4 and 6) visit only two pages but show the same pattern. Therefore visitor 4 and 6 can be in the same cluster, say $c _ { 2 } .$ . However, if we group visitors based on an order-dependent method, three clusters can be constructed. For example, we can put visitor 1 and 3 into the same cluster, $c _ { 1 } ,$ because they have the same navigation pattern, $p _ { 1 }$ first followed by $p _ { 3 }$ and $p _ { 2 }$ . The second cluster $c _ { 2 }$ can be formed with two visitors (visitor 2 and $^ { 4 ) }$ who visited $p _ { 3 }$ first followed by $p _ { 2 } ,$ but $p _ { 1 }$ may or may not be visited. Finally, visitor 5 and 6 can form the last cluster $c _ { 3 } .$ Table 2 summarizes clustering results based on two representation methods with visitors' IDs in each cluster.

Overall, the boolean representation is easier to understand and implement. However, the order-dependent method seems to be superior in the sense that it can better represent visitors' sequential preferences of visiting. Note that it is not a trivial task to take explicit feedback from users about their preferences and interests. However, by weighting users' preferences of Web pages based on their visiting orders over multiple pages, the order-dependent method is able to accurately model user activities on the Web and can be used to develop predictive models for a variety of purposes. This subtle difference becomes critical when the identified clusters are combined with a recommendation engine to provide users with a customized marketing message by placing advertisements at the right time at right pages [6]. The identified access patterns of users can be also used to improve Web site design for easier navigation and dynamic connections between highly correlated pages.

It is important to note that representation methods of navigation patterns affect the outcomes of clustering algorithms and following decision making processes. Further, comparison between clustering outputs of two methods should be interpreted only from managerial perspectives, rather than from numerical perspectives based on evaluation metrics such as intracluster compactness or inter-cluster separability. This is mainly because two clustering outputs are based on two different datasets that have different scales and/or different cluster structures. Therefore, in the following sections, clustering results will be presented and discussed based on managerial insights.

## 3. Clustering and visualization with SOM

## 3.1. SOM algorithm detail

Clustering may be performed using various methods developed by many scholars in statistics and data mining community. A good review and discussion about underlying theory and various algorithms can be found in [9,11] and citations there. Although these algorithms have been used by many researchers for various applications, the main focus of these algorithms is to decompose the dataset into a set of disjoint clusters, not to visualize identified cluster structures. However, being able to visualize cluster structures is a highly recommended component of clustering algorithms because of “unsupervised” and hence subjective nature of clustering process. This is one of many reasons that SOM has been widely accepted as a new clustering algorithm. Unlike other clustering algorithms, SOM can not only group data points into the clusters, but also graphically represent the relationship among the clusters. SOM is also different from other methods in the sense that it is a data-driven non-parametric algorithm. Therefore, SOM does not need assumptions about the distribution of the datasets and thus it may be able to find hidden structures from high-dimensional data sets [12].

The architecture and training process of SOM to find cluster structures is very similar to those of artificial neural networks [13]. Fundamentally, the SOM defines a mapping from input data onto a two-dimensional map consisting of (user-defined) number of nodes. Initially, each individual node is assigned a randomly generated vector of real values and the vector associated with an individual node j is called a reference vector $r _ { j } .$

Once an initial map is constructed, SOM iteratively updates its map structure by modifying reference vectors at each node as it reads input vectors successively. That is, for each input vector $x _ { i } ,$ the node of which distance to the $x _ { i }$ is minimal is chosen as the best matching node (or the winning node) and reference vectors of the winning node and its neighborhood nodes are updated using a predetermined formula. This way the winning node can precisely represent the current input record and neighborhood nodes can gradually specialize to represent similar inputs. A formal description of SOM algorithm is summarized as follows.

• Step 1: Initialize a map. Create a map with initialized reference vectors $r _ { j }$ for individual nodes in a map. Initialize other parameter values such as a neighborhood size $( N _ { c } ^ { t } )$ and learning rate $( \boldsymbol { \alpha } ^ { t } )$ at the time of t.

• Step 2: Determine the winning node. Select the best matching node with the minimum distance to an input vector $x _ { i } .$ . The distance from input vector $x _ { i }$ to node j is computed as follows:

$$
\delta_ {i j} = | | x _ {i} - r _ {j} | | = \sqrt {\Sigma_ {p = 1} ^ {P} (x _ {i p} - r _ {j p}) ^ {2}}\tag{1}
$$

where $P$ is the dimension of input vector $x _ { i }$ .

r _ {j p} ^ {t + 1} = r _ {j p} ^ {t} + h _ {j} (x _ {i p} - r _ {j p} ^ {t})\tag{2}

• Step 4: Repeat. Repeat from step 2 for the number of epochs and, at each training time t, adjust $N _ { c } ^ { t }$ and $\boldsymbol { \alpha } ^ { t } .$

For a practical purpose, a small map with less than a few hundred nodes is recommended for cluster identification purposes. Parameter values such as learning rate and neighborhood size can be tuned. A rule of thumb is that these parameter values are chosen to be large in the beginning of the training process but decrease slowly during learning. However, it has been shown that the selection of parameters does not greatly influence the outcomes of the training process when training small maps [13]. Therefore, this paper does not extensively test many combinations of parameter values. We implemented a SOM with a hex-angular map consisting of 8 × 12 nodes. Several combinations of learning rates have been tested using four values (0.12, 0.08, 0.05, and 0.03) and three values (0.05, 0.03, and 0.02) during the first and second phase of training, respectively. However, outputs with various learning rates were not significantly different when each record is presented 500 times during the training process. Therefore, this paper presents outputs based on learning rates 0.05 and 0.03 for the first and second phase. Overall, parameter values used in this study were chosen to meet the suggestions in [13].

## 3.2. Visualization of clustering results

Visualizing clustering results is a challenging task because most datasets are multi-dimensional. That is, when the dimension of datasets is greater than three dimensions, it is not easy to present clustering outputs in a graphical form that humans can understand. However, since the ultimate goal of data analyses including clustering is to provide decision makers useful information, it is highly recommended to have an effective visualization tool that shows the overall structure of clusters with key characteristics of each cluster. This problem becomes more serious when datasets are preprocessed with an order-dependent representation method because it is not possible to keep “sequential order” information in the process of computing centroids.<sup>1</sup> In order to illustrate problems related to cluster visualization, Fig. 1 presents two SOM maps built on Data<sup>boolean</sup> and Data<sup>order</sup> of the msnbc dataset.<sup>2</sup> Note that SOM produces a map for each dimension and hence there can be P maps for a P-dimensional dataset. Each hex-angular map in Fig. 1 consists of 96 (=8×12) nodes for a chosen dimension and shows clusters by using different colors depending on centroid values at each node. Although it is easy to identify three clusters (ones with white, gray, and black colors) in Fig. 1, it will not be easy to visually identify clusters and understand characteristics of each cluster when we have to consider all P maps. Also note that maps from two re presentation methods show different cluster locations and possibly different characteristics of cluster.

In order to visualize cluster structure in a complete dimension, we can construct a new map in which the value of node j is an average of centroid values of all dimensions of node j in multiple maps as shown in Fig. 2. However, in an order-dependent representation, this method will lead to the loss of information about visitors' preferences reflected in their sequential visiting orders. Further, SOM does not provide an interactive way to explore each cluster. As a solution to these problems, the proposed system presents clustering results of all dimensions in a two-dimensional format while keeping information of sequential orders. Further, it allows the decision makers to obtain detailed information about the number of visitors and their visiting patterns for a chosen node.

## 4. Research model and data description

## 4.1. Research model

Fig. 3 shows the overall process of the current study that consists of five major steps. In the first step, visitors' navigation records are retrieved from Web server logs. Next, acquired datasets are transformed in two different ways: a boolean and an order-dependent representation. The boolean approach represents navigation patterns using only whether or not a specific page is visited or not, while an order-dependent approach takes into account visiting sequences of individual pages. Then, SOM algorithm will be applied to both datasets to find cluster structures. In the visualization step, SOM outputs are read and processed to provide detailed statistics and characterize individual nodes based on identified navigation patterns. This visualization tool presents multi-dimensional clustering outputs of SOM into a single two-dimensional format and allows decision makers to review summary statistics of each cluster. This way it helps decision makers understand clustering outputs and hence develop right marketing programs and applications tailored to visitors' preferences and interests.

## 5.2. Clustering and visualization with boolean representation

The proposed visualization system not only presents multi-dimensional clustering outputs into a twodimensional map but also provides an interactive GUI interface that allows decision makers to obtain microscopic view of each node in a map. For example, when decision makers want to know information about a specific node, they can click a right mouse button on the node that they are interested in and choose “Statistics” option. The same utility can be implemented by choosing the same option from View on the menu bar and click on the node. ## 6.2. Plain state-transition diagrams of K-mean<sup>boolean</sup>

Navigation sequences of visitors can be modeled with Markov state-transition diagrams that consist of system states (a set of pages) and transition probabilities between states. State-transition diagrams can greatly help analysts understand users' navigation patterns by graphically displaying pages as individual nodes and transitions between pages as either arrows or arcs. In this paper, two different types of statetransition diagrams will be considered: plain and directional state-transition diagram. The plain statetransition diagrams are constructed for K-mean<sup>boolean</sup> clusters to show how often $p _ { i }$ and $p _ { j }$ are viewed together, regardless of which page is visited first and which one is next. In contrast, the directional statetransition diagrams are constructed for K-mean<sup>order</sup> clusters and they can show the transition probabilities from $p _ { i }$ to $p _ { j } .$

Assuming that there are $P$ pages, transition probabilities between $p _ { i }$ and $p _ { j }$ in a plain state-transition diagram can be computed as follows:

$$
\operatorname{prob} \left(p _ {j} \mid p _ {i}\right) = \frac {\# \text {   of   } \left(p _ {i} \cup p _ {j}\right)}{\# \text {   of   } p _ {i}}, i \neq j\tag{3}
$$

where $\#$ of $( { p } _ { i } \cup { p } _ { j } )$ represents the number of visitors who viewed both $p _ { i }$ and $p _ { j } .$ For example, when 200 visitors viewed both $p _ { 1 }$ and $p _ { 2 }$ while a total of 1000 visitors visited $p _ { 1 }$ , the prob $( p _ { 2 } | { \overset { - } { p } } _ { 1 } ) = { \frac { 2 0 0 } { 1 0 0 0 } } { = } 0 . 2$ . Note that information about navigation directions (either from $p _ { 1 }$ to $p _ { 2 }$ or the other way) or information about if visitors viewed other pages before visiting $p _ { j }$ are not relevant to compute Eq. (3). However, prob $( p _ { j } | p _ { i } )$ is different from prob $( p _ { i } | p _ { j } )$ ).

After computing transition probabilities based on Eq. (3), plain state-transition diagrams were constructed for all five K-mean<sup>boolean</sup> clusters and they were shown in Fig. 8. Transitions between states are denoted by arrows and only transitions of which transition probability is greater than 0.5 are shown to improve the readability.

## 6.3. Directional state-transition diagrams of K-mean<sup>boolean</sup>

Although plain state-transition diagrams in Section 6.2 provide information about which pages are viewed together, they cannot provide information about which page will be visited next after a specific page $( \operatorname { s a y } p _ { i } )$ is visited and what is a probability of a direct transition from $p _ { i }$ to $p _ { j }$ . Note that prob $( p _ { j } \mid p _ { i } )$ simply show how often $p _ { j }$ and $p _ { i }$ are visited together without any information about transition direction. Therefore, it is necessary to have a new formula to compute a probability of a transition from $p _ { i }$ to $p _ { j } .$ Assuming that there are $P$ Web pages, a transition probability from $p _ { i }$ and $p _ { j }$ can be computed as follows:

$$
\operatorname{prob} ^ {\mathrm{o}} \left(p _ {i} \Rightarrow p _ {j}\right) = \frac {\# \text {   of   } (p _ {i} \Rightarrow p _ {j})}{\# \text {   of   } p _ {i}}, i \neq j\tag{4}
$$

where ${ p _ { i } } ^ { \Rightarrow } p _ { j }$ represents a direct transition from $p _ { i }$ to $p _ { j }$ without visiting any other pages. In order to highlight the difference between $\operatorname { p r o b } ( p _ { j } \Rightarrow p _ { i } )$ and ${ \mathrm { p r o b } } ^ { \mathrm { o } } ( p _ { j } { \Rightarrow } p _ { i } )$ assume that 1000 visitors viewed $p _ { 1 }$ and, among them, 100 visitors viewed $p _ { 2 }$ right after visiting $p _ { 1 }$ . Also assume that a total of 200 visitors viewed both $p _ { 1 }$ and $p _ { 2 } .$ Note that, among 200 visitors who visited both $p _ { 1 }$ and $p _ { 2 } ,$ , 100 visitors viewed $p _ { 2 }$ right after $p _ { 1 }$ and the other visitors visited $p _ { 2 }$ before visiting $p _ { 1 }$ or after visiting other Web pages. Now according to Eq. (3), $\mathsf { p r o b } ( p _ { 2 } | p _ { 1 } )$ is computed as follows:

$$
\operatorname{prob} \left(p _ {2} \mid p _ {1}\right) = \frac {2 0 0}{1 0 0 0} = 0. 2.\tag{5}
$$

However, according to Eq. (4), ${ \mathrm { p r o b } } ^ { \mathrm { o } } ( p _ { 1 } \Rightarrow p _ { 2 } )$ is computed as follows:

$$
\operatorname{prob} ^ {\mathrm{o}} \left(p _ {1} \Rightarrow p _ {2}\right) = \frac {1 0 0}{1 0 0 0} = 0. 1.\tag{6}
$$

It is easy to understand that prob $( p _ { j } | p _ { i } ) \succeq \mathrm { p r o b } ^ { \circ } ( p _ { i } \Rightarrow p _ { j } )$ Although it is desirable to construct directional statetransition diagrams for clusters of $\mathrm { K - m e a n } ^ { \mathrm { b o o l e a n } }$ , it is not possible because Data<sup>boolean</sup> does not contain information about navigation orders. However, in order to compare plain and directional state-transition diagrams, navigation orders were restored and put back into each clusters of K-mean<sup>boolean</sup>. This can be done using unique record IDs assigned to each records to find matching records in Data<sup>order</sup>. Once a matching in Data<sup>order</sup> is identified, navigation order of a matching record is simply copied. Note that a boolean representation is a special case of an order-dependent representation.

Five directional state-transition diagrams were constructed this way and shown in Fig. 9. Again, arrows in diagrams represent transitions between pages, and thicker arrows imply transitions with higher probabilities to navigate between pages. Only transitions of which transition probabilities are greater than 0.1 are shown.

All five diagrams show different patterns, representing well separated clusters of visitors' navigation patterns. According to the diagram of $c _ { 1 } ^ { \mathrm { b } } , \ p _ { 1 }$ was frequently visited (and hence is likely to be visited again in future) by many visitors who visited at $p _ { 9 } , p _ { 1 3 } ,$ $p _ { 6 } ,$ and $p _ { 8 } .$ . In particular, it shows that about a half of visitors who viewed $p _ { 9 }$ (54% of visitors) visited $p _ { 1 }$ next, and a half of visitors of $p _ { 1 3 }$ (48% of visitors) are likely to visit $p _ { 1 }$ next. Although this diagram shows similar navigation patterns identified in Fig. 8(a), it is worthy to note differences between two diagrams. First of all, although it is shown in Fig. 8(a) that all visitors who already viewed $p _ { 6 }$ visited or will visit $p _ { 1 } ( { \mathrm { p r o b } } ( p _ { 1 } |$ $p _ { 6 } ) = 1 . 0 )$ , the direct link of $p _ { 6 } { \Rightarrow } p _ { 1 }$ has a comparatively lower probability (0.16). ## 7. Conclusions and future research

SOM is a data-driven clustering algorithm to find hidden structures in datasets and visualize findings in a two-dimensional map. However, a task to build a single combined map for a complete dimension of datasets still remains. Note that visualizing clustering results of high dimension datasets is a generic problem not only to SOM but to all clustering algorithms. In addition, many previous studies have not fully utilized sequential visiting order in clustering process and hence resulting clusters may not truly reflect visitors' preferences. This research intends to provide a solution to these problems and the detailed contribution of this research is summarized as follows:

• This paper introduces a novel way to incorporate sequential navigation order into a clustering process. By weighting the importance of Web pages based on their visited orders, an order-dependent representation can accurately represent visitors' interests. Further, clustering results also reflect not only how many same pages visitors visit but also how close navigation sequences of visitors are.

• This paper also introduces a simple but effective way to summarize multi-dimensional clustering outputs of SOM. In particular, without resorting to another clustering algorithm, the proposed visualization system makes it possible for users to visually identify similar groups of navigation patterns. It also graphically shows that clustering outputs from two representation methods are significantly different.

• State-transition diagrams are used to visualize navigation patterns of visitors for datasets based on either a boolean or an order-dependent representation. The estimated probabilities of transitions between states can be used to dynamically recommend a page for visitors to visit next.

In future work further analyses on managerial insights gained from two different methods will be included. At the same time, a more accurate model of navigation patterns will be studied. Although the proposed system successfully utilizes sequential orders to weight individual pages for clustering purposes, it is just one of many possible ways to represent individual preferences and interests. For example, the time that a user spends on a particular page or the frequency of occurrence of a page reference can be a good indicator of visitors' interests on that page [16,20]. Note that none of these measurements of users' interests is complete. Therefore, it is desirable to develop a model that uses multiple criteria with the same or subjectively determined weights in the process of constructing clusters.
