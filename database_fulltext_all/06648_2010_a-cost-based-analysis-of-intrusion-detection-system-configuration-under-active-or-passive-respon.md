# A cost-based analysis of intrusion detection system con<sup>fi</sup>guration under active or passive response

Wei T. Yue <sup>a,</sup>⁎, Metin Çakanyıldırım 1

<sup>a</sup> Department of Information Systems, City University of Hong Kong, Tat Chee Avenue, Kowloon Tong, Hong Kong

## a r t i c l e i n f o

Article history: Received 13 July 2007 Received in revised form 1 May 2010 Accepted 12 June 2010 Available online 19 June 2010

Keywords: Information security IDS con<sup>fi</sup>guration Intrusion response Investigation capacity

## a b s t r a c t

This paper studies the joint decisions of IDS con<sup>fi</sup>guration and alarm investigation capacity under active and passive responses. In active response, alarm events are blocked immediately, whereas alarm events are allowed to access the information assets in the passive response. Despite facilitating information <sup>fl</sup>ow, passive response exposes the assets to attacks while the security analysts investigate the alarms. On the other hand, active response may unnecessarily delay the benign traf<sup>fi</sup>c since alarm events are blocked. We <sup>fi</sup>nd closed-form formulas for the optimal investigation capacity and show the optimal con<sup>fi</sup>guration under active response is smaller than under passive response. We also provide expressions that can be used to evaluate security costs and bene<sup>fi</sup>ts under various con<sup>fi</sup>gurations, capacities and responses. Numerical studies are done to illustrate the sensitivity of the optimal decisions.

## 1. Introduction

As greater connectivity allows information systems to extend their reach, assuring information security has become a challenge. Recent surveys have shown that organizations today are increasingly experiencing Information Technology (IT) security breaches [1]. A <sup>fi</sup>rm must <sup>fi</sup>rst detect attacks and then determine the proper responses for those attacks. Intrusion detection system (IDS) is one of the many important security tools used to accomplish the above goals [4]. Despite the interdependencies of the detection and response decisions [10], these decisions are often not considered jointly in the previous research. In this paper, we consider how strict we should set (or con<sup>fi</sup>gure) our IDS and how we should respond to the alarms generated by the IDS. The <sup>fi</sup>rst decision determines the amount of alarms that we will encounter, and the second decision determines what is the best approach to investigate and respond to those alarms. These decisions are jointly optimized in a model to illustrate the interdependencies of intrusion detection and response. Speci<sup>fi</sup>cally, we show how the optimal decisions are affected by the different sets of input and cost parameters in intrusion detection and response.

In IDS con<sup>fi</sup>guration, detection rules can be chosen to be broadly or speci<sup>fi</sup>cally de<sup>fi</sup>ning the malicious and benign activities. Hence, IDS can be con<sup>fi</sup>gured to be ‘strict’ or ‘loose’ based on how we implement the rules. In terms of alarm response, it can take various forms and it is related to the level of investigation capacity of the <sup>fi</sup>rm. In the passive response, alarms are not formally responded by the IDS until the security analysts investigate them. Therefore, greater investigation capacity is required to ensure timely investigation of the alarms. In the active response, predetermined actions are taken by the IDS before the analysts are involved. Hence, the automated actions reduce the need to security investigation capacity. In order to minimize the overall security costs with the deployment of IDS, we need to determine the appropriate response type, investigation capacity, and IDS con<sup>fi</sup>guration.

There are two broad approaches used by IDS to determine whether an event is malicious: misuse detection and the anomaly detection methods. In misuse detection, the IDS matches suspicious activities with prede<sup>fi</sup>ned rules. In anomaly detection, the IDS <sup>fi</sup>rst de<sup>fi</sup>nes the acceptable network and system behaviors from historical data, and then classi<sup>fi</sup>es behaviors outside normal behavior to be malicious [4]. In both approaches, the IDS attempts to classify benign and malicious events. Hence, an alarm could represent wrong decisions on benign events (false alarm) or correct decisions on malicious events (detection). Consequently, a <sup>fi</sup>rm needs to consider the tradeoff between false alarm cost and misdetection cost while con<sup>fi</sup>guring an IDS.

In previous literature, detection and response decisions are often separately treated. Gaffney Jr. and Ulvilla [9,12,25] and Çavuşoĝlu and Raghunathan [7] study the cost tradeoff in IDS con<sup>fi</sup>guration without addressing the possibilities of different intrusion response approaches. On the other hand, some previous studies have mainly focused on <sup>fi</sup>nding the proper evaluation criterion in automated response [2,5,6,13,24] and do not consider the fact that how the IDS is con<sup>fi</sup>gured could affect the response decisions. In this paper, we use a queueing theoretic formulation to capture the cost tradeoff in IDS con<sup>fi</sup>guration and also the costs arising from an alarm while it is waiting to be investigated by the security analysts. Furthermore, investigation cost is also included in the model.

There has been some serious debate in the industry about the appropriateness of using the active or passive response [16]. An alarm generated by the IDS often requires intensive forensics effort by the security analysts to investigate its authenticity. If a <sup>fi</sup>rm adopts the policy of investigating all the alarms, the investigation capacity has to be planned so that alarms are investigated in a reasonable time. Failure to do so can lead to excessive damages caused by malicious events waiting to be investigated. Alternatively, a <sup>fi</sup>rm can adopt an active response to limit the damage of the malicious events after the alarm, but this response blocks each benign event that raises an alarm. In the worst case, hackers can exploit the active response. For example, by spoo<sup>fi</sup>ng IP addresses hackers can perpetrate an unintended denial of service attack [18].

We adopt the assumption that an event related to an alarm is blocked until proven benign (blocked when proven malicious) in the active (passive) response. The active response involves blocking alarms. An alarm event cannot access the information assets in the active response until it is judged to be benign by the security analysts. In the passive response, on the contrary, an event related to an alarm are not blocked while it is investigated. The event is blocked only when the security analysts determine that the alarm event is malicious. In practice, active response appears in many forms, including dropping the connection of suspicious events (referred to as shunning), recon<sup>fi</sup>guring <sup>fi</sup>rewalls to curb attacks, delaying response [21], redirecting traf<sup>fi</sup>c to dedicated honeypot systems so that some intelligence on attacks can be collected, containing and eventually eliminating worm and spam attacks [19,26], etc. Currently, many commercial IDSs, such as enterasys, etercept, netRanger and others can operate under active response or passive response approach.

The objective of this paper is to coordinate three important decisions made in managing an IDS: the response approach, the false alarm rate and the investigation capacity. This coordination has not been addressed with an optimization methodology in the literature. Our analysis allows us to observe the impact of the different input and cost parameters on the optimal decisions. One of the important managerial insights we derived is the optimal response approach depends on the accumulation rate of the damage cost to the accumulation rate of the delay cost. Furthermore, con<sup>fi</sup>guration and investigation capacity should be lower inactive response than in passive response, We also show that a firm which found active response to be appropriate should continue to use the active response if the IDS technology improves. Lastly, we demonstrate how the input and cost parameters affect the optimal investigation capacity. For example, more benign traf<sup>fi</sup>c would require more investigation capacity in passive response. Similar to IT security risk management [22], our models are based on cost-and-bene<sup>fi</sup>t analyses to determine the appropriate security protection actions. Thus, with a speci<sup>fi</sup>c focus on IDS, our models add to the cost-and-bene<sup>fi</sup>t models applied in IT security risk management.

In the next section, we introduce model components. We lay out the optimization models and our results in Sections 3 and 4. We numerically illustrate the results in Section 5. In Section 6, we summarize our <sup>fi</sup>ndings and conclude the paper with a brief discussion of the limitations and extensions of our models. We relegate the proofs and long derivations to the Appendix.

## 2. Model components

In turn, we discuss the tradeoffs in a con<sup>fi</sup>guration decision, the alarm investigation process, queue and the associated costs. Our models are based on the abstractions of the real world problem where these components are incorporated, which can restrict the application of our forthcoming results. Despite this, cost components, their tradeoffs, the general idea of coordinating con<sup>fi</sup>guration, capacity and response can guide the decisions made in practice.

## 2.1. Alarm detection

Using an IDS to classify an event can potentially result in two types of errors: i) false alarm: Classifying a benign event as intrusive, and ii) misdetection: classifying an intrusive event as benign. To evaluate the performance of a diagnostic device such as the IDS, two related probabilities (percentages) are typically used: the number of alarms per benign and intrusive events. Let these probabilities be $\phi$ and $\phi _ { D } ,$ which are related by a curve Ω: ϕ =Ω(ϕ). Ω is called the receiver operating characteristic curve (ROC). It has been used in evaluating the performance of the IDS [3,14,15,17,27]. Tan et al. [23] discuss how to create an ROC curve from a decision-tree-based system. Ω is an increasing, concave curve with Ω(0)=0 and $\Omega ( 1 ) = 1 ;$ see Fig. 1. Ideally, one would like to keep ϕ small while increasing Ω(ϕ). This is not possible because ϕ and Ω(ϕ) increase or decrease together because Ω is an increasing curve.

## 2.2. Alarm investigation

Since benign events largely outnumber malicious events, false alarms are prevalent in the IDS [3]. Security analysts are used to inspect alarm logs and investigate alarms in order to identify malicious events. Alarm investigation is often a time-consuming process, and the presence of many false alarms increases the workload of security analysts, whose capacity is limited.

Human security analysts are typically hard to train and recruit in the short term. Thus, we assume that the alarm investigation capacity, represented by the number n of security analysts, stays constant over the time horizon covered by our model. The time spent by security analysts on investigating alarms and verifying threats is considerably higher in comparison with the time the IDS spends analyzing the event (which is an automated process). Therefore, the latter time is ignored.

The security analysts investigate all the alarms generated by an IDS<sup>1</sup> but in a FIFO (<sup>fi</sup>rst-in-<sup>fi</sup>rst-out) manner. We let $C _ { s }$ be the average cost of investigating a single alarm. After the investigation, a security analyst can determine with certainty if an event is benign or intrusive without any errors. Due to a lack of investigation capacity, investigation of some alarms are delayed until the security analysts become available.

We visualize a queue of alarms waiting to be investigated by the security analysts. An alarm is removed from the queue when its investigation is complete. The time an alarm spends in the queue is important and is called the time in the (investigation) system. During this time, a passive IDS logs the attack and alerts the security analyst while an active IDS blocks the event. In the former case, the time in the system increases vulnerability of the information assets to the intrusive events. We let $C _ { d }$ be the average damage cost per unit time an intrusive event can induce until its investigation; see the security decision tree and the possible outcomes in Fig. 2. In the latter case of an active IDS, the time in the system increases the processing time of the benign events. Then, a blocked benign event costs $C _ { f }$ per unit time during its investigation; see Fig. 3. This cost can be considered as a penalty for delaying the service to a benign event that raised the alarm. Note that the time spent in the system by a benign (intrusive) event in the passive (active) response does not give rise to any.

## 2.3. Alarm Queue Formulation

Given a speci<sup>fi</sup>c networking traf<sup>fi</sup>c load and time interval, we model benign and intrusive event arrivals by independent Poisson processes with rates $\lambda _ { B }$ and $\lambda _ { I } .$ This formulation is equivalent to saying that the total arrival rate is $\lambda _ { B } + \lambda _ { I }$ and that the percentage of benign arrivals is $\lambda _ { B } / ( \lambda _ { B } + \lambda _ { I } )$ . Under this framework, the alarm arrival process to the security analysts is also Poisson with rate $\phi \lambda _ { B } + \Omega ( \phi ) \lambda _ { I } .$ The remaining events, whose rate is $( 1 - \phi ) \lambda _ { B } + ( 1 - \Omega ( \phi ) ) \lambda _ { I } ,$ , are judged to be benign by the IDS and thus are not investigated.

We assume that the mean and variance of the investigation time of an alarm can be estimated. Let $\nu _ { B }$ and ν respectively denote random variables for the investigation time of a benign and an intrusive event. We further suppose that n security analysts can effectively pool their capacity to work as a team, which then can investigate a benign and an intrusive alarm in $\nu _ { B } / n$ and $\nu _ { I } / n$ time. Such a pooling simpli<sup>fi</sup>es our model and the queue in front of the security analysts becomes an M/G/1 queue with the arrival rate of $\lambda ( \phi ) { : = } \phi \lambda _ { B } + \Omega ( \phi ) \lambda _ { I }$ and the service time of ν /n or ν /n depending on whether an alarm under investigation is benign or intrusive. Note that the false alarm rate ϕ regulates the arrivals to the alarm queue while the investigation capacity n regulates the departures from the queue. ϕ and n indeed will become the decision variables in our optimization models. Choice of ϕ is termed as the con<sup>fi</sup>guration of the IDS while n deals with the investigation capacity. Important notations are listed in Table 1.

We assume that an intrusive event that is not detected by the IDS causes some damage to the information assets, which requires expenses of A to repair. When the system is under repair, the alarm queue is frozen; i.e., no alarms arrive at or depart from the queue. While the system is down, the events that would have used the system are redirected to other systems. A cost of redirecting (or denial of service) to such events can be included in the repair cost A. Furthermore, alarms in the queue would not be investigated since all of the investigation resources would be used to <sup>fi</sup>x the problem. Thus, no alarms depart from the queue. Since the queue is frozen and redirecting costs are included in A, without loss of generality, we can take the repairs to be instantaneous. It is also important to note that A and $C _ { d }$ are related in a way damage cost $C _ { d }$ over time cannot be larger A.

We can interpret $C _ { d } , ~ C _ { f } , ~ C _ { s }$ and A as average values. Typically, common IT security risk assessment process requires the estimation of cost parameters. Although this paper does not deal with the estimation of the parameters for a speci<sup>fi</sup>c <sup>fi</sup>rm per se, we concede that the estimation is important, and sometimes challenging; yet some of our structural results are independent of the speci<sup>fi</sup>c values of the costs.

## 2.4. Cost components

Both active and passive responses incur costs proportional to the time spent in the system by an arbitrary alarm. Let this time be denoted by $W ( \phi , n )$ . The expected cost of delaying a benign event in the investigation queueing system in the active response is $\mathbb { E } ( W ( \Phi , n ) ) C _ { f }$ . Multiplying this by the arrival rate $\phi \lambda _ { B }$ of the benign events to the investigation system, we obtain the long run average (per time) cost of delaying benign events:

$$
C _ {f} \lambda_ {B} \phi \mathbb {E} (W (\phi , n)).\tag{1}
$$

For the passive response, a similar deduction leads us to the long run average damage cost caused by alarms while they are in the investigation system:

$$
C _ {d} \lambda_ {I} \Omega (\phi) \mathbb {E} (W (\phi , n)).\tag{2}
$$

We remark that these costs can also be interpreted as the costs incurring per unit time once the queue reaches the steady state.

In both active and passive responses, undetected intrusions lead to long run average damage costs

$$
A \lambda_ {I} (1 - \Omega (\phi)).\tag{3}
$$

Moreover, the cost of security personnel (investigation capacity) incurred per time would be the same in both responses, i.e.,

$$
C _ {s} n.\tag{4}
$$

All of the costs in Eqs. (1)–(4) are incurred per time. Note that the personnel and undetected intrusion costs are the same under both responses. On the other hand, active response has delay costs while the passive response has damage costs caused by the alarms in the investigation system; see Figs. 2 and 3. The total cost for the active response is the sum of the costs in Eqs. (1), (3) and (4) whereas the total cost for the passive response is the sum of Eqs. (2), (3) and (4).

For the costs in Eqs. (1)–(2), we need to explicitly obtain the expected time $\mathbb { E } ( W ( \boldsymbol { \Phi } , n ) )$ spent in the investigation system, which depends on the arrival/service patterns to/in the investigation queue. Depending on the probabilistic assumptions about these patterns $\mathbb { E } ( W ( \boldsymbol { \Phi } , n ) )$ can be complicated to obtain — sometimes simulation may be the only viable approach.

$$
\mathbb {E} (W (\phi , n)) = \frac {\lambda (\phi) \mathbb {E} (\nu^ {2} (\phi , n))}{2 (1 - \lambda (\phi) \mathbb {E} (\nu (\phi , n))} + \mathbb {E} (\nu (\phi , n)).\tag{5}
$$

where $\nu ( \phi , n )$ is the investigation time of an alarm. The derivation of the <sup>fi</sup>rst and second moment of this random variable is relegated to the Appendix.

## 3. The con<sup>fi</sup>guration and capacity optimization model

A successful implementation of an intrusion detection process relies on the optimal choices of the IDS con<sup>fi</sup>guration and the investigation capacity. We consider setting up a single IDS to respond either actively or passively. Thus, the response type is not switched from active to passive or vice versa. Similar to the previous literature [7,9,25], we use the expected costs as measures of performance, and we seek optimality with respect to the cost objectives.

The IDS event classi<sup>fi</sup>cation mechanism is the same with the active or passive response, but the resulting total cost TC is different. As indicated in Eqs. (1)–(4), the total costs including delay and damage costs arise the mode of response, the damage cost from undetected intrusions and the investigation capacity costs. Using subscript A (P) to represent the active (passive) response, the total costs respectively for the active and the passive response are

$$
T C _ {A} (\phi , n) = C _ {f} \lambda_ {B} \phi \mathbb {E} (W (\phi , n)) + A \lambda_ {I} (1 - \Omega (\phi)) + C _ {s} n,\tag{6}
$$

$$
T C _ {\mathrm{p}} (\phi , n) = C _ {d} \lambda_ {I} \Omega (\phi) \mathbb {E} (W (\phi , n)) + A \lambda_ {I} (1 - \Omega (\phi)) + C _ {s} n.\tag{7}
$$

With these formulas, we can evaluate the total costs. But the minimization of the total costs is more challenging.

Previous studies on minimizing the total cost with the static model (e.g., [7,25]) have

$$
T C _ {S} (\phi) = C _ {f} p _ {B} \phi + A p _ {I} (1 - \Omega (\phi)),\tag{8}
$$

where $p _ { B } { = } \lambda _ { B } / ( \lambda _ { I } { + } \lambda _ { B } )$ and $p _ { I } { = } \lambda _ { I } / ( \lambda _ { I } + \lambda _ { B } )$ are the probability of a benign event and probability of a malicious event, and subscript S denotes the static case. Note that in the static model, alarms are assumed to be investigated immediately and $C _ { f }$ has the interpretation of investigation cost per event. Furthermore, the issues of investigation capacity and response options were not considered in the static model. To optimally run the intrusion detection process, the coordination of the investigation capacity, response options and false alarm rate is important. This paper seeks to achieve such a coordination.

Judging from Eqs. (6) and (7), the choice of optimal ϕ in our models is less straightforward than the choice of optimal ϕ in the static model of $\operatorname { E q . } \left( 8 \right)$ . To obtain our analytical results, we assume that the benign and intrusive event investigation times are exponentially distributed. In many practical cases the number of benign events would be very large with respect to the number of intrusive events. We call this case RElatively Negligible Intrusives (ReNI). The quality of ReNI approximation and its effect on the optimal solution will be investigated in the numerical experiments section.

With exponential service time and ReNI approximation, the investigation queueing process becomes an M/M/1 queue with arrival and service rates λ(ϕ) and nμ. Thus, the expected waiting time expression becomes considerably simpler than the expression in Eq. (5):

$$
\mathbb {E} (W (\phi , n)) = \frac {1}{n \mu - \lambda (\phi)}.\tag{9}
$$

See Appendix for the derivation. In order to keep the queue length <sup>fi</sup>nite, we require a constraint: nμNλ(ϕ).

While in practice n is often used to determine the investigation capacity, for convenience in derivation, we de<sup>fi</sup>ne slack capacity s in terms of n: $s { : = n \mu - \lambda ( \phi ) } = n \mu - \phi \lambda _ { B } - \Omega ( \phi ) \lambda _ { I } .$ . The investigation queueing process is stable if $\mu n { > } \lambda ( \phi )$ , so we require $s { > } 0 .$ The slack s increases with n, but unlike n, it depends also on the con<sup>fi</sup>guration level ϕ. In terms of the new decision variable $s ,$ the costs (Eqs. (6) and (7)) become

$$
T C _ {A} (\phi , s) = \frac {\phi \lambda_ {B}}{s} C _ {f} + (1 - \Omega (\phi)) \lambda_ {I} A + \frac {(s + \phi \lambda_ {B} + \Omega (\phi) \lambda_ {I})}{\mu} C _ {s},\tag{10}
$$

$$
T C _ {P} (\phi , s) = \frac {\Omega (\phi) \lambda_ {I}}{s} C _ {d} + (1 - \Omega (\phi)) \lambda_ {I} A + \frac {(s + \phi \lambda_ {B} + \Omega (\phi) \lambda_ {I})}{\mu} C _ {s}.\tag{11}
$$

Without the loss of generality, we can argue for $A \geq C _ { s } / \mu .$ Otherwise, the second and the third terms in the total costs can be combined and the multiplier of $\Omega ( \phi )$ turns out to be positive. That is, the total costs increase in ϕ so the optimal value of the false alarm rate would be zero in both active and the passive response. In other words, the use of IDS can be justi<sup>fi</sup>ed only when $A \geq C _ { s } / \mu$ . With Eqs. (10) and (11), we <sup>fi</sup>rst study a case where the investigation capacity is <sup>fi</sup>xed and thus reduces the problem to a con<sup>fi</sup>guration problem. The optimal response approach can also be clearly identi<sup>fi</sup>ed.

## 3.1. Fixed investigation capacity

When we employ the same investigation capacity in active and passive response, total costs are the same except for the <sup>fi</sup>rst terms on the right-hand sides of Eqs. (10)–(11). These terms represent the delay and the damage costs incurred for the alarms in the investigation queueing process. We observe that the total costs are the same when these two terms are equated, i.e.,

$$
\frac {\phi}{\Omega (\phi)} = \frac {\lambda_ {I} C _ {d}}{\lambda_ {B} C _ {f}}.
$$

Since the right-hand side above is made of only problem parameters, we can de<sup>fi</sup>ne a new parameter α,

$$
\alpha := \frac {\lambda_ {I} C _ {d}}{\lambda_ {B} C _ {f}}.\tag{12}
$$

The ratio α is the ratio of the accumulation rate of the damage cost to the accumulation rate of the delay cost if IDS alarms for all the events.

Since Ω(ϕ) is an increasing concave function, it is easy to see that $\phi / \Omega ( \phi )$ has a nonnegative derivative over $0 \leq \phi \leq 1 ;$ ; it increases from $1 / \Omega ^ { \prime } ( 0 )$ to 1, where prime (′) denotes the derivative. Therefore, if there is a ϕ solving $\phi / \Omega ( \phi ) = \alpha$ it is unique. We use $\phi ^ { C }$ to denote the false alarm rate satisfying $\phi ^ { C } / \Omega ( \phi ^ { C } ) = \alpha .$ When α is smaller than $1 / \Omega ^ { \prime }$ (0) or greater than 1, no value of the false alarm rate ϕ can achieve $T C _ { A }$ $( \phi , n ) = T C _ { P } ( \phi , n )$ for any investigation capacity n. If αN1 (or αb $1 / \Omega ^ { \prime }$ (0)), the active (or passive) response is optimal and most of the ensuing discussion is not relevant. For 1/Ω′(0)≤α≤1, active response would yield lower costs for $\phi \le \phi ^ { C }$ . Hence, the choice between an active or a passive response entirely depends on the false alarm rate for a <sup>fi</sup>xed investigation capacity. We also illustrate that active response is preferred when the <sup>fi</sup>rm faces large damage from attacks, and passive response is preferred when the cost arises from the delay of service to the benign events is large.

## 4. Flexible investigation capacity

When investigation capacity is made <sup>fl</sup>exible, the <sup>fi</sup>rm has the option to choose the optimal investigation resources. The con<sup>fi</sup>guration and capacity optimization model with the generic cost function TC is

$$
\begin{array}{c} \text {Configuration and capacity} \\ \text {optimization model:} \end{array} \quad \begin{array}{c} \min _ {0 \leq \phi \leq 1} T C (\phi , s). \\ s \geq 0 \end{array}
$$

When the generic cost function TC is replaced by $T C _ { A }$ or $T { \cal C } _ { P } ,$ we obtain the optimization models for the active and passive responses. Except for the time spent in the investigation system, all the other terms in the total costs are separable by ϕ and s. This connection between the con<sup>fi</sup>guration ϕ and the slack s makes the optimization models nontrivial.

We use sequential optimization to <sup>fi</sup>nd optimal ϕ and s; <sup>fi</sup>rst we optimize $T C ( \phi , s )$ with respect to s, then with respect to ϕ. Formally,

$$
\min _ {\phi , s} T C (\phi , s) = \min _ {\phi} \left\{\min _ {s} T C (\phi , s) \right\} = \min _ {\phi} T C (\phi , *),\tag{13}
$$

where $T C ( \phi , \ ^ { * } )$ denotes the minimum cost obtained at a given con<sup>fi</sup>guration ϕ and the corresponding optimal slack capacity. By using sequential optimization, we do not sacri<sup>fi</sup>ce from the optimality as evidenced by the equalities in Eq. (13). We <sup>fi</sup>rst consider the case where the <sup>fi</sup>rm has to <sup>fi</sup>x the IDS con<sup>fi</sup>guration. This arises when the rule-sets are impossible or very dif<sup>fi</sup>cult to recon<sup>fi</sup>gure. Moreover, recon<sup>fi</sup>guration can be a time-consuming process which involves long analysis sessions [8][p.212].

## 4.1. Fixed IDS configuration

Given that ϕ is <sup>fi</sup>xed, the convexity of the cost is important while minimizing. By looking at the total costs in Eqs. (10) and (11), and taking their derivative with respect to slack capacity, we arrive at the next result.

Theorem 1. Both $T C _ { A } ( \phi , s )$ and $T C _ { P } ( \phi , s )$ are strictly convex in s for every fixed ϕ. Moreover, the optimal slack capacities for the active and passive responses are given by

$$
s _ {A} ^ {*} (\phi) = \left(\frac {\mu \lambda_ {B} C _ {f}}{C _ {s}}\right) ^ {1 / 2} \phi^ {1 / 2},\tag{14}
$$

$$
s _ {P} ^ {*} (\phi) = \left(\frac {\mu \lambda_ {I} C _ {d}}{C _ {s}}\right) ^ {1 / 2} \Omega (\phi) ^ {1 / 2}.\tag{15}
$$

From Eq. (14), an increase in benign traf<sup>fi</sup>c, the false alarm rate or waiting costs increase the slack capacity in the active response. From Eq. (15), a rise in intrusive traf<sup>fi</sup>c, detection rate and the damage cost increases the slack in the passive response. In essence, we deploy more investigation capacity in active response when the IDS is prone to classify benign events as malicious and the associated cost is higher. In passive response, if there are more intrusive events undetected and the consequent damage cost is higher, more investigation capacity is needed. In both active and passive responses, the security analyst costs reduce the slack capacity. Note that optimal slack values are automatically both positive so the waiting times in the investigation queueing process remains <sup>fi</sup>nite.

For the ratio of the optimal slacks, we have

$$
\frac {s _ {P} ^ {*} (\phi)}{s _ {A} ^ {*} (\phi)} = \left(\frac {\Omega (\phi) \lambda_ {I} C _ {d}}{\phi \lambda_ {B} C _ {f}}\right) ^ {1 / 2} = \left(\frac {\Omega (\phi)}{\phi} \alpha\right) ^ {1 / 2}.\tag{16}
$$

Namely, the ratio of the optimal capacity slack in the passive response to that in the active response is equal to the square root of the ratio of the rate the damage cost accumulates in the passive response to the rate delay cost accumulates in the active response.

From Eq. (16), the ratio of the slacks cannot be said to be smaller or larger than 1. To make such a statement, we de<sup>fi</sup>ne the slacks $s _ { O }$ and s under optimal response and non-optimal response. When $\phi \geq \phi ^ { C }$ , the optimal response is passive response so $s _ { O } ^ { * } ( \bar { \phi } ) { = } s _ { P } ^ { * } ( \phi )$ and $s _ { N } ^ { * } ( \phi ) =$ $s _ { A } ^ { * } ( \phi )$ . On the other hand, when $\phi { \le } \phi ^ { C } ,$ the optimal response is active response so $s _ { O } ^ { * } ( \phi ) = s _ { A } ^ { * } ( \phi )$ and $s _ { N } ^ { * } ( \phi ) = s _ { P } ^ { * } ( \phi )$ . Then, we have the next lemma.

Lemma 1. The optimal slack under optimal response is less than the optimal slack under non-optimal response, i.e., ${ s } _ { O } ^ { \bar { * } } ( \phi ) { \leq } { s } _ { N } ^ { * } ( \phi )$ for every fixed ϕ.

This lemma says that the optimal slack is less under the optimal response than under the non-optimal response for any given con<sup>fi</sup>guration level ϕ. Since n is increasing monotonously as s does so, the optimal investigation capacity under the optimal response would be less. It is interesting that we can make this statement without specifying ϕ or the response approach.

We can eliminate the slacks from the total costs by substituting the optimal slacks in Eqs. (14) and (15) into the respective cost functions in Eqs. (10) and (11):

$$
T C _ {A} (\phi , *) = 2 \left(\frac {\phi \lambda_ {B} C _ {f} C _ {s}}{\mu}\right) ^ {1 / 2} + (1 - \Omega (\phi)) \lambda_ {I} A + \frac {(\phi \lambda_ {B} + \Omega (\phi) \lambda_ {I})}{\mu} C _ {s},\tag{17}
$$

$$
T C _ {P} (\phi , *) = 2 \left(\frac {\Omega (\phi) \lambda_ {I} C _ {d} C _ {s}}{\mu}\right) ^ {1 / 2} + (1 - \Omega (\phi)) \lambda_ {I} A + \frac {(\phi \lambda_ {B} + \Omega (\phi) \lambda_ {I})}{\mu} C _ {s},\tag{18}
$$

where the star “\*” indicates that the optimal value is used for the slack capacity.

Previously we compared the active response cost $T C _ { A } ( \phi , s )$ and the passive response cost $T C _ { P } ( \phi , s )$ when the capacity was <sup>fi</sup>xed at the same level in both active and passive capacity. Now we compare them when the slack capacity is chosen to be optimal in both responses. To compare the two response costs, we examine when the two responses yield the same costs. We establish that there exists a unique threshold false alarm rate, at which the two responses result in the same cost. Surprisingly this false alarm rate is $\phi ^ { C }$ . The threshold false alarm rate $\phi ^ { C }$ increases with the intrusive traf<sup>fi</sup>c and damage cost, and decreases with the benign traf<sup>fi</sup>c and waiting cost. Our results are listed in the next lemma.

Lemma 2. i) Active and passive costs are equal when each is computed at their respective optimal slack capacity and $\bar { \phi } = \phi ^ { C } .$ . For $\phi { \le } \phi ^ { C } ( o r \phi { \ge } \phi ^ { C } )$ active response is less (or more) costlier than the passive response. ii) The threshold false alarm rate $\phi ^ { C }$ increases with the distinction power of the IDS and $( \lambda _ { I } C _ { d } ) / ( \lambda _ { B } C _ { f } )$

The implication of Lemma 2.i is important; the same value of $\phi ^ { C }$ solves $T C _ { A } ( \phi , \mathrm { \scriptsize ~ ^ { * } } ) - T C _ { P } ( \phi , \mathrm { \scriptsize ~ ^ { * } } ) = 0$ and $T C _ { A } ( \phi , s ) - T C _ { P } ( \phi , s ) = 0$ for any <sup>fi</sup>xed s. Thus, the threshold value $\phi ^ { C }$ that governs the choice between the active and passive response is the same whether the slack capacity is kept at a given suboptimal level or it is optimized. Moreover, Lemma 2.ii says that, between two IDSs con<sup>fi</sup>gured at the same level, the one with greater ability to distinguish between a benign and an intrusive event is more likely to be used in the active mode. In other words, if the active mode is optimal for an IDS, it also optimal for another, improved IDS with higher distinction power.

## 6. Concluding remarks

Previous studies have assumed that alarms generated by the IDS are immediately investigated. This paper removes this assumption by using queuing theory to incorporate delays into the investigation process. By doing so, it can explicitly capture the effect of alarm investigation capacity on the delays. Moreover, it studies the total costs under both active and passive responses. Eventually, it minimizes the total costs to <sup>fi</sup>nd the optimal con<sup>fi</sup>guration, capacity and response. Typically, a <sup>fi</sup>rm would <sup>fi</sup>rst evaluate the factors related to security risks through risks assessments. This knowledge will then allow proper technology con<sup>fi</sup>guration and deployment in the risk mitigation stage. The insights gained from this paper contribute to the managing of IDS deployment.

\begin{array}{c} P \binom {\text { An   event   is   benign }} {\text { but   raises   an   alarm }} = P \binom {\text { An   event }} {\text { is   benign }} P \binom {\text { It   raises } \mid \text { An   event }} {\text { an   alarm } \mid \text { is   benign }} \\ = \frac {\lambda_ {B}}{\lambda_ {B} + \lambda_ {I}} \phi . \end{array}
$$

Similarly, the probability of an intrusive event arrival is

$$
P \binom {\text { An   event   is   intrusive }} {\text { and   raises   an   alarm }} = \frac {\lambda_ {I}}{\lambda_ {B} + \lambda_ {I}} \Omega (\phi).
$$

We obtain the conditional probability that an event is benign given that it raises an alarm, i.e.,

$$
\begin{array}{c} P \left( \begin{array}{c c} \text {It is} & \text {Event raises} \\ \text {benign} & \text {an alarm} \end{array} \right) = \frac {\frac {\lambda_ {B}}{\lambda_ {B} + \lambda_ {I}} \phi}{\frac {\lambda_ {B}}{\lambda_ {B} + \lambda_ {I}} \phi + \frac {\lambda_ {I}}{\lambda_ {B} + \lambda_ {I}} \Omega (\phi)} \\ = \frac {\phi}{\phi + (\lambda_ {I} / \lambda_ {B}) \Omega (\phi)}. \end{array}\tag{A - 1}
$$

where the <sup>fi</sup>rst equality is due to Bayes theorem. We can also obtain

$$
\begin{array}{c} P \left( \begin{array}{c c} \text {It is} & \text {Event raises} \\ \text {intrusive} & \text {an alarm} \end{array} \right) = \frac {\frac {\lambda_ {I}}{\lambda_ {B} + \lambda_ {I}} \Omega (\phi)}{\frac {\lambda_ {B}}{\lambda_ {B} + \lambda_ {I}} \phi + \frac {\lambda_ {I}}{\lambda_ {B} + \lambda_ {I}} \Omega (\phi)} \\ = \frac {\Omega (\phi)}{(\lambda_ {B} / \lambda_ {I}) \phi + \Omega (\phi)}. \end{array}\tag{A - 2}
$$

Let ν(ϕ, n) be the investigation time of an alarm event when the IDS is con<sup>fi</sup>gured at ϕ and the investigation capacity is n. Note that $\nu ( \phi , n )$ is not for an arbitrary event but for an event that raises an alarm. We can obtain the <sup>fi</sup>rst moment of this random variable by conditioning:

$$
\begin{array}{l} \mathbb {E} (\nu (\phi , n)) = P \left( \begin{array}{c c} \text { It   is } & \text { Event   raises } \\ \text { benign } & \text { an   alarm } \end{array} \right) \mathbb {E} \left(\nu (n) \bigg | \begin{array}{c} \text { Event   is   benign   but } \\ \text { it   raises   an   alarm } \end{array} \right) \\ + P \left( \begin{array}{c c} \text { It   is } & \text { Event   raises } \\ \text { intrusive } & \text { an   alarm } \end{array} \right) \\ \mathbb {E} \left(\nu (n) \bigg | \begin{array}{c} \text { Event   is   intrusive   and } \\ \text { it   raises   an   alarm } \end{array} \right) \\ = \frac {\phi}{\phi + (\lambda_ {I} / \lambda_ {B}) \Omega (\phi)} \frac {\mathbb {E} (\nu_ {B})}{n} + \frac {\Omega (\phi)}{(\lambda_ {B} / \lambda_ {I}) \phi + \Omega (\phi)} \frac {\mathbb {E} (\nu_ {I})}{n} \end{array}\tag{A - 3}
$$

where the second equality follows from Eqs. (A-3)–(A-6) and the expected investigation times for benign and intrusive events are $\mathbb { E } ( \nu _ { B } ) / n$ and $\mathbb { E } ( \nu _ { I } ) / n$ with investigation capacity of n. The second moment follows similarly

$$
\mathbb {E} (\nu^ {2} (\phi , n)) = \frac {\phi}{\phi + (\lambda_ {I} / \lambda_ {B}) \Omega (\phi)} \frac {\mathbb {E} (\nu_ {B} ^ {2})}{n ^ {2}} + \frac {\Omega (\phi)}{(\lambda_ {B} / \lambda_ {I}) \phi + \Omega (\phi)} \frac {\mathbb {E} (\nu_ {I} ^ {2})}{n ^ {2}}. (A - 4)
$$

We already know that the arrival rate to the investigation queue is $\lambda ( \phi ) = \phi \lambda _ { B } + \Omega ( \phi ) \lambda _ { I } ,$ . The service times are de<sup>fi</sup>ned by the <sup>fi</sup>rst and the second moments given in Eqs. $( A { - } 3 ) { - } ( \mathsf { A } { - } 4 )$ . Note that the arrival rate depends only on ϕ whereas the service times depend on both ϕ and n. Since the investigation queueing process is $\mathsf { M } / \mathsf { G } / 1$ , the expected waiting time can be expressed by the Pollaczek–Khintchine formula [20]:

$$
\mathbb {E} (W (\phi , n)) = \frac {\lambda (\phi) \mathbb {E} (\nu^ {2} (\phi , n))}{2 (1 - \lambda (\phi) \mathbb {E} (\nu (\phi , n))} + \mathbb {E} (\nu (\phi , n)).\tag{A - 5}
$$

Hence, we complete the derivation of $\mathbb { E } ( W ( \boldsymbol { \Phi } , n ) )$ .
