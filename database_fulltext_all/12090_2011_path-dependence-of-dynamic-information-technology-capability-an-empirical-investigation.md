Abst ract : Organizations seek to differentiate themselves in the marketplace by deploying information technology (IT) to develop dynamic IT capabilities and resist competitors’ attempts to imitate or improve these capabilities. While this strategy has been justified on the grounds that dynamic IT capabilities are durably heterogeneous, there does not seem to be empirical evidence supporting or refuting this assumption. This study empirically validates the assumption of durable heterogeneity of dynamic organizational IT capability (ITC) due to path dependence. We capture ITC heterogeneity by introducing a framework in which firms try to achieve ITC leadership in their industry and we propose that durable ITC heterogeneity can be attributed to path dependence, and hence, it can be tested using Heckman’s true state dependence of ITC leadership status. Using random and fixed effect dynamic logit models, we investigate true state dependence of ITC leadership on a sample of large U.S. firms. The results, which are robust to alternative sample, dependent, and control variable specifications, show that achieving ITC leadership is a true state-dependent process, suggesting durable heterogeneity of ITC due to path dependence. The study contributes to the dynamic capabilities literature and has important managerial implications. The proposed framework for conceptualizing durable resource heterogeneity due to path dependence is general and versatile, thus providing a foundation for future research on dynamic capabilities. The findings provide empirical evidence to confirm that ITC is durably heterogeneous and should be managed as a potential source of competitive advantage.

Key w ords and ph rases: dynamic organizational IT capability, dynamic random effects, fixed effects logit models, IT business value, path dependence, true state dependence.

Wh il e providing th e th eoret ic al foundat ion for information technology (IT) business value research [114, 123], the resource-based view (RBV) is built on the assumption of durable heterogeneity of resources and capabilities [58]. RBV researchers assume that firms possess different resources and capabilities, and some firms leverage these resources and capabilities to implement strategies that competitors will find costly to implement; moreover, these differences can be long lasting (durable heterogeneity) and thus a source of sustained competitive advantage [5, 8, 58, 92, 116]. Several empirical studies on IT business value hypothesize that certain IT resources and capabilities are durably heterogeneous and proceed to evaluate the competitive performance of firms possessing such IT resources and capabilities [12, 14, 39, 104]. Evidence of superior performance is used as an implicit support for the underlying assumption of durable heterogeneity due to isolating mechanisms such as causal ambiguity and path dependence [12]. However, there is a counterargument suggesting that IT has become readily available among competing firms (commoditization of IT), eroding its ability to serve as a source of competitive advantage [19, 122].

Both sides have relied either on implicit or anecdotal evidence to support their arguments [79]; however, there does not seem to be empirical evidence supporting or refuting the durable heterogeneity of IT resources and capabilities. Given the indirect relationship between IT resources and capabilities and firm value [10, 72, 114], empirical evidence is needed to confirm/refute durable heterogeneity of IT resources and capabilities. Resolving the issue is far from being a mere theoretical exercise. If IT resources and capabilities are readily available, they should be managed as “commodity inputs” [79, p. 17], whereas if IT resources and capabilities are durably heterogeneous, they should be managed as potential sources of sustained competitive advantage [12, 14, 39, 104].

Motivated by this debate, the main focus of this study is an examination of the role of path dependence as an isolating mechanism that leads to durable resource heterogeneity of dynamic organizational IT capability (ITC). We define ITC as a firm’s ability to integrate, build, and reconfigure IT with organizational and managerial processes in order to align with a rapidly changing competitive environment. Examining the durable heterogeneity of ITC implies that the capability is observable and easy to measure [8]. However, if ITC is durably heterogeneous, it is by definition unobservable [50]. We can bypass this problem by concentrating on one of the ITC attributes (e.g., path dependence) [8, 50]. In this study we develop a conceptual framework that maps the heterogeneity of ITC to an annual industry competition for ITC leadership. Using a firm’s ability to achieve ITC leadership as a proxy for ITC heterogeneity, we propose that temporary and durable ITC heterogeneity can be attributed to path dependence, and hence, it can be tested using Heckman’s [56, 57] true state dependence of ITC leadership status.

Using a random and fixed effect dynamic logit model, we investigate the true state dependence in ITC leadership while controlling for spurious dependence due to unobserved firm characteristics. Our empirical analysis, based on a sample of large U.S. firms during the period 1997–2004, shows that achieving ITC leadership is a persistent (true state-dependent) process. We find that a firm’s prior ITC leadership experience has a positive and significant effect on its ability to achieve ITC leadership status in the current period, suggesting temporary ITC heterogeneity. In addition, a firm’s prior ability to sustain ITC leadership over several consecutive periods (systematic ITC leadership) increases the probability that this firm will maintain its status in the current period, indicating durable ITC heterogeneity. The results are robust to alternative sample, dependent, and control variable specifications.

## Literature Review

Th e RBV and dynamic c apabil it ies perspect ive have together become the de facto framework of choice for theoretical and empirical research on IT business value [114, 123]. The premise of RBV is that firms possess different resources and capabilities (heterogeneity); some firms leverage these heterogeneous resources and capabilities to implement valuable strategies that their competitors will find costly to implement, and these differences among competing firms can be long lasting (durable heterogeneity) [5, 8, 58, 92, 116]. According to Barney, if the number of firms that possess a resource or capability “is less than the number of firms needed to generate perfect competition equilibrium in an industry” [7, pp. 163–164], the resource or capability is rare (heterogeneous) and a potential source of competitive advantage.<sup>1</sup> In addition, if competitors find it difficult to acquire, substitute, or imitate these resources (durable heterogeneity), then these firms enjoy a sustainable competitive advantage. Figure 1 provides a graphical representation of durable and nondurable heterogeneity. In Figure 1a, the initial number of firms possessing a specific resource/capability is small (heterogeneity) but it approaches the number needed to quickly generate perfectly competitive equilibrium (nondurable heterogeneity); hence, the specific resource/capability becomes a commodity [14]. In Figure 1b, the initial number of firms possessing the specific resource/capability is and remains well below the number needed to generate competitive equilibrium. It is important to distinguish between heterogeneity and durable heterogeneity because, while the latter “is concerned with sustainability of competitive advantage,” the former is a “necessary condition for any advantage” [14, p. 258].

Evidence of superior performance underlines the importance of possessing durably heterogeneous capabilities [8]. Evidence of superior performance provides implicit support for the underlying assumption of durable heterogeneity of ITCs due to isolating mechanisms such as causal ambiguity and path dependence (see Figure 2b).<sup>3</sup> However, given the indirect relationship between IT resources and capabilities and firm value [10, 72, 114], more evidence is required to confirm durable heterogeneity.

## Dynamic Organizational IT Capability

Numerous studies on IT business value research have argued and shown that integration of IT with improvements in organizational structure and business processes (complementary resources) leads to value creation (e.g., [14, 16, 17, 18, 82, 95, 99, 123]). Firms exhibiting these traits possess what Bharadwaj [12] coined an organizational IT capability: a firm’s ability to mobilize and deploy IT-based resources (i.e., flexible IT infrastructure, human IT resources, and intangible IT-enabled resources such as knowledge, synergy, and customer orientation) in combination with other resources and capabilities.

Given the dynamic nature of IT and competitive environment [14], ITCs have to evolve in order to stay aligned with increasingly turbulent and dynamic global markets [35, 51, 91, 103, 106, 111]. Bhatt and Grover [14] frame intensity of organizational learning, which involves accumulation, sharing, and application of knowledge, as a dynamic organizational capability, and argue that, since development of ITCs requires learning and experience, intensity of learning will facilitate the development of ITCs. Firms with strong dynamic capability (i.e., intensity of organizational learning) can leverage feedback cycles of experience to build stronger or reconfigured ITCs.<sup>5</sup> Thus, combining the above definition of organizational ITC [12] with the importance of renewal of organizational capabilities from the traditional notion of dynamic capabilities [110], we define dynamic organizational IT capability as a firm’s ability to integrate, build, and reconfigure IT-enabled resources concurrently with organizational and managerial processes in order to align with a rapidly changing competitive environment.

## Path Dependence

Path dependence was introduced and subsequently defined by David [36, 37] as follows: a stochastic process that converges to an invariant asymptotic distribution (i.e., converges to a unique and stable equilibrium) is a path-independent process. Furthermore, a stochastic process whose asymptotic distribution evolves as a consequence or functions of the processes’ own history is a path-dependent process. In a path-dependent process, the prevailing probabilities of transition from one state to another are functions of the past transient states that the process has visited [37]. In business value of IT literature, path dependence has been seen as one of the isolation mechanisms that prevents commoditization of IT resources and capabilities, that is, it prevents convergence to a perfectly competitive equilibrium.<sup>6</sup> Primary reasons behind path dependence of IT resources and capabilities include (1) asset accumulation, that is, the role of prior firm-specific IT investments [13, 14, 93], and (2) organizational learning, that is, the fact that superior knowledge builds on prior knowledge and experience [14, 91, 93].

The focus of this study is an examination of the durable heterogeneity of ITC due to path dependence. If ITC is not path dependent, prior events related to a firm’s acquisition and development of ITC do not matter. The end result is always the same; a unique and stable equilibrium is always reached when almost all firms in the industry possess the same ITC. Thus, ceteris paribus, lack of path dependence means that ITC is nondurably heterogeneous (as in Figure 1a). However, if ITC is path dependent, barriers to imitation are high, and the number of firms possessing ITC will remain well below the level needed to generate a perfectly competitive equilibrium. Thus, ceteris paribus, path dependence means that ITC is durably heterogeneous (as in Figure 1b).

## ITC Leaders and Their Strategies

To capture the durable heterogeneity in our conceptualization of ITC, we introduce, à la Powell [96], an annual distribution of industry leadership.<sup>7</sup> While the competitive benefits of ITCs have been documented [12, 14, 104], not all firms see the value of developing these capabilities or have the initial endowment needed to acquire and develop ITCs. As McFarlan and Nolan [89] explain, IT is “the name of the game” for some firms, whereas for others it is simply a low-value support activity. Thus, we assume that only a subset of the population (ITC candidate firms) has been active at picking resources and developing capabilities that could form the foundation of ITC.

Consistent with the theory of preferences [68], we assume that a group of independent experts can make binary comparisons examining candidate firms A and B to determine which one has superior ITCs, we can develop an annual ranking of all firms in a particular industry, and classify them as ITC leaders or non-ITC leaders. We introduce a variable $I T C _ { i t }$ , which takes the value of 1 $( I T C _ { _ { i t } } = 1 )$ when firm i is an ITC leader in year t, and a value of $0 ( I T C _ { i t } = 0 )$ when firm i is a non-ITC leader. Therefore, based on the annual distribution of candidate firms, we can establish temporary (one year) resource heterogeneity in terms of ITC as the characteristic of ITC leaders. However, achieving such ITC leadership once may not ensure competitive advantage in a Schumpeterian world where “firms are constantly seeking to create ‘new combinations,’ and rivals are continuously attempting to improve their competences or to imitate the competence of their most qualified competitors” [109, p. 552]. Success in such environments is possible for firms that develop a superior capacity to dynamically reposition themselves [35, 51, 110, 111]. Consistent with the idea of environmental dynamism in D’Aveni [35] and Porter [94], Helfat and Peteraf [58] explain that companies will try to reconfigure their capabilities in order to stay competitive.

While several studies examine the duration of IT-enabled competitive advantage [40, 45, 60, 78], none of them features explicit quantitative measurements of duration in months or years. One notable exception, however, is Dehning and Stratopoulos [39], who show that the duration of an IT-enabled competitive advantage is approximately five years. In addition, it has been argued that short-term (three to five years) performance variations are driven by firm-specific resources and capabilities [96]. In our study, we make the distinction between systematic and occasional ITC leaders by considering the status of a firm $( I T C _ { _ { i t } } = 1 \ \mathrm { o r } \ I T C _ { _ { i t } } = 0 )$ over periods of four consecutive years.<sup>8</sup> Concentrating on firms that have been ITC leaders at least once over a four-year period, we classify firms that take and maintain a leading ITC position in all four years as systematic ITC leaders; the rest are occasional ITC leaders. This setting allows us to establish that durable heterogeneity of ITC is a characteristic of systematic ITC leaders because they have been able to achieve and maintain ITC leadership over four consecutive years. We cannot reach a similar conclusion by observing the status of occasional ITC leaders simply because we cannot make the distinction between intention and happenstance. The group of occasional leaders may include firms that become ITC leaders only once and are unable to repeat this in subsequent years (happenstance), but it may also contain firms that choose to become ITC leaders only in certain years (intention). ## True Versus Spurious State Dependence

State dependence has been defined as the conditional probability that a firm that has experienced an event is more likely to experience the same event in the future than one that did not have such experience [56, 57]. Heckman [56] argues that we can attribute this increased probability either to true or spurious state dependence. True (structural) state dependence means that past experience changes the future behavior of a firm. It changes a firm’s preferences, choices, and constraints in a way that affects the probability that the firm will experience the same event in the future.<sup>9</sup> For example, it has been argued that technologically innovative firms are more likely to be innovative in the future because success breeds success [77], technological innovation involves dynamic increasing returns [76, 87], and because the existence of sunk costs in research and development (R&D) investments leads to such an effect [107].

But spurious state dependence means that firms may differ in certain observable and unobservable characteristics that influence the probability that they will experience the event, but will not be influenced by that experience [56]. For example, technological innovation may be linked to observable characteristics such as firm size, competitive environment, or financial resources, as well as unobservable characteristics such as technological opportunities or risk attitudes. If these unobserved determinants are correlated over time but are not appropriately controlled, past technological innovation may appear to affect future innovation merely because it picks up the effect of these persistent unobservable characteristics.

In the context of our research, state dependence is the conditional probability that a firm that has been an ITC leader (systematic ITC leader) is more likely to be an ITC leader (systematic ITC leader) in the future than a non-ITC leader (occasional ITC leader). In analyzing the dynamics of a firm’s ITC leadership status, we are interested in whether ITC leadership is state dependent, and if state dependence in ITC leadership is observed, what drives this phenomenon. We argue that ITC leadership is a true state-dependent process. In the following section we summarize arguments from RBV and IT business value literature supporting the position that ITC leadership is a true state-dependent process.

## Research Hypotheses

ITC heterogeneity implies that competitors cannot readily acquire resources in factor markets or develop them internally [4, 41]. This is hindered by various isolating mechanisms (barriers) such as causal ambiguity, time compression diseconomies, and path dependence. Path dependence as an isolating mechanism explaining heterogeneity of capabilities has been argued by RBV and IT business value researchers. In the RBV, the work of Helfat and Peteraf [58] on the capability life cycle provides a good example. Helfat and Peteraf argue that capability evolution is a “strongly path-dependent process”; that is, it is dependent on prior knowledge/experience, initial path chosen, success of initial choices, and choices made under an environment of bounded rationality. They conclude that “[t]he entire capability lifecycle . . . provides an explanation for the emergence and sustained heterogeneity of capabilities” [58, p. 1009].

A similar position is echoed in the IS literature. In their extensive review of the IT business value research, Piccoli and Ives [93] conclude that IT-dependent strategic initiatives are path dependent, and this path dependence can be attributed to, among other things, the role of ITCs, resource complementarity, and prior knowledge/experience. The general argument is that firms develop a set of unique ITCs over time that succeeds in distinguishing them from (and advantaging them over) their competitors (e.g., [10, 12, 93, 103]). Duration of this advantage increases if firms can leverage/integrate complementary IT resources [9, 70, 93, 103]. Furthermore, strategic application of IT is more likely to be successful when a firm has gained knowledge/expertise over time [88]. Therefore, both RBV and IT business value literature indicate that ITC leadership is a true state-dependent process.

Our conceptualization of systematic ITC leaders is based on the view that such leadership is more than simply the sum of isolated decisions [93, 101]. Instead, it is the result of numerous reinforcing actions aimed at enhancing the integration of IT with organizational and managerial processes. It is the result of a virtuous circle, one in which firms with strong organizational learning can leverage feedback cycles of experience to build stronger or reconfigured ITCs [14]. Comparing the evolution of ITC of a bellwether, for example, Harrah’s Entertainment Inc., versus its top competitors shows that Harrah’s has not only been able to develop a superior ITC over the years but also managed to stay ahead of its competitors.<sup>10</sup> The anecdotal evidence reinforces the underlying agreement in both the RBV and IT business value literature that holds dynamic capabilities such as ITC are path dependent and thus heterogeneously distributed among competing firms, and that this heterogeneity is durable. ## Methodology

Sample Selection—Proxy for ITC Leaders

To ident ify ITC l eaders, we use the annual list of the InformationWeek 500 (IW500) from the period 1997–2004.<sup>12</sup> Since 1997, InformationWeek (IW) has been producing an annual list of the nation’s largest and most innovative users of IT. One of the IW editors described the methodology that IW used for the selection of the 500 most innovative IT users as follows:

[C]ompanies were required to fill out a qualifying questionnaire/application detailing their IT strategies, plans and practices. An InformationWeek editorial panel determined the weightings for each question/response. In addition, companies had the option to complete an essay/essays (depending on the year) on their organization’s most innovative technology initiative within the past 12 months and other topics (again, this varied by year). Completion of the essay/essays earned companies additional points. Based on the qualifying questionnaire and essay(s), companies earned a preliminary score. InformationWeek editors reviewed these scores and individual applications to determine the final rankings.<sup>13</sup>

To be included in the IW500 list, a firm must demonstrate an ability to integrate deployment of new IT such as architecture, infrastructure, business, and e-business applications with organizational and procedural changes. This initial examination of the IW500 criteria, during the sample period, suggests a satisfactory mapping between our definition of ITC leaders and the IW500 firms.<sup>14</sup> However, since the exact criteria that the IW500 selection committee uses are confidential, as an additional “reality check” we mapped observed characteristics of IW500 firms to theoretically expected characteristics of ITC leaders. The results of this crude reverse engineering approach described below provide anecdotal support, but not scientific validation, to the mapping of IW500 firms to ITC leaders.<sup>15</sup>

•	 Step 1: Characteristics of IW500 firms. According to the IW500 selection committee, IW500 firms demonstrate a “consistent pattern of technological, procedural, and organizational innovation” [67, p. 4]. Using this IW500-based definition as our source, two authors and one research assistant independently read all IW500- related articles and research reports looking for references to strategy, technology, organization, and business processes–related characteristics of IW500 firms. This search resulted in a list of 211 references to either single or multiple characteristics of IW500 firms.

•	 Step 2: Expected characteristics of ITC leaders. Using the IT business value literature that was leveraged to define ITC (e.g., [2, 14, 16, 95, 99, 123]) as our source, two of the authors identified a set of expected characteristics associated with ITC leaders: (1) IT strategy—integrating business/corporate and IT strategy; (2) IT leadership championing (by top executives) the use of IT and the role of IT executives; (3) IT management—identifying IT priorities (as reflected in the IT budget) and having a plan for analysis, development, implementation, evaluation, and monitoring; (4) maintaining an organizational culture that supports open communications, flexibility, knowledge sharing/distribution, education, and training; (5) leveraging IT to achieve value and supply chain integration; and (6) investing in needed hardware and software technologies.

•	 Step 3: Mapping of IW500 references to characteristics of ITC leaders. An independent reader with considerable IT experience and expertise, along with the two authors and a research assistant, assigned each of the 211 references to characteristics of IW500 firms from Step 1 to one or more of the characteristics of the ITC leaders from Step 2. The percentage of agreement and interrater reliability among the four readers was 87.08 percent. This score falls within the range of substantial agreement [27], thus indicating that IW500 firms seem to be a reasonable proxy for ITC leaders. See Appendix A for a representative sample of IW500 references and their mapping to expected characteristics of ITC leaders.

## Sample Selection—Proxy for Non-ITC Leaders

To identify non-ITC leaders and non-ITC candidate firms, we used Hoover’s Handbook of American Business (from 1997 to 2004) [62] to manually match IW500 firms with their top three competitors. Hoover’s compiles the profiles of major U.S. firms each year (i.e., firms with sales of \$2 billion or more). Each profile includes a list of the firm’s competitors, and this list is updated each year. On average, there are approximately 20 competitors listed for each firm.<sup>16</sup> We chose to match with up to three of the top competitors because we wanted to create a group of “candidate ITC leaders” that should be similar in size and from the same industry as the matching IW500 firms. Selecting only one competitor as in Bharadwaj [12] is too restrictive [104]; arguably, more than two firms in industry can develop ITCs. Conversely, selecting the entire industry is too general and not consistent with the argument that not all firms see the value of or are able to develop ITCs [89]. We consider our choice of the top three competitors as a logical compromise between these two extremes.

The following matching process (see Appendix B, Panel A) was repeated for each of the eight years in our sample: (1) R emove from the IW500 list non-publicly traded organizations as well as those not included in the corresponding annual issue of Hoover’s. (2) For each IW500 firm, we record all competitors listed in Hoover’s to control for industry and size. Only firms with at least \$1 billion in sales can participate in the IW500 survey [67].<sup>17</sup> (3) For IW500 firms with more than three competitors, we retain the three closest in terms of size. The matching process produced 7,680 firm-year observations (8 years).

## Control Variables

A firm’s choice regarding a particular ITC strategy is based on the expectation that this strategy may lead to superior performance. Based on recent studies of the effects of ITCs on firm performance [12, 104], we control for the effects of known factors that might be associated with ITC, such as size, prior performance, and reputation. Previous studies show that firm size (SIZE), a natural log of total assets used as a proxy, enhances a firm’s ability to sustain a competitive advantage. Large firms tend to have greater market power or positional advantage as well as superior financial and human resource endowments [15, 84, 102]. We control for the past financial performance of a firm—return of assets (ROA)—for two reasons. First, a firm’s strategic ITC choice could be a function of its past performance [104]. Second, it is likely that the selection of ITC leaders by industry experts might be influenced by the firm’s past performance [12]. A firm’s reputation might be another factor that may influence the selection of ITC leaders by industry experts. Market-to-book value (MV) has been suggested as a proxy for reputation because it captures tangible and intangible assets [102], as well as the market’s expectations of future economic returns [86]. Finally, we control for fixed industries and year effects. All financial data are from Compustat.

## Econometric Framework

We introduce the following dynamic binary choice model to test for the true state dependence of ITC leadership and systematic ITC leadership:

$$
y _ {i t} = 1 \left\{X _ {i t} ^ {\prime} \beta + \gamma y _ {i t - 1} + \alpha_ {i} + \varepsilon_ {i t} > 0 \right\},\tag{1}
$$

where $i = 1 , 2 , . . . , N$ and $t = 1 , 2 , . . . , T , 1 \{ . \}$ is an indicator function, $y _ { i t }$ is the tested leadership status of firm i in year t. In Hypothesis 1, we have that $y _ { _ { i t } } = 1$ for ITC leaders and $y _ { _ { i t } } = 0$ for non-ITC leaders. In Hypothesis 2, we have $y _ { i t } = 1$ for systematic ITC leaders and $y _ { i t } = 0$ for occasional ITC leaders. $X _ { i t }$ is a vector of exogenous observables, $y _ { i t - }$ is the status of firm i in year $t - 1 , \mathsf { \alpha } _ { i }$ captures permanent unobserved heterogeneity, and $\ \varepsilon _ { \scriptscriptstyle i t }$ is an idiosyncratic random error term.

The conditional probability that firm i will attain leadership status in year t is

$$
P \left(y _ {i t} = 1 \mid X _ {i}, \alpha_ {i}, y _ {i 0}, y _ {i 1},..., y _ {i t - 1}\right) = F \left(X _ {i t} ^ {\prime} \beta + \gamma y _ {i t - 1} + \alpha_ {i}\right),\tag{2}
$$

where $F$ is a cumulative distribution function, $X _ { _ i } = ( X _ { _ { i I } } , . . . , X _ { _ { i T } } )$ is a set of exogenous variables observed in-sample over $t = 1 , 2 , . . . , T ,$ , and $y _ { i 0 }$ denotes leadership status of firm i in year $t = 0 .$ .<sup>18</sup>

Two estimators, random effect (RE) and fixed effect (FE), of model (1) are considered in this paper. These estimators differ in terms of their treatment of the initial ITC leadership status, $y _ { i 0 } \mathrm { . }$ its relation to firm-specific unobserved permanent component, $\mathbf { \alpha } _ { \mathrm { ~ i ~ } } ^ { \mathbf { { \alpha } } }$ and the exogenous variables, $X _ { _ i }$ . We use the Wooldridge [120] dynamic binary choice model to estimate the RE model, and the Honoré and Kyriazidou [61] dynamic logit model with strictly exogenous regressors for the FE estimator. The RE estimator will be consistent and efficient if, and only if, the model is correctly specified, whereas the FE estimator is consistent independent of the initial conditions. For this reason, we use Hausman’s [52] specification test to compare the RE and FE estimates as a specification check of the validity of RE estimates. See Appendix C for a more detailed econometric discussion, as well as pros and cons of the RE and FE estimators and a description of the Hausman test in the context of our analysis.

## Results for Temporary Resource Heterogeneity Assumption (H1)

The RE estimations of the ITC leadership Equation (2) are presented in the restricted and the unrestricted models. Both models allow the ITC leadership to be dependent on lagged ITC leadership status (captures true state dependence), the initial values of ITC status, firm-specific time-varying exogenous variables, and unobserved permanent firm heterogeneity (captures spurious state dependence). To mitigate the possibility of endogeneity bias in the RE estimation due to the contemporaneous inclusion of ITC leadership and firm-specific time-varying exogenous variables, we add the timevarying exogenous variables $( S I Z E _ { i t - 1 } , R O A _ { i t - 1 } ;$ , and $M V _ { _ { i t - 1 } } )$ with a one-period lag. The unrestricted model shows that one of the time-varying exogenous covariates $( S I Z E _ { i t - 1 } )$ appears to be statistically significant. Based on the insignificant results from the Wald test for joint exclusion of $R O A _ { i t - 1 }$ and $M V _ { i t - 1 }$ , we decided to exclude them from the restricted version of the model.<sup>19</sup>

Consistent with H1, the results of restricted RE estimates indicate that ITC leadership is a state-dependent process; the parameter related to true state dependence, a firm’s prior period ITC leadership status, has a positive and highly significant $( \gamma = 0 . 3 5 9 )$ effect on the current period’s ITC leadership status. In addition, as indicated by the highly significant estimates of $\sigma _ { \eta } \left( 0 . 7 9 7 \right)$ ), we note that unobserved permanent heterogeneity accounts for a significant portion of the overall variance.<sup>20</sup> Last, there is moderate evidence of time effects and very strong evidence of industry effects (the Wald test in the restricted model; $p = 0 . 0 4 1$ and $p = 0 . 0 0 0$ , respectively).

We would like to preface the discussion of the FE results in Panel B of Tables 1 and 2 with a few limitations [61]. First, the FE estimation requires the absence of time effects; however, the RE results in Panel A (as indicated by the p-value of the Wald test for the joint insignificance of time effects in our regressions, denoted as Wald2 in Panel A of Tables 1 and 2) suggest the presence of moderate time effects in the data. Second, our RE results reveal limited within-variation in the exogenous variables of our regressions; this could hamper the identification of the FE estimates since the FE approach requires enough variations of exogenous variables over time. Comparing the RE and FE estimates of state dependence coefficient (γ) suggests that they are not overly sensitive to the exclusion of time effects in the Honoré–Kyriazidou [61] FE estimates and different combinations of the exogenous variables in the regressions. We therefore only report firm size as the time-varying exogenous variable in most of our regressions.<sup>21</sup>

Panel B of Table 1 presents Honoré and Kyriazidou’s [61] FE estimates as well as Chamberlain’s [22] FE estimates. The former includes firm size as an exogenous variable, whereas the latter does not include any exogenous variables. The significance of the firm size coefficient (0.173) suggests the irrelevance of the Chamberlain estimate and indicates a positive bias due to the neglect of other significant time-varying exogenous variables and general time effects. In general, we expect that the Chamberlain FE estimate will be less precise due to the conditional nature of these estimates (omission of firm size; a significant variable) and the requirement for four or more observations for the FE estimator. Given this expected bias in the FE estimators, a formal comparison of the RE and FE state dependence estimates (γ) using a Hausman test to examine the null hypothesis of no contrast between the RE and FE estimates is invalid. Nevertheless, we interpret closeness between the RE estimate $( \gamma = 0 . 3 5 9 )$ and the Honoré–Kyriazidou [61] FE estimate $( \gamma = 0 . 3 8 2 )$ as tentatively confirming the validity of the fully specified RE dynamic logit model.

## Results for Durable Resource Heterogeneity Assumption (H2)

Table 2 reports the estimation results for $y _ { i t } = 1$ for systematic ITC leaders versus $y _ { i t } = 0$ for occasional ITC leaders in Model 2.1, as well the comparison between $y _ { i t } = 1$ for occasional ITC leaders versus $y _ { _ { i t } } = 0$ for non-ITC leaders in Model 2.2.<sup>22</sup> Consistent with the prediction of H2, the results show that structural (true state) dependence exists within the group of systematic ITC leaders. Specifically, in Model 2.1, conditional on the observed and unobserved firm characteristics, a systematic ITC leader in t – 1 has a probability of being a systematic ITC leader in $t ,$ which is approximately 41.5 percent higher than that of an occasional ITC leader in t – 1 becoming a systematic ITC leader in t. In Model 2.2 an occasional ITC leader in t – 1 has a probability of being an occasional ITC leader in t, which is 21.3 percent higher than that of a non-ITC leader in t – 1 becoming an occasional ITC leader in t.

In addition, we note that while unobserved permanent heterogeneity accounts for a significant part of the overall variance in both models, it is relatively smaller in

Model 2.1 (0.598) than in Model 2.2 (0.672). However, a formal likelihood ratio test suggests that the quantitative improvement is not statistically significant at the 5 percent level. Finally, based on fitted likelihood values, Model 2.1 (–1,018.4) seems to have a better fit than Model 2.2 (–1,026.1).<sup>23</sup> Overall, results suggest that true state dependency is more prominent within the systematic ITC leaders.

The FE results, presented in Panel B of Table 2, confirm our RE estimation. Notice that the size variable in the Honoré–Kyriazidou [61] FE estimate in Models 2.1 and 2.2 are similar to those obtained in the respective RE models and are statistically nonsignificant. This means that when firm size is excluded, we can arrive at the Chamberlain FE estimates (0.408 in Model 2.1 and 0.207 in Model 2.2), which are relatively closer to the respective estimates from the RE model (0.415 and 0.213). In addition, we can use the Hausman test to assess the null hypothesis of no difference between the RE and FE estimates [25]. The results indicate that the null hypothesis cannot be rejected in Models 2.1 and 2.2 (p-values are 0.213 and 0.178, respectively) and validate the RE estimates. In sum, the results clearly support the true state dependence of systematic ITC leadership (H2) while controlling for spurious dependence due to unobserved heterogeneity.

## Robustness Checks

## Compustat Data Set

To assess the robustness of our results in relation to alternative sample selection processes over an extended period, we used Compustat to match each IW500 from 1997 to 2009 to its top competitor while controlling for industry and revenue effect by following a procedure suggested by Bharadwaj [12]. To avoid confusion, in the rest of our discussion we refer the original data set as Hoover’s and the new one as the Compustat data set. Table 3 summarizes the main results of our robustness checks.

The RE estimation of the ITC leadership (H1) status based on the Compustat data, reported in column 1 of Table 3, is positive, highly significant (γ = 0.341), and comparable to the estimates from the Hoover’s data set $( \gamma = 0 . 3 5 9 )$ . ## IW500 Data Set

While we tried to ensure that competitors in Hoover’s and Compustat are a reasonable proxy for firms that might have been considered by IW500, the truth is that we cannot guarantee that these firms were indeed IW500 candidates. In addition, it is likely that the IW500 committee may be biased by a firm’s prior ITC reputation. Finally, the IW500 selection process indicates that self-selection bias may be a problem. In an attempt to mitigate the issue of true candidate firms, we limited our analysis to only IW500 firms. This makes for a more homogeneous data set in the sense that all firms have chosen to participate, and appeared in the IW500 list at least once. Thus, this homogeneity might mitigate to some extent the effect of selection committee biases and self-selection bias. To compensate for the number of firms, we extended the new data set (from this point forward referred to as the IW500 data set) to 2009.<sup>24</sup> This alternative data set yielded 17,238 firm-year observations (13 years).

The RE estimated parameter for ITC leadership (H1)—reported in column 3 of Table 3—is positive $( \gamma = 0 . 2 9 5 )$ , highly significant, and comparable, though relatively lower, to the estimates from Hoover’s (0.359) and the Compustat data set (0.341). The FE results show that the FE estimate of the size variable is significant. While this renders the Hausman test invalid, we interpret the closeness between the RE estimate (0.295) and the FE estimate (0.395) as tentatively confirming the validity of the fully specified RE model. The results for H2—reported in column 4—show that a systematic ITC leader in t – 1 has a probability of being a systematic ITC leader in t, which is approximately 39.3 percent higher than that of an occasional ITC firm, and are comparable to Hoover’s (41.5 percent) and Compustat’s (41.8 percent) results. In addition, the Hausman test $( p = 0 . 1 5 7 )$ confirms the validity of the RE estimates. Overall, the robustness check for Hypotheses 1 and 2 based on only IW500 firms reinforces our previous results.

## Industry Effects

Given the strong industry effect (Wald3) in all three samples and variable specifications, we ran the analysis at the industry level.<sup>25</sup> Building on prior literature, we considered manufacturing [42], high-tech [47], and service/finance sectors [24, 42, 65, 98]. Running the analysis for each sector and with all three data sets (Hoover’s, Compustat, and IW500) confirmed our previous results for manufacturing and high-tech, but we found uninformative and unstable results for the finance/service sector. More specifically, the H1 and H2 state-dependence results (γ) of ITC leaders and systematic ITC leaders in the manufacturing sector, based on all three data sets, were positive, significant, and in the range of 0.365 to 0.375 and 0.381 to 0.383, respectively. Similarly, the H1 and H2 state-dependence results (γ) of ITC leaders and systematic ITC leaders in the high-tech sector, and for all three data sets, were positive, significant, and in the range of 0.383 to 0.392 and 0.384 to 0.402, respectively. The estimates of the coefficient measuring the effect of state dependence in the finance/service sector are uniformly small and not significant. Moreover, the signs of the explanatory variables were frequently switched when insignificant explanatory variables were excluded from the regressions. For instance, the unrestricted model for the finance sector (in parallel to that reported in Table 1) suggests that the parameter estimate of ITC leadership status of firm i in year t – 1 is 0.016 and statistically not significant. In addition, the parameter estimates of ROA and MV are also not statistically significant. When we exclude ROA and MV from the restricted model, the estimate of the parameter on the ITC leadership status of firm i in year t – 1 is 0.023 but remains statistically not significant.

## Controlling for the Effect of Operationalization of Systematic ITC

To test the generalizability of our results, we considered classifications for systematic ITC leaders based three- or five-year windows [12, 39, 96] and found comparable results when using the Hoover’s, Compustat, and IW500 data sets. For brevity, columns 5 and 6 in Table 3 show the results for H2 based on the Hoover’s data set for the three-year (five-year) classification. A systematic ITC leader in t – 1 has a probability of being a systematic ITC leader in t, which is 37.7 percent (39.5 percent) higher than that of an occasional ITC firm and comparable to results produced by the four-year specification of a systematic ITC leader in all three data sets.

From a pure probability perspective, a systematic ITC leader has a much greater chance of keeping its leadership state (1/2) than an occasional ITC leader (1/32). While there is only one possible combination {1111} that describes a systematic ITC leader, there are 16 possible combinations ({1000}, {0100}, ..., {1110}) that describe occasional ITC leaders, and only one of these combinations (a firm that firm achieved ITC leadership in the last 3 consecutive years {0111}) has a chance to become a systematic ITC leader in the following year. Does this inherent unfairness due to the operationalization drive the results in $\mathrm { H } 2 ? ^ { 2 6 }$ The ideal solution to this problem could have been to run the econometric analysis with Bayesian priors; however, this is not feasible with dynamic RE/FE logit models. Nonetheless, to account for this possible bias, we ran the following robustness checks. First, we tried a less durable operationalization for systematic ITC leaders (3 years instead of 4). This reduces the number of possibilities for occasional ITC leaders by half (8 cases instead of 16). If the results were driven by the operationalization we should have seen a significant drop in our estimate of state dependence of systematic ITC leaders. However, as we have seen (Table 3, column 5), the RE estimate $\gamma = 0 . 3 7 7 \ ( p < 0 . 0 0 1 )$ , though lower, remains comparable to the 4-year specification. Recall that the corresponding probabilities from the Hoover’s, Compustat, and IW500 data sets were 0.415, 0.418, and 0.393, respectively.

Second, instead of testing for $\mathsf { P r } ( S _ { i t } = 1 | S _ { i t - 1 } = 1 ) \geq \mathsf { P r } ( S _ { i t } = 1 | S _ { i t - 1 } = 0 )$ , we tested for Pr $( I T C _ { i t } ^ { } = 1 | S _ { i t - 1 } ^ { } = 1 ) \ge \mathrm { P r } ( I T C _ { i t } ^ { } = 1 | S _ { i t - 1 } ^ { } = 0 )$ . This variation lets us examine the probability that systematic ITC leaders could continue improving their relative position compared to occasional ITC leaders, while controlling for the probability that the results might be driven by intrinsic unfairness of our setting. The RE estimate $\gamma = 0 . 3 5 1$ $( p < 0 . 0 0 1 )$ remains in the same ranges as with previous tests and the coefficient of $S _ { i t - 1 } = 1$ is positive and significant $( 0 . 1 5 5 , p < 0 . 0 0 1 )$ . Thus, the results indicate that systematic ITC leaders are more likely to improve their position over the next period than occasional ITC leaders. Overall, results with the Compustat and IW500 data sets remain unchanged and do not seem to be driven by the operationalization of systematic ITC leaders.

## Different Specification for Control Variables

The IS and management literature suggests different proxies as well as alternative measurements for some of the control variables. For example, firm size has also been measured as a number of employees [98] or as a log of market capitalization [13] and MV has been measured as relative market to book value [12] or as market capitalization divided by the book value of common equity [28]. In untabulated tests, we utilize these alternative measures and the results remain unchanged. In addition we considered firm age (AGE) because older firms benefit from accumulated experience, but other researchers have countered that firms become increasingly ossified as they age [74]. The results remain unchanged when we introduce AGE into the model specification. The estimated coefficient for AGE was negative and marginally significant or insignificant in H1 and insignificant in H2.

## Discussion

In t oday’s dynamic ec onomy, firms are faced with a continuously evolving competitive landscape. In their quest for competitive superiority, firms seek dynamic capabilities that are durably heterogeneously distributed. In this study we developed a framework that let us capture the path dependence of durable heterogeneous ITC by evaluating the state dependence of transitions in ITC leaders. Using a random effect as well as a fixed effect dynamic binary model within a group of large U.S. firms, the results confirmed the true state dependence in ITC leadership, thus supporting our position that path dependence contributes to the durable heterogeneity of ITC. Given that competitors sooner or later catch up with an ITC leader firm, the long-term benefits of a one-time IT investment have been questioned. Our study makes explicit the distinction between the ability to achieve ITC leadership once (occasional ITC) versus achieving and, importantly, sustaining it (systematic ITC). Our econometric analysis shows that, at least within the group of large U.S. firms, both achieving and sustaining ITC leadership status seems to be a true state-dependent process: ITC is heterogeneously distributed in the short term (H1: temporary resource heterogeneity) as well as in the long term (H2: durable resource heterogeneity).

This study makes two theoretical and methodological contributions to RBV and IT business value research. First, we develop a framework for conceptualizing durable resource heterogeneity due to path dependence. Our approach is general enough to be applicable across different conceptualizations of dynamic capabilities and versatile enough to address different settings such as path dependence of durable heterogeneity in e-commerce [123] and new product development dynamic capability [91]. Therefore, “given the early stage of this field of inquiry” [59, p. 99], the approach presents a promising opportunity for further empirical research on dynamic capabilities. Furthermore, the conceptual framework renders the durable resource heterogeneity assumption due to path dependence empirically testable, thus opening RBV to potential falsification [6, 97]. Second, Wade and Hulland [114], in their review of resource-based studies in IS research, argue that prior studies (e.g., [12, 104]) have not used the RBV construct measures in their empirical analysis. The comment “RBV not measured” seems to be a common tag for a lot of the studies that they reviewed [114]. Our study provides the missing empirical validation for the durable heterogeneity of ITC.

The implications of the conceptual framework and empirical results of this study are clearly supported by the observed practices of numerous ITC leaders in our sample.<sup>27</sup> (1) It is part of our ITC definition and a matter of fact for chief information officers (CIOs) of ITC leaders, such as Hilton and Georgia-Pacific [21, 44] that firms operate in a dynamic competitive environment. (2) It is part of our ITC definition, and consistent with practices of numerous ITC leaders, that firms build and reconfigure IT with organizational and managerial processes. For example, Wal-Mart sees a data warehouse as an opportunity to leverage knowledge to improve business processes [85]; Equifax observes that network integration goes hand-in-hand with improvement of business processes [29]; the CIO of Sears sees Web technology as an opportunity to change its relationships with customers and suppliers [83]; Snap-on Incorporated uses IT to improve not only business processes but also the products themselves [21]; and Georgia-Pacific has started a program for developing leaders at every level of the IT organization [119]. (3) Our framework stresses the importance of ITC as a continuously evolving dynamic capability. Randy Mott, the former CIO of Wal-Mart, elegantly conveys this message when he states, “success is not a destination, but a journey” [85, p. 298].

Finally, given sufficient time and resources, it is likely that a firm can become an ITC leader and ultimately transition from the ranks of non- or occasional to those of systematic ITC leaders. While we were able to find such examples in the list of ITC leaders, the experience of companies such as Intel [33], Global Crossing [63], and Dow Chemical [121], to name a few, shows that this is neither instant nor inexpensive. It took Intel five years to transform their internal IT department; a similar transformation at Global Crossing took four years. The transformation at Dow Chemical started in the mid-1990s, and it took several years of redesigning processes and implementing a common platform: “During that transition IT went from something that was viewed as fairly broken to one of the strengths of our organization” [121].

Similar to prior studies in IT business value, our research suffers from a limitation that Kohli and Grover describe as “[t]he subjectivity of primary data, inaccessibility of reliable secondary data, [and] unavailability of appropriate proxies” [72, p. 27]. More specifically in our case, the analysis is based on the premise that a firm’s listing in IW500 is a true measure of ITC leadership. However, we cannot confirm that the companies ranked in the list of IW500 are independently evaluated each year, we cannot rule out that the selection committee is not biased, and we cannot rule out selfselection bias from our data set. Limiting our analysis to IW500 firms and introducing control variables provides some relative control but does not mitigate these problems.

Finally, our propositions have been validated with large U.S. firms. We hope that future studies will leverage our conceptual framework and methodology in order to replicate our findings with a more reliable and more diverse data set. Future studies may also want to explore the role of path dependence on the durable heterogeneity of ITC at the industry level. While our results for the manufacturing and high-tech sector were consistent with or hypotheses, the results from the finance/service sector seem paradoxical given the critical role of IT in these two sectors.

## Conclusions

Buil ding on th e evol ut ionary ec onomic s, RBV, and IT business value literature, we propose a setting in which systematic ITC leadership (a proxy for duration of ITC heterogeneity) is observable and its true state dependence (a proxy for path dependence) can be econometrically validated. Our results show that ITC is path dependent on prior choices and experiences, and thus durably heterogeneous. Firms that have developed the ability to distinguish themselves from their competitors through ITC are more likely to repeat this in the future than firms lacking such experience. Such systematic ITC leadership is not easy to achieve. As we demonstrate, differences among systematic, occasional, and non-ITC leaders are significant, and it is relatively easier to move from occasional to non-ITC leadership and vice versa than to shift into systematic ITC leadership. This study has important theoretical implications as it is one of the first attempts to develop a theoretical framework for conceptualizing and empirically validating the durable heterogeneity assumption of resources and capabilities due to path dependence.

The first estimator is the RE model, proposed for dynamic binary choice models by Wooldridge [120]. For the logit model, Chamberlain [22] and Cox [32] consider the case with no exogenous regressors and show that the parameter measuring state dependence, $\gamma ,$ can be identified without making any assumptions on $\mathsf { \mathbf { \alpha } } _ { _ i }$ or its relationship with $y _ { i 0 }$ and $X _ { i } .$ The FE approach uses the fact that the number of periods that an individual firm is active in being an ITC leader is a sufficient statistic for $\gamma .$ Conditional on the number of active periods in a string of observations for firm i and under the absence of true first-order state dependence, strings with runs of active or inactive periods should be no more prevalent than strings in which the firm frequently switches between states. The relative frequencies of runs and switches then identify $\gamma$ and the coefficients of time-varying variables in $X _ { i } .$ The FE estimator does not identify the coefficients of time-invariant variables or the distribution of $\mathbf { \alpha } _ { \mathbf { \beta } _ { i } }$ by construction.

The FE approach has been extended to the logit case with exogenous regressors by Honoré and Kyriazidou [61]. They show that a similar conditioning argument will work with a proper matching of the values of exogenous variables, $X _ { i t } ,$ in certain periods if—conditional on this match—there is enough variation in $X _ { _ { i t } }$ in other periods. For discrete covariates, the match can be exact, whereas for continuous covariates, kernel weighting needs to be applied. This means that, in practical terms, only a single continuous covariate is feasible and that convergence of the estimator will be slower than that the usual convergence rate. Moreover, the need to match the values of $X _ { i t }$ over time means that time dummies cannot be allowed by this method. The large data requirements of the FE approach and its practical limitations seem to raise the concerns with FE estimation typically associated with the analysis of linear panel data models.

However, there are data-related concerns that weigh in favor of the FE approach when a survey-based panel data set is used. Further explanatory variables could possibly either be time invariant or have low within-variation. The effects of the additional explanatory variables will then be absorbed by the fixed effects, so that there is no informational gain in adding these variables. If adding further explanatory variables leads to a substantial reduction in sample size due to item nonresponse, the informational advantage of the RE approach is even smaller.

In summary, we expect that the FE model will result in loss in precision due to the matching and differencing that is required to non-parametrically absorb $\mathbf { \alpha } _ { \mathrm { ~ i ~ } } ^ { \mathbf { { \alpha } } }$ and $y _ { i 0 } .$ Thus, we use Hausman’s [52] specification test to compare the RE and FE estimates and assess the trade-off between the FE and RE models. This amounts to testing the RE assumptions that $\mathbb { \alpha } _ { i } \sim N ( \mathbb { \alpha } _ { _ 0 } + \mathbb { \alpha } _ { _ 1 } y _ { i 0 } + X _ { i } \mathbb { \alpha } _ { _ 2 } , \mathbb { \sigma } _ { \mathfrak { n } } ^ { 2 } )$ and $y _ { _ { i 0 } } = 1 \{ X _ { _ { i 0 } } ^ { \prime } \beta _ { _ { 0 } } + \delta _ { _ { 0 } } \alpha _ { _ { i } } + \mathfrak { E } _ { _ { i 0 } } )$ where $\mathfrak { E } _ { i 0 } \sim \mathrm { i . i . d }$ . logistic.
