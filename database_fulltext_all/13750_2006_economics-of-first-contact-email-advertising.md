# Economics of first-contact email advertising

Ram D. Gopal <sup>a,\*,1,2</sup>, Arvind K. Tripathi <sup>b,3</sup>, Zhiping D. Walter <sup>c,4</sup>

<sup>a</sup> Operations and Information Management, University of Connecticut Storrs, CT, 06269, United States <sup>b</sup> Management Science Department, Box 353200, University of Washington Business School Seattle, WA 98195-3200, United States <sup>c</sup> College of Business and Administration, University of Colorado at Denver, Box 165 P O Box 173364, Denver, CO, 80217, United States

## Abstract

Since the advent of the Internet, email has emerged as an important new form of personal communication. The focus of this research is on commercial advertising through the email channel. We analyze the underlying economics of a business model termed admediation that facilitates effective first-contact email advertising. Admediary is a trusted third party that facilitates a mutually desirable communication between buyers and sellers via email, and operates under the <sup>d</sup>opt-in’ mode widely supported by the consumer advocacy groups. Our analytical model examines the incentive structures for all participating entities, and derives pricing strategies, profit implications and characteristics of the email lists. We develop and model a form of price discrimination we term sequential elimination price discrimination that can be practiced via email. Our results indicate that the transactions facilitated by the admediary can create significant value whereby every participating entity realizes increased benefits. These findings underscore the potential of admediation to restore email as an effective communication media for online advertising. <sup>D</sup> 2005 Elsevier B.V. All rights reserved.

Keywords: Email advetising; Online advertising; Spam; Unsolicited commercial email; Admediation; Junk email

## 1. Introduction

Astronomical growth of e-commerce has turned the Internet into a domain of intense corporate activity. Ecommerce has provided opportunities for companies, irrespective of their size, to compete globally. This has prompted traditional market players to obtain an e-commerce business strategies to remain competitive in this electronic marketplace. Along with other business functions, there has been a remarkable boost in online-marketing activity, with companies attempting to develop new methodologies to more effectively market their wares online. According to Interactive Advertising Bureau,<sup>5</sup> online ad spending in US totaled nearly \$2.99 billion in the second quarter of 2005, up more than 26% from the same period in 2004, and increased 6.6% over the first quarter of 2005. For all of 2004, this number totaled \$9.6 billion, up 31.5% from the 2003 total of \$7.3 billion. As the number of Internet users, estimated at 729.2 million as of March 2004,<sup>6</sup> continues to grow, this trend is expected to continue.

Internet technologies offer a number of options for pursuing online advertising. The majority of current advertising dollars are generated through banner advertising and content sponsorship over the Web.<sup>7</sup> However, according to e-Marketer, an online market research company, email stands out as the <sup>b</sup>killer-app<sup>Q</sup> of the online advertising world. This is because email can be precision-targeted, responded to instantly, and unbelievably cheap.<sup>7</sup> Furthermore, it offers opportunities for private communication, and when properly utilized, helps build consumer trust on a long-term basis. But since its inception, this mode of advertising has been plagued by a problem commonly termed as Unsolicited Commercial Emailing<sup>8</sup> (UCE).

The problem of UCE arises due to the peculiar cost structures inherent with email advertising. Sellers can relatively easily obtain unprocessed lists of email addresses, and the cost of sending email solicitations to these lists is minimal. The task of tailoring the lists to target likely consumers is quite expensive, and often is not feasible due to unavailability of the necessary information to identify interested consumers. From a seller’s perspective, it makes economic sense to simply flood the entire list with solicitations as they become cost effective even at extremely low response rates. The incentives to do so are especially high for smaller establishments that can ill-afford the traditional and more expensive advertising channels and for establishments that care little about the negative public stigma associated with UCE. In fact, the majority of solicitations are for objectionable products and services, which are often illegal and fraudulent. Well-established and reputable firms have shied away from UCE as it has become synonymous with fraud.

The true costs of such advertising campaigns shift to the consumers and ISPs (Internet service providers). The negative externalities borne by the email users arise from the frequency, volume, irrelevance of email solicitations, the lack of control, and intrusions to personal privacy [11]. While not all unsolicited emails are necessarily unwanted, the majority is. Most email users perceive no value in receiving these messages. According to a recent report (http://www.rhsmith.umd.edu/ ntrs/), the cost of dealing with junk email in US reached \$22 billion in 2004. So pervasive is the problem that AOL antispam filters blocks 1.4 billion spam messages daily.<sup>9</sup> Considering the seriousness of the problem, the

FTC<sup>10</sup> has set up a special mailbox (uce@ftc.gov) to assess the emerging trends and developments. By the year 2002, the FTC mailbox had received over 8.3 million pieces of emails from consumers. On average, consumers forward 15,000 pieces of UCE per day to this mailbox.

A number of consumer organizations<sup>11</sup> have rallied together to address this problem, from both technical and legislative venues. A plethora of technical solutions based on schemes such as sender’s address verification,<sup>9</sup> reverse filtering,<sup>12</sup> counterattacks, and blacklisting of known UCE senders have been implemented. While not foolproof, as senders constantly revise and update the tactics they deploy, these techniques have helped lower the overall burden on consumers and ISPs. The fight on the legal front is also gaining momentum. Beginning with the state of Washington in 1998, a slew of states have enacted laws to provide legal protection to their constituents. A number of federal laws are also under active consideration.<sup>13</sup> It is widely believed that effective legislative efforts will begin to impose significant costs on the offenders and will thus serve as an important deterrent.

A significant point of debate in crafting the legislation relates to the legal definition of UCE. Consumer advocacy groups favor a more stringent version that entails <sup>b</sup>opt-in.<sup>Q</sup> The opt-in approach allows businesses to send email solicitations only to individuals with whom they have prior business relationship in that they have received an explicit consent to send solicitations for product and services. Thus, any mode of advertising that involves making a <sup>b</sup>first-contact<sup>Q</sup> email solicitation with potential prospects will be deemed illegal under this scheme. The Direct Marketing Association (DMA), representing legitimate advertising agencies, argues that the opt-in approach will have a <sup>b</sup>throw the baby out with the bath water<sup>Q</sup> effect in that email will cease to exist as a viable channel for any form of advertising that entails a first-contact with prospects [4]. While they are supportive of efforts to curb fraudulent advertising, their interests lie in ensuring the availability of the email channel for legitimate and reputable sellers to reach potential customers. They also argue that opt-in can significantly increase the search costs for consumers to obtain information about products and promotions, as they would have to initiate and bear the effort of contacting potential sellers. They support an <sup>b</sup>opt-out<sup>Q</sup> approach wherein businesses can make first contact with consumers but must honor a recipient’s request to be removed from the email list. Consumer advocacy groups are strongly opposed to the opt-out approach, as they believe that it will continue to legitimize UCE. It would provide every seller at least one free shot at each potential consumer. The volume of emails, majority of which consumers have no interest in, will continue to be large, and consumers will continue to face the burden of opting out from all email lists that include their information.

Given the conflicting interests of the business and the consumer groups, the nature of the future legislation against UCE remains unclear. Regardless, the public outcry against the problem of UCE has led the majority of reputable companies to adopt an <sup>b</sup>opt-in<sup>Q</sup> approach. As a result the email channel is typically excluded from the advertising arsenal, despite its potential to be an effective advertising tool. Recently, a new type of advertising business model has emerged to enable these companies to solicit prospects via email. Gopal et al. [4] term this business model admediation. An admediary enables sellers to make first contact with potential consumers while operating within the <sup>b</sup>optin<sup>Q</sup> mode. The economic viability of this business model and the ensuing nature of email solicitations is the central focus of the paper.

## 1.1. Concept of admediation

The business model of admediation derives its roots from the well-established concept of intermediation and creates value through incentive-based approaches that match interested buyers and sellers [4]. Consumers provide to the admediary their email addresses, buying preferences, and consent to receive email in exchange for useful product and pricing information, monetary incentives, and a guaranty from the admediary that the individual personal information will be safeguarded. From this perspective, the admediary provides a realization of a reverse marketplace by bringing products and services from the sellers in the market to a consumer’s door.

Sellers subscribe to the admediary in order to solicit potential customers. In return, the sellers compensate the admediary. Besides the targeted list of consumers, the sellers are also attracted due to the fact that this mode of advertising is perfectly legal under all legislative schemes under consideration and is acceptable to the public. This is because the email itself originates from the admediary who has an explicit consent from the subscribed consumers, even though the content of email may originate from sellers that wish to make first contact with consumers. Since the sellers need to pay the admediary to avail of the services, this model is only attractive to legitimate businesses. Companies that engage in questionable business practices (for example, those peddling pornographic products or miracle medical products) would continue to find UCE attractive. To these companies, long term image of their product factors less into the bottom line, and even the low cost of advertising via an admediary is astronomical compared to the close to zero marginal cost of UCE. As we demonstrate later in the paper, the services offered by the admediary are particularly attractive to legitimate businesses whose consumers incur high search costs to acquire information on the products and services offered by these businesses.

A number of advertisers are beginning to offer email services that are based on the concept of admediation. A recent Business Week article [6] highlights the unique advantages of their business model. Consumers base their decisions on their own criteria and thus wield complete control over the process. Also, unlike auctions, consumers don’t have to compete with other buyers and thus avoid the problem of winner’s curse. The popularity of these sites appears to be growing and is evidenced by the fact that many of these sites have large subscriber base and very high response rates of their email lists.

Table 1 provides an illustration of a few representative companies and the key characteristics of their email offerings. These companies have undertaken a number of important steps to prevent abuse of their subscribers’ personal information and privacy requirements. As a part of the overall trust building effort, all adhere to strict privacy policies that prevent them from sharing, distributing, or selling subscriber information to any third party. Further, they limit the volume of emails that are forwarded to the subscribers, and offer the option to consumers to opt-out of the subscriber lists. Interestingly, the compensation schemes offered to consumers for consent and reading emails from sellers do vary amongst the admediaries. Per email compensation varies from zero to as high as \$0.08 per email that is sent to a consumer.

The possibility of compensation for simply reading email advertising messages, and the purely voluntary and incentive based subscription decisions raise the specter of moral hazard and adverse selection problems. The moral hazard arises from the inability of normal contracts to achieve an efficient allocation [2,9]. The moral hazard in this case arises from the possibility of subscribers joining email lists for the sole purpose of receiving compensation offered by admediary, with no ensuing interest in the product or service offered by the originating seller. Most of the companies that offer monetary compensation for email advertisements place limitations on the volume and frequency of emails they send to individuals. As a result, the incentive for individuals to subscribe purely to extract compensation is mitigated.

The adverse selection problem is rooted in asymmetric information and can create serious misallocations and raises the possibility of complete market breakdown [1]. In the case of admediation, the adverse selection problem leads to the question of the quality and desirability of the prospects on the subscriber lists, from the viewpoint of the sellers. If potentially lowvalued consumers dominate the subscriber lists, then such lists are of limited value to advertisers. Such a scenario can raise important questions on the long-term viability of this mode of advertising. However, the overall incentives offered by admediaries, when properly implemented, should attract both high and low valued consumers. High valued consumers are typically less price-sensitive and are less attracted by the low values of compensation (typically less than \$0.1/email) for email advertisements. The incentive for such consumers comes primarily from savings in the time and effort expended to search, evaluate, and acquire products and services. Thus the subscriber lists can capture potential consumers across the value spectrum. The high response rates reported by a number of admediaries provide credence to its effectiveness in addressing the adverse selection problem.

## 1.2. Research issues

The focus of this article is on analyzing the economics involved in the business model of admediation. We address issues that include the following: What types of sellers are attracted to admediation? What compensation policies to consumers and pricing mechanisms to sellers are viable? What are the characteristics of email lists under various compensation schemes? What are the pricing implications of admediation? What are the consumer surplus and welfare implications?

We begin the model development by considering a single seller. Consumers are considered to have ex ante belief about product characteristics and pricing of such characteristics. A large part of seller participation decision is based on how costly it is for their prospective customers to search for their products. We also address the moral hazard problem that arises because of potential compensation offered to email recipients. An important proposition derived from this analysis states that the sellers whose products or services involve higher search costs for customers have significantly higher incentives to participate with admediary.

We then develop and model a unique form of price discrimination termed sequential elimination price discrimination that is facilitated by the email technology. The assumption that value of a product to a consumer discounts over time is crucial in this form of price discrimination. When this discount factor is significant (for instance, seasonal goods), consumers tend to make a purchase as soon as the price is less than their valuation of the product. When this discount factor is negligible, consumers will not make a purchase if they know the price will come down if they wait. When the discount factor is in between, at each subsequent lower price offering, some consumers may wait while others may make a purchase. Our analysis indicates that even though this form of price discrimination involves multiple solicitations, the admediary pricing structure ensures that the volume of emails remains under check.

We extend the model to consider multiple sellers and derive optimal pricing strategies for the admediary. This is followed by simulation experiments to provide additional insights. The results suggest that price discrimination, when feasible, will emerge as the dominant pricing strategy. Admediary profits, seller profits and participation rates, consumer surplus, and social welfare are all higher in most situations when the price discrimination strategy is implemented. Consumer surplus is also higher for products and services with higher quality. Interestingly, sellers whose products incur lower search costs on consumers tend to send more sequential solicitations than sellers whose products incur higher search costs. Since higher search costs producers are currently the most common practitioners of UCE, our analysis validates the role of admediation in potentially discouraging UCE. Together these results underscore the economic viability of admediation and its ability to provide significant value-added for all participating entities.

The remainder of the paper is organized as follows. Section 2 provides the underlying methodology and develops the economic model for the single seller case. The moral hazard problem that arises in this context and mechanisms to deal with this problem are also addressed. Section 3 develops the optimal pricing strategies for the case of multiple sellers and the simulation experiments are presented in Section 4. Section 5 presents summary comments and highlights directions for future research.

## 2. Model development for single seller

We begin the model development by considering the case of a single monopolistic seller. Multiple seller case is discussed in Section 3. Each participating party is assumed to exhibit a value maximizing behavior. In particular, the seller and the admediary attempt to maximize their profits. Consumers make sign up and purchase decisions to maximize their utility.

The consumers face information uncertainty regarding the features and the price of the product or service offered by the monopolist. A customer incurs a cost of s to search and locate the product, and to acquire information on the features offered and the price charged. The admediary sets up a mailing list for the product in order to reduce the search cost for the consumers. Interested consumers sign up and consent to receive email messages from the sellers via the admediary. The admediary charges the seller c for each email sent to each address. Each participating consumer receives a payment of h for each email that they receive from the admediary. If a consumer does not sign up, she incurs a fixed search cost of s to locate the product. If the consumer does sign up with the admediary, she incurs a cost R to read an email message. We make the safe, practical assumption that $s > R$ . Note that prior to the search (sign up) decision, the expected total cost of purchase includes the search cost (or reading cost less compensation from the admediary) and the expected price of the product. However, once the consumer conducts the search (or reads the email), these become sunk costs. The subsequent decision to purchase is based on the revealed actual value and the actual price of the product.

The initial model assumes that each consumer receives a single email message from the admediary. The specter of multiple solicitations presents possibilities for interesting pricing strategies and is discussed later in this section.

## 2.1. Single seller single solicitation model

Consumers make subscription decisions based on their expectations regarding the value, features and the price of the product, and the services offered by the admediary. We assume that the product embodies a universal set of features, i.e. all possible features that can potentially be offered in that product. Without loss of generality, we consider the elements of this set to consist of equal-valued features. We assume that the demand function for the fully featured product is linear with a downward slope of a and intercept of a $V _ { m }$ , i.e. the demand function is $D = \alpha V _ { m } - \alpha p$ . Thus, the total demand would be 0 and $\alpha V _ { m }$ at prices $V _ { m }$ and 0, respectively. Without loss of generality, the marginal cost of the product is assumed to be zero. The seller’s actual product offers a fraction, $f \in ( 0 , 1 ]$ , of the universal set of features. f is private information to the seller. However, seller communicates this information to the admediary. Consumers, a priori, are uncertain about the actual subset of features, $f ,$ offered by the seller. This level of uncertainty is captured by consumer ex ante belief about the distribution of f. This belief f is drawn from distribution U[0, 1]. The actual realization of f is revealed to consumers in the email offering, together with the price. The demand function for a product with a fraction of f features is hence $D { = } \alpha V _ { m } { - } \left( \alpha / f \right) p$ . ## 2.2. Single seller multiple solicitation

We now consider the possibility of multiple solicitations from the seller. Recall that the equilibrium condition is that the admediary offers full compensation. Under this condition, all consumers with a positive expected valuation for the product would enlist with the admediary. After receiving email communications from the seller, only those whose value exceeds the offered price would purchase the product. However, after a period of time, the seller might benefit from offering the product at a lower price for the non-buyers. This strategy represents a form of price discrimination over time that works by a sequential elimination of the subscribers from the email list.

There exists a wealth of literature on price discrimination over time [10], and the impetus for these studies is the observation that for a large number of products, the prices tend to decline over time [7,8]. A fundamental question that arises in this context is: why would a consumer purchase a product at a higher price, and not wait until it is offered at a lower price? Clearly price discrimination over time is feasible only if consumers face a penalty or loss of value due to waiting. Such penalties arise in a number of scenarios, including a potential lack of availability of the product in the future or a loss of realized value due to non-consumption for a period of time [3,5,10]. The former arises, for example, when limited quantities are produced and there exists a distinct possibility that the product may not be available in the future. An example of the latter is fashion goods, where consumers are willing to pay a higher price when the good is in fashion despite the prospect of significantly lower price in the future. Another example is seasonal goods (such as golf accessories) whose price is significantly higher at the beginning of the season and declines sharply towards the end of the season. Some consumers succumb to higher prices to ensure usage (and hence realize higher value) over the whole season, rather than wait and then obtain only a limited usage. Such products permit a seller to practice a form of price discrimination that works on the principle of sequential elimination of subscribers from the email list. The mechanics underlying this form of price discrimination as applied to admediary work as follows.

The admediary offers full compensation to the consumers, and those with a positive expected valuation for the product sign up. The seller sends an initial email solicitation to all consumers on the list, offering the product at a price $p _ { 1 }$ . After a certain period of time, the seller removes the buyers from the email list, and sends a subsequent email to the remaining list, offering the product at a price of $p _ { 2 }$ where ${ p } _ { 2 } { < } p _ { 1 }$ . Let v denote valuation of the full-featured product by a particular consumer. Then $f \nu$ denote his valuation of the product with f features. Consider a consumer with $f \nu > p _ { 1 }$ . The net utility of this consumer if she responds to the first solicitation is $f { \boldsymbol { \nu } } - p _ { 1 }$ . On the other hand, she can choose to wait for the second solicitation and acquire the product at a lower price. Let $\delta , 0 { \leq } \delta { \leq } 1$ , characterize the consumer’s willingness to wait or the value discount factor. We assume that all consumers have the same willingness to wait and that it is public knowledge. If this consumer waits for the second solicitation, the net value is $\delta ( \mathcal { f } \nu - p _ { 2 } )$ . Note that when $\delta = 1$ all consumers wait for the cheapest price, and when $\delta = 0$ a consumer makes a purchase as soon as an offering is made as long as his valuation $f \nu$ is higher than the offered price. When $0 < \delta < 1$ , consumers with lower valuations prefer to wait and will buy at $p _ { 1 }$ only if $f \nu - p _ { 1 } > \delta ( f \nu - p _ { 2 } )$ or $\begin{array} { r } { f \nu > \frac { p _ { 1 } - \delta p _ { 2 } } { ( 1 - \delta ) } . } \end{array}$ The seller can repeatedly solicit the consumers, each time offering the product at a price lower than the preceding one. The economic rationale for a seller to price discriminate as above is to extract additional consumer surplus. The temptation of a seller to practice unfettered price discrimination is curbed by the fact that the admediary charges c for each email solicitation. The admediary, in turn, needs to compensate consumers for each email. The following discussion presents the analytical development of the multiple solicitation model.

## 3. Multiple sellers

In this section, we extend the previous models to consider multiple sellers in the market. We consider n non-competing sellers in the market, with each selling one product. The demand for the products is assumed to be independent of others. The admediary doesn’t discriminate among sellers and charges the same fee to all sellers. We assume consumers of all markets have the same reading cost of R. As before, the equilibrium condition is that $\theta { = } R .$ The admediary’s problem is then to determine $\gamma$ to maximize his profit. Given the fee set by the admediary, the seller determines the participation strategy. A participating seller sets $k$ and price at each solicitation to maximize his profit. Note that the exact nature of price discrimination followed by the participating sellers may vary, and in fact some sellers may solicit consumers only once (if $\delta = 1$ , for instance). Consider the implications of $\gamma$ on the admediary profits. A higher value of $\gamma$ increases admediary profit per email but elicits lower seller participation. A lower value of $\gamma$ reduces per email profits but attracts increased seller participation.

Let $\gamma ^ { * }$ denote the profit maximizing charge imposed on each email. ## 5. Summary comments

The analytical models together with the empirical study provide the following key findings: (1) As long as the search cost for the product or service is larger that the cost to read an email message, the admediary has an incentive to create an email list; (2) the transactions facilitated by the admediary create signif icant value-added, as evidenced by its positive impact on social welfare; and (3) admediation draws sellers with high search cost products and services. These findings illustrate the potential of admediation to restore email as an effective communication media for online advertising.

Our analysis suggests that price discrimination, which entails multiple solicitations, will emerge as the dominant advertising strategy. At the same time, admediation incorporates self-regulatory mechanisms to ensure that consumers do not bear any negative externalities, and that the volume of emails remains under check. For high search cost items, consumers prefer price discrimination as it draws more sellers to participate and hence increases consumer surplus. Currently, most admediaries follow a single solicitation model. By providing full compensation to the consumers and allowing sellers to price discriminate, these organizations can improve their bottom line and gain increased subscription. Our analysis also reveals that the size of the email list is a critical factor that draws sellers.

A number of issues deserve further investigation. Our assumptions regarding the constancy of reading and search costs, and a consideration of only non-competing sellers need to be relaxed to derive further implications of admediation. The form of price discrimination developed in this paper works on the principle of sequential elimination of consumers based on their valuations that discount over time. When this discount factor is not significant, consumers will wait and not make a purchase as long as they expect the price to come down. Thus this form of price discrimination is only viable for products whose value discounts significantly over time such as seasonal goods. Other mechanisms, such as auctions, provide alternative ways to segregate consumers. Integration of other mechanisms within the framework of admediation may enhance its scope and effectiveness. While the current models utilize email as the primary communication tool, other technologies, such as intelligent agents that work on behalf of users, can be similarly explored.

## Appendix A. Proof of proposition 1

Proposition 1: If $( \gamma ^ { \ast } , \theta ^ { \ast } , \ p _ { ( f ) } { } ^ { \ast } , \ \nu ^ { \ast } )$ is a Perfect Bayesian Equilibrium to the game described above, then $\theta ^ { * } { = } R$

We prove Proposition 1 by contradiction. Let $( \gamma ^ { * } , \theta ^ { * } ,$ $p _ { \mathrm { L } } { } ^ { * } , p _ { \mathrm { H } } { } ^ { * } , \nu ^ { * } )$ be a Perfect Bayesian Equilibrium to the dynamic game with incomplete information, and $\theta ^ { * } { < } R$ . Without loss of generality, we assume that the realization of f is either $f _ { \mathrm { L } } \ \mathrm { o r } f _ { \mathrm { H } } ,$ with equal probability. Let $\nu ^ { * }$ denote the lowest valuation for the full-featured product amongst the consumers who sign up with the admediary. Since $s > R ,$ , all consumers will prefer signing up to search. Hence all consumers with positive expected utility from signing up will do so and the marginal consumer who signs up is the one whose expected utility is zero. Therefore, the expected utility for consumer with $\nu ^ { * }$ is 0. Thus,

$$
\begin{array}{c} 0. 5 ^ {*} (f _ {\mathrm{L}} v ^ {*} - p _ {\mathrm{L}} ^ {*} - (R - \theta^ {*})) + 0. 5 ^ {*} (f _ {\mathrm{H}} ^ {*} v - p _ {\mathrm{H}} ^ {*} \\ - (R - \theta^ {*})) = 0. \end{array}
$$

Simplifying,

$$
v ^ {*} = \frac {p _ {\mathrm{L}} ^ {*} + f _ {\mathrm{H}} ^ {*} + 2 (R - \theta^ {*})}{f _ {\mathrm{L}} + f _ {\mathrm{H}}}.\tag{A1}
$$

We now prove that $( \gamma ^ { * } , \theta ^ { * } < R , { p _ { \mathrm { L } } } ^ { * } , { p _ { \mathrm { H } } } ^ { * } , \nu ^ { * } )$ satisfying Perfect Bayesian Equilibrium cannot satisfy Eq.

(A1). We proceed by considering all possible values of $\nu ^ { * }$ . Since either $\nu ^ { * } { \leq } \frac { 1 } { 2 } V _ { \mathrm { m } }$ or $\nu ^ { * } { > } \frac { 1 } { 2 } V _ { \mathrm { m } }$ must be true, we construct a contradiction for each possible value of $\nu ^ { * }$

$$
v ^ {*} \leq \frac {1}{2} V _ {\mathrm{m}}.
$$

If f is the realization of f , the monopolistic price is $\begin{array} { r } { p _ { \mathrm { L } } ^ { * } = \frac { f _ { \mathrm { L } } } { 2 } V _ { \mathrm { m } } } \end{array}$ . Since $\nu ^ { * } { \le } \frac { 1 } { 2 } V _ { \mathrm { m } }$ , we have $f _ { \mathrm { L } } \nu ^ { * } { \le } \frac { f _ { \mathrm { L } } } { 2 } V _ { \mathrm { m } }$ , that is, all consumers whose valuations are higher than the monopolistic price would have signed up. Hence, the optimal price for the seller to set is $\begin{array} { r } { p _ { \mathrm { L } } ^ { * } = \frac { f _ { \mathrm { L } } } { 2 } V _ { \mathrm { m } } } \end{array}$ Similarly, when $f _ { \mathrm { H } }$ is the realization of $\setminus f ,$ the optimal price to set is $\begin{array} { r } { p _ { \mathrm { H } } ^ { * } = \frac { f _ { \mathrm { H } } } { 2 } V _ { \mathrm { m } } } \end{array}$ . Therefore, Eq. (A1) can be expressed as

$$
v ^ {*} = \frac {V _ {\mathrm{m}}}{2} + \frac {2 (R - \theta^ {*})}{f _ {\mathrm{L}} + f _ {\mathrm{H}}}.
$$

Since $\theta ^ { * } { < } R$ it contradicts $\nu ^ { * } { \le } \frac { 1 } { 2 } V _ { \mathrm { m } }$

Case (2): $\begin{array} { r } { \nu ^ { * } { > } \frac { 1 } { 2 } V _ { \mathrm { m } } . } \end{array}$

In this scenario the seller does not set the price to monopolistic price because all consumers who have signed up have valuations higher than that price. The optimal price to set is then the lowest valuation of all consumers who have signed up, that is, ${ p _ { \mathrm { { L } } } } ^ { * } { = } { f _ { \mathrm { { L } } } } { \nu ^ { * } }$ and $p _ { \mathrm { H } } { } ^ { * } { = } f _ { \mathrm { H } } \nu ^ { * }$ . Substitute these values into Eq. (A1) and simplifying we obtain

$$
v ^ {*} = v ^ {*} + \frac {2 (R - \theta^ {*})}{f _ {\mathrm{L}} + f _ {\mathrm{H}}}.
$$

Since $\theta ^ { * } { < } R$ , this results in a contradiction. In conclusion, there is no Perfect Bayesian Equilibrium when $( \gamma ^ { * } , \theta ^ { * } < R , { p _ { \mathrm { L } } } ^ { * } , { p _ { \mathrm { H } } } ^ { * } , \nu ^ { * } )$

## Appendix B. Price Discrimination Strategy

The seller’s problem involves determining the optimal number of email solicitations to consumers, and the price to offer with each solicitation. We begin the optimization by determining the optimal prices for a given value of k. The optimization problem is

max

$$

The first order conditions for prices yield

$$
