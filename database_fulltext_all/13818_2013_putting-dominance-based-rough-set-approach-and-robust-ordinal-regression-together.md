# Putting Dominance-based Rough Set Approach and robust ordinal regression together

Salvatore Greco <sup>a</sup>, Roman Słowiński <sup>b,c</sup>, Piotr Zielniewicz <sup>b,</sup>⁎

## a r t i c l e i n f o

Article history: Received 2 February 2012 Received in revised form 13 July 2012 Accepted 20 September 2012 Available online 28 September 2012

Keywords: Multiple criteria decision aiding Preference elicitation Robust ordinal regression UTA<sup>GMS</sup> and GRIP methods Necessary and possible preference relation Dominance-based Rough Set Approach

## a b s t r a c t

We propose to apply the Dominance-based Rough Set Approach (DRSA) on the results of multiple criteria decision aiding (MCDA) methods, in order to explain their recommendations in terms of rules involving conditions on evaluation criteria. The rules represent a decision model which is transparent and easy to interpret for the DM. In fact, decision rules give arguments to justify and explain the decision and, in a learning perspective, they can be the starting point for an interactive procedure for analyzing and constructing the DM's preferences. It enables his/her understanding of the conditions for the suggested recommendation, and provides useful information about the role of particular criteria or their subsets. DRSA can be used in junction with any MCDA method producing a classi<sup>fi</sup>cation result or a preference relation in the set of alternatives. In this paper, we apply DRSA to a recently proposed MCDA methodology, called Robust Ordinal Regression (ROR). The ROR approach to MCDA, also called disaggregation–aggregation approach, aims at inferring parameters of a preference model representing some holistic preference comparisons of alternatives provided by the decision maker (DM). Contrary to the usual ordinal regression approaches to MCDA, ROR takes into account the whole set of possible value of preference model parameters compatible with the DM's preference information, to work out a <sup>fi</sup>nal recommendation. In consequence, ROR gives a recommendation in terms of necessary and possible consequences of the application of all the compatible sets of parameter values to the considered set of alternatives. UTA<sup>GMS</sup> and GRIP methods apply this approach, considering general monotonic additive value functions, and produce as a result the necessary and possible preference relations. In this paper we show how DRSA completes the decision aiding process started with ROR, providing a very useful interpretation of the preference relations in terms of decision rules.

## 1. Introduction

Multiple criteria decision aiding (MCDA) helps in construction of an aggregation model on the base of preference information provided by the DM. Such an aggregation model is called preference model: it induces a preference structure in the set of considered alternatives (for a recent state-of-the-art, see [10]).

The preference information may be either direct or indirect, depending if it speci<sup>fi</sup>es directly values of some parameters used in the preference model (e.g., trade-off weights, aspiration levels, discrimination thresholds, etc.), or if it speci<sup>fi</sup>es some examples of holistic judgments from which compatible values of the preference model parameters are induced indirectly.

Direct preference information is used in the traditional aggregation paradigm, according to which the aggregation model is <sup>fi</sup>rst constructed and then applied on the set of alternatives to get information about the comprehensive preference. Eliciting direct preference information from the DM can be counterproductive in real-world decision making situations because of a high cognitive effort required. Very often this information is not easily de<sup>fi</sup>nable. Consequently, asking directly the DM to provide values of the parameters makes the DM rather uncomfortable. For example, this is the case of the price or the interest rates in cost– bene<sup>fi</sup>t analysis, or the case of the coef<sup>fi</sup>cients in objectives and constraints of mathematical programming models, or the case of attribute weights and several thresholds in outranking methods.

Indirect preference information is mainly used in the ordinal regression (or disaggregation–aggregation) paradigm, according to which the holistic preference information on a subset of some reference alternatives is known <sup>fi</sup>rst, and then a preference model compatible with this information is built and applied to the whole set of alternatives. Presently, MCDA methods based on indirect preference information and the ordinal regression paradigm are of increasing interest because they require relatively less cognitive effort from the DM.

The ordinal regression paradigm is concordant with the “posterior rationality” postulated by March in 1978 [30]. It has been known for at least 50 years in the <sup>fi</sup>eld of multidimensional analysis. It is also concordant with the induction principle used in machine learning.

This paradigm has been applied within the two main MCDA approaches: the one using a value function as a preference model [44,34,23,38], and the one using an outranking relation as a preference model [26,31]. The ordinal regression paradigm has also been used in MCDA methods involving a new family of preference models—a set of dominance-based decision rules induced from rough approximations of holistic preference relations [14,16,8,18,21].

Recently, the ordinal regression paradigm has been revisited with the aim of considering the whole set of value functions compatible with the preference information provided by the DM, instead of a single compatible value function used, for example, in the UTA-like methods [23,38]. This extension has been implemented in methods called $U T \bar { A } ^ { G M S }$ [21] and GRIP (Generalized Regression with Intensities of Preference) [11]. These methods are not revealing to the DM one compatible value function, but they are using the whole set of compatible (general additive monotonic, not piecewise linear only) additive value functions to set up a necessary weak preference relation and a possible weak preference relation in the whole set of considered alternatives. Moreover, in $U T A ^ { G M S }$ , the preference information has the form of a partial preorder (instead of a complete preorder) in a subset of reference alternatives. GRIP can be seen as an extension of $U T A ^ { G M S }$ permitting to take into account additional preference information in the form of comparisons of intensities of preference between some pairs of reference alternatives. These comparisons are expressed in two possible ways (not exclusive): comprehensively, on all criteria, and partially, on any criterion. The necessary and possible weak preference relations are exploited such that one <sup>fi</sup>nally obtains two types of preference relations in the set of alternatives: the necessary preference relation (that, being a re<sup>fl</sup>exive and transitive binary relation, is a partial preorder) identifying preference statements being true for all compatible value functions, and the possible preference relation (that is a strongly complete and negatively transitive binary relation) identifying preference statements being true for at least one compatible value function. Distinguishing necessary and possible consequences of preference information on the considered set of alternatives, $U T A ^ { G M S }$ and GRIP answer questions of robustness analysis [35].

Even if the information required from the DM is easily de<sup>fi</sup>nable, like a set of pairwise comparisons, it is often processed in a way which is not clear for the DM, such that (s)he cannot see what are the exact relations between the provided preference information and the <sup>fi</sup>nal recommendation. Consequently, very often the decision model is perceived by the DM as a black box whose result has to be accepted because the analyst's authority guarantees that the result is “right”. In this context, the aspiration of the DM to <sup>fi</sup>nd good reasons to make decision may be frustrated and raises the need for a more transparent methodology in which the relation between the original information and the <sup>fi</sup>nal recommendation is clearly shown. Such a transparent methodology searched for has been called glass box [19]. Its typical representative is using a learning set of decision examples as the input preference information provided by the DM, and it is expressing the decision model in terms of a set of $" i f \ldots , t h e n \ldots "$ decision rules induced from the input information. From one side, the decision rules are explicitly related to the original information and, from the other side, they give understandable justi-<sup>fi</sup>cations for the decisions to be made.

The rules induced from the input information provided in terms of exemplary decisions represent a decision model which is transparent for the DM and enables his understanding of the reasons of his past decisions. The acceptance of the rules by the DM justi<sup>fi</sup>es, in turn, their use for future decisions.

The induction of rules from examples is a typical approach of arti-<sup>fi</sup>cial intelligence. This explains our interest in rough set theory [32] which proved to be a useful tool for analysis of partially inconsistent data describing decision situations in terms of exemplary decisions [33,39]. The rough set analysis and, more precisely, its dominancebased version [14,13,16,41], aim at explaining the values of some decision attributes, playing the role of “dependent variables”, by means of the values of condition attributes (criteria), playing the role of “independent variables”.

The Dominance-based Rough Set Approach (DRSA) permits to structure ordinal data into lower and upper approximations $\left[ 1 6 , 4 0 , 1 5 , 4 2 \right]$ corresponding to sets of classi<sup>fi</sup>cation examples (the case of ordinal classi<sup>fi</sup>cation problems) or sets of pairwise compari sons of alternatives (the case of ranking and choice problems), which are consistent (lower approximation) or inconsistent (upper approximation) with the dominance principle. Then, $^ { \ast } i f . . . , t h e n \ldots ^ { n }$ decision rules are induced from lower and upper approximations, giving, respectively, certain and possible relationships between evaluations of alternatives on particular criteria and classi<sup>fi</sup>cation decisions (ordinal classi<sup>fi</sup>cation), or between differences of evaluations for pairs of alternatives and preference relations (ranking and choice).

As DRSA is able to explain in comprehensible rule terms the pref erence relations in the set of alternatives, we propose in this paper to apply DRSA on results of the GRIP method. The rules provide useful information about the conditions on evaluation criteria for the necessary and possible preference relations. From the rules, one can also learn about the role of particular criteria or their subsets in the decision model. Although the present study shows the usefulness of the junction DRSA–GRIP, DRSA can be used in junction with any robust regression method, and, more generally, with any MCDA method producing a classi<sup>fi</sup>cation result or a preference relation in the set of alternatives. The DRSA decision rules give arguments to justify and explain the decision. For example, the preference, either necessary or possible, of alternative a over alternative b can be supported by a decision rule r that implies such preference because of a strong preference on criterion $g _ { j _ { 1 } }$ and at least mild preference on criterion $g _ { j _ { 2 } }$ . In this case, the strong preference on criterion $g _ { j _ { 1 } }$ and the at least mild preference on criterion $g _ { j _ { 2 } }$ become the arguments suggested by the rule for the preference of a over b. Moreover, in the learning perspective of a constructive approach to decision aiding, the rules can be the starting point for an interactive analysis and construction of DM's preferences. In fact, the DM could not accept some decision rules because (s)he does not agree with the arguments suggested by them. Let us suppose that the DM disagree with decision rule r, mentioned above, because (s)he <sup>fi</sup>nds that the strong preference on criterion $g _ { j _ { 1 } }$ and the at least mild preference on criterion $g _ { j _ { 2 } }$ do not constitute a suf<sup>fi</sup>cient argument for the preference of one alternative over another one. In this case, the DRSA methodology gives also the information about what pairs of alternatives are supporting rule r. If the DM <sup>fi</sup>nds among these pairs of alternatives one such pair for which the preference suggested by r is non-acceptable, (s)he can add an inverse preference relation on this pair to be considered by GRIP as new preference relation, and the procedure should start again. The procedure ends when the DM <sup>fi</sup>nds acceptable the possible and the necessary preference relations, as well as the arguments given by DRSA decision rules to explain these preferences.

The paper is organized in the following way. Section 2 reminds some concepts of robust ordinal regression, as well as some elements of the GRIP method which is presently the most general of all UTA-like methods. Section 3 reminds basic concepts of the Dominance-based Rough Set Approach, and shows how DRSA can be applied on results of GRIP to explain them in terms of decision rules. Section 4 presents two illustrative examples. Finally, in the last Section $5 ,$ some conclusions and further research directions are provided.

## 2. Robust ordinal regression

Let us consider an MCDA problem where a <sup>fi</sup>nite and non-empty set of alternatives $A , \ ( | A | = m )$ , is evaluated on a <sup>fi</sup>nite family $F =$ $\{ g _ { 1 } , . . . , g _ { n } \}$ of n criteria. The set of the indices of criteria is denoted by $I { = } \{ 1 { , } { \ldots } , n \}$ . It is assumed, without loss of generality, that the greater $g _ { i } ( x ) , x { \in } A$ , the better alternative x on criterion $g _ { i } ,$ for all $i \in I .$ The family of criteria F is supposed to satisfy some consistency conditions, i.e., completeness (all relevant criteria are considered), monotonicity (the better the evaluation of an alternative on the considered criteria, the more it is preferable to another), and non-redundancy (no super-<sup>fl</sup>uous criteria are considered) [36].

With respect to set A, a single DM, or a group of DMs, may wish to get recommendation on one of the following questions: (i) what is the subset of best alternatives in A, (ii) how to assign alternatives from A to pre-de<sup>fi</sup>ned and preference ordered classes, or (iii) how to rank the alternatives in A from the best to the worst. It is well known that the only objective information coming out from the above problem statement is a weak dominance relation in set A. In fact, alternative a dominates alternative b if a is at least as good as b on all criteria from $F ,$ and there is no doubt that then a should be comprehensively considered at least as good as $b ,$ independently of speci<sup>fi</sup>c preferences of the DM. Instead, when a is not dominating b, the statement that a is at least as good as b depends on the preferences of the DM. Let us recall that the weak dominance relation is a partial preorder, i.e. it is a re<sup>fl</sup>exive and transitive binary relation. According to the weak dominance relation, alternative $x \in A$ is preferred to alternative $y \in A$ (denotation $x \succeq y )$ if and only i $\because g _ { i } ( x ) { \geq } g _ { i } ( y )$ for all $i \in { \cal F } .$ Moreover, x is indifferent to y (denotation $x { \sim } y )$ if and only $\mathrm { i f } g _ { i } ( x ) = g _ { i } ( y )$ for all $i \in F ;$ <sup>fi</sup>nally, x is incomparable with y otherwise, i.e. i $\because g _ { i } ( x ) > g _ { i } ( y )$ for at least one criterion $i \in F$ and $g _ { j } ( x ) { < } g _ { j } ( y )$ for at least another criterion $j \in F .$ Since incomparability is the most frequent situation, the weak dominance relation is usually very poor. In order to enrich this relation, the DM has to provide preference information which is used to construct a preference model (also called aggregation model or decision model) making the alternatives more comparable. This model can then be used in order to work out a recommendation with respect to one of the above mentioned questions.

The robust ordinal regression approach (ROR) extends the simple ordinal regression by taking into account not a single instance of the preference model compatible with DM's preference information, but the whole set of compatible instances of the preference model. In result of considering the whole set of compatible instances of the preference model, one gets two kinds of results with respect to each pair of alternatives $x , y \in A { : }$

• necessary preference relation $x \gtrsim ^ { N } y ,$ , if and only if x is at least as good as y according to all instances of the preference model compatible with the preference information,

• possible preference relation $x \gtrsim { P } y ,$ if and only if x is at least as good as y according to at least one instance of the preference model compatible with the preference information.

The necessary preference relation can be considered as robust with respect to the preference information. The robustness of the necessary preference relation refers to the fact that a given pair of alternatives compares in the same way whatever the instance of the preference model compatible with the preference information. Indeed, when no preference information is given, the necessary preference relation boils down to the dominance relation, and the possible preference relation is a complete relation. Every new item of the preference information, e.g., a pairwise comparison of some reference alternatives for which the dominance relation does not hold, is enriching the necessary preference relation and it is impoverishing the possible preference relation, so that they converge with the growth of the preference information. Such an approach gives also space for interactivity with the DM.

## 3. Dominance-based Rough Set Approach

Classical rough set approach to reasoning about data, proposed by Pawlak [32], cannot deal with the preference order in the value sets of condition and decision attributes.

To deal with ordinal classi<sup>fi</sup>cation and ranking problems, it was necessary to generalize the classical approach, taking into account preference orders and monotonic relationships between condition and decision attributes. This generalization, called Dominance-based Rough Set Approach (DRSA), has been introduced by Greco, Matarazzo and Słowiński [12,14,13,20,16,17,40].

The knowledge about ordinal evaluations of alternatives and monotonic relationships between these evaluations are typical for data concerning multiple criteria decision or decision under uncertainty, where the order of value sets of condition and decision attributes corresponds to increasing or decreasing preference. Criteria and the class assignment considered within DRSA are equivalent to condition attributes and the decision attribute, respectively, in the classical rough set approach. DRSA methodology aims at obtaining a representation of the DM's preferences in terms of easily understandable $" i f . . . , t h e n \ldots "$ decision rules, on the basis of some decision examples given by the DM.

3.1. DRSA applied on pairwise comparison tables for multiple criteria ranking problems

To apply DRSA to multiple criteria choice and ranking problems, it has been proposed in [14,13] a Pairwise Comparison Table (PCT), $\mathrm { i } . \mathsf { e } .$ . a decision table including pairs of alternatives for which multiple criteria evaluations and a comprehensive preference relation are known. PCT represents preference information provided by the DM in the form of decision examples (pairwise comparisons of alternatives).

Induction of decision rules is a computationally complex problem and many algorithms have been introduced to deal with it. ## 3.2. Application of DRSA on the results of ROR

As announced in the Introduction section, our aim is to apply DRSA on the PCT de<sup>fi</sup>ned by results of ROR. More precisely, the necessary preference relation $\succeq ^ { \mathbf { \bar { N } } }$ , and the possible preference relation $\succsim { P } ,$ de<sup>fi</sup>ne two pairwise comparison tables: $P C T ^ { N }$ and $P C T ^ { P } ,$ , respectively. In $P C T ^ { N } ,$ , the rows include pairs of alternatives from A, and the n columns include evaluations of the alternatives on particular criteria; the $( n + 1 )$ -th column informs if for a given pair of alternatives relation $\succsim$ holds or not. $P C T ^ { P }$ is de<sup>fi</sup>ned analogously, with the difference that the $( n + 1 )$ -th column concerns relation $\succsim { } ^ { P }$

Applying DRSA on $P C T ^ { N }$ and $P C T ^ { P }$ we will get explanation of the two relations resulting from ROR in terms of $^ { \ast } i f . . . ,$ then $\cdots ^ { n }$ decision rules. They clearly show conditions for existence of these two preference relations, expressed as minimal conjunction of elementary conditions concerning evaluations on particular criteria. These minimal conditions can be interpreted as arguments for an explanation and a justi<sup>fi</sup>cation of the decision. The rules are characterized by numerical measures, like support and con<sup>fi</sup>dence, but one can also know what pairs of alternatives from A support particular rules. This permits to start an interactive decision process with the DM. In fact, if the DM does not agree with the arguments suggested by the decision rules, he/she can look for some supporting pairs of alternatives causing this disagreement. If the DM is able to <sup>fi</sup>nd one or more such pairs, he/she can add inverse preference relations on them into the preference information considered by GRIP, and the procedure should start again, until the DM accepts as well the results of GRIP, as DRSA decision rules explaining them.

It is also interesting to observe the changes of these rules in result of the evolution of preference information at the input of ROR. In particular, one can read in rule terms the conditions of passing from possible to necessary preference relation for a given pair of alternatives. Of course, also these rules can be used in an interactive decision process with the DM. In fact, if the conditions of the decision rules explaining possible preference relations, that are not necessary, are accepted by the DM, these preference relations could be added as new preference information at the input of GRIP, and the procedure could restart computing the new necessary and possible preference relations, as well as the corresponding decision rules.

We will illustrate all these interesting issues in two examples considered in the next section.

## 5. Concluding remarks

In this paper, we propose to apply the Dominance-based Rough Set Approach (DRSA) on the results of other MCDA methods in order to obtain a simple, intuitive and convincing explanation of the recommendations. The need for the explanation appears when the user of an MCDA method needs some clear arguments to convince him(her)self and other stakeholders about a recommendation given by the method.

In this paper we considered a speci<sup>fi</sup>c MCDA methodology, being the Robust Ordinal Regression (ROR). It is characterized by consideration of all the instances of a given preference model (for example the monotonic additive value functions considered within the Multiple Attribute Utility Theory) compatible with the preference information supplied by the DM. Along this paper, we showed how the recommendations of ROR can be explained in terms of rules involving conditions on evaluation criteria. In this perspective, DRSA completes the decision aiding process started with ROR, providing very useful information. In fact, the decision rules represent a decision model which is transparent and easy to interpret for the DM and give arguments to justify and explain the decision. In a learning perspective, they can be the starting point for an interactive analysis and construction of a DM's preference model. The rules enable DM's understanding of the conditions for necessary and possible relations (being the typical output of ROR methodology), and provide useful information about the role of particular criteria or their subsets in the decision model. Encouraged by the results presented in this paper, we plan to use DRSA in junction with other MCDA methods in various decision con texts. In particular, we intend to apply DRSA to:

• ROR for sorting decision problems, i.e. assignment of alternatives to a set of prede<sup>fi</sup>ned and preference ordered classes $( \mathrm { U T A D I S } ^ { G M S } )$

• ROR for outranking methods (ELECTRE<sup>GKMS</sup> and PROMETHEE<sup>GKS</sup>),

• ROR for group decision methods,

• the case where necessary and possible preference relations are considered at different levels of credibility,

• the case where the criteria are hierarchically structured,

• the case where some evaluations on considered criteria are imprecise.

Moreover, we intend to conjugate our approach with the ROR idea of the representative value function [25]. In this case, the DM would get three kinds of preference relations: possible, necessary and the one given by the representative value function. All these relations would then be explained by DRSA decision rules.
