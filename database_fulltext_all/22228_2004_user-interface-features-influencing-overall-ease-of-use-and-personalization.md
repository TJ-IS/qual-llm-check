# User interface features influencing overall ease of use and personalization<sup>\$</sup>

Ram L. Kumar<sup>a,\*</sup>, Michael Alan Smith<sup>a,1</sup>, Snehamay Bannerjee<sup>b,2</sup>

<sup>a</sup>Business Information Systems and Operations Management, The Belk College of Business Administration,

Received 25 March 2002; received in revised form 22 November 2002; accepted 8 June 2003

## Abstract

This study examines user perceptions of gathering information on, locating, and buying compact discs through Web-based interfaces. A group of part-time MBA students in Hong Kong performed a specific set of tasks using the Web sites of two vendors of compact discs. The tasks were selected to be general enough to apply to a variety of on-line shopping situations. As they performed tasks, they answered questions regarding their perceptions of several user interface features as well as their perceptions of overall ease of use. User interface features associated with a perception of overall ease of use were identified, as were differences based on personal characteristics of respondents. Also, differences in perceptions of interface features that might be due to personal characteristics, such as age and sex, were identified. The methodology and results help identify user interface features that a designer should emphasize and features for which personalization is likely to be beneficial. <sup>#</sup> 2003 Elsevier B.V. All rights reserved.

Keywords: User interface design; Personalization; e-Business; On-line shopping; IS effectiveness

## 1. Introduction

Despite the recent demise of many Internet-based companies, the phenomenon of on-line shopping on the World Wide Web persists. Effective user interface design has been recognized as a critical success factor for Web sites, including those that support on-line shopping. Interface designers often, however, make intuitive and heuristic decisions about interface features. Some guidance is emerging as principles and practical guidelines but there remains the need to test the applicability of these general guidelines to specific and important domains, such as on-line shopping. The focus of this research is on user interface design for online shopping, which is an important component of the usability of a Web site, in addition to task-technology fit [16] and training methods [8]. We seek to identify specific user interface features that affect overall ease of use for common on-line shopping tasks, such as the tasks involved in shopping for compact discs (CDs).

It is now common for Web site designers to personalize the Web site for different user groups.

Schonberg et al. [24] recognize that, while there are several ways to personalize a Web site, it is not clear how and what to personalize to provide features that customers value. For example, features important to expert users may differ from those important to novices. We also seek to demonstrate a systematic analysis of user interface features that could be candidates for personalization, in the context of on-line shopping for CDs.

A survey was administered in a laboratory setting, involving subjects from an appropriate demographic group, to study the effect of different user interface features on perceptions of overall ease of use and to identify features that could be personalized. Subjects filled out questionnaires while completing typical on-line shopping tasks. Results show the effect of personal characteristics, such as age, sex, and computer training, on perceptions of different user interface features. Particular attention was paid to features that are suitable for personalization. Implications for interface designers and researchers are discussed.

## 2. Human computer interaction, Web usability and personalization

Researchers have proposed several theories of user interface design. Predictive theories link variables, such as task completion time or error rate, to other variables, such as time to complete a sub-task (e.g. locating a particular item on display) [6,15]. Explanatory theories describe the process by which users interact with computers and the factors that influence user percep tions of the human–computer interface. These theories often use taxonomies to compare and contrast human interaction with computers. Taxonomies could be based on characteristics of hardware or software, of the user, of the tasks that users are attempting to complete using the computer, or other factors [3,4,9,20]. Researchers have created models that describe the process of human computer interaction. Popular models include ‘‘Goals, Operators, Methods, and Selection rules’’ (GOMS) [5], and the Seven Stages of Action model [19]. MIS researchers have studied ‘‘perceived ease of use’’ and other factors, in the context of information technology adoption. Moore and Benbasat [17] discussed the development of several constructs to measure adoption of IT innovations. They have presented validated items for measuring overall ease of use that can be used for a variety of IT innovations.

The seven stages of action model in human–computer interaction (HCI) posited the following stages: (a) forming the goal, (b), forming the intention, (c) specifying the action, (d) executing the action, (e) perceiving the system state, (f) interpreting the system state, and (g) evaluating the outcome. Based on this model, Polson and Lewis [22] suggested that there are four critical points in HCI at which failures can occur: (1) users could form inadequate goals, (2) users might not find the correct interface features, (3) users may not know how to carry out a desired action, and (4) users might receive inadequate or inconsistent feedback.

Web usability studies can be classified into conceptual studies that suggest guidelines for Web interface designs, studies providing heuristics or checklists for Web site comparison, and empirical studies of Web user satisfaction. Zhang and Von Dran [25,26] developed a list of 44 core features that affect user satisfaction, based on an analysis of multiple studies and user input in the context of a Web site providing news service (CNN). These factors included user interface-related factors that can be manipulated by the designer, such as visual appearance, as well as factors that depend on the domain (news service), such as credibility and impartiality of the news source.

Language used is important because users and computer application designers often have different vocabularies [7]. Using terminology familiar to users, instead of computer jargon, allows them to get desired results in less time. Arrangement of information [23], including factors such as page length and number of links or branching factors, is very important in Web-page design. For example, a long page with no links is appealing only if the user is expected to read the entire text sequentially. Moving to the scroll bar and scrolling down is a boring task for most users. Hence, information that has to be presented should be split into screen size clusters wherever possible. For a highly visible home page, designers must consider the sequencing, clustering, and emphasis for objects, since the clustering of items implies relationships. Users expect the first item on a page to be important and they are likely to select it.

A complex software system can be more easily understood if the interface features remind the user of tools and systems with which they are already familiar [2]. This can be accomplished by the use of metaphors, such as the ‘‘shopping cart’’ used by many Web sites.

Size and contrast of letters influence perceptions of user interface design [18]. Important items should be emphasized by using an appropriate combination of large fonts, color highlights, and shading surrounding boxes.

Since reactions to interface features are expected to differ from user to user, the issue of personalization is important. Goals include increasing ease of use, increasing sales, creating a one on one shopping experience, improving customer service, and building a targeted community [10]. Web sites often present different interfaces to users based on data collected from or about him or her at the time of registration or by tracking activity. While personalization is an important means of competing [21], it makes the task of the user interface designer expensive and challenging. In addition to making design choices regarding factors such as size of letters, colors used, etc. the designer now must choose which features to personalize, and the basis (age, sex, etc.).

Research in personalization can be classified into three streams. The first examines different technologies, for example, cookies, push technologies (http:// www.marimba.com), dynamic personalization, and data mining. The second examines Web user interface design, including personalization [12]. It has been recognized [11] that successful user interface design should be based on users’ tasks and the context in which they are accomplished. The third examines the need to identify interface features for which users value personalization and how can we measure the effectiveness of Web sites [13,14].

In addition to relating specific user interface features to ease of use of a Web site, in the context of general on-line shopping tasks, this research contributes to research in personalization by illustrating how users’ reactions to interface features in a specific context can be used to identify candidate features for personalization.

## 3. Research design: models

Our objective was to determine the effect of user interface characteristics on user perceptions of overall ease of use for Web pages. This could assist researchers and designers interested in personalizing Web sites for on-line shopping. Since task and context are important, we studied a realistic e-commerce task in an on-line shopping context involving appropriate users. A survey administered in a laboratory setting is used to identify factors that affect user perceptions of overall ease of use and features for which personalization would likely affect user perceptions.

The dependent variable is ‘‘Overall Reaction’ (OVER\_REACT), which was measured by asking the participants to indicate their ‘‘overall reaction to using the Web site’’ on a five point Likert scale ranging from ‘‘very hard to use’’ to ‘‘very easy to use’’. This variable is similar to the overall ease of use construct discussed by Moore and Benbassat.

We selected 16 interface variables from those in previous HCI literature. These, in the opinion of the three researchers, influence feedback, the ability of users to find the correct interface feature, or their knowledge of how to carry out a desired action (theory of critical points at which HCI failures occur) for common on-line shopping tasks. Table 1 gives the interface features, how the participants were questioned about the features, and the scale for each. For example, language can influence the ease of finding features, knowing how to carry out a particular action, and quality of feedback.

All variables were measured by asking users their perceptions. Therefore, all variables represent user perceptions of factors, such as overall ease of use, amount of information on the screen, etc. With respect to each, we examined its relationship to the dependent variable (OVER\_REACT). The following hypotheses were tested using all data gathered:

Hypotheses relating OVER\_REACT to user interface features:

H1.1: Amount of information on the screen (AMT\_INFO) is not significantly related to overall reaction to using the Web site (OVER\_REACT).

H1.2: Arrangement of information on the screen (ARGMT\_INFO) is not significantly related to overall reaction to using the Web site (OVER\_REACT).

H1.16: Ease of Tracking Steps Completed (TRAK\_STEP) is not significantly related to overall reaction to using the Web site (OVER\_REACT).

## 4. Research design: data collection

Two sites, http://www.amazon.com and http:// www.cduniverse.com, were used to generalize findings. Each participant visited both sites. The order of visits was randomly assigned. At each site, participants completed the following set of on-line shopping tasks:

1. Find the pages describing each of two CDs: U2 ‘‘All That You Can’t Leave Behind’’ and Limp Bizkit ‘‘Significant Other’’.

2. Add these CDs to the shopping cart.

3. Read a review of a CD by Lauryn Hill.

4. Remove the U2 CD from the shopping cart.

5. Create a new account, even if the user has an old account.

6. Fill out billing information incorrectly. Submit it. Then return to correct the inputs.

7. Stop before confirming the order.

These tasks are general enough to model on-line shopping for a variety of products.

This experiment was conducted in summer 2001 using part-time MBA students in a university in Hong Kong. The respondents hold full-time executive or managerial positions. Their ages range from mid 20s to early 40s. One hundred twenty-three participants filled out paper survey forms as they completed the tasks involving the two Web sites. Of these, 108 visited Amazon first and 138 visited CD Universe first. The average time to complete the survey was 11.0 min with a standard deviation of 4.4. Participants are described in Table 2.

## 5. Results and discussion

We chose Amazon and CD Universe since the sites appeared similar in terms of user interface. A major difference was the respondents’ level of familiarity with each. There was a significant difference in perception of usability of both sites (Amazon mean ¼ 3:9, and standard deviation ¼ 0:6; CD Universe mean ¼ 3:07, and standard deviation ¼ 0:92, F ¼ 63, a ¼ 0:000). Even though the means were significantly different, the factors affecting overall ease of use were identical (the same factors were significantly correlated with overall perception of ease of use of each Web site). Our analysis was based on combining responses for both sites, since our intent was to study user interface design across Web sites.

Our first analysis indicates which user interface features are associated with overall of ease of use. ANOVA was used to determine whether the perception of overall ease of use varied with participants’ reactions to the various interface features. We chose ANOVA over regression, since we were not interested in predicting the value of our independent variable. Also, since many of the independent variables were correlated (see the correlation matrix in Appendix A), regression with multicollinearity typically does not yield correct significance values for individual variables. All user interface features, except for the perception of distraction due to banner advertisements, were significantly related (a ¼ 0:05) to overall perception of ease of use. Correlation analysis was consistent with ANOVA results. We tested whether these results varied with Web site (Amazon or CD Universe) by analyzing the data for each site separately. All the user interface variables, with the exception of banner advertisements, were significantly correlated to overall ease of use for both. These results identify features on which, in the absence of information about user characteristics, interface designers should focus.

While the results of the first analysis identified important user interface features, they do not indicate the effect of personal (demographic) characteristics on reactions to the same features. Hence, for the second analysis, the data set was examined using the coded values of personal characteristics of respondents to partition the sample. For example, the age of each respondent was coded as age $< 3 0 , 3 0 \leq \mathrm { a g e } < 3 5 .$ , or age  35. This divided the data set into three subgroups and the ANOVA was performed on each sub-group to study hypotheses H1.1–H1.16. Similar analyses were conducted for different personal (demographic) characteristics (Table 3). These were chosen to be illustrative of variables that could be collected at the time of user registration and could serve as the basis for personalization. For example, undergraduate major is used as a surrogate for profession (engineer etc.).

The analysis indicates that many of the sub-groups react differently to the interface features. Significant (a ¼ 0:05) results are displayed in Tables 4 and 5. Table 4 illustrates that AMT\_INFO is a significant influence on overall perception of ease of use by the following types of respondents: (a) less than 30 years old, (b) do not access the Internet everyday, (c) majored in something other than engineering or non-IS business as an undergraduate, (d) had less than 15 years computer experience, (e) had not purchased CDs from Amazon in the past.

Combinations (e.g. respondents whose age is less than 30 and undergraduate major is engineering) were not analyzed due to the small sample sizes for those cases. Such information could be used by a user interface designer who knows something about the personal characteristics of the users of a particular Web site. For example, in the case of a site for selling CDs targeted at the under 30 s, the information displayed on the screen (AMT-INFO, ARGMT\_INFO, CONTRAST, and FIND\_REV) is a candidate for customization.

It is interesting that respondents who accessed their computers every day associate a different set of factors (CORR\_CLR, DEL\_CD, FIND\_REV, PRICE\_CLR, SEARCH\_CD, SHOP\_CART) with overall ease of use of the interface than respondents who did not access their computers every day. Our-third analysis tested hypotheses relating reactions to interface features and user personal characteristics. ANOVA was performed to test the effect of each coded personal characteristic on each of the sixteen user interface features. Significant results are shown in Table 6. For those analyses for which the equality of variance assumption was violated, non-parametric tests were run; none of these indicated significant differences.

There is a significant age-based difference in the scores assigned to CORRECT\_INPUT but to any other user interface features. Users in each of the three age groups, therefore, had significantly different perceptions of whether instructions for correcting wrong inputs were clear but did not differ significantly in their perception of the other user interface features.

Since CORRECT\_INPUT influences perceptions of ease of use of the interface (based on the second analysis) for users under 30 and since age groups differed in their perceptions of what constitutes ease of correcting wrong inputs, it is important to determine a good way to implement CORRECT\_INPUT for users under 30.

Since CORRECT\_INPUT was not significant in influencing perceptions of ease of use for other age sub-groups, there is no need to personalize the user interface based on CORRECT\_INPUT for different age sub-groups. ## 6. Conclusions

This paper contributes to the literature on Web interface design by empirically identifying perceived relationships between user interface features and overall ease of use for a set of common on-line shopping tasks for products such as CDs. It also illustrates that demographic sub-groups, based on factors such as age, sex, and amount of computer experience, differed in their perceptions of user interface factors significantly related to overall ease of use. Hence, user interface designers may want to identify features significantly related to overall ease of use for the target group.

User perceptions of the significance of various interface factors in affecting overall ease of use differ significantly with personal characteristics such as age, sex, and amount of computer experience. Hence, user interface designers might want to analyze which user interface features to personalize. The type of analysis: first identifying user interface factors that are significantly related to overall ease of use for the target demographic of the Web site, then analyzing differences among sub-groups in perceptions of each significant user interface feature can help indicate which user interface features to personalize. Techniques such as protocol analysis [1] could be used to gain a better understanding of user perceptions of particular interface features.

Although this research examined CD purchases in Hong-Kong, the results could be generalized to interface design of other digital products for which shoppers complete similar tasks during on-line shopping.
