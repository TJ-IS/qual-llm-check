# The Value of Information

Catherine Griffiths and Peter Clark, Imperial College

In an exercise to suggest guidelines by which the effectiveness of IT investments can be judged, or at least compared, we need to consider the question 'What is the value of (an item) of information?'

We have been drawn to this question by two paths:

1. Can the production of information be usefully compared to manufacturing. This entails deriving an end-user value (price).

2. How well does an investment in IT pay back in terms of increasing the value of the information provided.

At one point we thought that we had a simple problem to solve along the lines of:

The only use for information is for decision making, therefore the value of the decision gives the value of information input to it.

Fortunately, we did not spend any time in solving this problem before deciding that information had many more uses which, although decision-based, had more value for other purposes.

We now think it valuable to deal with the following questions

1. How is information classified?

2. How can uses of information be classified?

3. How can uses be evaluated (to determine value of input information)?

4. Does information itself (rather than the knowledge of its existence) have any value before it is applied?

5. How is the application of information evaluated? (cf. presentation, accuracy, timing).

## 4. Does information itself have any value without application?

Obviously the knowledge that a fact is known has value (if only to save re-searching it), but is information intrinsically valuable without applying it? There might be a value on a personal level which might explain the popularity of puzzle books. Perhaps 'pure' research results come in the same category, though we suspect that however 'pure' the research, the funder expects some good to come of it even if the researcher is indifferent to its application.

5. How is the application of information evaluated?

This covers the leverage used on the raw information, and the trade-off between speed of production and accuracy/completeness. It may be an iterative, honing and guiding process (especially in decisions).
