## 1. 核心大问题

> 编码智能体在信息操纵环境下如何保持任务绩效与安全？本文以攻防生命周期三个阶段回答：如何实时识别攻击（检测算法，研究一）、如何系统生成攻击并据此鲁棒化而不支付自主性税（攻击仿真+鲁棒化算法，研究二）、如何定位被操纵的上下文单元并净化恢复（归因与净化算法，研究三）。

## 2. 三个研究设计（全部为算法开发）

### 研究一（检测算法）：AgentShield-Detect——编码智能体对抗攻击的实时检测

- **定位**：系列的切入点——先识别威胁，才能防御与处置（对应 AI 抵制"子研究一是研究切入点"）；检测是 IS 最正统的主题（欺诈网站/欺诈评论/社交机器人谱系）。
- **研究问题**：如何从输入文本、行为轨迹与工具调用结构中实时识别对抗攻击，且低误报、自身不被绕过？
- **方法（算法开发）**：三通道特征（文本意图、行为序列、工具调用结构）→ 无标签轨迹自编码器 + agent-工具-文件异构图 GNN → 逐时间步攻击概率；以研究二攻击库对抗训练，报告对抗绕过率。
- **数据**：SWE-bench Verified 正常轨迹 + AgentDojo / MalSkillBench / 研究二攻击库（全部公开）。
- **指标**：P/R/F1、AUC、检测延迟、误报率、对抗绕过率。
- **锚点**：#25（第三方请求结构）、#28（情感+显式方面特征工程）、#30（行为+文本融合）、#32（众包弱标签）、#11（外部验证信号）。
- **输出**：实时检测器 + 门控信号（研究二输入）+ 报警轨迹（研究三输入）。
- **拟投**：DSS / JAIS。

### 研究二（攻击仿真+鲁棒化算法）：AgentDefense-Robust（含 AttackRL-Agent）——RADAR 完整落地编码智能体

- **定位**：研究一的延续与深化——把 RADAR 范式（RL 攻击仿真 + RL-RO）完整迁移到编码智能体，攻击不再单独成篇而是作为框架组件与贡献 2。
- **研究问题**：如何系统生成多样化、可迁移的自适应对抗攻击并据此鲁棒化，而不支付自主性税？
- **方法（算法开发）**：双组件框架——AttackRL-Agent（对抗 MDP + PPO 生成式攻击策略，覆盖 issue/文件/工具三通道，奖励=危害信号−隐蔽性惩罚）+ RL-RO 训练器（对抗重训练/DPO/minimax，训练数据=攻击序列）+ 研究一检测器运行时门控。
- **数据**：SWE-bench Verified（良性）+ AgentDojo（攻击）+ 对比 SWExploit、FCV、RLbreaker。
- **指标**：ASR、Robust Resolve Rate、RAUC、Autonomy Tax 检验、成本。
- **锚点**：#49 RADAR（r-VAC + RL-RO）、#26 ARText（对抗重训练 + 性能-扰动曲线）。
- **输出**：自适应攻击库（研究一对抗训练数据 + 研究三 ground truth）+ 鲁棒化 agent + 门控闭环。
- **拟投**：JMIS / MISQ（CS 侧并行 IEEE S&P / CCS）。

### 研究三（归因与净化算法）：AgentTrace——上下文操纵归因与净化

- **定位**：研究一与研究二的横向延伸——检测报警之后、恢复之前的关键环节（NIST 响应与恢复）；IS 文献空白（攻防综述确认无归因研究；Shapley 综述确认代码级上下文归因缺失）。
- **研究问题**：如何自动定位被操纵的上下文单元（issue 段落、仓库文件、工具描述、技能包），并给出低误净化的净化方案与恢复验证？
- **方法（算法开发）**：归因引擎（Shapley 近似 KNN-Shapley/IPSS + 行为差分）估计每个上下文单元对恶意行为信号的贡献 → 单元级风险排序；risk-utility 掩蔽决策（#50 式）生成净化方案 → 净化后重放任务验证恢复。
- **数据**：研究二攻击库（带 ground truth 操纵位置）+ SWE-bench Verified 正常轨迹。
- **指标**：定位 top-k 命中率、定位 F1、净化后任务恢复率、误净化率、计算开销；基线=全量回滚、随机定位、梯度归因。
- **锚点**：#50（Shapley 特征归因与掩蔽，MISQ 2026）、#21（事件属性归因）、#11（外部验证信号）、#26（性能-扰动曲线思想）。
- **输出**：单元级归因报告 + 净化器 + 脆弱点反馈（研究一可解释输出、研究二加固依据）。
- **拟投**：DSS / JAIS。

### 组合验证（末章）

检测→防御→归因端到端闭环：研究一检测器 → 研究二鲁棒化+门控 → 研究三归因净化，在同一基准套件上报告端到端收益（ASR 从基线降至 X、检测率 Y、定位命中率 Z、任务恢复率 W）。

## 5. 与 RADAR 的关系

- 研究二 = RADAR 的完整落地：r-VAC 攻击器 → AttackRL-Agent（编码智能体动作空间）；RL-RO → 对抗重训练/DPO/minimax；并补 RADAR 未报告的良性效用（Robust Resolve Rate + Autonomy Tax 检验）。
- 研究一 = RADAR 没有的检测阶段：把 IS 检测谱系系统迁移到编码智能体，并为研究二提供运行时门控。
- 研究三 = RADAR 隐含未展开的"洞察与处置"：RADAR 声称攻击序列"provides actionable insights into the vulnerabilities"，本研究把这一洞见操作化为"单元级归因 + 净化恢复"算法。
- 叙事定位：RADAR 是 IS 攻防研究开创点，本论文将其发展为覆盖"感知—预防—响应"的完整攻防算法体系。
