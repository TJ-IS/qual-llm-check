- 目的：把三研究落到可执行层面。所有数字为保守估算（2026-08），以实际版本与报价为准。

## 二、要多少算力（三档方案）

### 方案 A：全 API（最便宜，起步推荐，预算 $1.5k–3k，0 张 GPU）
- agent 基底用开源 API（DeepSeek-V3 级，约 $0.4/M token 混合价；单任务约 40k token → $0.028–0.16/任务）。
- 总任务执行量估算（见第三节）：约 3.5–4.5 万次任务执行 × 平均 $0.03–0.07 ≈ **$1.5k–3k**。
- 检测器/归因模型是小模型（GNN、自编码器、文本编码器），用 Kaggle/Colab 免费额度或 1 张 24G 卡跑 1–2 天即可。
- 缺点：PPO 攻击训练迭代慢（每次查询 API 有延迟），可控但需排队脚本。

### 方案 B：本地微调 + API 重放（推荐，预算 $3k–6k，1 台 2×4090 或云 1×A100-80G）
- 本地 2×4090（24G×2，二手约 ¥2.5–3 万或云租 $0.6–1/h）：
  - 研究一：检测器训练 1–2 天；
  - 研究二：攻击策略与鲁棒化 LoRA 微调（7B/14B，2–4 天/模型，共约 2 周）；
  - 研究三：无大模型训练，只需推理（归因重放）。
- 重放与评估全部走 API（约 $1.5k–2.5k）。
- 时间：三研究串行约 10–12 个月（含实验迭代），并行 6–8 个月。

### 方案 C：全本地（可控但贵，预算 $15k–30k 或设备 ¥40–60 万，4×A100-80G 或 4×H100）
- 本地跑 70B 模型推理约 25–35 tok/s/卡：单任务约 20–25 分钟，4.5 万任务单卡约 687 天 → 4 卡并行约 5–6 个月（只算推理）。
- 若改用 32B 模型（Qwen2.5-Coder-32B）速度约 2–3 倍，可压到 2–3 个月。
- 云租 4×A100 约 $4–8/h：跑 3 个月约 $9k–17k（不含训练时间重叠）。

**推荐：方案 B**（本地 2×4090 微调 + DeepSeek API 重放），总预算约 $4k–6k、周期约一年内完成三个研究的实验。

## 三、实施步骤（6 步，含每步成本与耗时）

### 第 0 步：搭环境（1 周，约 $50）
- OpenHands（开源 scaffold，支持 SWE-bench 评估协议）+ Docker 沙箱（每实例独立容器）；
- 接 API（DeepSeek）或本地 vLLM（32B/70B）；
- 先跑通 SWE-bench Verified 5 个实例的评估脚本（resolve 判定用官方测试）。

### 第 1 步：正常轨迹（研究一数据，2–3 周，API 约 $300–600）
- 200 实例子集 × 每实例 1 次正常运行 = 200 次任务（SWE-bench 官方协议，含测试执行）；
- 可选：直接复用 SWE-Gym 公开轨迹（省掉这一步的大部分），只自跑 50 条补充；
- 产出：正常轨迹日志（文本/工具调用/文件操作），用于检测器训练与误净化评估。

### 第 2 步：训练检测器（研究一，2–3 周，本地 1–2 天算力 + 迭代）
- 三通道特征 → 自编码器 + GNN → p_t；先无标签训练，再用攻击库（第 4 步）对抗训练；
- 注意：研究一需要研究二的攻击库做对抗训练 → **实验顺序是：先跑通攻击器雏形（第 3 步的小规模版）再回头训练检测器**，或者先用公开攻击（AgentDojo/MalSkillBench）训练检测器、攻击库出来后做对抗再训练（推荐后者，不阻塞）。
- 产出：检测器 v1（公开攻击训练）→ v2（对抗训练）。

### 第 3 步：训练攻击器（研究二，最耗时，4–8 周，API $800–1,500）
- 对抗 MDP + PPO：环境交互是成本大头。预算：PPO 100–200 轮 × 每轮 32 实例 ≈ 3,200–6,400 次任务执行；
- 技巧：先在小环境（20 个 SWE-bench 实例）验证奖励信号（危害判定器用 CodeQL 规则 + LLM-as-judge），再扩大到 100–200 实例；
- 产出：攻击策略 + 300–500 攻击库（每攻击实例另付 1 次执行，约 $100–200）。

### 第 4 步：鲁棒化训练（研究二，3–4 周，本地 2–4 天算力 + API $300–500）
- 对抗重训练 + DPO（LoRA 微调 7B/14B，本地 2×4090 各 2–3 天）；
- RL minimax 简化：2–3 轮攻防交替（攻击器 vs 防御器），每轮 32–64 实例；
- 评估矩阵：{攻击库, SWExploit, FCV, RLbreaker} × {无防御, 纯规则, 训练防御, 训练+门控} × 3 种子 ≈ 200 实例 × 16 配置 × 3 ≈ 9,600 次任务执行（API 约 $300–700）。

### 第 5 步：归因与净化实验（研究三，4–6 周，API $1,000–2,000）
- 用第 3 步攻击库（300–500 实例，ground truth 已知）+ 200 正常轨迹；
- 每攻击实例：Top-K=20 预筛（免费，检测器打分）→ 20 次对照重放 + 10–20 次 Shapley 校准重放 ≈ 30–50 次任务执行；
- 500 实例 × 40 ≈ 20,000 次任务执行（API 约 $600–1,400）；
- 净化后恢复验证：每实例再 1–3 次重放（净化后上下文）≈ 1,500 次（$50–150）；
- 基线：全量回滚（每实例 1 次）、随机定位（10 个实例 × 20 次）。

### 第 6 步：全量验证 + 写作（2–3 个月，API $500–1,000）
- SWE-bench 500 全量 × 精选配置（3–5 个）× 1 种子 ≈ 2,000–2,500 次任务执行；
- 端到端组合验证（检测→防御→归因闭环）≈ 500–1,000 次。

## 四、总账

| 项 | 方案 A（全 API） | 方案 B（推荐：本地微调+API 重放） | 方案 C（全本地 4×A100） |
|---|---|---|---|
| GPU | 0–1×24G | 2×4090（或云 1×A100） | 4×A100/H100 |
| 现金预算 | $1.5k–3k | $4k–6k（含设备或云租） | $15k–30k（云租）或设备 ¥40–60 万 |
| 任务执行总量 | 约 3.5–4.5 万次 | 同左（重放走 API） | 同左（本地） |
| 周期 | 12–15 个月 | 10–12 个月 | 6–9 个月（32B 模型） |
| 主要风险 | PPO 迭代慢、API 限额 | 需维护本地环境 | 设备投入大、推理慢于旗舰 API |

关键假设（可调）：单任务平均 40k token；DeepSeek 级 API 混合价约 $0.4/M token；旗舰 API 仅校准用。若换更强基底模型（GPT-5 级），任务成本 ×10–50，预算按比例上调，不建议作为主方案。

## 五、可以先做的零成本验证（1–2 周内）
1. 用 5–10 个 SWE-bench 实例跑通 OpenHands 评估协议（验证环境）；
2. 用 AgentDojo 公开攻击复现 2–3 个注入攻击（验证沙箱与危害判定）；
3. 检测器雏形在公开攻击样本上出第一版 P/R 数字（无需攻击库）；
4. 归因雏形：对 1 个攻击实例手跑"单元移除→重放"流程，验证行为差分信号是否区分操纵单元（验证核心假设，成本 <$50）。
