# 重要性论证与理论选择逆向分析：导师范式与 IS 安全算法多范式对照

## 0. 文档目的与结论先行

本文不是新的论文草稿，而是后续重构三项研究的判定依据。分析对象包括肖老师的两篇理论驱动深度学习研究，以及多组具有代表性的 IS 安全算法、检测、优化与决策研究。所有判断均回到本地全文原文，而不是依据题名、摘要或二手总结。

最重要的结论是：**权威 IS 算法论文不存在唯一的“理论写法”**。至少有三条成熟而合法的逻辑链。

1. **机制生成型**：情境中的独特机制使既有方法的某项假设失效；领域理论把该机制变成可测量的中间构件；构件进一步改变表示、网络结构、目标函数与评价。肖老师的两篇研究属于此型。
2. **规范问题型**：安全或决策理论直接定义行动者、状态、目标、约束与损失，算法是该规范问题的求解器。RADAR、动态入侵防御、Shapley 数据掩蔽属于此型。
3. **问题结构型**：论文不强求一个行为理论，而由真实运营矛盾、数据结构、威胁面或计算复杂性推出工件。主动威胁情报、敏感事务数据隐藏、第三方请求结构检测属于此型。

三种范式的共同底线不是“必须有几个理论”，而是以下可追踪链条：

> 重要现象 → 情境特有机制/结构 → 既有假设失效 → 可计算设计要求 → 工件改变 → 机制与结果双重评价。

据此，三项研究首先应被视为一个受公开数据约束的连续攻防计划，而不是三个可任意重构的独立问题。研究一保留并强化面向 coding-agent 情境的 AttackRL：它不仅生成攻击，还必须交付研究二可用的任务前静态快照与操纵单元真值，以及研究三可用的完整执行轨迹与时间步危害真值。研究二保留静态预测，核心问题改写为：攻击者如何把恶意目的潜藏在看似正常、功能相关的问题、代码和工具信息中，以及防御者能否在执行前利用异构静态信号定位这种潜藏操纵。研究三利用只有 agent 执行后才出现的计划、调用、观察和环境变化进行流式检测与门控，其必要性来自 coding agent 的运行轨迹，而不是来自对研究二的否定。

这里新增一条比“解释上是否贴切”更严格的原则：**理论必须适合在本研究中被使用**。一个理论即使能够宽泛描述现象，只要其核心构念需要另做质性研究才能发现、缺少公开数据中的稳定测量、依赖研究者主观命名，或者无法无歧义地改变算法，就不应成为算法论文的核心理论。按这一原则，技术可供性被排除为研究一的核心理论候选。

### 1.2 逆向分析维度

每篇论文按十个问题分析：

1. 论文先证明什么现实后果，而不是先宣布什么文献空白？
2. 情境对象相对既有对象有何结构差异？
3. 哪一项既有方法假设因此失效？
4. 理论的行动者、分析层次和因果机制是什么？
5. 理论生成了哪些可观测或可计算对象？
6. 它实际改变了输入、表示、架构、目标、约束或评价中的哪一项？
7. 论文如何评价理论机制，而不只评价最终准确率？
8. 该写法能否迁移到编码智能体安全，迁移边界是什么？
9. 核心构念是否已经存在于可获得数据，还是必须先开展一项情境化发现与量表/编码开发研究？
10. 理论带来的数据、标注、估计和验证负担，是否与本项目资源及算法论文篇幅相称？

## 2. 肖老师两篇研究：机制生成型范式

### 2.1 DSDL：动态期望—体验—失验—满意度进入网络内部

论文没有以“语音数据还没有被某模型处理”作为主要理由，而是先确立新商业模式中的实际决策问题：实时语音互动蕴含购买意向，但企业既缺少客户画像，又必须在交互尚未结束时识别动态响应。既有方法依赖预先存在的个人信息、静态量化特征或交互后的总体判断，因此与“无画像、动态、多视图、需早期预测”的情境不匹配。

期望失验理论不是装饰性解释，而是生成四类计算对象：个性化动态期望、文本与音频共同构成的实际体验、二者差异形成的失验，以及累积满意度。它们进一步改变：

- 表示：产品属性上的个性化期望与逐轮体验，而非整段语音的通用嵌入；
- 架构：文本—音频交错建模和动态累积模块；
- 目标：购买响应预测同时受黑箱表示和理论中间状态驱动；
- 评价：除预测性能外，还检查累计满意度、个性化偏好及关键属性解释。

可迁移原则：理论必须产出“网络不使用理论就不会存在”的中间状态。不可机械迁移之处是，安全问题未必存在一个成熟社会理论能精确生成神经构件。

还需注意，两篇导师论文能够采用机制生成型范式，是因为理论构念可由现有语音、文本、评论、产品属性和时间数据直接构造，并可在同一实证设计中检验。若一个安全理论要求研究者先访谈开发团队、归纳情境化构念、建立编码表并完成构念效度检验，它就不是同等成本的迁移；这会把一篇算法论文扩展成“先做构念发现、再做算法开发”的两项研究。导师范式应学习的是理论—测量—算法的闭环，而不是强求所有研究都先找到一个宏大机制理论。

### 2.2 ACAA：注意不是通用网络权重，而是客户真实处理信息的过程

论文从一个容易被忽略的矛盾出发：平台提供的评论不等于客户实际处理的评论；简单的评论级数量指标无法适应评论信息质量、客户需求和产品属性的演化；通用的相似度注意机制又可能让语义重复评论获得高权重，与客户需要多样信息的机制相悖。

客户注意过程与粒度被拆为评论集合、子集、单条评论和评论元素四层，并产生及时性、语义多样性、投票认知和变化的多模态互动四类指标。这些指标分别改变时间权重、相容性函数、投票加权与模态融合粒度。论文由此证明的不是“加一个 attention 层”，而是“客户注意机制如何改变深度学习中的注意计算”。

可迁移原则：若理论声称解释注意、信任、机会或韧性，就必须改变相应的计算粒度和关系，而不能只在引言中提供名词。

### 2.3 两篇导师论文的共同骨架

| 环节 | 共同做法 | 对本项目的约束 |
|---|---|---|
| 重要性 | 先说明新情境中的组织决策价值 | 先说明编码智能体如何改变软件组织的安全暴露与后果 |
| 特殊性 | 明确无画像、动态、多模态、信息处理粒度等结构差异 | 不能只写“更自主”；要说明混合信任上下文、工具权限、序贯执行和持久代码产物 |
| 假设失效 | 指出静态特征、全量评论、通用注意等具体假设 | 指出文本分类、功能正确性、一次性输入或静态规则的具体失效点 |
| 理论作用 | 生成动态满意度、注意指标等计算对象 | 理论必须生成攻击过程、犯罪机会、运行可靠性等可观测对象 |
| 算法作用 | 理论改变网络结构和目标 | 理论至少改变表示、目标、约束、门控或评价之一 |
| 机制评价 | 评价中间状态与表示质量 | 三项研究均需设置机制消融和中间状态效度检验 |

## 3. IS 安全算法论文：多种合法范式

### 3.1 RADAR：规范理论直接定义攻防优化问题

**重要性链**是：网络攻击规模和严重性上升 → AI 防御代理已成为大规模安全运营的必要组成 → 对抗者可通过一系列离散修改规避检测 → 组织对 AI 防御的依赖与其对抗脆弱性并存。论文用可执行文件签名、校验和、数据包编码和分片等具体序列说明问题，而非只诉诸“缺少研究”。

**理论链**是：鲁棒优化将防御学习定义为对手与防御者的内外层优化；有效鲁棒防御要求有效攻击仿真。强化学习则适配离散、序贯、黑盒攻击，并使学习到的轨迹成为攻击策略知识。理论直接定义行动者、状态、动作、奖励和两阶段训练。

**迁移边界**：RADAR 适用于“攻击仿真是鲁棒训练内层问题”的研究。现有研究一几乎沿用同一条理论链，只把恶意软件输入换成编码智能体输入，容易被判断为情境替换。若研究一主要交付攻击生成与威胁建模，而不是鲁棒防御代理，就没有必要再次把鲁棒优化置于中心。

### 3.2 ARText：行为理论给出元需求，技术理论负责算法细节

ARText 先说明预测分析已嵌入关键组织决策，但受决策影响的主体会操纵输入；经验风险最小化默认训练与部署数据同分布，这一假设在策略性输入下失效。技术威胁规避理论只被用于提出两个高层需求：威胁评估对应鲁棒性评价，威胁应对对应鲁棒性增强。具体的性能扰动度量、集成多样化和对抗重训则来自统计学习与安全方法。

启示有二。第一，IS 安全工件可以使用行为理论组织设计要求，无需让行为理论解释每个神经元。第二，TTAT 在原文中并没有推出动作门控阈值、三档处置或误报上限。现有研究三用 TTAT 直接解释自动门控，超出了原论文的理论作用范围。

### 3.3 DTL-EL：无核心行为理论也可以是强 IS 计算设计

论文从主动威胁情报的运营困难出发：黑客论坛中的漏洞代码数量大、噪声高且缺少标签，人工标注形成负担，阻碍战术、运营和战略情报。它识别出两个数据结构：目标域论坛噪声大且未标注；外部漏洞仓库和暗网市场拥有可迁移的元数据或标签；漏洞代码还具有长依赖。

由此直接推出深度迁移学习、基于标题的隐状态预初始化和自注意机制。论文的理论基础是计算设计科学、迁移学习与数据特征的匹配，而非强行加入社会行为理论。

启示：如果一个 coding-agent 安全问题的关键贡献来自混合代码—指令对象、真实执行验证或序贯工具轨迹，完全可以走“情境数据结构＋方法基础”的路径。理论缺位不可取，但“没有单一社会理论”不等于理论不足。

### 3.4 Wolf of Wall Street：理论决定证据集合，并主动排除不适配理论

信息操纵理论用于预测不诚实主体的自我披露会不同；担保理论用于预测更难由本人操纵、经外部确认的信息会增加识别价值。理论因此决定由低到高的验证信息集合和分类器比较，而不是决定通用网络架构。

更重要的是，论文明确排除了假设重复发送者—接收者互动的人际欺骗理论，因为 LinkedIn 资料是静态独白。这个排除动作体现了高水平理论选择：先核对行动者、沟通关系和交互形式，再谈理论新颖性。

对现有研究三的直接诊断是：编码智能体日志通常不是攻击者向防御者的自我披露；调用图也不天然是“外部担保”。除非能够证明攻击者是三个通道共同的信息发送者，且验证级别由可操纵性严格排序，否则 IMT 与担保理论不应作为核心理论。

### 3.5 敏感事务数据隐藏：问题结构和计算复杂性推出算法

2020 年研究的真实矛盾是：细粒度事务数据对供应链伙伴有价值，但数据所有者担心局部门店与组织层面的敏感模式泄露。多分区带来本地与全局约束，精确方法的变量与约束规模爆炸。分布式分解和拉格朗日松弛的直觉由问题结构产生，评价同时覆盖可扩展性、隐私保护与推荐效用。

2022 年研究进一步把敏感关联规则隐藏表述为 NP-hard 问题，先给出非线性整数规划，再分解为事务消毒和准确率最大化，继而线性化、删减冗余约束并扩展到一亿条事务。它没有借行为理论来证明每个优化变量。

启示：预算化预置防御若确实有新的组合结构，应先证明 coding-agent 单元、动作、依赖和跨层约束如何改变问题，而不是把通用背包问题包装为“情境新颖”。

### 3.6 Shapley 数据掩蔽：理论/原则改变分析单位

该研究的重要性不只是隐私泄露，而是去标识和仅掩蔽机密字段仍无法阻止推断泄露；现有风险—效用分析停留在数据集层面，而真正的干预发生在特征层面。Shapley 值为每个特征分别分配披露风险和数据效用边际贡献，使分析单位由数据集下沉到特征，并形成风险—效用前沿。

对研究二的启示是，单元级风险必须有原则地说明“为什么风险可以归属于该单元”。但直接照搬 Shapley 也有风险：其合作博弈边际贡献假设未必适合序贯、相互依赖的 agent 攻击机会，而且会再次形成对单篇文章的结构模仿。

### 3.7 社交机器人检测：理论给出“哪些众包证据更可信”

论文先发现现有机器人检测只使用机器人自身内容和行为，忽略真实用户的回复；但众包反应并非同等可信。言语行为理论区分断言、承诺、宣告、指令和表达，因而给出对用户回复意图与确定性进行分类、加权的逻辑。理论的行动者、数据对象和计算作用完全一致：人类回复者发出言语行为，回复文本是可观测证据，类别影响众包标签权重。

启示：一个理论若只对某个通道有效，可以诚实地用于特征加权，而不必声称解释整个工件。研究三也可以用高可靠性理论规定运行证据要求，同时让控制理论规定门控动态。

### 3.8 第三方请求结构检测：难操纵的后台结构可胜过表面内容

该研究不使用核心社会理论。它指出内容、黑名单与投诉存在易伪装、滞后和类别局限；第三方请求网络是网站业务模式的结构性产物，比表面内容更难随意伪装，并能跨钓鱼、假新闻和欺诈电商类别提供通用证据。

启示：研究三真正有价值的不是“多三个通道”，而是证明哪些运行结构是完成危害动作必经、比表面文本更难同时伪装。只有具有这种生成约束的结构信号，才类似第三方请求网络，而不是任意添加的图特征。

### 3.9 动态入侵防御：检测与反应必须联合、随时间优化

Yue 与 Cakanyildirim 将 IDS/IPS 的问题表述为动态系统：配置越敏感，检测更多攻击也产生更多误报；全部人工调查形成积压和延迟；全部自动阻断又产生错误拒绝。最优控制模型联合选择检测工作点与主动/反应式处置比例，状态变量包括告警队列中的良性/恶性事件、错误拒绝和漏检事件。

这比 TTAT 更直接地支持研究三的动作门控。它说明门控不是三个静态阈值，而是由事件到达率、告警积压、调查能力、误报成本、漏报损害和时间共同决定的动态决策。

### 3.10 安全控制最优分配：可用性来自参数—决策闭环，但形成研究二的直接先例

Zhang、Chari 与 Agrawal（2018）没有为安全控制分配强加行为理论，而是从组织已经大量投资、但控制投入未按风险与业务影响排列这一决策失灵出发。其确定性与随机优化模型直接以资产/应用、攻击类别、保护等级、控制成本、损失和突破概率为参数，目标是配置具体控制并最小化突破损失与控制成本。论文还正面处理参数可用性：突破概率难以获得，问卷估计有误差，因此用随机模型吸收估计不确定性。

这篇论文对本项目有双重意义。一方面，它展示了“可使用理论”的一个强版本：每个构念都有参数位置、估计来源、误差处理和决策后果，无需先发现情境化社会构念。另一方面，它是研究二不可回避的直接先例。若研究二仍只是“预测风险概率—在预算下分配输入过滤、沙箱和监控”，新颖性不足。编码智能体情境必须实质改变决策问题，例如把任务所需能力、最小授权、跨单元依赖、工具副作用、审批时点和正常任务可完成性共同纳入，而不是只把 IT 资产换成问题段落/仓库文件。

### 3.11 数字化高可靠组织：算法不能被称为正念，分层社会技术安排才是机制

Salovaara、Lyytinen 与 Penttinen（2019）研究的正是计算机安全公司的纯数字运营。其重要性链非常贴近本项目：数字威胁具有规模、速度、异质性和可变性，迫使组织依赖算法；但算法受 frame problem 限制，无法可靠识别开发者认知框架之外的状态，自动化因此同时创造效率与“mindlessness”。论文通过理论生成型案例研究发现，高可靠不是由一个更聪明的自动检测器单独产生，而来自分层配置：核心数字操作高速处理已知情况，人类情境敏感操作监视、解释例外、改进规则并应对未见威胁；集体正念是整个社会技术系统的涌现属性。

这纠正了对研究三的过度理论化。研究三不能声称 agent 或门控算法“具有集体正念”，也不能把五项正念特征直接翻译成五个模型特征。该理论可在两个条件下提供高层设计要求：工件明确区分已知事件的自动快速路径与不确定事件的人类升级路径；评价同时覆盖自动处理规模、未见攻击识别、误报/漏报、升级负荷和规则更新。门控状态、阈值和控制策略仍应由动态入侵防御、反馈控制或可审计的决策模型给出。

### 3.12 SIGHT：容易伪造的表面信号使早期筛查失灵，替代信号恢复诊断力

Twyman、Pentland 与 Spitzley（2020）把大规模职位申请概括为一个“破损的信号系统”：申请者能够低成本伪造看似合格的表面信号，而招聘方逐一核验的成本过高。信号理论没有停留在背景，而是生成三项系统要求：减少对容易操纵的自报信号的依赖；自动收集额外且较难操纵的行为信号；通过标准化采集与多信号分析降低接收方的核验成本。原文再用理论选出的信号训练多类分类器，而不是为了某个数据集穷举所有特征。

这比犯罪机会或权限配置更贴近研究二的可行路线。恶意 issue、代码注释、配置和工具描述都在向 coding agent“发出”与任务相关、可执行或可信的表面信号；攻击成功的关键是用较低修改成本使恶意内容看起来与正常开发对象一致。研究一的 AttackRL 可以显式优化这种伪装并产生配对真值，研究二则在执行前比较容易操纵的内容信号与较难同时操纵的结构、跨通道一致性和来源信号。需要保留的边界是：不能直接搬用人类说谎时的心理生理特征；可迁移的是 false signaling、操纵成本与替代信号诊断力。

### 3.13 假网站检测：潜藏性并不否定静态预测，反而要求领域结构化多源线索

Abbasi、Zhang、Zimbra、Chen 与 Nunamaker（2010）面对的同样是高度伪装且持续演化的欺诈对象。假网站会复制合法网站的文本、图像和风格，并用 JavaScript、URL 与链接结构掩盖身份。论文并未因此转向运行时或组织私有数据，而是用公开可收集的网页文本、源代码、URL、图像和链接线索建立静态检测；再由统计学习理论与领域特定 kernel 支持大规模异构特征、结构相似性、跨域泛化和动态更新。

其关键启示是：研究二的静态性不是缺陷。coding-agent 攻击的特殊困难恰恰在于恶意指令潜藏在功能合理的 issue、代码、配置和工具元数据中，且各通道可彼此伪装。静态预测应学习“表面任务信号—代码/仓库结构—工具能力描述”之间的领域关系，并以未见仓库、未见攻击家族和自适应 AttackRL 攻击检验泛化。数据可以完全来自公开基准与研究一生成的公开扩展，不需要真实组织权限或成本数据。

## 5. 重要性论证的通用结构

### 5.1 应采用的五步链

1. **组织依赖和价值**：编码智能体正在接入真实软件开发流程，承担读取、修改、测试与执行任务；其价值来源于授权行动，而非只生成文本。
2. **价值—风险同源**：同一组授权行动同时扩大攻击者可借用的能力。风险不是一般 LLM 输出不当，而是可信边界内的实际状态改变。
3. **情境特有机制**：混合信任上下文进入同一决策历史；工具可用合法接口完成未授权目的；多步行动会产生新状态和新证据；代码产物可持久进入供应链。
4. **既有假设失效**：拒绝率不等于可执行安全；功能测试通过不等于补丁安全；静态输入分数不等于运行时风险；通用内容扫描无法恢复指令与代码的跨层关系。
5. **可计算必要性**：因此需要分别生成可行动攻击、在任务开始前配置守护、在行动实际化过程中持续检测和控制。

### 5.2 不应再使用的弱论证

- “相关研究很少，因此重要。”空白只能证明新，不能证明值得研究。
- “模型参数不可修改，因此做外置防御。”这是实施边界，不是科学重要性。
- “编码智能体更自主，所以风险更高。”缺少自主如何改变攻击路径与后果的机制。
- “多模态信号通常更好，所以融合三个通道。”必须说明每个通道由何种攻击生成过程产生、为何难以同时伪装。
- “事前方法无法发现运行时风险。”这种写法会把研究三表述为驳斥研究二；正确写法是预判和韧性是复杂系统可靠性的互补机制。

## 6. 对三项研究的直接重构含义

### 6.1 研究一：先由可验证的攻击过程定对象，再决定是否需要核心理论

研究一目前不宜预先确定核心行为理论，但 AttackRL 不是可有可无的求解器，而是三项研究的上游核心工件。最稳健的路线是从公开基准中已有的任务、输入载体、动作轨迹、环境变化和可执行危害标签构造 coding-agent 特化的攻击 MDP：高层策略选择问题、仓库文件或工具/技能通道及操纵算子，生成器实例化内容，外部验证器以功能保持、危害实现和隐蔽性共同给出奖励。相对于通用代码越狱或 RADAR 的样本规避，状态必须包含仓库与 agent 反馈，动作必须改变 agent 会读取的异构开发对象，成功必须由真实执行或持久代码危害验证。

AttackRL 的设计还必须从一开始服务后续研究。每个成功与失败回合同时保存：（1）攻击前与攻击后的任务前静态快照、被操纵单元及攻击通道标签，供研究二训练静态预测器；（2）完整 action–observation 轨迹、首次风险显现时间和首次危害动作时间，供研究三训练流式检测器；（3）攻击策略、预算与隐蔽性分数，用于冻结防御器后的自适应压力测试。这样，研究一的价值不仅是 ASR 更高，而是建立可复现的攻防实验基础设施。

`Choice and Chance` 所刻画的蓄意与机会性安全妥协路径，可以作为待检验候选：如果公开轨迹能够稳定区分攻击者选择、环境机会、阶段推进和最终妥协，它可能给出路径结构；如果这些状态必须由研究者事后主观编码，它也应被淘汰。强化学习、马尔可夫决策过程或约束搜索只是候选求解方法，不自动构成 IS 理论贡献。研究一也可以合法采用“安全问题结构＋形式化攻击过程＋计算方法”的范式，而不强塞一个社会理论。

此前考虑的技术可供性视角现予以撤回。可供性是行动者—目标—技术之间的关系性构念，通常需要在具体情境中发现并验证；现有公开基准并未提供稳定的“感知可供性/实际化”标签。若直接把读取、编辑、执行和调用命名为可供性，容易退化为研究者自定的能力清单；若严格遵循理论，又需另做质性发现和构念验证。这既扩大研究范围，也削弱可复现性。因此，后文可以用“授权能力”描述事实，但不把技术可供性作为算法核心理论。

与 RADAR 拉开距离的依据也不能只是替换理论名称。RADAR 的核心问题是为鲁棒防御寻找规避样本；研究一只有在分析单位、状态转移、成功条件和评价对象上都转向“跨载体、跨步骤、造成真实环境或持久代码改变的攻击过程”，才形成实质差异。

### 6.2 研究二：保留静态预测，以“潜藏的虚假信号”解释 coding-agent 特殊性

研究二不应被改造成依赖真实组织权限、调查容量和经济损失的数据项目。公开 benchmark 能够可靠支持的是执行前静态筛查：给定问题描述、仓库快照以及工具/技能描述，预测任务是否含攻击，并定位被操纵的段落、文件或元数据单元。

其特殊性不是“静态方法天然不足”，而是 coding-agent 为完成任务必须读取语义丰富且本来就可执行的异构对象，攻击者可把恶意目的潜藏在功能合理的 issue、代码、注释、配置和工具说明中。表面内容由攻击者低成本操纵，且恶意性往往只有在 agent 将多个通道组合后才显现；这使关键词、单文本分类和独立扫描失效，但并不否定执行前预测。

信号理论与 SIGHT 提供了比犯罪机会更贴切的候选逻辑：攻击对象向 agent 发出“与任务相关、功能合理、值得执行”的表面信号；AttackRL 以较低修改成本制造虚假信号；防御器减少对单一自报内容的依赖，联合使用跨通道一致性、代码/仓库结构和可公开获得的来源信息等较难同时操纵的静态信号。MISQ 假网站检测进一步提供直接算法先例：对高度伪装的异构对象做静态多源、结构化检测，并在未见领域和动态对手上检验泛化。

预算化预置防御仍可保留，但预算必须采用公开实验可测的技术口径，例如最多允许深度扫描/复核的任务或单元比例、模型调用次数、token、延迟或计算成本。评价报告 recall@budget、允许通过后的残余 ASR、正常任务误拦截和完成率，不需要虚构组织货币成本。研究一的静态快照与操纵单元真值作为训练/压力测试来源，独立公开攻击基准和按仓库/攻击家族留出用于外部验证。

### 6.3 研究三：以新增运行证据和动态控制建立必要性

研究三的必要性最直接：只有 coding agent 真正运行后，防御者才观察到计划、工具选择、调用参数、工具返回、文件差分、命令执行和网络/进程状态；这些变量在研究二执行前的信息集中不存在。研究二给出静态先验风险与可疑单元，研究三随着 action–observation 轨迹到来更新风险并在首次危害动作前门控。研究三因而是研究二的信息增量和决策延伸，而不是对静态预测有效性的否定。

动态入侵防御、序贯信号检测或反馈控制可以直接定义可实现的门控：风险状态由研究二的静态先验和当前工具/环境证据持续更新；控制量是放行、限权/延迟、阻断或确认；损失同时包含漏报危害、误报干扰和运行延迟。数字化高可靠组织与 frame problem 可以解释为什么静态规则无法穷尽运行状态，但只能作为重要性与边界背景；除非公开实验确实实现并评价人类升级闭环，否则不要求组织访谈、真实调查容量或集体正念构念。

数据直接来自研究一记录的完整轨迹、公开 agent 轨迹和可执行攻击环境。研究三还可把研究二风险分作为 \(p_0\)，以运行证据更新为 \(p_t\)，并以 AttackRL 针对冻结检测器生成的自适应攻击评价绕过率和对抗重训。这样，三项研究形成“生成攻击—静态预警—运行确认与阻断”的可复现实验链。

## 7. 理论选择的硬性判据

后续任何理论进入论文前，必须同时通过下列检查。

1. **行动者一致**：理论中的行动者是谁？攻击者、agent、开发者、安全团队还是组织？不得偷换。
2. **分析层次一致**：文本、动作、会话、任务、仓库和组织层次不能混用。
3. **生成机制一致**：理论描述的机制是否真的产生论文所使用的数据？
4. **可观测性**：核心构念能否从公开基准、agent 轨迹或仓库元数据测量？
5. **计算后果**：理论至少改变表示、架构、目标、约束、策略或评价中的一项。
6. **反事实差异**：移除理论后，算法是否会变成另一种设计？若完全不变，理论只是叙事。
7. **边界明确**：明确理论不解释什么，以及由哪一方法理论补足。
8. **避免同构**：即使理论适配，也要检查是否与目标参照论文形成“换场景不换逻辑”。
9. **现成可测**：核心构念须能由公开基准、agent 轨迹、工具日志或仓库状态稳定操作化；若必须先做大规模访谈、开放编码或新量表开发，原则上不适合作为当前算法研究的核心。
10. **低主观映射**：从原始数据到理论变量的映射应可复现。不能依靠研究者把一般能力、任意特征或事后观察主观命名为理论构念。
11. **资源可承受**：额外标注、专家判断、因果识别和参数估计工作必须与现有公开数据和项目资源相称。
12. **可在同一研究中证伪**：必须能设计现实可行的实验，让理论导出的结构与不使用该结构的方案产生可检验差异。

其中第 4、9—12 项共同构成“可使用性审计”。只要核心构念不可获得、测量映射不稳定，或采用该理论意味着另启动一项构念发现研究，即使概念上很有吸引力，也应降为背景视角或排除。

## 8. 本阶段判断与下一步确认点

当前较优的架构以公开数据和研究间复用为先：

- 研究一：**coding-agent 特化 AttackRL＋执行验证＋双视图攻击基准**；安全问题结构规定状态、动作、奖励与真值，社会理论仅在确实增加可测设计时采用；
- 研究二：**虚假信号/信号可操纵性（候选机制）＋异构静态表示与风险定位＋可测技术预算下的预置筛查**；犯罪机会与任务权限路线降为备选；
- 研究三：**研究二静态先验＋运行轨迹证据更新＋动态检测—反应/反馈控制**；数字化高可靠组织仅作背景，除非人机升级能够在公开实验中实现。

三篇共用研究一的攻击引擎与基准，但必须按仓库和攻击家族划分训练、验证与测试，并以独立公开攻击基准做外部评估，避免研究一生成器与研究二/三防御器相互“出题—答题”的循环偏差。下一步应围绕这一可实现架构重写数据字段和实验协议，再决定理论最终取舍。
