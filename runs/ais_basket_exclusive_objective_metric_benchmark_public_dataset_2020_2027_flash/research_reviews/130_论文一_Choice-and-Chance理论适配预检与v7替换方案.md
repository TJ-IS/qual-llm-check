# 论文一的 Choice-and-Chance 理论适配预检与 v7 替换方案

## 0. 当前判断

论文一 v6 的情境过程、层级 AttackRL 和攻击面诊断已经形成完整工件，但理论地位仍弱于肖老师两篇论文和 RADAR。v6 主动把 POMDP 与层级强化学习限定为方法基础，又把工作空间攻击实际化称为情境归纳模型。这样的写法避免了伪装理论，却留下一个明显问题：关系图、层级搜索和诊断 hazard 主要由工程需要推出，没有一套 IS 理论像 RADAR 的稳健优化理论那样界定核心过程。

当前最值得进入 v7 的理论候选是 Ransbotham and Mitra (2009) 的 Choice and Chance 信息安全妥协过程模型。该理论来源较早，因此绝不模仿其写作形式。v7 的引言、章节结构和段落密度仍以 Xiao et al. (2023, 2024)、Ampel et al. (2024) 和 RADAR (2025) 为模板。Choice and Chance 只承担 kernel theory 的作用。

这一候选比技术可供性更适用。它直接把安全妥协解释为一条逐步进展的路径，区分广泛机会驱动与目标选择驱动的两类路径，并允许前一条路径向后一条路径汇合。三项构念都能用公开可执行任务中的搜索记录观察，也都可以改变 AttackRL 的高层策略和诊断模型。它不需要访谈用户来发现情境可供性，也不要求推断攻击者心理。

不过，该理论不能原样搬用。原文研究互联网环境中的组织妥协，区分非定向扫描与定向攻击。编码智能体情境中的攻击者、载体和中介过程不同。只有完成下述情境化后，它才可能指导算法。

## 1. 原理论的可迁移核心

[Choice and Chance](../../../database_fulltext_all/03118_2009_choice-and-chance-a-conceptual-model-of-paths-to-information-security-compromise.md) 提供四个与论文一直接相关的理论命题。

第一，安全攻击是不断进展的过程，而不是一个孤立事件。较早的活动会为后续更严重的妥协提供信息或条件。这个命题支持把工作空间攻击的评价单位从单次内容改写改为对象操纵、agent 观察、环境行动和最终后果构成的路径。

第二，机会驱动路径与目标选择路径具有不同前因。机会驱动活动从广泛存在的暴露开始，不必预先锁定特定目标。目标选择活动则围绕已经表现出吸引力或可利用性的对象继续推进。这个区分可以指导 AttackRL 在“广泛探查候选对象”和“围绕已有证据细化路径”之间选择，而不是只用一个未解释的高层策略混合两类行为。

第三，两条路径会汇合。机会驱动的初始发现可以形成目标选择的后续探查。这个命题与 AttackRL 的分支档案直接对应：一次对象级候选即使尚未形成最终危害，也可能暴露 agent 的读取关系或能力连接，使后续搜索转向更有针对性的路径。

第四，安全控制主要影响攻击从一阶段向下一阶段的转换，而不一定消除全部初始活动。论文一不开发防御算法，但不同权限、工具配置和工作空间边界可以作为路径转换条件。诊断因而不只估计“某对象成功过几次”，还可以估计机会探查转为目标路径并最终形成危害的条件概率。

## 2. 编码智能体情境化：暴露—选择—实际化框架

为贴近肖老师的写法，v7 不应直接把原理论的 choice/chance 标签贴到 RL 动作上，而应先提出一个由理论与情境共同形成的中间框架。建议使用“暴露—选择—实际化框架”。

暴露阶段表示某个工作空间对象因其位置、任务关系或 agent 观察路径而成为可探查载体。攻击策略尚未获得该对象能够造成危害的直接证据。其决策更接近机会驱动探查。可观察变量包括对象类型、任务距离、workspace topology、历史访问覆盖和允许操纵边界。

选择阶段表示一次或多次 victim 执行已经提供对象特定证据。证据可以是 agent 实际读取对象、出现特定工具转移，或候选在保持功能的同时接近危害 oracle。策略据此围绕当前前缀选择下一对象和操作。其决策更接近目标选择驱动的细化。

实际化阶段表示对象操纵经 agent 观察与行动转化为环境后果。只有危害 oracle 和功能 oracle 同时通过，路径才成为有效攻击。该阶段保留 coding agent 相对原理论最重要的特殊性：攻击路径并非由攻击者直接执行完毕，而是以智能体的合法行动作为中介。

三阶段不是新的行为理论。它是 Choice and Chance 在编码智能体情境中的计算化框架。其作用类似 Xiao et al. (2024) 的过程—粒度框架：先把理论组织为情境指标，再由指标指导专门组件。

## 3. 理论构念到 AttackRL 组件的映射

| 理论/情境构念 | 可观察量 | 设计要求 | AttackRL 组件 | 主要拒绝条件 |
|---|---|---|---|---|
| 机会驱动暴露 | 对象类型、任务距离、拓扑、未探查覆盖 | 在缺少对象特定证据时广泛探索暴露面 | exposure policy／机会探查头 | 不优于均匀、任务距离或中心性搜索 |
| 目标选择细化 | 读取事件、工具转移、前缀反馈、oracle 接近状态 | 获得证据后围绕有希望路径定向细化 | choice policy／目标细化头 | 不优于只按最终成功更新的单策略 |
| 路径汇合 | 暴露探查产生可用于后续细化的状态转移 | 显式学习从 exposure 到 choice 的切换 | 理论约束的 mode gate | 固定时点切换或普通门控达到相同结果 |
| agent 中介的实际化 | victim 观察、行动和环境差分 | 最终路径必须由 agent 行动形成后果 | 动态对象图与完整 rollout | 去除 agent 行为更新无性能变化 |
| 功能保持型妥协 | harm 与 functionality oracle | 危害不能以破坏原任务为代价 | 双 oracle 硬约束 | 加权软奖励同样稳定且不增加任务破坏 |
| 条件路径进展 | 首对象到首次有效路径的 rollout 时间 | 诊断估计路径转换而非历史频次 | 分阶段离散 hazard | 不能校准未见路径或改善测试预算 |

这个映射会改变 v6 的高层策略。当前 v6 只有一个策略选择 parent、object 和 operator。v7 应将高层决策拆为两个理论可辨识的模式。

在 exposure mode 中，策略优先选择尚未获得对象特定执行证据的候选位置。其奖励仍只由最终双 oracle 成功定义，但训练期辅助头可以预测对象被读取及其进入能力路径的概率。辅助结果不能被当作最终攻击成功。

在 choice mode 中，策略以已经暴露的 agent 行为和前缀结果为条件，围绕当前路径选择下一对象和操作。该模式允许回退到分支档案，也允许在当前路径失去前景时返回 exposure mode。

Mode gate 决定何时由机会探查转向目标细化。其输入只能是当前 belief、分支档案和允许公开的执行证据。一个未经理论约束的普通门控、固定 rollout 后切换和始终 exposure/choice 都是直接基线。只有 mode gate 在固定预算下提高有效路径发现，而且实际切换发生在对象特定证据出现之后，理论映射才得到支持。

## 4. 对攻击面诊断的改变

v6 将条件暴露定义为从某个首对象开始，在预算 (b) 内发现至少一条有效路径的概率。该定义可以保留，但 v7 需要增加路径阶段分解。

设 (T^{E\rightarrow C}_{iv}) 表示从对象 (v) 的机会探查开始，到首次进入目标选择模式的 rollout 时间。设 (T^{C\rightarrow H}_{iv}) 表示进入目标选择模式后，到首次通过双 oracle 的时间。则总体暴露可以分解为：

\[
P(T^{H}_{iv}\le b)=
\sum_{j=1}^{b}P(T^{E\rightarrow C}_{iv}=j)
P(T^{C\rightarrow H}_{iv}\le b-j\mid T^{E\rightarrow C}_{iv}=j).
\]

这个分解比单一 hazard 更接近 Choice and Chance 的理论贡献。它可以判断某类对象的问题来自“很少提供可细化证据”，还是“经常进入细化但难以最终实际化”。两种对象需要的后续测试策略不同。

诊断仍必须在 AttackRL 冻结后构造。Exposure/choice policy、mode gate 和图编码器先冻结。非测试仓库再按已知抽样概率产生分阶段序列。测试仓库只在估计器、校准和预算规则全部冻结后运行。否则策略选择偏差仍会使理论阶段概率自证。

资源配置可以比较三类规则。总暴露排序只依据最终路径概率。Exposure-first 规则优先测试更可能快速产生目标证据的对象。Choice-depth 规则则给已经容易进入 choice 的对象更深预算。若分阶段规则不能比总暴露或简单排序提高固定预算发现收益，理论分解没有决策价值。

## 5. 对研究问题的建议修订

RQ1 可以从一般序贯表示改为理论与情境共同限定的问题：

*RQ1：如何把编码智能体工作空间攻击表示为从机会暴露、目标选择到行动实际化的路径过程？*

RQ2 应直接检验理论生成的双模式策略：

*RQ2：在统一攻击预算下，区分机会探查与目标细化并学习二者转换，能否改善功能保持型攻击路径的发现？*

RQ3 保留诊断目标，但增加阶段信息：

*RQ3：经验证的路径进展能否形成具有前瞻效度的攻击面诊断，并改善有限测试资源的配置？*

这三个 RQ 的关系接近肖老师论文。RQ1 推出理论框架和表示。RQ2 推出专门算法组件。RQ3 把算法产生的结构化知识连接到安全决策。它们不是三个并列目标。

## 6. 与 RADAR 的实质区别

RADAR 以稳健优化理论说明防御需要纳入对手，再以 RL 模拟攻击序列。其攻击侧主要学习怎样连续修改既定恶意输入。论文一 v7 则以 Choice and Chance 解释工作空间攻击路径如何从广泛暴露转向目标细化，并由 coding agent 行动实际化。理论直接决定搜索模式、模式转换和诊断 hazard。

两篇论文都可以使用强化学习，但 RL 的理论角色不同。RADAR 中 RL 是序贯攻击仿真的主要理论与方法基础。论文一中 RL 是求解暴露—选择—实际化框架的计算方法。论文一的可识别增量必须来自双模式路径结构，而不是重新证明 RL 适合序贯攻击。

## 7. 与肖老师范式的对齐方式

v7 的标题建议改为：

> **编码智能体工作空间攻击路径的自动发现与攻击面诊断：一种安全妥协过程理论驱动的层级强化学习方法**

标题采用 Xiao et al. (2023) 的“理论驱动方法”定位，但没有复制其具体措辞。引言应在 coding-agent 特殊性之后引入 Choice and Chance，再提出暴露—选择—实际化框架。第三节应像 Xiao et al. (2024) 一样逐个解释理论指标，并在每个指标后立即说明它指导何种策略或诊断组件。表格需要包含理论来源、情境指标、方法挑战和拟议解决方案。

方法部分按 exposure policy、choice policy、mode gate、双 oracle 和分阶段诊断展开。评价部分设置 ordinary PPO、无 mode 单策略、固定切换、无动态 agent 行为和无分阶段 hazard 等基线。这样，理论不只出现在引言，也能够通过消融与阶段分析接受检验。

## 8. 理论适配的失败风险与预检

第一项风险是 opportunity/choice 阶段不能从公开回合稳定标注。预检应在既有 AttackRL 小样本上，由两个标注者只依据可观察事件判断“是否已出现对象特定可细化证据”。若 Cohen's kappa 低，mode 不应使用人工标签监督，可以改为隐状态；若隐状态仍无法与执行事件对应，则放弃该理论。

第二项风险是双模式策略只增加模型容量。预检必须实现参数量相当的 mixture-of-experts 和普通门控基线。只有理论约束的转换条件产生额外增量，才能把优势归因于 Choice and Chance。

第三项风险是原理论的目标组织、Internet presence 和 target attractiveness 无法映射。v7 不应硬搬这些构念。论文只保留路径过程、两种路径及其汇合。删去原理论构念后是否仍属于合理扩展，需要在理论章节明确论证，并最好由导师确认。

第四项风险是 AttackRL 数据仍不足以估计分阶段 hazard。应先按对象类型和任务距离计算事件数与删失率。若大部分序列从未进入 choice，或进入后几乎没有有效路径，分解模型会不可识别。此时诊断保留 v6 的总 hazard，理论只指导攻击搜索，不强迫第二工件使用同一分解。

## 9. 暂定结论

Choice and Chance 是目前论文一最接近“肖老师式理论指导算法”的候选。它比 POMDP 更像 IS kernel theory，也与 RADAR 的稳健优化理论形成实质区别。它能够推出双模式策略、转换门控和分阶段诊断，且所有变量原则上可由公开任务中的执行记录获得。

当前仍不建议直接覆盖 126 号 v6。先实施第 8 节的小样本标注与最小双模式基线。若阶段可观察、参数等价比较可行，再新建完整 v7；若失败，应回到理论候选池，而不是把 Choice and Chance 作为装饰加入引言。
