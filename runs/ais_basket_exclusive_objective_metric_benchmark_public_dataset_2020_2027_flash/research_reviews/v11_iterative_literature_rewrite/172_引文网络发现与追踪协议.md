# 权威论文引文网络发现与追踪协议

## 1. 文件角色

本文件规定如何从权威原文的引用特性倒推三篇论文的文献发现方法。它不保存每篇文献的详细结论，详细阅读记录仍写入 165。它也不替代论文专账中的主张和可行性。本文件只维护搜索触发器、前后向追踪、来源组合、记录字段和停止规则。

## 2. 基本原则

高质量论证通常同时需要历史源头与后续累积证据。早期文献负责定义原始理论、方法或构念，较新文献负责说明该知识后来如何被操作化、修正、转入新情境、与其他理论重组或被指出边界。只引用早期经典会使当前适用性缺乏证据，只引用近期论文又会造成理论溯源不清。

文献年代本身不决定质量。判断依据是来源在论证链中的责任。经典来源不能被近期二手概括替代，近期来源也不能仅因发表时间新就被当作理论发展。直接引用关系、实际使用位置和经验检验必须逐项核对。

## 3. 四条发现路径

### 3.1 从权威原文向后回溯

对 ACAA、DSDL、Siering 等权威原文的引言、综述和理论节逐段提取引用，并给每个来源标记角色。

- 原始理论或经典构念
- 后续理论发展、测量或边界
- 当前研究情境的近期实证
- 计算方法或评价方法
- 数据、基准或行业事实
- 相邻先例、反例或限制

优先检查一个重要段落为何同时组合不同年代来源。旧文献和新文献共同出现时，分别核对它们承担的是源头定义、后续操作化还是当前事实，不能把组合引用视为可互换来源。

### 3.2 从经典来源向前追踪被引

任一核心主张只依赖较早来源时，沿 cited-by 搜索后续直接引用者。先在 AIS Senior Scholars' Basket 和本地全文中查找，再使用官方期刊页、OpenAlex、Semantic Scholar、Crossref 或学术搜索索引扩大范围。候选论文必须回到正文和参考文献确认直接引用。

向前追踪时记录后续论文对旧来源的处理。

- `理论发展` 表示增加构念或关系并进行新的概念或经验检验。
- `构念或测量修正` 表示改变连续性、测量、分析层级或边界。
- `相邻适用` 表示不改变源理论，却在相近对象、技术、数据或决策任务中真实操作化同一机制、测量或理论引导设计逻辑，并给出可核边界。
- `局部采用` 表示借用分类、变量或一条关系解决另一个问题。
- `跨理论重组` 表示保留部分旧知识但把主要解释转交给另一理论。
- `背景延续` 表示只在综述或定位中提及。
- `反驳或替代` 表示明确指出旧机制不适用并采用其他解释。

只有前两类可以直接支持理论累积。相邻适用可以支持范围受限的当代适用性或设计可迁移性，但必须写明连接的是现象、机制、测量、算法构件还是评价方式。局部采用和跨理论重组需要收缩源理论中心性，背景延续只能证明文献仍可见。

被引检索采用“双种子”而不是只追一篇权威范文。第一颗种子是当前命题最早的可核源头，第二颗种子是最近的已核实质发展者。分别追踪两者的 cited-by，再比较重合节点、只引源头的重启分支和只引近作的应用分支。只追权威范文本身容易得到把它当作方法邻居的论文，却漏掉沿源理论继续发展的节点。

### 3.3 沿中间节点继续追踪

发现新的直接引用者后，检查它是否同时引用谱系中的中间论文。若存在 `经典源头 → 中间发展 → 近期重组`，记录完整边而不是只保留源头与最新论文。若最新论文没有引用看似相关的中间论文，则不得根据年代、作者或主题补造继承关系。

重要中间节点至少向前再追踪一代，直到出现以下情况之一。

1. 新论文只作背景引用，没有新的理论或测量变化。
2. 连续两个检索批次不再出现新的实质关系类型。
3. 已找到能够承担源头、后续发展、当前情境和边界的充分来源组合。
4. 新增论文不再改变正文主张、设计责任或实验。

### 3.4 共同被引与相关文献扩展

查看经典源头与近期论文共同引用了哪些来源，可以发现平行理论、测量和方法。共同被引只用于发现候选，不证明继承。主题相似、共同作者、相同术语、同一方法或年份相邻也只产生候选，必须再核对正文直接关系。

## 4. 来源组合标准

关键理论或机制段优先形成以下组合。

| 责任 | 首选来源 | 不能替代的内容 |
|---|---|---|
| 源头定义 | 原始理论或原始方法 | 构念、关系、分析单位和原始边界 |
| 后续发展 | 直接引用源头并实质修改或检验的论文 | 累积、修正或不再成立的部分 |
| 当前适用 | 近期且与当前情境直接相关的实证、设计或基准论文 | 当前对象、数据和技术事实 |
| 边界或替代 | 明确指出限制、反例或转用其他理论的论文 | 为什么当前稿件必须收缩或改理论 |

一段不必机械拥有四类来源，但任何核心理论链至少应有源头和一个经过核查的后续节点。若声称理论在当前技术情境仍适用，还需近期直接应用或明确的情境扩展证据。

## 5. 年代与被引追踪触发器

以下条件触发 forward cited-by 检索和人工复核。

1. 关键理论命题只由十年以上的来源承担。
2. 一段讨论当前智能体、工具、数据或组织情境，却只引用早期历史文献。
3. 理论源头与当前研究之间相隔十年以上而没有中间直接引用节点。
4. 稿件使用近年论文声称旧理论得到继续验证，却没有核对该论文正文如何使用旧理论。
5. 同一旧来源在引言、综述、理论和方法中反复承担不同责任。
6. 权威原文在相同论证位置同时使用经典与近期来源，而当前稿只有经典来源。
7. sub-agent 建议保留旧理论，但没有提供最新直接引用者、边界论文或未发现结果。
8. 最新直接理论发展距离研究截止年超过五年，或方法来源全部早于当前技术范式。
9. 权威论文出版年与首次投稿相隔三年以上，稿件却按出版年把其书目视为近期覆盖。
10. 当前表述出现动态、累积、因果、持续、粒度或偏好投射，但被引论文的分析单位、时间粒度或标签不同。
11. 一个来源连续承担三个以上异质主张，或占据一个子节四分之一以上的来源责任。

十年是检索触发器，不是删除线。经典理论即使更早仍应保留，触发器只要求检查后来是否发展、修正或替代。

## 6. 每个候选来源的发现记录字段

向 165 登记候选或已读文献时，至少保留以下字段。

| 字段 | 内容 |
|---|---|
| `found_via` | 权威原文参考文献、经典来源 cited-by、中间节点、共同被引或关键词搜索 |
| `upstream_source` | 触发发现的直接上游论文 |
| `direct_citation_verified` | 是否在正文和参考文献中核验直接引用 |
| `relation_type` | 理论发展、测量修正、相邻适用、局部采用、跨理论重组、背景延续、反驳或无直接关系 |
| `claim_role` | 源头、后续累积、当前情境、方法、数据、边界或反例 |
| `evidence_scope` | 已读的完整章节和原文位置 |
| `changes_triggered` | 对引言、综述、理论、方法、实验或跨稿接口造成的修改 |
| `retained_limits` | 仍不能支持的外推 |
| `next_forward_search` | 是否需继续追踪被引和追踪到哪一代 |
| `primary_theory` | 后续论文真正采用的主要解释框架，防止把背景引用写成理论中心 |
| `analysis_unit` | 组织、个体、任务、对象、会话、事件或其他实际分析单位 |
| `time_granularity` | 年月、阶段、会话、回合、事件或预算格 |
| `measurement_and_label` | 构念如何观测，结果是否只是代理标签 |
| `submission_and_reference_cutoff` | 投稿时间、出版时间及参考文献实际截止 |
| `cited_by_query` | 查询平台、日期、检索式、返回量与去重方式 |
| `bibliographic_anomaly` | 书评式来源、预印本与正式版差异、正文和参考文献未对应等异常 |
| `applicability_bridge` | 相邻来源具体连接的对象、机制、测量、构件或评价责任，以及不能跨越的分析层级 |
| `citation_context` | 权威稿或中间节点使用该来源的原句、行号和关系措辞，不能只记参考文献条目 |
| `bridge_subtype` | 同机制相邻应用、测量迁移、设计架构先例、方法先例或边界证据 |
| `match_vector` | 分别记录分析单位、时间粒度、输入、行动、结果和标签的一致、部分一致或不一致 |
| `evidence_mode` | 构念由直接测量、行为代理、模型推断还是理论假设取得 |
| `paired_anchor` | 相邻文献在正文中必须与哪一源理论或实质发展者配对使用 |
| `allowed_claim` | 当前稿由该来源允许写出的最强表述 |
| `prohibited_upgrade` | 禁止升级为理论发展、机制验证、因果关系或当前对象直接适用的表述 |
| `manuscript_slot` | 现象、综述、理论、方法或评价中的主要落点，防止方法先例进入理论本体 |
| `version_identity_checked_at` | 最近一次用官方页面与原文核对题名、作者表、版本号和资源范围的日期 |
| `paper_vs_code` | 分列论文、官方数据或测试资源、官方实现与本文派生 runner 的责任、版本和差异 |
| `scope_negative_level` | 未报告、指定范围直接未见或系统覆盖后缺失，并保存实际检查范围和禁止外推 |
| `source_counterevidence` | 来源中限制、未应用、反例或与目标稿相冲突的原句与位置 |
| `citation_cluster_responsibility` | 复合句或引用簇中每个主张原子的来源、支持等级和未闭合责任 |

## 7. 搜索顺序

1. 从当前主张列出最早源头和最新已知来源。
2. 在权威范文参考文献中寻找相同构念、同类方法和边界来源。
3. 对最早源头和最近已核实质发展者分别做被引检索，按年份、期刊、主题和引用上下文筛选并比较两组结果。
4. 在候选排序中优先保留标题、摘要或引用上下文明确出现核心关系、测量、边界或竞争理论的论文；被引次数只作排序信息。
5. 优先阅读全文可取得、权威期刊或当前情境直接相关的候选。
6. 对候选核对正文引用位置、参考文献和实际理论责任。只在参考文献出现的候选登记为异常，不建立理论边。
7. 检查候选是否引用中间节点，并补全或排除引用边；同时检查它真正采用的主要理论，防止把背景源头抬升为主线。
8. 对只作背景的分支登记后停止。对相邻适用节点先核查其 applicability bridge 和边界，若它已经到达当前对象或方法责任则可作为适用性证据，若仍隔一层情境则继续追踪一代。理论发展、测量修正、跨理论重组和反驳节点至少再追踪一代。
9. 把实质节点写入 165，将对单篇论文的影响写入 168 至 170。
10. 新证据改变通用写作规律时再更新 164。
11. 对 arXiv、DOI、数据卡和官方仓库执行当前版本身份核查。保存旧题名、当前题名、作者表、版本号、提交或访问日期及能力范围变化；持久标识符只连接版本谱系，不证明所有版本表述相同。
12. 把论文、官方资源、官方实现和本文派生 runner 建成不同节点。先读取论文是否实际应用该资源，再读取官方产物的当前能力；“已发布但本文未应用”登记为资源边和限制边，不建立论文实施边。
13. 对经典方法同时执行 forward cited-by 与近期适用性搜索。原始节点承担定义，后续节点承担真实发展或当前条件；若近期应用只共享名称而数据结构、检验族、重采样单位或 estimand 不同，登记为方法邻居而非直接支持。
14. 对评价指标和多重检验按主张原子分叉检索。AUPRC、proper scores、calibration 和 selective risk 分属不同支线；Holm 与 Benjamini--Hochberg 分别追踪其原始方法、错误族与现代应用，不能由共同出现在权威论文中合并责任。

## 8. 停止规则

搜索不以找到固定篇数结束。满足以下全部条件后可以暂时停止。

- 已有原始源头。
- 已有至少一个经过正文核查的后续实质节点，或明确记录在规定范围内未发现。
- 已有与当前研究对象直接相关的近年来源或公开资源。
- 已有边界、反例或替代理论证据。
- 新增两个候选批次没有改变主张、映射或评价设计。
- 仍未解决的缺口已经写入对应论文专账，而不是被遗漏。

第一代 backward 和 cited-by 候选不能用主题饱和代替直接关系核验。只有确实修改、采用、重组或反驳核心机制的节点才继续追踪其下一代，仅借用背景或指标的分支可在登记后终止。核心理论只有找到原始来源并完成至少一次近五年 forward 检索后才能暂时停止。投稿前和重大正文重构后重新运行增量检索。

## 9. 防止引文失真

- 不把被引次数高当作当前主张正确。
- 不用近期综述替代可取得的原始理论和原始实证。
- 不把一篇近期论文的参考文献表出现旧来源写成理论获得检验。
- 不用主题相似或共同作者制造引用链。
- 不因追求近期性删除真正的经典源头。
- 不为每个旧来源机械补一篇新来源。只有新来源实际承担发展、当前适用或边界责任时才进入正文。
- 不把搜索引擎摘要作为正文证据。摘要用于筛选，结论回到论文全文。
- 相邻文献只有真实操作化共同机制或测量时才标为理论适用。只共享主题、技术名或任务名时仍属背景，学习构件映射时标为设计架构先例，借用编码器或优化器时标为方法先例。
- 核心机制链至少区分源头或实质发展者、相邻适用节点和当前研究扩展。相邻节点不能单独承担理论本体，三类责任也不能塞进同一括号后写成共同验证。
- `evidence_mode` 为行为代理或模型推断时，正文不得使用验证了构念的表述。使用同一结果标签训练出的模型权重也不能再作为该构念的独立验证证据。
- `match_vector` 任一关键维度不一致时，正文明确标为本文扩展、待检验关系或有限类比。相邻桥仍隔一层情境时至少继续追踪一个中间节点。
- 权威稿出现书评式源头、正文书目不对应或中间论文实际引用其他源头时，回到真正源头重建谱系，不复制权威稿的引文边。

## 11. 可迁移发现记录

本节只记录经过主代理原文抽查且适用于三篇论文的规律。单篇特有规律留在 168 至 170。

### 2026-08-23 初始规律

1. 核心理论不能只靠源头文献支撑当前适用。应追踪后续直接引用者，并说明构念后来被操作化、修正、转入其他理论或停止检验。
2. 最新论文不是自动的最强证据。Choice-and-Chance 谱系显示，近期论文可能只作背景定位，而较早的中间论文反而真正改变测量或关系。
3. 引用图通常分叉而非形成按年份排列的直线。信号理论和最优控制审计都发现多条平行分支，正文必须保留不存在的引用边。
4. 当后续论文改用另一理论解释旧分类时，当前稿件应降低旧理论的中心性，而不是把跨理论重组写成累积验证。
5. ACAA 的引言采用现象证据、冲突结果、机制和研究问题的推进，理论定位常出现有引文理据段与无引文作者设计段配对。高密度集中在事实、比较和理论关系，不要求给作者提出的每个实现句机械加引文。
6. ACAA 同段新旧来源并不自动形成谱系。Riley（1954）与 Kuan（2015）的核查暴露了书评式源头和实际直接引用不一致，Yin et al.（2020）还存在本地正文与参考文献未对应。权威稿自身必须进行书目和直接边复核。
7. DSDL 的理论网络从 Oliver 分叉到情境测量、纵向过程、函数形式修正、完整模型、技术信任和期望成熟度。追踪目标应是理论关系、测量和边界发生了什么变化，不是只问新论文是否引用旧论文。
8. DSDL 对累计满意度、片段级更新、时滞可忽略和行为标签的若干表述超出紧邻来源。遇到动态、累积、因果和代理标签词时，必须强制核对分析单位、时间粒度和测量。
9. Siering 的 DSR 架构由过程、正当化知识、原则定义、特征映射、情境知识、机器学习和评价等多组来源共同形成。一个看似连续的设计链不能由两篇通用 DSR 文献独自背书。
10. 较新论文中的理论综述表、竞争模型表和附录是高价值 citation hub。先从它们找到源头与分支，再以正文位置和参考文献核对直接关系。
11. 出版年份不能代表书目新近性。ACAA 的书目主要止于 2021 年，Siering 2021 于 2016 年投稿。当前稿需要按实际引用截止和技术范式执行 2022 至 2026 年增量检索。
12. 方法综述负责导航，正式方法论文与官方实现承担机制和复现责任。cited-by 数量只负责候选排序，并记录查询平台与日期。
13. 权威论文常把经典源头、中间经验研究和接近投稿期的方法来源混合使用。ACAA 的引言与理论定位可见 1954 至 2021 年来源，DSDL 的对应范围可见 1977 至 2021 年来源，且引用大量集中在中间年份。这说明高质量引用不是“旧文加一篇最新文”，而是让不同年代节点承担不同责任。
14. 卷期年份不能替代研究时间线。ACAA 于 2021 年投稿、2023 年 online first、2024 年进入卷期；以 2024 为起点判断其书目新近性会虚增三年。每次对标均记录投稿、接收、online first、卷期和实际参考文献截止。
15. ACAA 的本地后续节点中，在线评论实践论文可承担相邻情境适用，理论引导 GNN 论文可承担相邻设计适用；一般机器能力引用只属背景。DSDL 的后续节点中，理论引导虚假信息识别可承担相邻 IS 安全设计适用，其余聊天机器人和 voice AI 节点主要是情境背景。直接被引与发表较新仍不足以构成理论累积，但相邻适用的限定价值应被保留。
16. forward 搜索的负结果和邻接结果都具有写作价值。若近期节点都只作背景，应降低“持续发展或继续验证”的措辞。若出现相邻适用，应把它放在当前适用性或设计迁移位置，并继续用源理论和中间发展者承担理论本体，不能把两种责任合并。
17. ACAA 的有效评论情境桥是 Hovland and McGuire 到 Kuan et al. 再到 ACAA。Kuan 真实操作化 reception or attention 与 yielding or helpfulness 的阶段差异，因此能支持相邻情境适用；它不能支持四项注意指标、销售预测或神经注意层。Riley 的书评式条目不能替代这一真实中间节点。
18. DSDL 的 EDT 网络需要按责任分叉。McKinney et al. 负责 Web 情境中的构念测量，Bhattacherjee and Premkumar 负责阶段性信念变化，Venkatesh and Goyal 负责测量与函数形式修正。三条边都不能直接支持对话片段级更新、到店行为代理标签或神经状态的理论身份。
19. 相邻文献的价值可以是缩短适用距离、提供可行测量、示范设计架构或界定边界。只有第一类中的同机制真实操作化可以支持理论适用，其他类型必须按设计、方法或边界责任落位。
20. 模型输出或注意权重解释潜在构念时，必须有独立测量、外部标签或拒绝性实验。用训练标签形成模型，再用同一模型权重证明理论构念，属于循环解释。
21. 相邻 IS 控制论文只能支持“把响应写入状态动态、设置有限期边界或比较管理响应”在邻近场景中具有设计可迁移性。当前编程智能体中的响应效应、状态充分性、序贯支持和滚动策略增量均由本研究实验承担，不能因控制术语相同升级为机制证明。
22. screening 的桥梁核查不仅比较证据内容，还比较信息取得由谁启动、原始来源由谁控制以及是否存在独立可信根。接收者用解析器重新编码发送者控制内容不会自动形成独立 screen；若要主张 receiver initiation，优先寻找或构造相同内容、不同取得者或 provenance 的反事实。
23. 顶级算法开发论文通常并列维护四条引用支线。问题与数据来源负责说明任务为何重要，经典理论或方法源头负责定义核心关系，近期同领域研究负责当前适用，benchmark 方法来源负责竞争解释和复现。四类来源不能互相替代，也不应全部塞进一个括号共同背书工件。
24. 从权威论文倒推相关文献时，先标注正文每个引用在现象、缺口、理论桥、方法选择、数据形成和 benchmark 中的责任，再分别追踪。只从参考文献表按题名找相似论文，会把方法邻居误当理论发展，也会漏掉真正改变测量或比较单位的中间节点。
25. benchmark 引文应沿“缺失能力”而不是“最常见模型”扩展。CLHAD 的单语、机器翻译和跨语言迁移，DTL-EL 的非迁移、替代迁移与层转移，DeepIA 的层级分类与标签嵌入，以及 Explainable DRL 的短视、无记忆和不同注意模型，都先代表一种竞争解释。寻找新 baseline 时应查这些方法的被引与近期替代者，并验证其输入、输出和任务接口仍可比较。
26. 旧的经典方法源头应保留，但不能单独承担当前算法选择。对 RL、POMDP、校准、迁移学习、注意机制或图方法，使用“双种子”追踪经典源头与最近已核实质发展者，再从权威论文中提取直接任务邻居。若近期节点只作应用背景，仍保留经典定义并降低“持续验证”措辞，而不是机械用一篇新综述覆盖源头。
27. 资源谱系必须同时追踪论文、官方数据卡、runner 和当前版本。论文引用关系不能证明数据可训练、标签含义或当前 title；CyberSecEval 3 的官方卡明确为 test-only，SkillJect v3 的官方页面则把资源身份界定为攻击生成与轨迹评价框架。涉及资源能力时先查当前官方产物，再回论文核对形成过程与限制。
28. 同一攻击主题会产生不同 outcome。WAInjectBench 的恶意或良性图像检测、CyberSecEval 3 的模型响应注入成功、SkillJect 的轨迹中隐藏载荷执行，以及野外技能研究的已确认恶意行为属于不同分析单位和标签。相关文献发现要沿 outcome 和裁判责任扩展，不能因共同使用 prompt injection 或 skill 名称就组成共同训练集。
29. 不确定性来源应按对象形成并行引用支线。Romano et al. 负责交换性分类样本的边际覆盖，Lakshminarayanan et al. 负责 ensemble 预测分歧，Ovadia et al. 负责数据偏移下的经验失准，Liu et al. 负责能量 OOD 分数与检测指标，Geifman and El-Yaniv 负责选择风险和覆盖权衡。把这些来源串成单一保证链属于伪谱系；组合门控仍是当前研究必须直接评价的作者规则。
30. 经典控制或统计来源与作者协议之间也要保留断点。Bertsekas 的有限期边界不推出运行器如何写入行动上限，Roberts 的相关结构阻断不决定哪些任务相连，MacKinnon 的完整聚类推断原则不替代具体 paired bootstrap 算法。检索不到直接方法时，正文应标记作者预注册规则或具体待补责任，不能让经典来源包揽实现细节。
31. 层级算法来源同样只承担其原始对象。Sutton, Precup, and Singh 定义 option 的时序抽象、策略和终止结构，Schulman et al. 定义 PPO surrogate optimization；两者都不自动给出当前工件的候选生命周期、探索或细化终止、分层 log probability、确认后回报或预算规则。这些作者接口必须另找直接来源或作为待实现协议披露。
32. 发现型 outcome 的引用搜索应从标签生成和等价类两条支线展开。Klees et al. 2018 能承担随机搜索需独立重复、分布评价和启发式唯一计数会误导的直接方法责任，Magma 能承担以独立 ground truth 形成 bug-centric 指标的近期发展；两者都不能支持智能体候选和中性对照的来源归因、具体确认阈值、运行顺序、误差界、盲审去重或语义路径代码本。若没有匹配方法，保留精确待补责任比用相邻 benchmark 共同背书更可靠。
33. 从权威 IS 应用论文倒推统计来源时，先读取数据、方法、结果和局限的连续窗口，再沿正文引用回到规范方法原文。权威应用只证明某一程序在其数据结构和识别条件下如何使用。进入当前稿以前必须比较重采样或置换单位、零假设、可交换或聚类条件、配对结构、有效组数、estimand 与有限样本处理；同名方法但条件不同属于方法邻居，不是直接支持。
34. 后续算法论文直接引用原始方法并给出截断、近似、有限期或系统内实现时，要保存“定义节点 → 实现节点 → 本文适配”三段链。原始节点承担数学对象与一般条件，后续节点承担它实际实施的变体，本文只承担剩余边界。GAE 到 PPO 的链表明，较新论文不是用来替换旧来源，而是可能精确承担旧来源没有给出的实现责任；同时，若原始节点自述更早公式来源，只有在当前稿声称首创或方法史时才继续回溯该上游优先权。
35. 直接引用边是发展关系的必要证据之一，但不是充分证据。核到 A 引用 B 后，还必须比较 B 的数学对象、假设、输入输出与 A 的实际实施；若 A 只借用一般思想却实施不同公式，登记为“直接引用但对象变化”，不能写成该公式的延续。ACAA 引用 Bahdanau 但采用不同注意力形式是反例；Guo 与 DTL-EL、Gneiting and Raftery 与 DSDL 若没有核到直接实施边，只能分别作为规范方法节点和相邻 IS 披露节点。
36. 逐句检索的停止条件也要持久化。穷尽同功能来源池以后，若候选仍缺项目或构件身份、同段共享谓词、限定、时序或 `unit_role`，应记录负结果并保持回修，而不是扩展到一般定义、跨段局部命中或共同版式。论文一 U0049、U0068、U0112 及 U0001/U0018/U0227/U0299 表明，负结果本身能够界定作者责任和后续检索支线；GAE 到 PPO 的直接引用与实施连续性则是可继续登记为方法谱系的正例。
37. 理论或方法谱系要在新论文的连续大节中读取，不能只从参考文献表恢复箭头。先记录经典源头在目标段承担的精确定义，再记录中间节点是否补充时间变化、累计过程、情境适用、测量或实现，最后记录新论文实际保留和新增的责任。DSDL 对期望失验的使用表明，Oliver 的源定义、McKinney 的测量操作化、Bhattacherjee and Premkumar 的时间变化、Venkatesh and Goyal 的持续性与 Lankton 系列的累计过程各有不同责任；只引最早或最新节点都会丢失链条。连续窗口中的段落位置和引用上下文与引用边一起保存。
38. 全文搜索结果必须区分 `token_candidate`、`exact_phrase_hit`、`direct_method_support` 和 `adjacent_applicability`。检索词共同出现或题名接近只产生候选；只有目标对象、操作、比较、结果与限制同构且经连续大节核对，才可成为直接支持。2026-08-24 的反例是 `deterministic replay` 把含 experience replay 的 RADAR 返回为候选，而原文没有确定性重放或恢复实现。正例边界是 Wang et al.（2020）能够支持资源受限下在 full、random 与 selective 策略之间比较的相邻适用，却不能支持安全复核决策损失或两级队列。负结果和有限邻接都要写入台账，避免后续代理重复误升格。
39. 引用网络的节点身份使用 `bibliographic_identity_key`，优先由 DOI 或其他持久标识符组成；没有持久标识符时使用规范题名、完整作者表和年份的组合。首作者姓氏与年份只负责生成候选，不能单独建立正文引用边。同首作者同年多篇时，每个正文 mention 必须保存同一 `citation_atom`、用于唯一归属的名字或共同作者 marker、完整书目节点和未解析状态。generic surname-year、邻近 mention 的作者 token 和参考文献表中的同键共存都不构成直接边。身份解析以后仍须另查正文引用上下文和原文责任，不能把书目节点唯一化写成主张已获支持。
40. 表格引用节点必须保存列责和整行关系。一个单元格只有在表头、同一整行、表前引入和表后解释共同核对后才可建立写作或事实边；资源列不能代领论文使用列，条件列不能代领结果列，限制列也不能从孤立空白反推全领域不存在。
41. 负向范围边按证据等级登记。来源只未报告某能力时建立 `not_reported`；在预定连续章节、附录、官方资源或仓库直接核查后未见时建立 `checked_absence_within_scope`；只有能力矩阵、版本边界和系统排除规则齐全时才建立 `systematic_absence`。三种边不能相互升级。
42. 论文、资源、代码和派生 runner 是四类节点。CyberSecEval 3 的视觉测试“已发布但本文未应用”只能建立论文到资源的发布边和论文内未实施边，不能建立论文到视觉 runner 的实施边；本文自定重复次数、裁判或改写流程继续属于作者协议。
43. 版本谱系独立于书目持久标识符。每次重大回修及投稿前记录当前官方题名、作者表、版本号和核查日期；版本变化若改变资源能力或限制，重新审计所有正文责任而非只改书目字符串。本轮对 SkillJect 的官方摘要页与 v3 PDF 核查显示当前身份与三稿一致，因而撤回一个来自中间信息的漂移候选。该反例说明候选异常不能先于官方原文进入引文图。
44. 引用簇必须拆成责任图。Gneiting and Raftery 可承担 proper scoring rules，Van Calster 等可承担 calibration 评价，但二者不自动支持 AUPRC；Holm 与 Benjamini--Hochberg 分别控制不同错误目标，也需要明确检验族。对经典统计方法使用“原始节点加现代相近应用”的双层组合，应用节点不得替代规范条件。

## 12. 更新日志

### 2026-08-24 词项候选、精确命中与直接支持分层

新增规则 38。根据固定复核、配对重放和恢复的 Otero 检索及本地原文复核，把宽全文命中与直接支持彻底分开。RADAR 的 experience replay 命中被记录为检索反例，Wang et al.（2020）被限定为资源受限选择的相邻适用；三篇对应方法占位均保持开放。

### 2026-08-24 同首作者同年书目节点身份

新增规则 39。论文二 v13 删除 DataSentinel 正文责任后，旧脚本因两项 Liu 2025 共用首作者姓氏年份而把孤儿误判为已调用；Hu 2020 构造测试又显示跨 mention 的 Wang token 可以污染 generic 引文。当前流程把 DOI 或规范题名加完整作者表作为节点身份，把姓氏年份降为候选键，并要求逐 mention 在同一引文原子内唯一归属。该规则只修正文引用边身份，不改变 165 中任何来源责任或三篇 citation-support 未通过状态。

### 2026-08-24 统计应用先例到规范方法来源的反向追踪

根代理复读平台奖项与网站封锁两篇权威 IS 论文的完整方法、结果和讨论窗口。两文分别展示功效模拟和少聚类 wild cluster bootstrap 如何在具体数据条件后落位，并回引 Gubler et al.、Donald and Lang、Cameron, Gelbach, and Miller 等来源。新增第 33 条，要求统计检索同时保留应用先例、规范来源和作者协议三层；本轮不因发现同名方法而关闭三篇现有占位。

### 2026-08-24 原始定义到后续实现的公式谱系

根代理从论文一 GAE 公式反向读取 Schulman et al. 2015，再沿 PPO 第 5 节核实其直接引用和固定长度截断。新增第 34 条，要求方法引用链分别保存定义节点、后续实现节点与本文适配，避免只引新文献而丢失源对象，也避免只引经典来源而漏掉直接实现先例。GAE 原文提到更早相关公式的事实另存为历史优先权触发器，不在当前未声称首创的段落中无限回溯。

### 2026-08-24 直接引用边与实施对象连续性

论文二公式映射核到 ACAA 对 Bahdanau 的直接引用，但两文实际注意力公式并不相同；Guo 到 DTL-EL、Gneiting and Raftery 到 DSDL 也未核到可写成方法发展链的直接实施关系。新增第 35 条，要求引文边与数学对象连续性同时成立才登记发展节点；否则只记录直接引用但对象变化，或并行的规范方法与 IS 披露节点。

### 2026-08-24 逐句检索停止条件与负结果入账

### 2026-08-24 来源责任闭环后的网络规则

第 132 条，Chandy–Lamport、rr 与 DMTCP 在当前 P3 责任上登记 `read_do_not_cite`。原因是它们确认参与者域或记录边界，却不承担 chosen successor 的新增句责，也未验证与 TClone 的直接发展边。读过不引用可防止引文堆叠。

第 133 条，占位退休建立三条状态边而不是一个 closed 节点。`literal_removed` 记录正文变化，`citation_responsibility_bounded` 记录来源承担范围，`protocol_or_pilot_debt_open` 保留作者协议、实现和试点责任。

第 134 条，文献间没有核实直接引用边时，不得为叙事方便虚构发展链。相邻系统可以独立支持同一边界，但必须分别保存 native actor、controlled object、outcome、participant domain 与 nontransferable boundary。

### 2026-08-25 随机评价与区间来源网络增量

第 135 条，Yao et al. 2025 到 P1 只建立 `repeated_agent_reliability_measurement`。该边连接同一任务的多次独立试验与任务级可靠性，不连接中性对照、对内顺序、配对种子、`K`、`tau` 或 Wilson 区间。

第 136 条，Yang and Subramanyam 2023 到 P1 只建立 `topic_model_stability_adjacent`。该边限定为相同数据和参数设定下 LDA 主题模型结果跨运行变化，不连接一般随机工件或智能体确认对独立性。

第 137 条，Wang et al. 2020 到 P1 建立 `matched_evaluation_reporting_precedent`。相同数据划分、十次十折交叉验证、100 个估计、均值与 95% 区间属于相邻 IS 报告责任，不连接本文 pair indicator 或 agent seed distribution。

第 138 条，Brown, Cai, and DasGupta 2001 到 P1 建立 `binomial_interval_method`。该边只在固定二项试验模型下连接 Wilson 区间，不连接设计层独立同分布、共同 `p`、缺失机制或控制有效性。

第 139 条，Lin et al. 2024 到 Demšar 2006 与 Dietterich 1998 的分类器比较引用边，以及 RADAR 到 Demšar 的重复评价相邻引用边，登记为 `lineage_scope_check`。旧原文已直读，但其 actor、task 和依赖结构不等于随机智能体确认，因此本轮为 `read_do_not_cite`。

第 140 条，同一来源网络中建立 `confirmation_pair_repetition` 与 `whole_run_method_repetition` 两个不同节点。前者条件于首次命中候选，后者以完整方法运行为评价单位。相同 repeated-trial 术语不建立跨节点支持边。

第 141 条，较新来源引用旧理论时，必须比较旧原文与新文的对象、随机化单位、估计对象、依赖假设和新增边界。只有出现可核实的 scope development 才建立发展边。年代更新、共同引用或相邻适用只分别建立 application、boundary 或 adjacency，不能写成直接理论发展。

### 2026-08-25 AI 语义判断与对抗性结果边界网络增量

第 142 条，Pillet et al. 2026 到 P1 只建立 `specialized_semantic_model_validation_precedent`。该边连接分离的数据划分、固定种子、模型身份、人工或作者标签、分类指标和 ECE，不连接轨迹来源因果、提示注入鲁棒性或安全结果。

第 143 条，Zhou et al. 2024 到 P1 只建立 `structured_AI_coding_with_expert_benchmark`。该边连接角色、任务、输入和输出格式以及领域专家比较，不连接冻结版本、校准阈值、对抗性轨迹或模型即真值。

第 144 条，Ruan et al. 2024 ToolEmu 到 Debenedetti et al. 2024 AgentDojo 建立 `adversarial_evaluator_boundary_addition`。ToolEmu 采用完整轨迹 LLM 评价器并用人工标注验证，AgentDojo 因同一注入可能劫持评价器而改用模型输出及环境状态上的确定性效用和安全函数。

第 145 条，上述发展边在目标段的采用方式为 ToolEmu `read_do_not_cite`、AgentDojo `direct_adversarial_boundary`。旧节点解释方案演变，不新增独立句责。RADAR 只建立 `prose_sequence_prototype`，不得连接到 judge validity。

第 146 条，辅助裁判输出节点与安全真值节点必须分开。`candidate_content_trace_label` 可连接人工基准、逐类指标、校准、弃权和人工审计。`frozen_safety_result_contract` 只连接确定性结果条件。两节点之间禁止建立 `defines_truth` 边。

### 2026-08-25 分组划分与运行时隔离来源网络增量

第 147 条，Larsen and Bong（2016）到 Pillet et al.（2026）建立 `direct_citation_method_application_with_grouping_unit_adaptation`。旧文诊断 pair-level split 保留关系网络，新文明确沿用并改为 article-level sampling。该边不连接 P1 的软件分组键，也不标理论发展。

第 148 条，RATER 到 P1 的分组边只连接 `shared_upstream_unit_before_partitioning`。article、item text 和 construct definition pair 与 task、repository、original image 和 template instance 保持不同节点，禁止建立 object equivalence。

第 149 条，Wei et al.（2025）到 P1 建立 `development_selection_then_heldout_evaluation`。该边连接开发集表现选择参数与测试数据留作评价，不连接封存期禁止更新或结果反馈防火墙。

第 150 条，RADAR 到 P1 建立 `equal_RL_training_step_budget_adjacent`。该边只连接全部强化学习算法的相同训练时间步，不连接回报构成、开发试验数、初始化或空档案。

第 151 条，Ruoff et al.（2023）与 Temizkan et al.（2017）分别建立 `task_level_state_reset_adjacent` 和 `replication_initialization_adjacent`。前者对象为 dashboard，后者对象为十个感染节点初始化的 simulation。两边可共同指向运行时隔离责任，但不得直接指向 empty path archive。

第 152 条，Ampel et al.（2024）的早期训练与后期未见样本测试建立 `temporal_transfer_adjacent_read_only`。P1 当前没有时间 estimand、时间切分或结果报告合同，因此该边保持 `READ_DO_NOT_CITE_IN_SECTION_4_8`。

第 153 条，文献网络中新增 `static_partition_isolation` 与 `runtime_state_isolation` 两个不同节点。article-level group split 只能进入前者，task reset、replication initialization、carryover firewall 和 evidence-channel firewall 进入后者。相同的 isolation 上位词不产生跨节点直接支持边。

### 2026-08-25 写作原型、实质证据与状态对象分型增量

第 154 条，每个被采用来源可以同时建立 `writing_prototype_edge` 与 `substantive_evidence_edge`，但两边不得合并。前者连接问题诊断、先例采用、边界收束和作者协议的段落功能。后者只连接来源明确做过、发现或证明的精确谓词。原创协议没有后者时登记 `author_protocol_no_acceptable_external_anchor`，不得生成虚构 citation edge。

第 155 条，RADAR 到 P1 的预算网络拆成 `environment_training_time_step` 和 `optimizer_update_step` 两个节点。RADAR line 196 只进入前者。P1 的相同 optimizer-update count、development-trial budget 和 reward composition 分别进入作者协议节点，三者与 RADAR 之间禁止建立 direct-support edge。

第 156 条，封存网络拆成 `frozen_configuration` 与 `trajectory_runtime_state_evolution`。模型、门槛、停止规则、回报权重和配置版本进入前者；当前任务内按事件更新的关系图、路径档案和资源账本进入后者。两节点可在同一封存 episode 共存，禁止建立 `configuration_update_equivalent_to_state_update` 或其反向边。

第 157 条，方法段的首选论证路径登记为 `problem_diagnosis -> precedent_or_adoption -> non_equivalence_boundary -> author_protocol`。该路径是 prose-structure edge，不自动产生事实支持。只有 precedent 或 adoption 节点的来源原生谓词可进入实质证据边，boundary 与 protocol 节点继续由作者承担。

### 2026-08-25 模拟规划引文网络增量

第 159 条，Johnson 原文中出现的早期 GLMM 与设计文献仅登记为 citation-lineage leads。除非后续目标谓词需要并已直接读取这些旧原文，否则不因 Johnson 引用了它们而自动加入正文。新文献的引用关系用于发现，不承担传递证明。

第 160 条，两篇相邻 Basket 应用建立 `writing_prototype_read_only`，不建立重复数规划实质边。事后功效、聚合组推断与 wild bootstrap 不等于本文的前瞻 Nrep 规划。
