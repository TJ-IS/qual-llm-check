# Run scope

- Purpose: identify objective metrics and design-to-outcome logics that can be transferred from IS benchmark-improvement articles to genuinely coding-agent-specific thesis research.
- Candidate pool: the 956 matches from `ais_is_distinctive_benchmark_logic_flash/output_v1/decisions.jsonl`.
- Unit of analysis: one complete source article and its own prior-stage structured analysis per independent API request.
- No request contains multiple articles.
- Model: `deepseek-v4-flash`; maximum concurrency: 200.
- Coding-agent uniqueness requires both autonomous-agent properties and executable software-workspace properties.
- Ordinary correctness, defects, time, productivity, usability, or generic task-success metrics do not qualify alone.
- A retained outcome must support a coherent three- or four-study series and remain objectively measurable with thesis-scale resources.
- All artifacts are isolated in this run folder.
