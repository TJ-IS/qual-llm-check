# CASA 构念开发论文引言必要性逻辑审计

## 一、现稿问题

第 62 号稿的引言虽然已经按 Chen 等（2024）的句子位置配置了 C19 至 C39 标记，但若干段落只完成了形式对应，没有完全复现原文的必要性论证。

第一，C19.9 从 Kumar 等（2025）和 Dhanorkar 等（2026）关于持续互动、共同规划、实时查看和结果复核的发现，直接推导用户认识智能体任务状态是一个有待概念化的重要问题。前述研究能够支持用户仍需判断任务进展和结果，但不能单独支持必须形成一个新构念。合理的推导应止于编程智能体使用包含一种持续的任务状态判断要求；该要求为何适合由态势感知解释、为何需要情境化构念，应分别在后续基础构念和测量不匹配段落建立。

第二，C27 两段把七项人工智能辅助编程研究依次罗列后，再总结它们尚未形成共同构念。这些材料适合在理论背景中系统呈现，现稿也已在表 2 和 C53 至 C55 中完成这一工作。在引言重复罗列既没有像 Chen 等（2024）的 C27 那样继续比较旧量表和新交互的具体差异，也削弱了研究必要性这一主线。

第三，CASA 定义使用暂定一词，使正式构念定义呈现为工作备忘录。构念的经验维度尚待开发，并不意味着论文不能正式界定研究对象。正文应直接使用本文将 CASA 定义为，并在随后说明经验维度由阶段 1 确定。

第四，现稿使用较多冒号引出定义、问题、步骤和表格内容。Chen 等（2024）的正文主要依靠完整句子和段落推进，冒号集中于表题、固定术语或必要列举。新版应在正文中使用完整谓语表达，研究问题、步骤和阶段名称使用空格或独立标题，避免以冒号代替句法关系。

## 二、Chen 等（2024）引言的必要性链条

| --- | --- | --- |

## 三、Dong 第三章可以补充的引言逻辑

Dong 第三章的概念开发开篇有三项逻辑可用于加强 CASA 引言。

其一，概念开发是后续实证研究的基础。Dong 明确指出，社会化商务技术可供性的清楚概念和有效测量，是后续检验技术可供性影响的前提。CASA 引言也应说明，没有共同构念和量表，研究者无法系统比较不同用户和产品，也无法检验哪些界面、任务和用户因素影响这种认识，以及这种认识如何连接到使用评价。

其二，基础构念应当与研究情境中的目标行为具有内在联系。Dong 并非因为社会化商务新颖而采用技术可供性，而是因为该构念能够连接技术属性与用户购物目标。CASA 采用态势感知的理由同样应落到目标导向的动态判断。用户需要依据当前任务局面决定继续委托、补充信息、介入调整或接受结果，态势感知因此与编程智能体使用过程具有直接联系。

其三，情境化开发必须证明既有维度不能覆盖新情境。Dong 在概念开发章节比较了既有技术可供性维度与社会化商务的社交和交易目标。CASA 引言应具体说明，SART 的航空任务属性和 SAGAT 的预定任务真值不能表示由智能体行动持续生成、分布在软件制品与执行证据中的主观任务认识。

Dong 第二章承担完整理论综述，因此这些逻辑只用于引言的必要性表达。概念定义、跨情境文献表、动态态势感知理论及相邻研究缺口仍应放在 CASA 理论背景中，避免引言重复第二章式综述。

## 四、新版引言的证据边界

1. McKinsey Global Institute（2023）和 Stack Overflow（2025）只用于证明人工智能参与软件开发具有经济与实践重要性，不用于证明 CASA 已经存在或影响满意度。
2. Kumar 等（2025）和 Dhanorkar 等（2026）只用于证明真实编程智能体使用仍包含持续互动、任务查看、复核和后续判断，不用于直接证明新构念成立。
3. Endsley（2023）用于支持态势感知对人与人工智能有效互动及适当信任的重要性；Nadj 等（2020）和 Jaeger 与 Eckhardt（2021）用于支持态势感知在 IS 情境中能够连接系统设计、任务评价和行为结果。
4. Baronas 与 Louis（1988）只支持感知控制与系统接受的关系，Bhattacherjee（2001）只支持满意度与持续使用意愿的关系。CASA 对感知控制和满意度的作用仍是待检验关系。
5. 新版不会以任务表现、客观监督或正确接管定义 CASA，也不会在引言中展开主客观态势感知的测量争论。

## 五、写作约束

1. 引言每段只承担一个主要任务，段末句必须由段内证据自然推出。
2. 不使用暂定、初步定义或工作定义等研究备忘录措辞。
3. 删除引言中的相邻人工智能编程研究清单，将其保留在理论背景表 2。
4. 正文避免使用冒号引出定义、推论、研究问题和步骤。
5. 不把有待检验的 CASA 后果写成已经成立的因果关系。
6. 研究必要性最终落实为三个相互连接的问题，即现实使用需要任务状态判断、既有态势感知测量遗漏代理式软件状态、缺少构念和量表阻碍后续比较及因果研究。
