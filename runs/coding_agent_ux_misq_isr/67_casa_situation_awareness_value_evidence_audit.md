# CASA 引言第二段的态势感知价值证据审计

## 一、数据库检索结论

对 `database/ALL_AIS_Basket_11.csv` 的题名、摘要、作者关键词和索引关键词进行精确检索后，共有 16 篇记录命中 situation awareness 或 situational awareness。进一步检索 subjective situation awareness、subjective situational awareness、SART、Situation Awareness Rating Technique、self-reported situation awareness 和 perceived situation awareness，命中数量为 0。

这个结果意味着 Top11 摘要数据库能够支持个体态势感知具有决策、评价和行为价值，但不能直接支持主观态势感知的价值。CASA 引言需要把两类证据分开使用。Top11 文献负责说明态势感知为何值得研究，数据库外的主观测量经典文献负责说明主观态势感知为何仍具有独立的体验和行为意义。

## 二、Top11 数据库中的核心价值证据

### 1. Jaeger 与 Eckhardt（2021）

该文发表于 *Information Systems Journal*，题为 *Eyes Wide Open: The Role of Situational Information Security Awareness for Security-Related Behaviour*，DOI 为 `10.1111/isj.12317`。

这是数据库中最适合支持 CASA 研究价值的个体层实证研究。作者从一般态势感知文献中推导情境信息安全态势感知，并通过包含眼动、调查和实际行为的多方法网络钓鱼实验研究 107 名员工。研究发现，过去的网络钓鱼经验和系统警告提高态势感知，邮件的情境相关性和错误显著性降低态势感知；态势感知进一步提高感知威胁和感知应对效能，并最终影响实际安全行为。

该研究可以支持一个有限但关键的命题。个体对当前动态技术情境的认识不是附带体验，它能够连接系统设计和个体经验与后续评价及行为。该研究不能直接证明 CASA 具有相同后果，也不能证明主观自评与实际行为之间的关系，但它为研究编程智能体情境中的对应认知状态提供了信息系统领域的直接先例。

### 2. Nadj 等（2020）

该文发表于 *Decision Support Systems*，题为 *The Effect of Interactive Analytical Dashboard Features on Situation Awareness and Task Performance*，DOI 为 `10.1016/j.dss.2020.113322`。

作者以态势感知为理论透镜，通过 83 名参与者的实验和眼动数据检验交互式分析仪表盘对态势感知与任务表现的影响。结果显示，what-if 分析功能提高任务表现，却可能降低态势感知并产生脱离环路问题。

该研究可以支持引言中的第二个关键命题。系统提高任务表现并不意味着用户仍然了解任务局面，因而只观察编程智能体的任务完成率或产出质量可能遗漏一种独立的用户认知状态。该文不属于主观态势感知量表研究，也没有检验满意度或持续使用，因此只应用于证明态势感知不能由系统表现替代。

### 3. Jiang 等（2025）

该文发表于 *MIS Quarterly*，题为 *Supporting Community First Responders in Aging in Place: An Action Design for a Community-Based Smart Activity Monitoring System*，DOI 为 `10.25300/MISQ/2024/18446`。

研究关注远程且缺少专业医疗知识的社区响应者如何通过智能监测系统形成态势感知。作者依据感知、理解和预期提出四项设计原则，用于促进知情决策和及时响应。

该研究与编程智能体具有结构类比。两种情境中的用户都没有直接经历系统所监测或执行的全部过程，而需要通过系统呈现的信息形成任务认识并作出后续判断。该文能够支持状态呈现与知情决策之间的设计逻辑，但它是行动设计研究，不能作为 CASA 后果关系的直接实证证据。

### 4. Naderpour 等（2014）

该文发表于 *Decision Support Systems*，题为 *An Intelligent Situation Awareness Support System for Safety-Critical Environments*，DOI 为 `10.1016/j.dss.2014.01.004`。

文章认为正确理解复杂动态情境是改善表现和减少错误的重要认知因素，并据此开发态势感知支持系统。该文对态势感知价值的表述较强，但完整态势感知测量仍被列为后续评价工作。因此，它适合用于说明研究传统如何理解态势感知的价值，不宜作为已经验证主观态势感知后果的核心证据。

## 三、数据库中不应承担价值论证的记录

其余多数命中文献把 situational awareness 作为系统目标、组织能力、信息共享结果或应用收益。例如跨语言暗网分析、欧洲能源信息共享中心、运营商业智能平台和 Web of Things 推荐研究。这些文献可以证明该术语在信息系统研究中的使用范围，却没有把个体态势感知操作化为构念并检验其后果，不能用于引言第二段的核心推理。

## 四、主观态势感知的补充证据

### 1. Rose 等（2018）

该文发表于 *Applied Ergonomics*，题为 *The Low-Event Task Subjective Situation Awareness Technique*，DOI 为 `10.1016/j.apergo.2017.12.006`。作者针对低事件列车驾驶开发 LETSSA。研究显示，该主观测量能够识别态势感知差异，预测客观和主观任务表现，并且没有与工作负荷高度重合。

该文提供了最适合引言使用的主观价值证据。它表明经过任务情境化的主观态势感知不是单纯的界面偏好或工作负荷评价，能够与任务表现产生具有意义的关系。但该结果来自列车驾驶，不能直接证明 CASA 的后果。

### 2. Endsley 等（1998）

该研究同时使用 SART 和 SAGAT。SART 与简单主观态势感知、态势感知充分性、信心和主观表现高度相关，却与 SAGAT 没有显著对应。该结果说明主观态势感知能够反映用户如何评价自己的局面认识，并与信心和主观表现评价相联系，但不能保证用户实际掌握的任务状态正确。

这项证据适合支持 CASA 作为用户体验构念的独立意义。用户是否感觉自己了解编程智能体任务，可能影响其信心和后续选择，即使这种感觉与客观任务知识并不完全一致。引言不必展开主客观争论，只需用更直接的 Rose 等（2018）支持主观态势感知具有可研究的结果关联；Endsley 等（1998）留在理论背景中解释测量边界。

## 五、第二段应建立的完整逻辑

第二段需要依次建立三个前提。

第一，态势感知在动态信息系统任务中具有行为和决策价值。Jaeger 与 Eckhardt（2021）说明个体态势感知会影响评价和实际行为，Nadj 等（2020）说明任务表现不能代替态势感知。

第二，主观态势感知同样具有独立研究价值。Rose 等（2018）表明任务特定的主观态势感知能够预测主观和客观表现，且不同于一般工作负荷。

第三，编程智能体使用实际包含需要这种任务认识的连续判断。Kumar 等（2025）显示渐进互动与任务成功相关，Dhanorkar 等（2026）显示用户需要共同规划、实时查看和事后复核。

这三类证据共同支持的结论不是 CASA 已经影响满意度或任务表现，而是编程智能体形成了一个值得研究的态势感知问题。一般态势感知研究说明这种认知状态为何重要，主观测量研究说明用户自己的认识判断为何值得单独测量，编程智能体研究则说明这种判断发生在何种新的任务结构中。

## 六、建议替换的第二段逻辑

这种委托改变了用户参与软件任务的方式，但没有消除用户在任务推进过程中作出判断的需要。Kumar 等（2025）发现，采用渐进方式解决任务并持续调整智能体工作的开发者更容易完成真实软件任务。Dhanorkar 等（2026）进一步表明，开发者会在事前限制、共同规划、实时查看和事后复核等阶段持续判断智能体工作的进展与结果。这些活动要求用户不仅接收智能体最终提交的结果，还要认识智能体采取了哪些行动、软件制品如何变化以及当前结果对任务意味着什么。既有态势感知研究表明，个体对当前任务情境的认识与其后续评价和行为存在联系。Jaeger 与 Eckhardt（2021）发现，个体的情境信息安全态势感知提高感知威胁和感知应对效能，并最终影响实际安全行为。Nadj 等（2020）则发现，交互式分析功能可以提高任务表现却降低态势感知，说明系统产出改善不能替代用户对任务局面的认识。在其他动态任务环境中，主观态势感知也表现出与任务结果的关联。Rose 等（2018）开发的任务特定主观量表能够预测客观和主观任务表现，并且没有与工作负荷高度重合。在人与人工智能交互研究中，态势感知也被视为用户与自主系统有效互动的重要认知条件（Endsley, 2023）。来自相邻动态任务的证据由此表明，用户形成的任务认识可能关系到其后续评价与行动。由于编程智能体用户在不直接执行每一步操作的情况下仍需判断任务进展与结果，用户对智能体任务态势的主观认识因而构成一个具有理论和实践意义的研究问题。
