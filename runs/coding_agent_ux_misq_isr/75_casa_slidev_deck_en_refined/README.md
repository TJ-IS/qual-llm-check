# CASA Slidev Deck, English Refined Version

This is the refined English Slidev deck for the coding-agent situation awareness construct-development project.

It follows the style and narrative rhythm of `slidev_ref/slides.md`, using the `slidev-theme-scholarly` theme.

The 36-slide visible sequence uses the background before question formulation in `54_casa_task_and_experience_outcomes_v9.md` for Slides 2-6. Slides 7-23 follow the argument order of `68_casa_construct_development_article_plan_v5.md` for the research question and theoretical background. Slides 24-26 condense the method into Reddit-based construct development and subsequent scale development. Slide 27 closes the argument, and Slides 28-36 contain manually typeset references. A page-matched Chinese defense script is stored in `../76_casa_slidev_presentation_script_zh.md`.
