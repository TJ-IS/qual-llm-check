# 草案范围——用户确认前禁止运行

- 当前状态：仅设计和审阅提示词。
- 没有创建 API 运行配置、任务队列或结果文件，也不会在用户明确确认前调用模型。
- 每个请求只包含一篇完整文章；不同文章分别建立独立任务。
- 计划使用中文系统提示词和中文用户提示词。
- 第一层仅有两个必要条件：纯客观结果指标是最终目标与核心贡献；通过明确的软件制品设计或改造实现。
- 第二层是第一层通过文章中的严格子集：心理学相关理论实质指导软件制品设计。
- 理论要求不参与第一层判断。
- 不纳入广义 IS 独特性、抗技术过时、coding-agent 迁移、论文系列设计、模仿价值或实施难度等其他判断。
- 模型、候选文章范围、并发数和输出预算均尚未在本草案中执行；确认提示词后再确定或沿用用户指定设置。
