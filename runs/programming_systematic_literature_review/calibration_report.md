# 题录初筛边界校准

## 校准集

使用 `direct_programming_28_manual_review.md` 中已经逐篇阅读全文复核的 28 条记录：

- 人实际执行代码、SQL、电子表格、程序理解/修改或系统构建任务：20 条；
- 项目/团队层、纯代码制品/度量或确定性工具：8 条。

其中两篇 application domain knowledge 论文使用同一批 24 名 COBOL 程序员，因此 20 条论文记录约对应 19 个独立实证设置；题录校准按论文记录计数，不按样本计数。

## 冻结提示词结果

DeepSeek V4 Pro 使用题名、摘要和关键词，在不知道人工标签的批量初筛中得到：

| 人工标签 | 模型保留 | 模型排除 |
|---|---:|---:|
| 核心直接编程（20） | 20 | 0 |
| 项目/团队/纯制品边界（8） | 0 | 8 |

校准中特别验证了下列容易误判的边界：

- **保留：** 参与者连续七周亲自开发 CLIPS 知识系统，即使文章也研究开发方法和知识表示；
- **保留：** 用 SQL 查询编写绩效验证数据模型或表示方法；
- **保留：** 电子表格公式开发、检查和调试；
- **排除：** 软件团队集体所有权、编码规范和项目质量；
- **排除：** 开源项目核心—外围结构、项目面板和纯代码复杂度；
- **排除：** 确定性 COBOL 数据流分析工具本身。

## 不得过度解释

这组结果用于确认提示词能重现已知边界，不是随机抽样，也不是独立外部测试集，不能据此声称全库敏感度、特异度或 100% 准确率。全库候选仍需第二次独立题录判断和全文裁决。
