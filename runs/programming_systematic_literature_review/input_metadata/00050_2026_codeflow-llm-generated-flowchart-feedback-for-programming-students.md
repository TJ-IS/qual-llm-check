Title: CodeFlow: LLM-Generated Flowchart Feedback for Programming Students
Abstract: This poster introduces CodeFlow, a web-based system that leverages large language models (LLMs) to deliver real-time, visual feedback for programming students. CodeFlow translates student-written code into flowcharts, allowing learners to visualize and compare the logic flow of their incorrect submissions to correct solutions. The flowchart feedback highlights syntax errors and logic errors directly within the flowchart, offering an intuitive way for students to pinpoint issues without revealing full solutions. We hypothesize that by bridging flowcharts and coding, CodeFlow will enable students to gain a deeper understanding of program structure and enhance their debugging experience. © 2026 Copyright held by the owner/author(s).
