Title: From Black Box to Learning Artifact: A Proposed Pedagogical Redesign of AI Coding Assistants for Novice Programmers
Abstract: Large language model (LLM)-based coding assistants can generate complete, functional programs from natural language prompts, enabling rapid prototyping and lowering barriers to software creation. However, for novice programmers, these systems often function as black boxes: learners receive finished code artifacts without engaging in the reasoning processes through which programming knowledge is developed. In this poster, we explore how LLM-based code generation tools can be redesigned as learning artifacts and propose a pedagogical redesign of AI coding assistants for introductory programming contexts. Our approach scaffolds learners through three phases: problem understanding, incremental code generation, and solution evaluation. The system elicits and externalizes learners' requirements, incrementally maps requirements to generated code, and supports reflection through test-case construction and evaluation of generated solutions. We argue that by making the processes underlying code generation visible and inspectable, AI coding assistants can support purposeful, interest-driven programming while preserving learning-critical cognitive processes. © 2026 Copyright held by the owner/author(s).
