Title: Just-in-Time Tokens: Adaptive Token Pacing for Cognitive-Friendly LLM Streaming
Abstract: Modern LLMs stream text incrementally to improve responsiveness, yet unpredictable pacing often disrupts reading flow and ignores task-specific demands. We conducted expert interviews (N=4) and a pilot study (N=12) to identify key timing-related pain points. Based on these findings, we developed Just-in-Time, a scheduling framework that aligns text delivery with individual reading rhythms and task complexity using structured units. A controlled study (N=24) on programming tasks shows that Just-in-Time significantly reduces frustration and enhances cognitive alignment compared to standard streaming. This work underscores the critical role of adaptive timing in user-centered LLM interaction design. © 2026 Copyright held by the owner/author(s).
