Title: kAPR: A coverage-guided, context-aware agent for automated repair of Linux kernel bugs
Abstract: Context: With the widespread success of fuzzing, numerous bugs have been discovered in the Linux kernel, creating a backlog of unresolved bugs that underscores the need for automated program repair (APR). Large language models (LLMs) have recently emerged as a powerful paradigm for APR, achieving remarkable performance. However, unlike user-space programs, the Linux kernel presents unique challenges due to its massive scale and monolithic structure. Moreover, leveraging LLMs to achieve efficient and reliable automated repair for kernel bugs while safeguarding against model hallucinations remains a critical problem. Objectives: To address these challenges in OS-level repair, we introduce kAPR, a coverage-guided, context-aware APR system capable of patching real-world Linux kernel bugs while minimizing manual developer effort and verification overhead. Methods: kAPR employs a dual-agent framework tailored to the Linux kernel development process during patch generation and refinement. To facilitate the comprehension of bug-related code, which is essential for generating high-quality patches yet challenging within the massive Linux codebase, we equip the LLM agent with a coverage-guided code context retrieval (CG-CCR) algorithm, serving as an effective code navigation mechanism. Results: Through a comprehensive evaluation on 543 real-world Linux kernel bugs, kAPR demonstrates superior performance by successfully repairing 27.81% of cases – a significant improvement over state-of-the-art APR tools. Our detailed ablation study further reveals the contribution of each key component to kAPR’s effectiveness. Notably, kAPR has successfully generated three plausible patches for currently active Linux kernel bugs, demonstrating its practical utility in automating kernel maintenance tasks. Conclusion: kAPR establishes a new paradigm for operating system-level APR. It provides a practical and autonomous maintenance tool for designing next-generation resilient, self-maintaining operating systems. © 2026 Elsevier B.V.
