Title: Detecting Pure Functions in JavaScript Using Machine Learning
Abstract: JavaScript, as one of the most popular front-end languages today, has inspired the widespread development and use of various JavaScript libraries. However, the issue of "unused modules reducing program efficiency" has persisted. To address this, the concept of pure functions was introduced to JavaScript programming, with software tools available to remove unused modules from JavaScript project bundles, thereby optimizing the code. Nonetheless, such tools require access to complete source code to accurately identify pure functions in JavaScript, which is often impractical when certain parts of the source code are unavailable. This study focuses on analyzing JavaScript function call code rather than the complete code, using machine learning methods to determine whether a called function is pure. This is the first study to apply machine learning methods to research JavaScript pure functions. The main contributions of this paper include: (1) constructing a dataset comprising both pure and unpure function calls; (2) proposing four research methods: a traditional machine learning model based on character features, an LSTM model based on AST structural features, a CNN model based on large model explanations and BERT tokenization, and full fine-tuning of CodeBERT on code features. Experimental results show that the LSTM model based on AST structural features achieved the highest accuracy of 0.9787, though with significant variability, while CodeBERT fine-tuning reached an accuracy of 0.9552 with more stable results. The research results indicate that introducing machine learning methods into the detection of JavaScript pure functions is entirely feasible. © 2025 Knowledge Systems Institute Graduate School.
