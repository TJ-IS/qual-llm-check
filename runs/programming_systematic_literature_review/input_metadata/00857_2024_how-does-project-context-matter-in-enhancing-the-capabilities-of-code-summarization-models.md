Title: How does project context matter in enhancing the capabilities of code summarization models?
Abstract: High-quality code summaries are vital for improving code understanding, reuse, and maintenance efficiency. With the rise of deep learning, neural networks have become a hot topic in code summarization. Utilizing lexical and structural code information enhances summary quality, but often relies solely on the source code. Recent efforts to improve semantic understanding through additional randomly selected context have faced challenges of model interference. This paper introduces the CE-GCS method, incorporating a denoising strategy to remove dataset noise and redundant information. It leverages project-level context based on calling and dependency rules to enrich code representation. The GA-FCSM model, built on the Transformer architecture, utilizes multi-head attention to capture project-level context, integrating textual token sequence and AST structure information by fusion network to improve the performance of summary generation. Evaluating CE-GCS using BLEU, ROUGE, and METEOR, the paper demonstrates the importance of project-level context in enhancing semantic understanding. GA-FCSM outperforms baseline models that use various input combinations. Ablation experiments further highlight the contribution of textual tokens, AST, and context, while confirming the benefits of the fusion network and copy mechanism. The proposed context fusion index (CSF, CNF, CCF) offers new insights into the role of project-level context in code summarization. © 2024 Knowledge Systems Institute Graduate School.
