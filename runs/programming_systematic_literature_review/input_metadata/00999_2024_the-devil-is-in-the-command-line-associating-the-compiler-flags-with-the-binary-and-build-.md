Title: The Devil Is in the Command Line: Associating the Compiler Flags With the Binary and Build Metadata
Abstract: Engineers build large software systems for multiple architectures, operating systems, and configurations. A set of inconsistent or missing compiler flags generates code that catastrophically impacts the system's behavior. In the authors' industry experience, defects caused by an undesired combination of compiler flags are common in nontrivial software projects. We are unaware of any build and CI/CD systems that track how the compiler produces a specific binary in a structured manner. We postulate that a queryable data-base of how the compiler compiled and linked the software system will help to detect defects earlier and reduce the debugging time. © 2024 ACM.
