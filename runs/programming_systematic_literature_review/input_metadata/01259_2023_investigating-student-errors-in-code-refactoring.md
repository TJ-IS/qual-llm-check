Title: Investigating Student Errors in Code Refactoring
Abstract: Learning to develop code of good quality is challenging. One way to improve code quality is through code refactoring. Students make several mistakes when refactoring code. This research project aims to comprehend student errors in code refactoring, as well as to evaluate how the use of automated tools can help students remediate these errors.  © 2023 Owner/Author.
