Title: Proceedings - 2022 ACM/IEEE 44th International Conference on Software Engineering: Software Engineering in Practice, ICSE-SEIP 2022
Abstract: The proceedings contain 53 papers. The topics discussed include: a cross-company ethnographic study on software teams for DeVos and microservices: organization, benefits, and issues; a software impact analysis tool based on change history learning and its evaluation; a static analysis framework for data science notebooks; a unified code review automation for large-scale industry with diverse development environments; an empirical study on implicit constraints in smart contract static analysis; an industrial experience report on retro-inspection; automated labeling and classification of business rules from software requirement specifications; automated visual testing for mobile apps in an industrial setting; and automatic anti-pattern detection in microservice architectures based on distributed tracing.
