Title: A Dataset of Vulnerable Code Changes of the Chromium OS Project
Abstract: This paper presents a an empirically built and validated dataset of code reviews from the Chromium OS project that either identified or missed security vulnerabilities. The dataset includes total 890 vulnerable code changes categorized based on the CWE specification and is publicly available at: https://zenodo.org/record/453989. © 2021 IEEE.
