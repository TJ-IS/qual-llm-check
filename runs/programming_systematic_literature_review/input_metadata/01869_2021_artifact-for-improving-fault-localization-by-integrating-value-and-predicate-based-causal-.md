Abstract: This work presents an overview of the artifact for the paper titled 'Improving Fault Localization by Integrating Value and Predicate Based Causal Inference Techniques'. The artifact was implemented in a virtual machine and includes the scripts for the UniVal algorithm for fault localization employing the Defects4J test suite. Technical information about the individual components for the artifact's repository as well as guidance on the necessary documentation for utilizing the software is provided. © 2021 IEEE.
