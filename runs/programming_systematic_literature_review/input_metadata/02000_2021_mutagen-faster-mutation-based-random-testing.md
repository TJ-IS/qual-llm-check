Title: MUTAGEN: Faster Mutation-Based Random Testing
Abstract: We present MUTAGEN, a fully automated mutation-oriented framework for property-based testing. Our tool usesnovel heuristics to improve the performance of the testing loop, and it is capable of finding complex bugs within seconds. We evaluate MUTAGEN by generating random WebAssembly programs that we use to find bugs in a faulty validator. © 2021 IEEE.
