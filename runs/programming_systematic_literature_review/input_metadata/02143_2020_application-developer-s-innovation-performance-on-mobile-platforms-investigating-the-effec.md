Title: Application developer's innovation performance on mobile platforms - Investigating the effect of module reuse
Abstract: Firms are establishing online platforms to support professional developers in creating services, such as iOS and Android platforms for mobile applications. As the mobile application market is becoming more and more competitive, mobile application innovation is significant for professional developers. The key feature of platform-enabled innovation is the reprogrammable and reusable modules embedded in the platform development environments. However, how the professional developers' innovation performance is influenced by module reuse is unknown. Our study focuses on the important research gap. Drawing on knowledge reuse theory, we conceptualize two different kinds of module reuse, namely, module reuse for replication and module reuse for innovation. And then we investigate the different effects of module reuses on the developer's innovation performance. © Proceedings of the 24th Pacific Asia Conference on Information Systems: Information Systems (IS) for the Future, PACIS 2020.
