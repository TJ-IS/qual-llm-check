Title: Phoenix: A Tool for Automated Data-Driven Synthesis of Repairs for Static Analysis Violations
Abstract: One of the major drawbacks of traditional automatic program repair (APR) techniques is their dependence on a test suite as a repairspecification. In practice, it is often hard to obtain specificationquality test suites. This limits the performance and hence the viability of such test-suite-based approaches. On the other hand, staticanalysis-based bug finding tools are increasingly being adopted inindustry but still facing challenges since the reported violationsare viewed as not easily actionable. In previous work, we proposed a novel technique that solves both these challenges througha technique for automatically generating high-quality patchesfor static analysis violations by learning from previous repair examples. In this paper, we present a tool Phoenix, implementingthis technique. We describe the architecture, user interfaces, andsalient features of Phoenix, and specific practical use cases ofits technology. A video demonstrating Phoenix is available athttps://phoenix-tool.github.io/demo-video.html. © 2020 Copyright held by the owner/author(s).
