Title: Programming error repair guidance based on historical learning behavior
Abstract: Online programming education comes in many forms, but it has an ongoing challenge that it can't give students the quick and personalized guidance which can help to repair bugs when they make mistakes, and that, if the student's wrong program is directly be modified, the student does not understand why to do that, so there is no guiding significance. In this paper, we use the history programming data and the compile error reports from the educoder to provide personalized program repair guidance for students, the educoder is an online programming education system. We through three methods to repair the programming error and ensure that students understand the mistakes, there are error repair code generation, programming error classification, and personalized repair guidance. © 2019 IEEE.
