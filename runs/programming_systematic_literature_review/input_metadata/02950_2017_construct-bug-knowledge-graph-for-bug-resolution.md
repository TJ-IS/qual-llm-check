Title: Construct bug knowledge graph for bug resolution
Abstract: This paper proposed to utilize bug knowledge graph for bug resolution. Bug knowledge graph provide more comprehensive and relevant bug information (i.e., bug reports, commits, relevant developers, etc.). Moreover, our approach can automatically update bug knowledge graph based on the the lifelong learning topic model. Preliminary results show that bug knowledge graph can provide more accurate and comprehensive information related to a bug issue. © 2017 IEEE.
