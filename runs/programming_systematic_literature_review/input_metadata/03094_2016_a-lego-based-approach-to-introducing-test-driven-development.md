Title: A LEGO-based approach to introducing test-driven development
Abstract: Test-driven development (TDD) is an important software engineering technique that requires writing tests before writing the code to be tested. We describe an approach to introduce the main ideas and practices of TDD using an engaging hands-on activity where students write test cases and construct testable tangible objects with LEGO bricks.
