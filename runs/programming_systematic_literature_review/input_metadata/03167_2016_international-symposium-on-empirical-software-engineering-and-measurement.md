Title: International Symposium on Empirical Software Engineering and Measurement
Abstract: The proceedings contain 57 papers. The topics discussed include: an external replication on the effects of test-driven development using blind analysis; a study of documentation in agile software projects; towards effectively test report classification to assist crowdsourced testing; a pilot case study on innovative behaviour: lessons learned and directions for future work; preliminary findings about the nature of work in software engineering: an exploratory survey; monitoring software quality by means of simulation methods; moving to stack overflow: best-answer prediction in legacy developer forums; software project managers' perceptions of productivity factors: findings from a qualitative study; software development practices, barriers in the field and the relationship to software quality; experiences from measuring learning potential and performance in large-scale distributed software development; virtual team configurations that promote better product quality; an empirical study on performance bugs for highly configurable software systems; is newer always better? the case of vulnerability prediction models; and identifying thresholds for software faultiness via optimistic and pessimistic estimations.
