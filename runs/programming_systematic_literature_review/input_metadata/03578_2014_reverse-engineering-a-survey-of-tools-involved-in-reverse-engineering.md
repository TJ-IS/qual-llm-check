Title: Reverse engineering - A survey of tools involved in reverse engineering
Abstract: The process of making a copy of an existing product, component, or disassembly, without using architecture design involved in present model is termed as reverse engineering. As the term "reverse" suggests, it involves working in reverse order that is opposite of conventional software design, which typically create an architectural model upon which a given software is built. In reverse engineering, we take the existing product and track it in reverse way by starting with implementation and layering down toward its distinct elements in the architecture. It is the process of identifying the functional aspects of system, which involved technical consideration pertaining to the system, function and its operation. The role of reverse engineering in software evolution is prominent as it allows the code reuse and also it involves backtracking, which results in mapping in opposite direction, which helps in tracking the old systems which don't have forward tracking phenomenon, because of lost architecture and design and fundamentals. Thus Reverse Engineering helps to recapture lost information and transforming old systems to new ones. It also helps to understand non-functional requirements of the system in terms of strength and weakness which involves features like security, interoperability, reliability. In this paper various tools involved in reverse engineering are discussed which results in improvement of developing software design by use of existing source code. © ISCA, SEDE 2014.
