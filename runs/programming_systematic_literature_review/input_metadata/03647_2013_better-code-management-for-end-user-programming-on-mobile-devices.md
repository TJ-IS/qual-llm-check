Title: Better code management for end-user programming on mobile devices
Abstract: Recently, a radically new environment for end-user programming on mobile devices has been proposed. One of its representatives, TouchDevelop developed by Microsoft Research, has successfully drawn more than 5000 users, who have published around 30 thousands TouchDevelop scripts online. In this work, I introduce an approach to better manage the existing code base written by end users through a version-control and code-search system, and thus improve the productivity of end-user programming on mobile devices. © 2013 IEEE.
