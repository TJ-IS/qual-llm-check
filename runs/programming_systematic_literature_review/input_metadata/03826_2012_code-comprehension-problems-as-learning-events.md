Title: Code comprehension problems as learning events
Abstract: Code comprehension problems have been shown to be effective assessment items in computer science education. In this paper we present qualitative and quantitative results of a study evaluating the effectiveness of code comprehension questions with feedback as learning events. Students taking an introductory programming course that satisfies a university requirement interacted with an online tutoring system using code comprehension problems about simple array algorithms as a part of a homework assignment. Students answered the problems in their own words first, before selecting a multiple choice option from the system. Both the open-ended and multiple-choice responses were collected and analyzed. Results indicate that code comprehension questions with appropriate feedback can be learning events. The use of open-ended and multiple choice responses to the same question is also shown to be useful in refining distracter items for future assessment. Recommendations from this study can be applied not only to tutoring systems, but also to the type of interactions used in worked examples in class lecture and textbook production. © 2012 ACM.
