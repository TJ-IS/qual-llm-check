Title: Multiple Visualizations and Debugging: How Do We Co-ordinate These?
Abstract: There are many popular Integrated Development Environments (IDE) that provide multiple visualizations and other sophisticated functionalities to facilitate program comprehension and debugging. To better understand the effectiveness and role of multiple visualizations, we conducted a preliminary study of java program debugging with a professional, multi-representation IDE. We found that program code and dynamic representations (dynamic viewer, variable watch and output) attracted the most attention of programmers. Static representations like Unified Modeling Language (UML) Diagrams and Control Structure Diagrams (CSD) saw significantly lesser usage. Interesting eye gaze patterns of programmers were also revealed by the study. © 2012 Authors.
