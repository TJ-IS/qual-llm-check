Title: A first look at end-user visual computation supporting sharing & reuse with Inflo
Abstract: Inflo is a web-based tool designed to support quantitative decision-making problems such as carbon calculators. Using the dataflow programming paradigm, Inflo provides an extensible environment for end-user programming. Inflo is built around the idea of collaboration and openness for opportunistic code-reuse and unplanned code sharing. © 2011 IEEE.
