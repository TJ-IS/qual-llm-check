Title: Proceedings of the IASTED International Conference on Software Engineering and Applications, SEA 2011
Abstract: The proceedings contain 28 papers. The topics discussed include: an empirical study on test driven development process for android applications; FormalTCGenerator: a tool of automatically generating test cases for infinite states reactive systems; automatic correction of programming faults using semantic networks; finding duplicate code in Java using beacons and idioms; verifying embedded systems using component-based runtime observers; design changes to the COPAR service using Opnet modeler; an interoperability architectural model based on complex system theory for the ultra-large-scale systems; towards higher changeability for airplane cabin software; service oriented organizational interoperability architectural framework; and empirical analysis of object-oriented coupling and cohesion measures in determining the quality of open source systems.
