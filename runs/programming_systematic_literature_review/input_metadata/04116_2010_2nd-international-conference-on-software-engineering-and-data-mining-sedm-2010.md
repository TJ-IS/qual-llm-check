Title: 2nd International Conference on Software Engineering and Data Mining, SEDM 2010
Abstract: The proceedings contain 137 papers. The topics discussed include: co-operative studies supporting system for software engineering; a new concurrent test framework for distributed hardware-in-the-loop simulation test system; state-of-charge estimation for power Li-ion battery pack using Vmin-EKF; modeling and behavior checking of component based architecture; a feasible and cost effective two-factor authentication; ERP software requirement elicitation with reference models; extending SQL to support QoS and semantic data gathering in WSN; a modeling approach for development of an automotive AMT ECU software with UML-RT; design of software security detection system based on system call sequences; CAWD: a tool for designing context-aware workflows; using cognitive easiness metric for program comprehension; GUI test-case generation with macro-event contracts; a hybrid ACO algorithm for the next release problem; and knowledge-based environmental information system for sustainable development of wetland area.
