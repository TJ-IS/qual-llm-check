Title: 8th ACIS International Conference on Software Engineering Research, Management and Applications, SERA 2010
Abstract: The proceedings contain 39 papers. The topics discussed include: representing unique stakeholder perspectives in BPM notations; toward a business model for software product line architecture; an operational semantics for ASSL; multi-perspective software process modeling; flexible flow shop scheduling by intelligent multi-agents; managing semantics knowledge for 3D architectural reconstruction of building objects; the software modeling and implementation of reliable server pooling and RSPLIB; towards a pattern-based framework for goal-driven business process modeling; extending the UML metamodel to provide support for crosscutting concerns; functional requirement improvements through size measurement: a case study with inexperienced measurers; process patterns for MDA-based software development; applying the psychometric theory to questionnaire-based appraisals for software process improvement; and an approach for detecting execution phases of a system for the purpose of program comprehension.
