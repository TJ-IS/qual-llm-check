Title: A visual bug report analysis and search tool
Abstract: According to recent work, duplicate bug reports in bug trackers impact negatively on software maintenance and evolution productivity due to, among other factors, the increased time spent on report analysis and validation. In order to solve this problem, this work presents and evaluates a tool based on Information Visualization techniques, aiming to assist developers during analysis and identification of duplicate bug reports. The tool development was supported by a survey conducted to identify the best opportunities for visualization techniques, according to the cognitive process for understanding bug reports information.
