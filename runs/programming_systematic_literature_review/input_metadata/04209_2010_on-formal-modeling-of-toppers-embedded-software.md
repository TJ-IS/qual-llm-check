Title: On formal modeling of TOPPERS embedded software
Abstract: Today embedded software is widely used. As the complexity of embedded systems grows, the number of tasks performed by embedded software is increasing. These tasks must communicate with each other to achieve synchronization. And therefore, the growing complexity of communications is making it increasingly difficult to program and debug these tasks. To confirm the correctness of embedded software, this paper introduces a formal specification language for embedded systems that can deal with their concurrent nature. After formalizing the APIs of an embedded real-time operating system, we demonstrate how to describe and verify embedded software formally. © 2010 IEEE.
