Title: Optimal software release strategy
Abstract: An important problem in software engineering is to determine the proper release time of the prepared software while minimizing the expenses on software testing. Because of the importance of the problem, it is necessary to have a reasonably optimal solution to suit the time constraints of software life cycle activities. In this paper, we present a software testing and debugging approach which would result in the release of good quality software in optimal time. We also present a case study to test this approach for compiler software.
