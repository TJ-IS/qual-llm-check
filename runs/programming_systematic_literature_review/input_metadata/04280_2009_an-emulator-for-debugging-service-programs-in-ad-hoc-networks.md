Title: An emulator for debugging service programs in ad hoc networks
Abstract: Debugging of service programs for ad hoc networks using a real MANET requires an enormous number of devices, a vast testing space, and a lot of people. Many MANET emulators have been proposed to solve this problem. However, these emulators have drawbacks, especially in scalability. In this article, a real-time emulator, which has scalability, a monitoring function, and portability of service programs between the emulator and a real terminal, is proposed. The proposed emulator is confirmed as more effective than existing emulators. © 2009 IEEE.
