Title: Building infrastructure for end user development of interactive artifacts: A community-based approach
Abstract: Providing programming support for end users ofWeb 2.0 communities is challenging due to the lack of common domain among different communities. I suggest an infrastructure that supports community-based construction and appropriation of end user programming tools for interactive domains. I focus on theWeb as the target platform on which the created computational tools will be executed. ©2009 IEEE.
