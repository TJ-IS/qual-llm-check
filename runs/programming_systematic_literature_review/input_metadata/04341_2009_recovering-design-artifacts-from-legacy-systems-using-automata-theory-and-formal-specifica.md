Title: Recovering design artifacts from legacy systems using automata theory and formal specifications
Abstract: With ever increasing complexity of software, new business requirements and advent of modern technology shadows its impetus repercussion on most of prominent legacy systems making them obsolete with time. These systems mostly have monolithic architecture and run on legacy obsolete hardware. Legacy applications have conventional file systems and most of data dependencies are not enforced in database systems. The myriad dimensions of these systems can only be explored by incorporating reverse engineering, in this context, is the best method to extract useful artifacts and by exploring these artifacts for reengineering existing legacy systems to meet new requirements of organizations. The reverse engineering methodologies, techniques, and tools are used to extract the structure of existing legacy systems starting from the implementations and going back to design, architecture and requirements. We introduce a novel technique for extracting the design information from legacy code using automata theory and formal specifications.
