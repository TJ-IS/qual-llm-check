Title: SEEUP 2009: Workshop on software engineering foundations for end-user programming
Abstract: The goal of the SEEUP 2009 workshop is to discuss end-user programming with a specific focus on the software engineering that is required to make it a more disciplined process, while still hiding the complexities of greater discipline from the end user. The main topic is the understanding of the problems and needs of the real end users of end-user programming and a discussion of the software engineering and supporting technology that would have to be in place to address these problems and needs.
