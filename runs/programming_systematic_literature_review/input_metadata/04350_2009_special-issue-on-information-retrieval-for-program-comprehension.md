Title: Special issue on information retrieval for program comprehension
Abstract: Information retrieval for program comprehension (IR4PC) employing various interdisciplinary information search techniques to examine the properties of existing and newly created software is presented. IR4PC techniques are applied to static concept location for determining whether a particular software component is reusable, dynamic search or software reconnaissance, and developer identification. IR4PC is studied with the help of research papers such as 'Using Information Retrieval (IR) based coupling measures for impact analysis and 'an Information Retrieval (IR) process to aid in the analysis of code clones. Assessing IR-based traceability recovery tools through controlled experiments and an empirical analysis of Information Retrieval based concept location techniques in software comprehension are also helpful in IR4PC study.
