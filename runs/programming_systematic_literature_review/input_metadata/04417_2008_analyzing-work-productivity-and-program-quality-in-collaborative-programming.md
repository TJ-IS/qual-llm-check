Title: Analyzing work productivity and program quality in collaborative programming
Abstract: Pair Programming practices usually take place on a single computer where two programmers collaborate, taking on the roles of driver and observer. This article presents COLLECE, a groupware system to support synchronous Distributed Pair Programming practices, and includes a variety of experimental activities in which two groups of programmers were involved to solve various programming problems. The first group carried out the activities by employing Distributed Pair Programming practices using COLLECE, while the second group of solo programmers followed traditional programming practices. These experimental activities were used to conduct comparative studies of work productivity and program quality. ©2008 IEEE.
