Title: ESEM'08: Proceedings of the 2008 ACM-IEEE International Symposium on Empirical Software Engineering and Measurement
Abstract: The proceedings contain 60 papers. The topics discussed include: using empirical methods to improve industrial technology transfer; socio-technical congruence: a framework for assessing the impact of technical and work dependencies on software development productivity; a multiple case investigating the interaction between manufacturing and development organizations in automotive software engineering; problems in agile trenches; pair programming: what's in it for me?; why do programmers avoid metrics?; the impact of time controlled reading on software inspection effectiveness and efficiency: a controlled experiment; reducing biases in individual software effort estimations: a combining approach; empirical results from using custom-made software project control centers in individual environments; and a survey on software cost estimation in the Chinese software industry.
