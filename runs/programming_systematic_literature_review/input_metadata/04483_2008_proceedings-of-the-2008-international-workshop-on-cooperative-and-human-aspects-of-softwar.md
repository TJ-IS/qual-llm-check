Title: Proceedings of the 2008 International Workshop on Cooperative and Human Aspects of Software Engineering, CHASE '08, Co-located with the 13th International Conference on Software Engineering, ICSE 2008
Abstract: The proceedings contain 28 papers. The topics discussed include: continuous coordination within the context of cooperative and human aspects of software engineering; examining life at the code face; sharing usability information in interactive system development; scrum down: a software engineer and a sociologist explore the implementation of an agile method; effecting change: coordination in large-scale software development; articulation work in small-scale offshore software development projects; communication patterns in geographically distributed software development and engineers' contributions to the development effort; creating a cognitive metric of programming task difficulty; practices around customization of standard systems; collaborative process management and virtual teams; towards individualized software engineering: empirical studies should collect psychometrics; and benefits of interactive display environments in the software development process.
