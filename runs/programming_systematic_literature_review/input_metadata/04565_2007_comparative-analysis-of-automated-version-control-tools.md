Title: Comparative analysis of automated version control tools
Abstract: As software is developed and deployed, it is extremely common for multiple versions of the same software to be deployed at different sites, and for the software's developers to be working privately on updates. Bugs and other issues with software are often only present in certain versions because of the fixing of some problems and the introduction of others as the program evolves. Therefore, for the purpose of locating and fixing bugs, it is vitally important for the debugger to be able to retrieve and run different versions of the software to determine in which version(s) the problem occurs. All these tasks are related with version control. This paper makes an attempt to compare various version control tools and an effort has been made to show that how Subversion, an open source tool, when integrated with an application can be helpful in tracing the changes with minimum burdan on system and memory resources .
