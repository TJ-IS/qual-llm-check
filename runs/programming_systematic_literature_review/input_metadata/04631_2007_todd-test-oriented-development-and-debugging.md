Title: TODD: Test-oriented development and debugging
Abstract: The benefits of Test-Driven Development (TDD) can be appealing to many seeking to reduce the amount of time spent on a software project, but not all projects can implement the TDD methodology fully. A technique similar to TDD - test oriented development is introduced and a prototype software implementation in the form of an Eclipse plug-in is presented to support the adoption of this more pragmatic approach by developers to help them write high quality software. © 2007 IEEE.
