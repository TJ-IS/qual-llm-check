Title: A dynamic analysis for revealing object ownership and sharing
Abstract: We present a dynamic analysis for inferring object ownership and sharing, defined in terms of the write control graph. We render the results in an interactive hierarchical matrix visualizer. The purpose of the analysis and visualization is to reveal object ownership and sharing relations in the program, to facilitate program understanding and modification tasks. Copyright 2006 ACM.
