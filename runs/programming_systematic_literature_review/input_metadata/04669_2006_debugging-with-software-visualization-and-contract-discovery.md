Title: Debugging with software visualization and contract discovery
Abstract: Despite advances, debugging remains a drudgery, especially for software without proper documentation. Both top-down visualization-based approaches and bottom-up programmatic automation can improve this process. For a given system under test (SUT), we propose a combined method of: • Program trace visualization, with capability to zoom in to method call details (inputs and outputs) • Interactive declaration of observables for the internal state of the system • Statistical and visual analysis of the collected observable data • Programmatic declaration of expected behavior of the system using contracts (Design by Contract) on these observables • The ability to modify and repeat these steps without restarting the SUT We report that instrumentation necessary to collect trace data is feasible; large amounts of data can be gathered without significant performance penalty while the visualizer remains responsive to tester interaction. Our personal experience is that the system is very quick to set up, faults are discovered quickly, and inefficient algorithms (which may produce correct results) become obvious through the visualizer. We are currently setting up human-interaction experiments.
