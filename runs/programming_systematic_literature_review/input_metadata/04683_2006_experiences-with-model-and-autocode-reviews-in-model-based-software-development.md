Title: Experiences with model and autocode reviews in model-based software development
Abstract: Through the introduction of the model-based development, paradigm models became first class citizens in the development of in-vehicle software and are thus also object to strict quality assurance. Just as code reviews are widespread in classical software development, models also have to undergo a stringent review procedure - particularly if they serve as a basis for automatic software implementation by means of model-based code generators. In addition to model reviews, the generated production code (autocode) must be reviewed by performing so-called autocode reviews. This paper presents our procedures for a combined model and autocode reviews and provides examples, lessons learned, as well as significant experimental results drawn from a typical automotive embedded software development project.
