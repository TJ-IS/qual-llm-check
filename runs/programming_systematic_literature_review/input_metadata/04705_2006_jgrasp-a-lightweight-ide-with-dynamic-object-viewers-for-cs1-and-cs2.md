Title: JGRASP: A lightweight IDE with dynamic object viewers for CS1 and CS2
Abstract: The jGRASP IDE provides new object viewers that automatically generate dynamic, state-based visualizations of objects and primitive variables in Java. Multiple synchronized visualizations of an object, including complex data structures, are immediately available to users from the jGRASP debugger window or object workbench. Initial classroom use has demonstrated the object viewers' potential as an aid to student learning, while future research will explore their utility through controlled experiments. The following example illustrates an animated view for a linked tree structure. Figure 1 shows the UML class diagram with the TreeExample program which creates a LinkedBinarySearchTree instance called lbst, then proceeds to add various integer values to the tree. In Figure 2, the user is stepping through the addMethod to add the value 11. The dynamic object view of lbst in Figure 3 indicates the state of the instance after the links for the node with element value 11 are set and prior to count being updated. During this step, the node was moved in animated fashion from the "Local Variable Node References" area of the viewer into the data structure itself.
