Title: Lessons learned from designing a programming system to support middle school girls creating animated stories
Abstract: Traditional approaches to teaching computer science are often unsuccessful in attracting girls into the discipline. Our hypothesis is that presenting computer programming as a means to the end of storytelling will help motivate girls to learn to program, a traditional gateway to computer science. In this paper, we present a case study in designing a version of the Alice programming system to support storytelling. We present lessons we learned about what supports are necessary to enable girls to program animated movies and describe the kinds of programming tasks that arise in girls' stories. © 2006 IEEE.
