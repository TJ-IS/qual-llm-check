Title: A cultural shift in teaching CS programming courses and improving software quality
Abstract: Depending on software type typically, Software testing is about 40 % to 70% of total cost of Software but usually testing receives very little attention in CS curriculum. Many researchers have found that most of the students who complete introductory programming courses, and even many who complete a degree, are not proficient programmers and produce code of low quality. In this paper, we acknowledged this problem; we run an experiment and make a cultural shift in teaching introductory programming courses. In our approach, students must learn how to test their own code. The primary feature of our approach is that software testing is presented as an integral part of programming practice; specifically, a student who is to write a program begins by writing a test suite. Our initial results are that this approach improves students' program quality. We found that teaching basic concepts of software testing does not take much time; it helps beginner students to understand the requirements. 67% of the students claimed that applying our approach makes the code easier to debug and improve their code's reliability and quality.
