Title: Introducing Personal Software Process in a small computer science program
Abstract: In this paper, we present our approach and experience of adopting Personal Software Process (PSP) in a small computer science department. Since programming styles tend to be developed early in the learning process, teaching PSP techniques can help students become productive programmer. In a small Computer Science curriculum it is not very practical to offer specialized PSP courses. Our approach to incorporate only selected PSP topics such as code review and design review sessions into existing programming courses has significantly improved students' programming capability and help them better understand the software development process in real-world projects. Although this approach may not have the rigor of a specialized PSP course, it offers ample opportunity and time for students to practice and master PSP techniques.
