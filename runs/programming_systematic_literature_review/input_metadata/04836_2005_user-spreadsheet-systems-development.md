Title: User Spreadsheet Systems Development
Abstract: In the early days of computers, expertise was needed not only to develop systems, but also to use them. As IT tools have become more powerful and user friendly, more and more people have been able to use computers and programs as tools when carrying out working tasks. Nowadays it is even possible for people without special IT training to develop information systems that only IT specialists could have done some years ago. © 2005 by Idea Group Inc.
