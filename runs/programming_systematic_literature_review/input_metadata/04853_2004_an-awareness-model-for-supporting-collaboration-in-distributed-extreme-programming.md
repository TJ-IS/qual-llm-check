Title: An awareness model for supporting collaboration in distributed eXtreme programming
Abstract: Extreme programming (XP) [1] is one of the most innovative software development approaches of the last few years. The XP methodology relies predominately on the development team working in close proximity, ideally within the same workspace to facilitate tight communication. To allow XP to be utilized within distributed environments, it is necessary to introduce communication and awareness support that is closely comparable to traditional practices. We present, Moomba's awareness model, which is a distributed collaborative development environment. The model applies research across CSCW to relax the collocation requirement while preserving the high productivity and quality of the XP process.
