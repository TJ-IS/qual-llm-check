Title: Fault localization using visualization of test information
Abstract: Fault localization using software visualization, testing information and program analysis techniques was discussed. The technique had an impact on the cost and quality of software development and maintenance. Programmers used debugging tools to manually trace the program with a particular input, encounter a point of failure and then backtrace to find the related entities and potential causes. The technique developed by James A. Jones provided a new approach for locating faults in programs, a toolset for debugging software and a set of emperical studies which would provide feedback for future work.
