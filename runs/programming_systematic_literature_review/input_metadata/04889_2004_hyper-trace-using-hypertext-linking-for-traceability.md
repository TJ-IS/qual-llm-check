Title: Hyper-trace: Using hypertext linking for traceability
Abstract: Engineers recognize the value of tools that are both easy to use and possess measurable value to assist in the development of software. Hypertext linking is a process which can substantially aid the software development effort by maintaining traceability between work products. Hyper-Trace provides an effective method of hypertext linking that is relatively easy to integrate into the development process with minimum effort by the engineer, and that provides useful linking information when it is needed. All traceability information is maintained as part of each document, requiring no additional documents or databases.
