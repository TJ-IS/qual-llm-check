Title: Inroads - SIGCSE Bulletin -ITiCSE 2004 - Proceedings of the 9th Annual SIGCSE Conference on Innovation and Technology in Computer Science Education
Abstract: The proceedings contain 38 papers. The topics discussed include: using XML in a compiler course; didactic strategies for promoting significant learning in formal languages and automata theory; investigating wired and wireless networks using a Java-based programmable sniffer; on the achievements of high school students studying computational models; design and evolution of an undergraduate course on web application development; supporting active database learning and training through interactive multimedia; the backwash effect on SQL skills grading; electronic learning communities: strategies for establishment and management; if diversity is a problem could e-learning be part of the solution? a case study; roles of variables as seen by CS educators; the dimensions of variation in the teaching of data structures; and using narrative as a motivating device to teach binary arithmetic and logic gates.
