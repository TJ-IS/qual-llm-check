Title: The backwash effect on SQL skills grading
Abstract: This paper examines the effect of grading approaches for SQL query formulation on students' learning strategies. The way that students are graded in a subject has a significant impact on their learning approach, and it is crucial that graded tasks are carefully designed and implemented to inculcate a deep learning experience, An online examination system is described and evaluated.
