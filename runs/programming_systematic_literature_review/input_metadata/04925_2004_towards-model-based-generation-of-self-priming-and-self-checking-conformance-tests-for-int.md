Title: Towards model-based generation of self-priming and self-checking conformance tests for interactive systems
Abstract: This paper describes a model-based approach to generate conformance tests for interactive applications. Our method addresses generation of: (1) small yet effective set of test frames for testing individual operations, (2) a Set up sequence that brings the system under test in an appropriate state for a test frame (self-priming), (3) a Verification sequence for expected output and state changes (self-checking), and, (4) negative test cases in the presence of exceptions. Our method exploits a novel mutation scheme applied to operations modeled as relationships among parameters and state variables; a set of novel abstraction techniques which result in a compact finite state automaton; and search techniques to automatically generate the set up and verification sequences. We illustrate our method with a simple ATM application. © 2003 Elsevier B.V. All rights reserved.
