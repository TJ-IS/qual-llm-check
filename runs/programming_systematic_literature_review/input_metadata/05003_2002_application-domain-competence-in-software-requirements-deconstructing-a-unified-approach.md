Title: Application domain competence in software requirements - Deconstructing a unified approach
Abstract: In this paper, we present a research-in-progress study that examines the issue of how application domain competence is addressed in systems development literature. The underlying questions are: how does the area of systems development approach the concept of application domain? What steps do we take to ensure sufficient application domain competence when developing systems? We address this question by analysing a recent practical book on software requirements in the unified approach series, to get a picture of how this important area for IT professionals is presented and prescribed.
