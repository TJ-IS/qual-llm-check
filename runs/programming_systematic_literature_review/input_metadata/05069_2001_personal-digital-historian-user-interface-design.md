Title: Personal digital historian: User interface design
Abstract: Desktop computers are not designed for multi-person faceto- face conversation in a social setting. We describe the design of a novel user interface for multi-user interactive informal storytelling. Our design is guided by principles of experience sharing, the disappearing computer, visual navigation, and implicit query formulation. Copyright © 2012 ACM, Inc.
