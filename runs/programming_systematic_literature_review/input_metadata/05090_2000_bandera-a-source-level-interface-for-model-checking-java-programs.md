Title: Bandera: A source-level interface for model checking Java programs
Abstract: The Bandera toolset is designed to harness the power of existing model checking tools to apply them to reason about correctness requirements of Java programs. This toolset provides tool support for defining and managing collections of requirements for a program, for extracting compact finite-state models of the program to enable tractable analysis, and for displaying analysis results to the other user through a debugger-like interface.
