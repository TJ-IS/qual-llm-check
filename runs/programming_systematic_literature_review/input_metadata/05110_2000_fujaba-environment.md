Title: FUJABA environment
Abstract: The Fujaba (From Uml to Java And Back again) environment is designed to provide round-trip engineering support for UML and Java. Fujaba generates codes from collaboration diagrams. The current prototype of this environment comprises about 266000 lines of pure Java code.
