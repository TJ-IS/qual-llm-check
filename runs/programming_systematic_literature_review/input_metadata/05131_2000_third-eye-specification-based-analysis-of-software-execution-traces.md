Title: Third eye - specification-based analysis of software execution traces
Abstract: In the Third Eye project, a methodology was defined for tracing execution of software by reporting events meaningful in the application domain or essential from the implementation point of view. The implemented portable prototype of the Third Eye framework includes reusable software components for event definition and reporting and standalone tools for storage and query of event traces, constraint specification and trace analysis. In general, Third Eye is a practical framework for specification-based analysis and adaptive tracing of software systems.
