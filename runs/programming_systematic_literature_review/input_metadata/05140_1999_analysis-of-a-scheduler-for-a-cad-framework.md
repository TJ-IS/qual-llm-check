# Scopus title-abstract-keyword metadata
Title: Analysis of a scheduler for a CAD framework
Abstract: A key component of a software system was modeled and analyzed to understand a proposed algorithm prior to implementation. A Promela model of a linear scheduler for a computer aided design (CAD) framework was developed. The Spin simulator was used to debug the model and to illustrate how the algorithm works in different scenarios. The Promela model was modified and verified to be correct.
