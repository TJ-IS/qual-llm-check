Title: Call-mark slicing: An efficient and economical way of reducing slice
Abstract: Call-mark slicing is a program slicing technique which combines the static analysis of a program's structure with lightweight dynamic analysis. The data and control dependencies among the program statements are statically analyzed beforehand, and procedure/function invocations (calls) are recorded (marked) during execution. From this information, the dynamic dependencies of the variables are explored.
