Title: RMT (Recursive Multi-Threaded) tool: A computer aided software engineering tool for monitoring and predicting software development progress
Abstract: The Recursive Multi-Threaded (RMT) software life-cycle is demonstrated and the implemented computer aided software engineering tool based on RMT is presented. The RMT tool supports the monitoring of progress during development, addresses the specific needs of the developing object-oriented software, and attempts to resolve deficiencies found in many existing software life cycles. It uses a `thread' for partitioning and organizing software development activities. Threads support iteration and recursion which are critical concepts for the development of the software.
