Title: Adapting user interface design methods to the design of educational activities
Abstract: We have adapted the programming walkthrough technique to help design computer-supported educational activities in elementary school science. We present examples from a case study which illustrate ways in which design of an educational activity is similar to and different from design of a user interface. We have found that the walkthrough approach is useful in this new setting, and that it sheds new light on the general task-centered orientation to design.
