Title: On estimating the number of defects remaining in software
Abstract: There have been a number of methods used to estimate the number of defects remaining in software. In this paper we present an analysis for the method of dynamic software reliability models, and that of empirical models, particularly of the Halstead model. We then develop a new static model for estimating the number of remaining defects and use a set of real data to test the new model. The new model coincides with the Mills model in a particular case and shows its attraction in its applicability to a broader scope of circumstances. Bayesian versions of the Mills model and the new model are also developed. © 1998 Elsevier Science Inc.
