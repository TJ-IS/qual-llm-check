Title: Anywhere, anytime code inspections: Using the Web to remove inspection bottlenecks in large-scale software development
Abstract: The dissemination of critical information and the synchronization of coordinated activities are critical problems in geographically separated, large-scale software development. An Intranet Web that allows timely dissemination of information and effective coordination of distributed inspections may provide a solution. It includes an inexpensive tool that integrates seamlessly into the development process.
