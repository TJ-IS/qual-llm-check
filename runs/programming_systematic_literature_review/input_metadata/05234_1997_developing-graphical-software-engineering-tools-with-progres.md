Title: Developing graphical (software engineering) tools with PROGRES
Abstract: PROGRES is a partly rule-oriented, partly object-oriented language which supports the design of graph structures and the implementation of graph manipulating tools. It has a formal definition based on graph rewriting systems. Its integrated programming environment offers means for syntax-directed editing, type checking, interactive debugging, graph browsing, and rapid prototyping activities.
