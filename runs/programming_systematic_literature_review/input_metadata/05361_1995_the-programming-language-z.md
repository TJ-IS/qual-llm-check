Title: The programming language Z--
Abstract: Z is a specification language, and, rightly, not in general executable. Z-- is a programming language superficially identical to Z, but using only those forms of expressions and predicate which are immediately executable. The Z-- approach differs from other Z animations in being single-pass, without backtracking, and in modelling a set as its membership test, thus imposing no general restriction to finiteness. A prototype Z-- interpreter is described. © 1995.
