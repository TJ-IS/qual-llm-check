Title: A model-based framework for the integration of software metrics
Abstract: Because of the proliferation of software metrics, there is a need for analytical methodologies that integrate both software complexity metrics and various measures describing the software development environment. To facilitate this integration, a model-based framework is presented that provides for both software metrics research and the application of research results to software project assessment. A number of analytical methodologies are discussed to develop models predicting software quality factors. © 1994.
