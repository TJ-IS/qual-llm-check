Title: Automatically Generating Test Data from a Boolean Specification
Abstract: This paper presents a family of strategies for automatically generating test data for any implementation intended to satisfy a given specification that is a Boolean formula. The fault detection effectiveness of these strategies is investigated both analytically and empirically, and the costs, assessed in terms of test set size, are compared. © 1994 IEEE
