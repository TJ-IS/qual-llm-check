Title: Incremental, high level implementation of Prolog in an open system framework
Abstract: We propose a new framework to implement a complete logic programming system. This framework is composed of a set of new mechanisms intended to give high level and safe means to manage a computation history. Upon this framework we developed a logic programming environment prototype, called MxLog, featuring a complete Prolog-II interpreter and its debugging environment. This prototype has been realized following a new implementation philosophy independent by hardware constraints and based on an incremental strategy, expressed in terms of agents in a sequential open system.
