Title: Integrated system for query formulation and database design
Abstract: This paper describes a system that uses database design knowledge to formulate queries in response to high-level requests. By focusing on the conceptual design, it is possible to identify conceptual subgraphs that correspond to user intent. These subgraphs can be manipulated with respect to a request and mapped to a database query. Furthermore, by treating the subgraphs as knowledge constructs, it is possible to use the system for interactive design evaluation.
