Title: Program Concept Recognition and Transformation
Abstract: Syntactically, a computer program is a sequence of characters. Semantically, however, it contains abstract high-level conceptual information or concepts. the automated recognition of these concepts can greatly aid the understanding of programs and therefore support many software maintenance and reengineering activities. This paper describes an approach to automated concept recognition and its application to maintenance-related program transformations. a unique characteristic of this approach is that transformations of code can be expressed as transformations of abstract concepts. This significantly elevates the level of transformation specifications. © 1992 IEEE.
