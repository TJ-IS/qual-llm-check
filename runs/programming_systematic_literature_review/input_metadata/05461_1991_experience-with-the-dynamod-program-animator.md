Title: Experience with the DYNAMOD program animator
Abstract: DYNAMOD is a pilot software system of the program animation variety that aids the teaching and learning of Pascal program execution dynamics, time complexity, and space complexity. First developed in 1982, DYNAMOD incorporates many features now popular in modern programming language debuggers, such as highlighting of current line of execution, display of variable contents, and a count of statements executed. DYNAMOD is unique, however, in that it is not intended to be used as a debugger. Rather, it is intended for instructors who are trying to convey a new programming concept for the first time and for students who are trying to learn a new programming concept and are not yet capable of writing a simple demonstration program, much less of utilizing a sophisticated debugger for analyzing a program. DYNAMOD consists of a comprehensive library of programs expertly designed to convey particular lessons and a simple user interface. Instructors can demonstrate program execution dynamics in the classroom using DYNAMOD, and students can review programs from the library at their leisure. Continuing use of DYNAMOD in the introductory Pascal course has shown it to be an extremely effective teaching and learning tool. As a pilot project, DYNAMOD reveals directions to be taken in the development of a comprehensive program animation system. © 1991 ACM.
