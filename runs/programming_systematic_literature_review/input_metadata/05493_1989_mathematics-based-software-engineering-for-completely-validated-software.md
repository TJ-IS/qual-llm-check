Title: Mathematics-based software engineering for completely validated software
Abstract: Mathematics-based software engineering techniques in current practice permit industrial programming teams routinely to produce software to schedule and budget with from one to four errors per KLOC prior to first execution, with mathematical verification used in place of unit debugging. Other techniques in practice today for statistical system testing against usage probabilities can then reduce the error rate as low as desired, to zero-defect with high probability, if necessary. Statistical testing provides scientific, not anecdotal, evidence of reliability in terms of mean-time-to-failure (MTTF) estimates.
