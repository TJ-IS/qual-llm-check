Title: 1986 workshop on software testing, papers
Abstract: The issue includes four workshop papers reflecting some of the different research directions being taken in the software testing area. The first paper considers how to define path selection criteria that are applicable when programs contain infeasible paths. Two others are concerned with testing and debugging distributed and concurrent systems. The last paper deals with estimating the reliability of software. All the papers are abstracted and indexed separately.
