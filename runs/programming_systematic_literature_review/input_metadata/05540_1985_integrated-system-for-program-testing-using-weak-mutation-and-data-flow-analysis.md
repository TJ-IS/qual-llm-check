Title: INTEGRATED SYSTEM FOR PROGRAM TESTING USING WEAK MUTATION AND DATA FLOW ANALYSIS.
Abstract: A description is given of a tool for Fortran 77 programs which has been developed to help a user apply the weak mutation and data flow testing techniques. The tool instruments a given source program and collects a program execution history. It is then able to report on the completeness of the test data with respect to weak mutation and a family of data flow path selection criteria. Some preliminary experiments with use of the tool are described.
