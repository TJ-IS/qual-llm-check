Title: The design of an integrated, interrative and incremental programming environment
Abstract: We are currently implementing a system to help experienced programmers during the development, implementation and debugging of their programs. This system, built on top of a screen oriented structural editor, offers possibilities of attaching descriptors to every portion of the program and to maintain - simultaneously - different versions of the program being written, including tentative hypothetical versions. It comprises a mechanism to maintain minimal consistency between modified parts of code, the non-modified parts of code and the attached descriptors, as well as an evaluation module functioning in different modes : normal evaluation, symbolic eva7uation and checking evaluation. The standard programming AIDS, such as indexors, pretty printers, trace packages, undo- And history-facilities are generalized to handle the descriptors and unfinished programs as welt. © 1982 IEEE.
