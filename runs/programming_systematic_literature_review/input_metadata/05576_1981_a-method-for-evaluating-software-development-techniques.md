Title: A method for evaluating software development techniques
Abstract: This paper describes a method for measuring the contribution of an arbitrary program development technique to program correctness and cost. The method has been employed at the General Electric Corporate Research and Development Center to evaluate alternative program testing techniques. Following the method's description an example of its use is shown. © 1982.
