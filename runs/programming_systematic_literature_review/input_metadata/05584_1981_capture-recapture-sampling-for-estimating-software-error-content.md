Title: Capture-Recapture Sampling for Estimating Software Error Content
Abstract: Mills’ capture-recapture sampling method allows theestimation of the number of errors in a program by randomly inserting known errors and then testing the program for both inserted and indigenous errors. This correspondence shows how correct confidence limits and maximum likelihood estimates can be obtained from the test results. Both fixed sample size testing and sequential testing are considered.
