Title: PROCEEDINGS - INTERNATIONAL CONFERENCE ON SOFTWARE ENGINEERING, 5TH, 1981.
Abstract: Proceedings includes 50 papers dealing with recent innovations, theory and application of computer software engineering. The papers are organized in sessions covering, among others, software environments, abstract models, lfe cycle considerations, analysis of testing methods, real-time software design, human engineering, program testing, data abstraction, requirements engineering, concurrent systems, interactive systems, programming tools, and program decomposition. Topics discussed include data base systems, computer programming languages, computer architecture and the use of computers for aircraft design and the manufacture of integrated circuits. Forty-nine papers are abstracted and indexed separately.
