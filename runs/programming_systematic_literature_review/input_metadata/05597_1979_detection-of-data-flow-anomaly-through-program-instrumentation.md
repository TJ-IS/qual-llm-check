Title: Detection of Data Flow Anomaly Through Program Instrumentation
Abstract: A data flow anomaly in a program is an indication that a programming error might have been committed. This paper describes a method for detecting such an anomaly by means of program instrumentation. The method is conceptually simple, easy to use, easy to implement on a computer, and can be applied in conjunction with a conventional program test to achieve increased error-detection capability.
