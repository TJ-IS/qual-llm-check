Title: An Empirical Investigation on Source Code Comprehension Performance Between Naming and Structural Issues with and without Generative AI Assistance
Abstract: Context: Software developers frequently comprehend source code with code smells that reduce readability. A previous study conducted without generative AI assistance reported that source code with naming issues required greater cognitive loads than that with structural issues. Objective: This study investigated whether accuracy and time differed when comprehending source code with naming or structural issues with and without generative AI assistance. Method: We conducted two experiments with 106 software development practitioners. In the first experiment, the subjects comprehended the source code with either naming or structural issues without generative AI assistance and answered nine questions about the source code. In the second experiment, the subjects performed the same task but with generative AI assistance. Additionally, we performed propensity score matching and compared the subjects in both experiments. Results: In the first experiment, unpaired ttest results did not show a statistically significant difference in the percentage of correct answers between naming (mean 70.5%) and structural (mean 79.8%) issues after applying Holm’s correction (adjusted p = 0.0652, p = 0.0326) and no significant difference in the comprehension time (adjusted p = 0.329, p = 0.329). In the second experiment, no significant differences in the percentage of correct answers or comprehension time between naming and structural issues were observed. In the propensity score matching comparison, 25 pairs were matched. The results of the unpaired t-test did not show a statistically significant difference in comprehension time between those without generative AI assistance (56.2 min) and those with assistance (45.1 min) when comprehending source code with naming issues (adjusted p = 0.0622, p = 0.0311). There was a significant difference in the percentage of correct answers between those without generative AI assistance (78.2%) and those with assistance (66.7%) when comprehending source code with structural issues (adjusted p = 0.0354, p = 0.0177). Conclusion: This study indicates that the effectiveness of generative AI assistance can be influenced by differences in the types of code smells in the source code and suggests why the effectiveness of generative AI assistance in source code comprehension has varied across previous studies. © 1976-2012 IEEE.
