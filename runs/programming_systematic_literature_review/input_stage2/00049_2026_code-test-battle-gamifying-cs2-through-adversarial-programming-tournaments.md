Title: Code, Test, Battle: Gamifying CS2 Through Adversarial Programming Tournaments
Abstract: As abstract concepts like inheritance and algorithm analysis increase in complexity, maintaining student engagement in CS2 courses is difficult, and traditional lecture methods often fail to motivate students or emphasize critical skills like test-driven development and collaboration. We present Dungeon Master, a gamified tournament-based learning system that transforms CS2 curriculum into a progressive, competitive, collaborative experience. Student teams build hero characters throughout the semester, with each programming concept manifested as character capabilities: basic objects evolve into specialized classes using inheritance, manage inventories through collections, and execute battle strategies via recursive algorithms. This creates a cohesive narrative where abstract concepts become tangible and meaningful. The system features dual competition: automated tournaments where student-designed heroes battle using implemented algorithms, and adversarial testing where teams write unit tests to validate their code while exposing opponent flaws. Grounded in Eyal’s Hook Model for behavioral engagement, the system integrates Git workflows, automated evaluation via the Dungeon Master API, and live tournament events transforming classes into spectator experiences. Preliminary deployment (N=25 students) demonstrates high satisfaction with engagement (5/5), concept clarity (4.3/5), and collaborative learning (4.8/5). Our work demonstrates that theoretically grounded gamification can substantially enhance CS2 education while developing professional software engineering practices. © 2026 Copyright held by the owner/author(s).
