Title: Interactive Expression Trees for Database Querying
Abstract: query languages such as Domain Relational Calculus (DRC), Datalog (DLOG), and Relational Algebra (RA) are covered in an introductory database course. Unlike SQL queries, which can be executed, queries in these abstract languages usually are not executable due to the unavailability of query processors. In this paper, we present both backend query processors for these abstract query languages as well as an interactive Web-based expression tree visualizer for queries. The interactive tool allows teachers and students to visualize expression trees for these queries and interact with them to view values at sub-expression nodes. Since DRC, DLOG, and RA form a hierarchy of languages with DRC being purely declarative, DLOG being partly declarative and partly procedural, and RA being fully procedural, users can view translations of DRC expressions into DLOG and DLOG expressions into RA. Besides, since the system eventually translates all queries into SQL, the users can also view SQL equivalents of sub-expressions in any of the three languages. The system is built using Python and libraries such as ply, Dash, and Cytoscape, is lightweight, and easily deployable on any computer that supports Python. The Web application requires SQLite and comes with a collection of predefined databases to query against. Users can also upload their own databases. This tool will provide a platform for educators to explain abstract querying easily with automatically generated interactive expression trees. Students can also use the tool to better understand query formulation and execution in relational databases. © 2026 Copyright held by the owner/author(s).
