Title: RE-APR: Reasoning-Enhanced Automated Program Repair via Large Language Models
Abstract: Automated Program Repair (APR) aims to automatically fix buggy code to ensure the security and reliability of software systems. Existing approaches typically train on bug–fix code pairs, learning a direct mapping from buggy to fixed code. However, such models lack reasoning about the root causes of bugs and fail to provide repair rationales, resulting in limited trustworthiness. To address these limitations, we propose RE-APR, a reasoning-enhanced APR framework that constructs high-quality reasoning data to improve both interpretability and repair accuracy. Specifically, RE-APR enables models to first identify the security issues in buggy code and then provide repair suggestions before generating the final fixed code. This design enhances the model’s reasoning ability and interpretability, leading to more reliable repair outcomes. Experimental results on three widely used benchmarks demonstrate that RE-APR significantly outperforms current state-of-the-art (SOTA) baselines in terms of repair accuracy. © 2026 Copyright held by the owner/author(s)
