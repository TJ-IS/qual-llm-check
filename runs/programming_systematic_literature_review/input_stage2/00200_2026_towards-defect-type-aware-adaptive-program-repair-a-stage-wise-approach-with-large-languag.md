Title: Towards defect-type-aware adaptive program repair: A stage-wise approach with large language models
Abstract: Automated code repair techniques have demonstrated significant potential in reducing the costs associated with software debugging and maintenance. In recent years, with the breakthrough advancements of large language models(LLMs) in software engineering tasks, LLM-based code repair approaches have emerged as a prominent research focus. Existing methods primarily concentrate on enhancing input context or designing complex interaction mechanisms. However, they treat program repair as a homogeneous task, overlooking the differences and impacts of various defect types during the repair process. To address these limitations, this paper investigates the impact of defect types on the performance of LLM-based code repair and proposes TypeRepair, a defect-type-aware, multi-stage adaptive framework for code repair. The framework divides the automated program repair(APR) process into four key stages: defect localization, defect type identification, context selection, and patch generation. Additionally, we define ten common defect types and provide tailored repair guidance for each specific type, thereby enabling LLMs to perform fine-grained reasoning. We conduct comprehensive experimental evaluations on the Defects4J v1.2/v2.0, and QuixBugs datasets, comparing our approach against multiple state-of-the-art baseline methods. Experimental results demonstrate that TypeRepair outperforms state-of-the-art APR tools in overall performance. On the Defects4J dataset, TypeRepair independently repairs 33 bugs that no other method successfully fixes, indicating superior repair capability. For instance, on the Defects4J v2.0 dataset, TypeRepair achieves a 272.73% improvement over the baseline LLM when using GPT-3.5 and a 257.89% improvement when using GPT-4. These results indicate that the integration of defect-type-aware modeling with a multi-stage reasoning architecture effectively enhances the expressiveness of LLMs in code repair tasks, providing a systematic modeling paradigm for targeted repair toward specific defect types. © The Author(s), under exclusive licence to Springer Science+Business Media, LLC, part of Springer Nature 2026.
