Title: Unveiling the power of code pre-trained models in automated program repair: A systematic review
Abstract: Automated Program Repair (APR) aims to automatically fix software bugs, thereby enhancing software reliability. In recent years, Code Pre-trained Models (CodePTMs) have attracted considerable attention in the APR domain. While recent surveys cover the application of LLMs in SE broadly, there is a lack of focused analysis on the architectural evolution and specific integration strategies of CodePTMs within the APR pipeline. To address this gap, this survey presents a comprehensive review of current research on CodePTM-based APR techniques. By analyzing the state-of-the-art literature, we demystify the evolutionary trend of model architectures, categorize five distinct paradigms for integrating CodePTMs into APR workflows, and critically assess current evaluation metrics and benchmark datasets. Furthermore, this study identifies key open challenges and outlines promising directions for future research. Overall, this study aims to provide researchers with a thorough understanding of existing approaches and to foster further advancements in the application of CodePTMs to APR. © 2026 Elsevier Inc.
