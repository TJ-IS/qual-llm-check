Title: How to Help College Students Learn Programming Successfully
Abstract: Programming is a complex cognitive activity that demands global processing in the brain. It involves two distinct areas: algorithm development and its implementation in a computer, making learning programming particularly challenging. This paper examines the factors influencing the learning of programming and develops a conceptual framework to support college students' successful learning of programming. We provide a literature review, conceptual model, research methods, and initial data analysis. © 2025 Americas Conference on Information Systems, AMCIS 2025. All rights reserved.
