Title: What's bothering developers in code review?
Abstract: The practice of code review is widely adopted in industry and has been studied to an increasing degree in the research community. However, the developer experience of code review has received limited attention. Here, we report on initial results from a mixed-method exploratory study of the developer experience.  © 2022 IEEE.
