Title: Definition of Process Realization Pattern and Automatic Generation Method of Recognition Rules
Abstract: This article mainly introduces the background and related theories the generation of matching rules the design and implementation of matching tool modules. The matching rules will be analyzed from the perspectives of pattern definition pattern library construction and format conversion. The module design and implementation part uses multiple self-constructed algorithms to bring the theory to achieved. It is an important achievement in the field of process blueprint research. The article first analyzes the characteristics of the abstract realization layer process pattern, deeply explores the linear tree structure of the process pattern, and summarizes the hierarchical structure relationship of the nodes in the tree. The analysis between data flow and the abstract implementation layer process mode provides a theoretical basis for process pattern analysis and automatic generation of process model recognition rules, paving the way for code completion and code fusion recommendation, which will greatly reduce manpower and Time consumption. At the same time, based on the node mapping rules and the XML-PBD format conversion algorithm, the pattern conversion is incorporated into the library, which provides the basis for subsequent batch analysis. Secondly, based on the analysis of the capture group matching rules, through the control structure and data flow in the code. By constructing the pattern matching rule generation algorithm, the structural matching regular expressions and the conditional constraint expressions are respectively generated, and the corresponding process patterns are accurately identified. With the analysis of the processing flow, the process of generating process pattern recognition rules was systematically explained. At the same time, the XML-PBD conversion algorithm and the automatic generation algorithm of process pattern matching rules were constructed, finally complete the process pattern recognition rule generation tool.  © 2021 IEEE.
