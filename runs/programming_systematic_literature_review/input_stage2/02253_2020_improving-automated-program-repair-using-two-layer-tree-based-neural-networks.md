Title: Improving Automated Program Repair using Two-layer Tree-based Neural Networks
Abstract: We present DLFix, a two-layer tree-based model learning bug-fixingcode changes and their surrounding code context to improve Automated Program Repair (APR). The first layer learns the surroundingcode context of a fix and uses it as weights for the second layer thatis used to learn the bug-fixing code transformation. Our empiricalresults on Defect4J show that DLFix can fix 30 bugs and its resultsare comparable and complementary to the best performing patternbased APR tools. Furthermore, DLFix can fix 2.5 times more bugsthan the best performing deep learning baseline. © 2020 Copyright held by the owner/author(s).
