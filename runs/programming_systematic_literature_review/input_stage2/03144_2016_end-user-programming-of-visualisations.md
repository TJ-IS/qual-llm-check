Title: End-user programming of visualisations
Abstract: Visualisations are a useful tool for helping people understand and communicate data. However, flexible and powerful tools for creating visualisations are mainly accessible only to programmers. My proposal is to explore the use of programming by example and direct manipulation as the main paradigms for building visualisation tools for end user programmers. © 2016 IEEE.
