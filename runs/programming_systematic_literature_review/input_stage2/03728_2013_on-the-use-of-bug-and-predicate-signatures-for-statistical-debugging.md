Title: On the use of bug and predicate signatures for statistical debugging
Abstract: Recently, data mining techniques have been applied to mine software execution data in order to identify the program statements that are relevant to program bugs. While empirically effective, we observe that the effectiveness of such techniques can be improved by isolating the interferences between bugs using a "signature-based" approach. Our proposed approach is evaluated using real subject programs. Results show that we can pinpoint bugs precisely and support more complicated scenarios than existing work.
