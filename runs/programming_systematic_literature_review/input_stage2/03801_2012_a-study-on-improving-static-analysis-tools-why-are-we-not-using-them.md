Title: A study on improving static analysis tools: Why are we not using them?
Abstract: Using static analysis tools for automating code inspections can be beneficial for software engineers. Despite the benefits of using static analysis tools, research suggests that these tools are underused. In this research, we propose to investigate why developers are not widely using static analysis tools and how current tools could potentially be improved to increase usage. © 2012 IEEE.
