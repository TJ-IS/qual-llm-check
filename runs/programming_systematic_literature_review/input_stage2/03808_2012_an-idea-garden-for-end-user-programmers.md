Title: An idea garden for end-user programmers
Abstract: Research in end-user programming has seen many techniques aimed at making it easier for ordinary users to program. However, empirical studies continue to report barriers end users face. In my work, I propose an Idea Garden approach to help end users overcome barriers. Rooted in the Minimalist Learning Theory and theories in problem-solving and creativity, the Idea Garden aims to facilitate end-user programmers to generate and work with their own ideas. Expected benefits of this work include both a theory-based understanding of barriers and the Idea Garden approach itself, which is intended to be generalizable across different end-user programming environments. © 2012 Author.
