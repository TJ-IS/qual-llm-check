Title: Test-driven Development for the Web - Increasing Efficiency of Web Development
Abstract: With the rapid growth of World Wide Web, demands on website developers have increased dramatically. At the same time new web development challenges have emerged. These challenges include enabling web developers with a low level of experience, fast paced development cycles and a disconnect between different phases of web development. In this paper we present algorithms which address some of these challenges. Our algorithms lower the barrier of expertise and experience required to transform development requirements into web pages, bridge the divide between web testing and development as well as improve test case maintenance. We also present a survey we conducted among web developers to understand their problems, experiments to demonstrate the performance of our algorithms and a user study that shows the value of our approach. © 2012 Authors.
