Title: Modeling of code review process yield using Bayesian belief networks
Abstract: Delivering software with few defects is one of the success factors for many software companies. To achieve this, defects need to be identified and removed before the delivery of software, especially the defect removal in early stages of project life cycle like requirement analysis review, design review and code review are very important. In this paper we present a prediction model for defect density at code review phase. A lot of defect prediction models based on various techniques were proposed in the past. In this study we used Bayesian Belief Network modeling to develop the prediction model for defect density. The Bayesian network is used to model the dependencies between all the variables in the data. The Bayesian network modeling is very useful when less number of data points are available, data set contains missing values and all the predictor variables are not continuous. The model was validated with 3 code reviews and the results showed that the actual defect densities were within the predicted range. Hence it was decided to use this model for prediction and control of code review process.
