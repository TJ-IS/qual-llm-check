Title: Web-active users working with data
Abstract: Mashups have emerged as an area of interest for end-user programming research. While many users may find the ability to develop mashups useful, there are still many barriers to locating interesting data, figuring out how to "mash" it together and creating a useful view of the result. Furthermore, there is still much to learn about the motivations and needs of the user. In this paper, we present the results of interviews and think-aloud studies of non-programmers working with XML data and a mashup building tool. This work aims to better understand the users' mental models as they first attempt to use a novel mashup tool. We identify key areas where breakdowns occur and propose a future path for research.
