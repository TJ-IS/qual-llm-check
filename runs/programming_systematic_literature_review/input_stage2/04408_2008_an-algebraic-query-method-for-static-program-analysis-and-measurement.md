Title: An algebraic query method for static program analysis and measurement
Abstract: The provision of measurement during program comprehension is vital to software maintenance. In this paper we propose the deployment of an algebraic query language to perform numerical analysis and measurement of the program structure in a more generic and flexible way. In our approach, source code can be stored in a database where end-users can execute queries in an intuitive (high-level) query language. Moreover, new operators introduced in Online Analytical Processing (OLAP) are deployed by our language to ease summarization and aggregation of details.
