Title: Managing the programming tail
Abstract: A way of dealing with such students in a class learning programming, who are unable to keep up with the rest, is discussed. JavaSweetener is a program, designed to provide such students with supplementary computer-aided learning. The program is based on OOP and assumes no previous knowledge of programming and is especially tailored for beginners. It aims to enable students to learn the basics of Java language, acquire programming techniques, wire, debug, and understand the value of object-oriented programming.
