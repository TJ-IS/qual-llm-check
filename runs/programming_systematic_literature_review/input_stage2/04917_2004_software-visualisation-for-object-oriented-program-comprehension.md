Title: Software visualisation for object-oriented program comprehension
Abstract: The visualization of software through a range of abstraction levels for software comprehension was studied. The complex interactions inherented in the object-oriented paradigm make visualization an appropriate comprehension technique. The emperical evaluation of the fully specified model was performed for the effective support for software comprehension. The success of model depends on the model specification and the effectiveness of model in improving the visualization for software comprehension.
