Title: Using OCL-queries for debugging C++
Abstract: This demonstration will present a design and preliminary implementation of the OCL query-based debugger, OQBD, which is a tool to debug C++ programs using queries formulated in the object constraint language, OCL We will illustrate how queries can be formulated to verify constraints such as class invariants and pre and postconditions for member functions. The queries can be reused after code generation to verify the design contract, as part of the testing process, and to facilitate fault detection. © 2001 IEEE.
