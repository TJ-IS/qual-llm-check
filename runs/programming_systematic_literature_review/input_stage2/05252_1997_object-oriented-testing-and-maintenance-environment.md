Title: Object-oriented testing and maintenance environment
Abstract: Object-oriented paradigm provides power for software development but at the same time introduces understanding, complex interdependency, and object state behavior testing problems. An object-oriented testing and maintenance environment was developed to solve these problems. The formal test model consists of three diagrams: an object relation diagram (ORD) represents the relationships among classes in the source code; an object state diagram (OSD) describes the state behavior of an object class; and block branch diagram (BBD) represents the control structure of a member function and its interface.
