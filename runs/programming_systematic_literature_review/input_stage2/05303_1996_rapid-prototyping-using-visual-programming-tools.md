Title: Rapid Prototyping using Visual Programming Tools
Abstract: Commercially available visual programming tools offer an easily-learned and efficient means for the production of custom software - perhaps for a dissertation project, a deployable prototype for user testing, or even just a quick test of a new idea. This CHI tutorial provided an in-depth examination of two of these tools, Novell's AppWare and Pictorius' Prograph CPX, as well as an introduction to the area of visual programming. © Copyright on this material is held by the author.
