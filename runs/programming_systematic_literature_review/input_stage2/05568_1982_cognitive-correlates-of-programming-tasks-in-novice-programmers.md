Title: Cognitive correlates of programming tasks in novice programmers
Abstract: Despite the potential utility of an investigation of the cognitive components of programming, this issue has been essentially neglected in both the psychological and computer science literature. Previous research concerning the relationships among cognitive abilities and programming skills consist of a single study [6]. Other studies assessing programmer performance have ignored the role of cognitive abilities in programmers. A need exists to assess the fundamental psychological processes, i.e., the cognitive capabilities and information processing characteristics which an individual takes into the programming environment. By assessing the relationships between individual differences in cognitive functioning to measures of programming skill, some understanding can be obtained of how these cognitive abilities are utilized in the performance of programming tasks. © 1982 Association for Computing Machinery.
