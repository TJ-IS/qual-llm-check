## 一、系列主轴与重构原则

第一轮蓝图曾把三个题位设为有限窗口证据表示、任务到达时的信息服务组合和探索过程中的下一次信息行动，并设想论文二、论文一、论文三的概念时序。该题位定义与时序现已失效；当前结构只见 `00D`，本节以下均用历史现在时记录当时推理，不表示仍获授权。

重构不以网络更深或模块更多为目标。每篇先写出一个不知道 IS 理论的工程师最可能采用的通用基线，再要求理论模型产生该基线不会自然具有的条件行为。只有这种行为被公式、训练样本、推断规则和消融共同识别，理论才算进入算法关键路径。

| --- | --- | --- |
| 一 | 对候选片段独立打分并做 top-k 或预算选择 | 只有完整关系见证才能激活可正、可零、可负的高阶关系价值；部分端点不能冒充完整关系证据 |

## 二、历史论文一：深层—表层关系忠实的仓库证据构造

### 2.1 自然问题

给定任务、冻结仓库快照、上游候选片段和 token 预算，模型应如何构造一个既覆盖任务相关程序事实、又不因截断关系或碎片化呈现而误导 Coding Agent 的上下文表示。

这一问题不再把候选覆盖数量当作上下文质量本身。代码片段是仓库深层程序关系的表层见证。一个调用点、写入点或配置使用点若脱离其被调用定义、读取点或配置声明，可能造成比完全不展示该关系更强的错误暗示。因此，集合价值允许非单调，独立片段分数不能充分表示该问题。

### 2.2 理论来源与专属算法对象

中心理论采用表征理论与有效使用框架。仓库中的定义、调用、数据流、测试约束和配置依赖构成深层结构；被选代码区间及其路径、行号和顺序构成表层结构；上下文窗口与 tokenizer 构成物理结构。理论中的表征忠实被转化为深层事实到表层见证的对应质量，透明交互被转化为见证的边界完整性与呈现可达性，有据行动只由后续补丁和测试结果承担。

该映射推出三个普通相关性选择器不会自然维护的对象。

1. **关系见证路径。** 每个候选短路径表示一种可能需要共同呈现的深层事实。例如调用关系连接调用点与被调定义，数据流路径连接产生、传递和使用位置，测试路径连接断言与实现责任位置。路径只从修复前仓库和任务文本生成，参考补丁不参与路径构造。
2. **完整路径证书。** 节点可以凭自身行动价值单独入选，但只有一条路径的全部成员都被选择时才激活该路径的高阶交互。对路径 $p$、片段变量 $y_i$ 和证书 $z_p$，约束为 $z_p\leq y_i$（对所有 $i\in p$）以及 $z_p\geq\sum_{i\in p}y_i-|p|+1$。路径交互值允许为正、零或负，因此完整静态路径也不会被理论先验强行奖励。
3. **可证伪的关系扰动。** 完整路径、删除节点、同仓库 sibling 替换、保持文本但重连边以及关系类型打乱形成预算匹配的上下文对。只有在固定行动评估器观察到完整关系确实比扰动关系改善编辑决策时，该路径才获得正交互值。理论要求显式检验表征关系，数据负责判断具体静态关系是否忠实。

### 2.3 核心模型：关系忠实神经选择器

暂定模型名为 Relation-Fidelity Graph Packer，简称 RFGP。为避免把一篇论文做成多问题拼盘，核心模型只保留三个部件。

1. 查询条件关系图编码器只输出每个候选片段的单项行动值 $u_i$。它可以传播关系信息，但不能仅凭消息传递宣称最终所选片段形成了完整见证。
2. 共享参数的 typed-path scorer 读取路径成员表示与关系类型序列，输出可带符号的路径交互值 $v_p$。集合值固定为 $V_\theta(S)=\sum_i u_i y_i+\sum_p v_p z_p$。它不再另加 obligation coverage、通用 pairwise interaction、停止头或学习式排序头。
3. 小型 MILP 在 $\sum_i d_i y_i\leq B$ 下最大化 $V_\theta(S)-\lambda\sum_i d_i y_i$，并以线性约束实现 $z_p$ 的 AND 语义。$\lambda$ 是在验证集或部署偏好下固定的成本交换率，不被写成客观真值。模型允许空集和预算未填满，并报告质量—成本前沿、求解延迟与最优间隙。

选中片段随后进入冻结的确定性 serializer，按见证局部块、文件路径和起始行排列。同一片段只渲染一次。排序不作为本章的第三个学习问题。

### 2.4 训练信号与理论扰动

参考补丁只定义修复前提下的目标编辑行动 $a^*$，不进入模型输入、候选召回、图或路径生成。冻结行动评估器 $A_\psi$ 对上下文包 $S$ 给出目标行动 regret，例如 $Reg_\psi(S)=-\log p_\psi(a^*\mid q,S)$，由此构造包效用 $U_\psi(S)=\operatorname{clip}(Reg_\psi(\varnothing)-Reg_\psi(S))$。主要训练包包括空集、相关性 top-k、完整候选路径、预算匹配的 broken/rewired/type-shuffled 路径、同仓库 sibling 和高相似干扰包。

核心损失只保留包值回归与有观测依据的配对排序：$\sum_S\operatorname{Huber}(V_\theta(S),U_\psi(S))+\alpha\sum_{(S^+,S^-)}\log[1+\exp(-(V_\theta(S^+)-V_\theta(S^-))/\tau)]$。完整路径只有在实测效用高于其扰动版本时才进入正向排序，不把理论猜想硬编码成标签。大规模包由本地编辑行动评估器产生，预注册的 5%–10% 子集再用独立开放权重 patcher 与官方测试校核，避免模型只学习一个评估器的偏好。

本地工件包括修复前图与候选缓存、关系扰动生成器、冻结行动评估器版本、图编码器与 path scorer 权重、MILP 配置、tokenizer 和 serializer。冻结基础代码编码器时仍需在本地训练关系图层与路径评分器。

### 2.5 可证伪预测与消融

1. 在单文件局部任务中，RFGP 与独立相关性选择器差异较小；在调用、数据流和测试—实现跨文件任务中，signed path 交互应显著改变片段组合。
2. 当预算只够一个关系端点时，模型应有时选择完整的次相关关系或留出预算，而不是选择最相关的孤立片段。
3. 关系闭合提高而关键词召回不变时，Agent 的错误导航和无效编辑应下降；因此 pass-rate-per-token 可以提高，而 Recall@k 不一定提高。
4. 在存在多个貌似合理编辑位置或高相似干扰项的任务上，反事实行动价值头应比 qrel 相关性头产生更大差异；单一明显编辑点任务上的差异应较小。

关键消融包括等参数普通图 Transformer、把路径 AND 交互改成端点求和或平均、删除全部关系扰动、强制 $v_p\geq0$、把行动 regret 换成 qrel 或生成对数概率、令 $\lambda=0$、强制填满预算、随机化关系类型和用 greedy 替代 MILP。若完整路径相对严格匹配的 broken/rewired 路径没有更高的真实行动效用，或普通图模型产生相同选择行为，则删除路径机制并撤回理论专属主张。

### 2.6 数据与边界

ContextBench 承担文件、AST block 与代码行的忠实表示评价，SWE-Explore 承担轨迹相关行与受限行动评价，Agent Retrieval Bench 承担文件级和其已发布 span 证据的适配评价。CORE-Bench 可在完成版本与许可核验后承担大规模多层关系检索，GREPO 或 SWE-bench 训练仓库可用于图定位预训练；所有 2026 新资源先固定 commit 并完成 smoke test，不写成已经长期成熟。RepoShapley、SetR、GREPO、SweRank、RepoGraph 和 Code Graph Model 是直接技术比较对象。RFGP 的新颖边界是 issue-resolution 中的完整路径证书、broken-chain 忠实训练、决策 regret 与成本条件结构化解码的交集，不声称首次使用图、集合选择、边际效用或学习式上下文过滤。

## 三、历史论文二：任务需求—信息供给的方向匹配集合网络

### 3.1 自然问题

在任何任务特定候选产生以前，给定 issue、冻结仓库的任务无关摘要和若干具有独立执行成本的信息服务，模型应调用哪一组服务并为每项服务分配多少取得配额，使合并证据能够穿过共享上下文窗口并进入 Agent 的行动依据。输出不是固定类别，而是可随服务库与配额档位扩展的集合政策。

普通路由器直接从任务特征预测最佳服务或服务集合。这种映射无法说明一个集合为何适合任务，也会把供给不足、供给过量和不同均衡水平压缩为同一种误差。论文二因此不延续固定十六动作树模型，而学习任务需求与组合供给之间的有方向非线性匹配面。

### 3.2 理论来源与专属算法对象

中心理论采用非线性任务—技术匹配，并以有效使用的层级关系限定其结果责任。任务要求与技术能力必须分别表示；供给低于需求和供给超过需求都可能损害结果，但方向和强度不同；相同的匹配差距在不同需求—供给水平上也可能产生不同绩效。服务的潜在能力只有先取得目标证据、再在共享表示中保留、最后被 Agent 的行动过程实际采用时，才形成有效供给。

软件维护中的认知匹配研究进一步给出与 Coding Agent 直接相连的反单调预测：理解更多代码只有在所形成的表示与修改任务需要同类知识时才改善修改；失配时，额外理解会占用注意并降低修改绩效。因此，FIT-USE 不能把更高召回或更多上下文预设为正价值，过量分支必须允许与修改需求不匹配的证据产生干扰。

两个理论共同推出五个专属对象。

1. **需求向量。** issue 与仓库静态状态产生对词面定位、语义消歧、结构跳转和全局导航等能力的需求，而不是直接产生动作 logits。
2. **供给向量。** 每项服务依据其能力描述、索引状态和仓库静态条件产生供给。服务集合通过带冗余抑制的集合聚合器形成组合供给，不能把多个服务的分数简单相加。
3. **有方向缺口。** 对每个能力维度分别计算不足量与过量量。两个分支具有不同单调斜率和交互，保留错配方向。
4. **均衡水平。** 以需求与供给的共同水平区分低需求—低供给和高需求—高供给，即使二者的绝对差均为零。
5. **取得—表征—使用链。** 对同一目标证据分别记录它是否被任一服务取得、是否经过固定融合与装入器后仍在上下文中、是否继续出现在 Agent 最终声明的编辑依据中。三层概率满足使用不超过表征、表征不超过取得的嵌套关系，不能由三个彼此独立的质量头产生逻辑逆序。

### 3.3 核心模型：方向匹配集合网络

暂定模型名为 Fit-and-Use Service Policy，简称 FIT-USE。

1. 需求编码器从任务查询与部署前可见的仓库摘要产生非负需求向量及不确定度。
2. 服务编码器为每项服务及其配额产生条件供给向量。集合聚合器用可学习 noisy-union 与成对冗余门形成组合供给，使新增服务或增加配额既可能弥补能力缺口，也可能只增加重复信息、共享窗口挤出和成本。
3. 方向匹配层构造不足分支、过量分支和共同水平分支。每个分支采用单调神经样条或深度格点网络，强制不足随缺口增大不改善绩效，过量惩罚允许具有不同曲率，共同水平允许在零差距条件下继续区分任务难度与有效供给。
4. 嵌套使用头以三个条件二项似然建模 (p(U)=p(A)p(R\mid A)p(U\mid R))。其中 (A) 表示取得，(R) 表示固定装入后的表征保留，(U) 表示最终行动依据中的使用。该因子化在训练和推断时都保证层级次序，并把服务组合目标从原始召回改为预期有效使用。
5. 集合能量将匹配后的使用价值与服务查询成本分开预测。训练以同一任务缓存得到的集合—配额结果形成列表式后悔损失、反事实边际损失和方向导数约束。推断采用机会约束 beam search，只有减少需求缺口且有效使用增量下界高于成本影子价格的扩展才进入 beam；所有扩展均无正净值时输出空集。

### 3.4 理论带来的非显然行为

- 一个语义与结构需求都低、具有明确符号锚点的任务，不会仅因密集或图服务更强就优先调用它们；额外能力可能形成过量供给并付出成本。
- 一个结构需求高的任务即使词法服务返回高相关候选，仍可能被识别为结构供给不足。模型需要增加图或全局导航服务，而不是把已有高相似度当作匹配。
- 两个绝对差均为零的任务可以得到不同价值。高需求—高供给均衡应与低需求—低供给均衡分开估计。
- 同一服务在不同组合中的边际价值取决于它弥补的需求缺口和与已有供给的冗余，不能由固定服务权重表示。
- 一个服务即使取得更多金证据，也可能因共享窗口挤出而降低表征保留，或因 Agent 未采用而没有使用价值；FIT-USE 不允许取得率的上升自动等同于政策价值上升。

### 3.5 训练数据、评价和直接竞争

训练样本优先从完成版本与许可核验的 CORE-Bench、SWE-bench 训练任务或仓库隔离的 SWE-rebench 训练候选生成。参考补丁、测试变化和派生金文件只在离线阶段评价各服务集合的证据质量；部署特征不接触这些标签。每项确定性服务只运行一次最大深度并缓存有序结果，较小配额引用其前缀；不具前缀性质的 agentic 服务按预算档单独运行。固定融合与装入器离线合成 64 至 128 个集合—配额动作，取得与表征标签由公开 gold 和缓存确定。使用标签只在均衡抽样动作上运行固定本地开放权重 Agent，并从其最终 PATCH_CONTEXT 或等价的预注册行动依据日志判定；未运行 Agent 的动作仍用于取得与表征两层训练。

为支持神经模型，主训练不局限于 ARB 的 25 个仓库，而从大规模训练仓库构造数千项任务。ARB 作为冻结外部选择性检索场地，ContextBench 作为三级上下文和使用链迁移场地，SWE-bench Verified 稳定子集承担固定 Agent 行动评价。所有资源先执行仓库、任务、提交、issue 和补丁近重复审计。

主要比较包括直接动作 MLP、通用 Set Transformer、绝对差匹配、余弦匹配、无均衡水平模型、Hosanagar 式加性效用源选择、AIRCoder、R³AG、Retriever Portfolios 和原 TSMI 式树模型。理论消融分别把有方向缺口改为绝对值、强制不足与过量共享曲率、删除共同水平、把嵌套使用似然改为三个独立头、把目标退化为取得召回、删除冗余门和取消方向导数约束。论文只有在方向相反的错配分层、高低均衡分层和取得高但使用低的挤出分层上观察到预注册行为差异时，才声称理论产生了专属实现。

### 3.6 新颖边界

论文不声称首次做效用驱动的检索源选择、训练检索路由器、组合检索器或区分检索质量与生成效用，也不把融合本身作为贡献。相对于 Hosanagar 的加性服务器效用、Retriever Portfolios、R³AG、AIRCoder 以及其他 agentic router，研究对象是候选产生前的异质信息服务集合与配额，全部结果竞争同一有限上下文，技术贡献是需求—供给双编码、有方向的约束匹配面、取得—表征—使用嵌套链和空集可选的成本决策。若最新工作已经在相同部署信息下学习同类有方向集合匹配与嵌套使用链，则必须进一步收窄服务对象或撤回该题。

## 四、历史论文三：事项残差与边际差异约束的探索价值停止

### 4.1 自然问题

在 Coding Agent 首次编辑以前，冻结的动作生成器依据当前仓库状态提出一组具体信息行动，例如读取符号、调用者、测试或配置。模型应从候选行动与立即交付给下游修复或弃权之间作选择，并在所有候选行动的新增决策价值都不超过取得成本时停止。价值限定在固定后续探索政策与固定修复政策下，不解释为全局最优搜索。

普通停止模型把轨迹压成一个隐藏状态，再用轮数、token 或状态稳定性预测一个停止分数。这容易把资源消耗误当成信息充分，也不能回答当前候选行动中是否仍有某一项值得执行。论文三因此从前缀二分类改为带显式 STOP 外部选项的行动级信息价值控制。

### 4.2 理论来源与专属算法对象

认知停止研究表明，任务结构和表示策略会对应不同的充分性线索；系统价值理论要求把每一候选输入的新增结果收益与取得成本联合起来，并在没有候选输入产生正净值时停止。论文不把人的心理状态赋予 Agent，而把这些理论关系转化为状态表示选择与规范行动决策。

1. **任务结构门。** issue 中可辨认的目标、约束、复现步骤和验证条件决定任务在可分解—整体连续轴上的位置。该门只决定充分性状态如何表示，不直接决定停止。
2. **清单专家。** 对可分解任务，issue、失败测试和已取得证据形成 requirement—evidence 二部图。typed cross-attention 与逐事项 grouped noisy-OR 输出每项要求的满足度和残差；相近重复证据收益递减，但同一真实证据可以支持多个事项。
3. **稳定专家。** 对低锚点、跨模块和难分解任务，模型维护 repository-entity 修复信念；相邻事件间的 Jensen–Shannon 差异和关系修订率描述表征是否仍在实质变化。它不把累计信息量当作充分性。
4. **行动级规范价值。** 对每个候选行动分别预测相对于立即交付的结果收益分布和增量成本分布。STOP 是候选集合之外的显式外部选项，不是单一前缀分类标签。
5. **集合停止证书。** 只有所有候选行动的校准净价值上界都不为正时才停止。单个基础 Agent 下一行动无价值并不充分，因为候选集合中可能存在更好的替代行动。

### 4.3 核心模型：清单—差异价值停止网络

暂定模型名为 Structure-Adaptive Value-of-Information Controller，简称 SA-VOI。

1. 异构状态编码器在 requirement、evidence、repository entity、历史工具事件和候选行动之间进行消息传递。任务结构门把状态送入清单专家、稳定专家或二者的连续混合，但保留两套充分统计量供机制检验。
2. 清单专家对每项要求独立聚合具有相应关系类型的证据，使用 grouped noisy-OR 表示多份证据的递减补充，并显式保留未满足残差。该结构不把同一证据强制分配给唯一事项，因为一个测试或接口契约可以真实支持多项要求。
3. 稳定专家维护修复信念分布，以相邻前缀的 Jensen–Shannon 差异、实体边新增和假设排序变化表示修订。累计 token、轮数与墙钟通过结构隔离只进入成本侧，不能成为结果收益头的捷径。
4. 候选集合编码器对每项行动输出相对于立即交付的结果收益分布、成本分布与失败风险。结果和成本分头训练，最终按后置的单位权重形成净值；同一模型因此能报告质量—成本前沿，而不是把一个任意复合标签写死。总增量成本允许为负，因为一次额外读取可能减少后续诊断或修复成本。
5. 仓库级同时校准器对一项检查点的全部候选行动形成净值上界。只有最大上界不为正时输出 STOP，否则执行上界最高且满足风险限制的行动。该规则直接实现“所有候选均不值才停”。

### 4.4 训练标签与本地工件

在预注册的稀疏因果检查点上保存轨迹前缀。冻结动作生成器形成四项只读候选，包括基础 Agent 下一行动和三个由当前实体确定性展开的替代行动；HANDOFF 是 slate 之外的外部选项。每个检查点共享一次 HANDOFF 到下游修复或弃权的 rollout，再按已知抽样概率执行基础行动和至少一个替代候选，随后沿固定政策至交付；所有分支使用相同仓库快照、解码种子和总任务预算。结果、FAIL_TO_PASS、token、工具、墙钟和基础设施失败分开记录，以任务与仓库分组的 IPW 或 AIPW 估计候选行动相对 HANDOFF 的分布式净增益。近零边际样本追加第二种子，预算触顶属于政策终止，基础设施失败单列敏感性。

每个候选分支的标签覆盖该行动执行以后沿冻结探索政策直到自然 HANDOFF、再由固定下游策略修复或弃权的完整后缀。因此，短期不直接命中 gold、却能打开后续证据的 bridge action 已经体现在最终结果与总成本差中；核心模型不再额外增加 first-passage、survival 或 Bellman 评论家。只有 pilot 发现系统性 bridge 漏判时，事件时间才作为诊断性辅助分析，而不是第三项方法贡献。

大规模拟合使用仓库隔离的 SWE-Gym 与 SWE-smith 稳定任务，SWE-rebench 承担独立校准与公开测试，SWE-bench Verified 承担正式行动外部效标。ContextBench 和 SWE-Explore 只评价事项证据与边际创新机制，不伪装为相同任务的停止反事实。

本地工件包括任务结构标注器、事项图与修复信念生成器、动作 slate、动态图双专家模型、候选结果与成本分布头、风险校准分数、检查点抽样表、propensity 和配对完整后缀日志。远程模型可以作为固定基础 Agent，但控制器的训练和推断必须在本地完成。

### 4.5 可证伪预测与消融

1. 在显式锚点、复现步骤和验证条件充分的可分解任务上，清单专家应优于稳定专家；在低锚点、跨模块的整体任务上，稳定专家应更有用。任务结构与专家优势必须呈现预注册交互。
2. 在消耗很多 token 但关键事项仍无见证的任务上，SA-VOI 应比轮数或预算阈值更少误停。
3. 在修复信念已稳定且候选行动只返回重复证据的任务上，模型应更早停止；表示看似稳定但候选行动仍能补齐高价值事项时不能停止。
4. 当基础 Agent 的下一行动无价值但 slate 中存在低成本替代行动时，行动级控制器应继续，而单一 prefix 或 base-action 停止器会停止。
5. immediate gold overlap 为零但能够打开后续证据的 bridge action 应获得正的多步价值；一步新颖度模型会错误拒绝它。

关键消融包括等参数普通 GRU、普通轨迹 Transformer、池化 Set Transformer、随机或交换任务结构门、把逐事项残差改成全局池化、删除 duplicate discount、删除信念 JSD、只评价基础下一行动、让累计量进入结果头、把完整后缀效用换成一步新颖度、把候选集合停止证书改为单一 sigmoid，以及删除仓库级同时校准。Hosanagar 式加性检索—等待策略、Mookerjee 式价值停止、ECLoop、SWE-Router、FuseSearch、Guided Search Strategies、SuperScout 固定 scout—handoff、CodeRescue 式通用成本路由与通用过程奖励模型是直接比较或规范参照对象。研究边界是首次编辑前具体信息行动相对于立即交付的净决策价值、候选集合联合停止和任务结构自适应充分性表示；若只剩通用轨迹价值估计或检索效率奖励，则不构成独立贡献。

最新工作的边界必须写在正文而非只留在附录。SuperScout 已经把仓库探索结果组织为结构化 handoff 后交给 fixer，因而本文不声称首次连接搜索与交付；它的流程是固定 scout 后一次性交付，没有逐状态比较候选信息行动与立即 HANDOFF。CodeRescue 已经以 rollout 训练成本敏感动作路由并用 conformal risk control 调节预算，但对象是失败后的恢复或模型升级，控制的是平均成本风险。SA-VOI 只有保留首次编辑前同状态的 candidate-minus-HANDOFF 配对估计、任务结构双专家和“全部候选上界均不为正”的全称停止证书，才不退化成这些工作的组合。
