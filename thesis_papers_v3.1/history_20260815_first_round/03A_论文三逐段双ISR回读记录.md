## 引言第 1 段后的对抗性贡献审计

本节不是正文段落，也不把待检验判断写成研究结果。新增审计要求到达时，正文已完成摘要与引言第1段，因此在继续引言以前暂停写作，重新检查问题 headroom、最近直接工作与理论工件是否足以支撑独立研究。

### 1. SA-VOI 是否只是通用结果—成本路由器

**不利判定。** 从最外层输入输出看，SA-VOI 的确高度接近通用路由器：输入轨迹状态和候选动作，预测成功与成本，再根据风险校准选择动作或停止。Guided Search 已经以学习的绝对行动价值对候选做一步 lookahead；CodeRescue 已经从 rollout 训练异质恢复动作的结果—成本路由并用 conformal risk control 选择成本惩罚；ECLoop 已经依据结构化证据条件延迟缺乏依据的编辑。若删除任务结构双专家、同状态 candidate-minus-HANDOFF 估计和全 slate 停止逻辑，剩余工件没有足够的新颖性，不能因为决策发生在首次编辑前就成为独立贡献。

**目前唯一可能保留的非通用交集。** 第一，标签不是成功轨迹上的绝对 Q，而是同一状态下候选完整后缀相对立即 HANDOFF 的配对结果差与成本差。第二，任务结构不是普通输入特征，而应使清单残差与修复信念稳定成为两套不可互换的充分状态，并产生预注册交叉优势。第三，停止不是一个候选或一个前缀的分类，而是对完整 slate 的全称否定；任一候选仍可能有正净值时都不能签发 HANDOFF 证书。这三个对象必须同时产生普通 critic 不具有的行动行为。只证明其中一个组件提高预测精度，最多支持工程改进，不能支持当前理论驱动研究。

### 2. 现有证据只能说明问题可能存在，尚未证明 headroom 足够

| 现有原始证据 | 能支持的判断 | 不能支持的判断 |
|---|---|---|
| ECLoop 全部 500 项 SWE-bench Verified 实验报告 Pass@1 增加 4.8–11.8 个百分点、平均 token 最多下降 12.1%（预印本摘要：https://arxiv.org/abs/2607.28815） | 缺乏证据便编辑可能是有实质软件结果的失败，不只是审美问题 | 不能证明 SA-VOI 的价值状态、候选选择或成本停止优于结构化 evidence condition |
| Guided Search 用学习的行动价值和候选 lookahead 改善 SWE-bench Verified，并报告较长 horizon 可避免遗漏复现与测试（ICML 2025：https://arxiv.org/abs/2505.13652） | 同一状态的行动选择与长短 horizon 可能影响最终解决 | 不能证明这种分歧集中在首次编辑前的只读行动，也不能证明 paired VOI 优于绝对 Q |
| Agent Retrieval Bench 报告公开 Agent 轨迹在 27%–35% 样本上未取得任何 gold 文件，且自然 no-gold 上选择阈值存在校准缺口（预印本：https://arxiv.org/abs/2607.24882） | 仓库信息取得存在不足与选择性校准困难 | 不能把 gold-file 遗漏等同于误停，也不能证明继续哪项行动会改善补丁 |
| FuseSearch 报告强制并行执行中存在大量无新增实体的工具调用，并以定位 F1 与新颖信息比例训练（ACL Findings 2026：https://aclanthology.org/2026.findings-acl.143/） | 只读搜索中确有重复取得和成本空间 | 不能证明自然基础 Agent 普遍过搜，信息新颖度也不是下游决策价值 |
| SuperScout 在 SWE-bench Pro Python-266 以固定 scout—handoff 流程配合较廉价 fixer 达到 159/266；其 no-router 变体与路由系统打平（预印本：https://arxiv.org/abs/2608.04804） | 结构化仓库 handoff 本身可能具有很高杠杆 | 固定 handoff 已接近完整系统反而威胁逐状态自适应控制；该结果不能证明复杂停止器仍有增量空间 |

因此，当前不能在引言中断言基础 Agent 同时普遍存在早交付与过度探索。80 项 pilot 首先要估计四个经验量，而不是训练完整模型：符合首次编辑前至少两个检查点且每点至少两个可执行只读候选的任务比例；同状态候选完整后缀净值的离散程度；oracle 最佳候选与基础下一行动发生分歧的比例；立即 HANDOFF 优于所有候选和至少一项候选优于 HANDOFF 是否都具有非零且可复现的质量。

### 3. 与四项最近工作相比，只有一种高杠杆能力值得保留

| 直接工作 | 已有能力 | SA-VOI 必须新增的能力 | 若未观察到的处理 |
|---|---|---|---|
| SuperScout | 仓库 scout 产生并验证 structured handoff，再交给 fixer | 根据当前证据在多项具体信息行动与现在交付之间反复选择，并显著优于固定 handoff | 降级为固定 scout—handoff 的机制分析，不保留独立序贯论文 |
| CodeRescue | 失败以后在 cheap recovery 与模型 escalation 间做 rollout 结果—成本路由，并以 CRC 控制平均成本；该预印本已撤回但仍构成先验威胁 | 首次编辑前信息行动的同状态增量使用价值，以及控制误停而非平均成本的全 slate 排除证书 | 若普通 success/cost router 等价，删除双专家与理论贡献，至多保留阶段应用短文 |
| Guided Search | 以绝对 $Q_\pi(s,a)$ 选择 K 个候选并进行轨迹选择 | 不并行生成完整解，而在单路径探索中识别何项信息值得购买，并允许立即 HANDOFF 成为反事实外部选项 | 若等参数 critic 的行动排序、系统价值与成本前沿不劣，终止 SA-VOI |
| ECLoop | 用 issue 和仓库结构编译证据条件，条件未满足就阻止编辑 | 不把事项当固定必备清单；在成本和可替代候选给定时判断某项证据是否值得取得，并在整体任务上使用不同稳定线索 | 若 evidence condition 已覆盖主要误停且没有过搜收益，删除论文三或只研究其成本扩展 |

真正高杠杆的候选贡献不是“更准确的停止器”，而是同一控制器能处理三个方向不同的状态：基础下一行动无值但替代候选有值时改道，所有候选均无值时交付，显式事项与修复信念仍不稳定时拒绝仅凭累计预算停下。若 pilot 不能找到足够多的三类反例，复杂双专家没有研究必要。

### 4. 预注册 kill 与 demotion 条件

以下阈值用于 pilot 设计，正式数值仍需在任何结果可见以前由主研究方案冻结。

1. 若少于约 30% 的任务同时具有两个合格检查点和至少两个不同只读候选，判定适用面不足，停止独立论文。
2. 若候选完整后缀的 oracle 最优行动与基础下一行动在少于约 20% 的合格状态上分歧，或其净值差被重复种子噪声覆盖，删除候选选择主张。
3. 若“立即 HANDOFF 优于全部候选”和“至少一个候选优于 HANDOFF”任一方向少于约 10% 的合格状态，问题退化为几乎总停或几乎总继续，不训练序贯控制器。
4. 若固定 SuperScout 式 handoff、ECLoop 式条件门或等参数通用 critic 在系统价值、Pass@1 非劣与成本前沿上与 SA-VOI 等价，终止本题；不能用机制可解释性补救零行动增益。
5. 若双专家相对彼此和普通 Transformer 不出现预注册的 `task structure × expert advantage` 交互，删除认知停止理论和双专家。若 generic router 仍有效，只能降级为非理论工程研究。
6. 若同状态重复分支的净值符号一致率低于 0.70，或 full-slate 校准造成大面积默认继续和显著 freezing，停止扩展反事实标签或证书。
7. 若收益只表现为检索 F1、新颖信息比例或 stop accuracy，而未进入 Pass@1、测试进展、每解决任务成本或误停遗憾，不能保留 IS 系统价值主张。

### 5. 再次逐句回读 ACAA 与 DSDL 后得到的贡献纪律

**重要 outcome 先于方法。** ACAA 第39行从评论影响购买意愿推进到销售预测与运营价值，第41行才揭示“全部评论进入模型”与有限顾客注意的矛盾。DSDL 第39行先把及时响应预测连接到有限服务能力、邀请成功和营销效率，第41–43行再说明数据与既有模型为何不适用。两文因此先证明一个可度量最终结果和真实资源矛盾，再引入理论。论文三相应必须先用 pilot 证明首次编辑控制改变补丁结果与总成本；公开环境可运行本身不是重要性证据。

**理论缺口必须使普通算法产生方向性错误。** ACAA 第85–87行不是泛称 attention 不够好，而是指出 affinity compatibility 会偏爱相似评论，恰好违背 semantic diversity 对互补评论的要求；第108行据此设计反相关/互补注意。DSDL 第83–89行把 expectation、experience、disconfirmation 和 cumulative satisfaction 的关系固定下来，第91–95行说明个人资料缺失、问答交错和属性—片段异质性使普通静态表示失效。论文三若只说 GRU 不可解释仍然过弱；它必须观察“基础行动无值但替代行动有值”和“结构任务/整体任务的最佳状态线索反转”这两种普通池化模型会犯的方向性错误。

**不可替代状态来自理论实体，而不是更复杂的 hidden state。** ACAA 第91–122行先规定 process—granularity、reception/yielding 与四类注意，再让每个理论对象对应一个 compatibility function；第118–122行用表格逐项绑定理论、挑战和算法。DSDL 第83–95行先独立定义期望、体验、失验和累计满意，第99–103行才把它们映射为 preference embedding、cross-view attention 和 bidirectional sparsity。两文的关键状态可以被单独观察、可视化和删除。论文三只有逐事项残差和实体信念修订分别呈现任务类型条件化的行动信息，才达到同一标准；若它们只是给 candidate-value head 增加特征，应删除。

**机制效标和经济效标承担不同责任。** ACAA 第290–314行既检查四类 attention weight 是否按理论方向变化，也逐项删除机制，最终仍回到销售预测。DSDL 第267–295行分别比较动态满意、黑箱表示及二者结合，第285–307行让 cumulative satisfaction 单独预测真实响应并删除两类损失，因而理论中间对象不是装饰。论文三也必须同时报告事项残差/信念 JSD 的条件行为、candidate-minus-HANDOFF 排序、false-stop 以及 Pass@1 和每解决任务成本。只有机制指标改善而软件行动不变，结论应降级为状态表征研究；只有最终成本改善而理论交互不存在，结论应降级为通用路由。

**当前审计结论。** SA-VOI 不是已经成立的论文设计，而是一个值得用小规模因果 pilot 否证的候选。ECLoop 给出早交付 headroom 的积极信号，Guided Search 给出候选行动分歧的积极信号；SuperScout 的固定 handoff 结果和 CodeRescue 的通用结果—成本路由则构成强烈反证压力。正文应停在当前引言第1段，直到上述适用比例、双向停止 headroom、候选分歧和 generic-critic gap 有真实结果；在此以前继续写完整理论与方法章节会把尚未成立的问题包装成复杂工件。
