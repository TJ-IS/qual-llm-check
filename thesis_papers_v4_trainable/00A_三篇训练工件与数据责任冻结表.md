# 三篇训练工件与数据责任冻结表

> 当前效力说明　本表的最终解释以 `00D_三项独立训练Pilot冻结版.md` 为准。三项目前冻结为可证伪 Pilot，不是已经成立的论文贡献。旧的 typed task–evidence gap 探索方案已经终止。

## 一、暂定系列主轴

三篇围绕受限计算下仓库证据如何支持可验证软件行动展开。论文一学习任务所需仓库证据的层次表征。论文二学习在已有证据不足时下一步应取得什么。论文三学习候选补丁已经形成以后下一项验证是否值得取得，以及何时选择补丁或放弃。三篇分别对应表征、取得和验证使用，不以同一个检索器更换损失构成系列。

当前暂定名称如下。

- 论文一 HERA，Hierarchical Evidence Representation for Agents，面向 Coding Agent 的层次一致仓库证据表征与预算合成方法。
- 论文二正在重新冻结研究对象。原 TEGRA 方案因公共数据不能独立识别需求槽、证据槽与二者差值，且与训练型图探索近邻高度重合，已在立项闸门终止，不进入三篇终稿。
- 论文三暂称自适应验证世界模型，面向 Coding Agent 候选补丁的预算自适应验证与选择方法。正式近邻审计完成以前不设英文缩写，以避免与已有补丁正确性工作 BATS 混淆。

这些名称只服务于当前撰写。若正式近邻审计发现同名或完整问题已被覆盖，应改名或停止相应方向，不能靠增加组件维持表面差异。

## 二、论文一 HERA

### 研究问题

给定修改任务和冻结仓库快照，如何学习文件、定义块和代码行之间层次一致的任务证据表征，并在固定 token 预算内合成可供 Coding Agent 使用的证据包。

### 训练样本与输入

观察单位是一个任务、一个冻结仓库子图和其中的文件、AST 定义块、规范行窗口节点。任务编码为 (H_q\in\mathbb{R}^{m\times d})。仓库图由包含、导入、调用、定义引用和测试关联等可静态验证的边组成。节点初始表示由冻结文本与代码编码器产生，训练阶段只更新适配器、关系图网络、层次解码器和数据来源专属输出头。

### 架构与损失

三层关系感知 HGT 产生节点表示。层次解码器不独立预测三个相互冲突的概率，而是使用条件因子化 (p_f=\sigma(a_f))、(p_b=p_f\sigma(a_{b\mid f})) 和 (p_l=p_b\sigma(a_{l\mid b}))，从参数化上保证行、块和文件之间的证据一致性。文件使用多标签 Bernoulli 目标，块与行使用父节点内条件分布，并以 parent-OR 与自底向上重构校准三个层次。ContextBench 的文件、AST 块和行标注形成三个粒度的联合损失。SWE-Explore 的 core 与 optional 区域使用独立输出头和独立校准。预算解码器在 token 背包下选择行窗口，同时惩罚重复并加入最小父块和文件头。它是确定性推理解码器，但其效用分数来自训练后的 HERA checkpoint。

### 数据责任

- ContextBench 承担主要人类证据监督、三粒度评价和层次一致性检验。
- SWE-Explore 承担成功修复轨迹所观察证据的外部迁移与过程评价，不与人类 gold 合并成同一标签。
- ARB 承担文件级工作流外部泛化、自然无金标准任务与错误仓库控制，不承担块或行监督。
- SWE-bench 或更新的可执行任务只承担冻结 Agent 的下游传递检验。Gold patch 和隐藏测试不得进入 HERA 输入或调参。
- SWE-smith patch locus 如被使用，只能称为修复位置辅助预训练，并在主训练前完成。它不是真实上下文标签。

### 训练工件与资源

发布冻结基础编码器标识、以约 20M 参数为主设定的 HGT 与层次头 checkpoint、特征 schema、图 grammar、候选生成配置、tokenizer 和预算解码器。冻结高召回候选生成器先从完整仓库形成候选子图，主实验必须报告候选召回和 oracle 上限，不能把上游遗漏归因于层次模型。预缓存代码表示后，主训练预计使用一张 48GB 或两张 24GB GPU 数日。CPU 静态解析、图构建与索引另行记账。

### 不得声称

HERA 学习的是各数据来源定义下的任务相关证据分布，不证明这些证据对所有修复路径都必要。人类认为应读、成功 Agent 曾读和最终补丁修改的位置不是同一构念。HGT 本身也不是贡献，贡献必须来自任务条件的层次一致测量、来源分责和预算行动传递。

## 三、论文二候选 Pilot　修复位置后验驱动的主动仓库信息取得

### 研究问题

在探索步数或读取行数预算冻结时，如何显式维护文件、代码块和行区间的修复位置后验，并选择使预期 Bayes 定位风险下降最多的下一代码区域或关系邻域。

### 训练样本与输入

观察单位是任务、冻结仓库、探索前缀、当前 frontier 候选和 developer edit set。主标签由 gold diff 在 base snapshot 上确定的 file、最小语法块和修改行区间产生。时刻 (t) 的状态只含 issue、任务无关廉价索引元数据、已经读取的代码和历史动作。未读代码原文、完整代码 embedding、gold patch、未来返回与隐藏测试均不得进入状态。候选池由冻结 sparse/dense 名次、路径与类型元数据以及已读节点图 frontier 构成。

### 架构与损失

关系编码器从廉价元数据形成位置先验，已读内容经递归更新器形成状态。层次 belief 为 (b_t(f))、(b_t(b\mid f)) 和 (b_t(l\mid b))，乘积给出叶节点后验。outcome head 预测执行某个读取动作后可能得到的内容摘要分布，cost head 预测行数、token 和延迟。定位风险由 file、block 和 line 三层 gold log loss 或漏定位损失构成。动作值为当前风险减去观察结果期望下的后验风险，再扣除读取成本。训练使用层次 NLL、Brier 校准、观察结果 NLL、成本 pinball、hindsight 风险下降回归和保守 policy loss。先做短视 oracle imitation，再在冻结离线轨迹上训练，不使用会同时改变基础 Agent 的在线 PPO。策略在固定 (H) 步或固定行数下运行，不学习 STOP。

### 数据责任

- SWE-smith 或 SWE-Synth 的 gold diff 只承担规模化预训练的层次位置标签，合成 issue 不承担真实外推结论。
- SWE-Gym 的真实任务和容器承担内部定位与冻结 patcher 检验。
- SWE-rebench 中冻结日期后的新仓库承担主外测。训练集与外测在仓库族、issue、commit 和 patch 层去重。
- ContextBench 人工 needed-context 不作为本题位置后验标签，避免把“应读什么”和“最终改哪里”混成一个对象。
- 所有行为轨迹仅提供合法观察前缀。行为策略的下一动作不能冒充最优动作标签。

### 训练工件与资源

发布元数据图构建器、observation schema、层次 belief checkpoint、outcome 与 cost heads、固定预算 policy 和校准统计。Pilot 先取三百至五百个任务与约五千个观察前缀，在一张二十四 GB GPU 上训练最小模型，预计三十至八十 GPU 小时。只有 Pilot 同时改善后验校准、同预算定位召回和冻结 patcher 结果，才扩大到二十至八十百万参数的主模型和更大规模轨迹。

### 不得声称

不得把 developer patch locus 称为完成修复所需的全部上下文，不得让策略预先读取所谓未观察代码的内容表示，也不得把行为轨迹的下一动作称为最优取得动作。GraphLocator、ToolTrain、LocAgent、SWE-Search 和相关主动定位是正面近邻。若 VOI 策略退化为当前最高排名或最便宜动作，若静态检索器同预算持平，若增益只存在于合成 issue，或 belief 的校准与干预检验失败，本题停止。

## 四、论文三自适应验证世界模型

### 研究问题

在候选补丁与部署时可见的验证测试库已经冻结时，如何依据候选集合及已观察测试结果估计下一验证组的决策价值，并在有限预算内继续验证、选择补丁或放弃。

### 训练样本与输入

观察单位是一个 issue、固定候选补丁集合、任务可见验证组集合及其部分结果矩阵。候选节点包含 issue—diff 表示、修改路径、AST 或 API 变化与规模。验证节点包含测试来源、路径、关联模块、静态影响范围和预计成本。边状态为未运行、通过、失败、错误或超时及持续时间。训练数据先执行完整候选—验证矩阵，再随机遮蔽部分结果以产生大量可部署历史。

### 架构与损失

冻结代码编码器后，用二部关系图网络或 Set Transformer 编码候选集合、验证组和部分矩阵。候选 resolved 头预测最终可接受性及集合中至少存在一个正确补丁的概率。Masked outcome 头不把同一测试组在不同候选上的结果视为独立，而是使用测试共享潜变量的有限混合

\[
p(y_{1:K,m}\mid s)=\sum_{r=1}^{R}\pi_{m,r}(s)\prod_{k=1}^{K}p(y_{k,m}\mid r,s),
\]

表示 pass、fail、error 或 timeout 组成的相关结果向量。成本头预测在全部 (K) 个候选上执行该测试组的总容器时间中位数与尾分位数。训练损失由 resolved Brier 或 BCE、任一正确补丁的集合级损失、遮蔽结果负对数似然、成本 pinball 和任务内候选排序组成。

终端决策显式比较错误发布与错误放弃。选择候选 (k) 的期望损失为错误补丁损失乘以其不正确概率，放弃的期望损失为漏掉池内正确补丁的损失乘以任一候选正确的联合概率。当前停止损失 (L_{\mathrm{stop}}(s)) 是这些终端动作中的最小值。某验证组的价值为

\[
\operatorname{EVI}(m\mid s)=L_{\mathrm{stop}}(s)-\mathbb{E}_{y_{1:K,m}}L_{\mathrm{stop}}(s\oplus y_{1:K,m})-\lambda\widehat c_m.
\]

当 (K=6) 且结果合并为三类时，可以对 (3^6=729) 个向量精确求和。结果类别更多时使用冻结随机种子的 Monte Carlo 估计。推理选择预算内正价值最大的验证组。无正价值或预算耗尽时选择期望终端损失最低的补丁，否则放弃。

### 数据责任

- SWE-Gym 与 SWE-smith 提供可执行训练环境，固定同一开放 Agent 生成未经结果筛选的候选池。
- 验证测试库由冻结测试生成器只看 issue 与 buggy repo 一次生成，并加入确定性回归或静态检查。准入只使用语法、收集、在 buggy base 上可执行、重复稳定和时限规则。不得根据 gold patch 或隐藏测试通过情况筛选。
- 官方 evaluator 只产生训练终端 resolved 标签和最终评价。Gold patch、隐藏测试名和隐藏测试结果不进入节点、测试菜单或策略历史。
- SWE-rebench 承担时间隔离外测。SWE-bench Verified 只保留历史可比性副表，不承担主要外推。

### 训练工件与资源

发布 5 至 10M 参数的验证 world-model checkpoint、冻结编码缓存规范、测试库生成器哈希、验证菜单 schema、结果与成本校准器、信息价值解码器和损失比配置。候选正确性头还要形成集合中至少存在一个正确补丁的联合估计。验证结果头用测试共享潜变量的混合分布表示同一验证组在多个候选上的相关结果，而不把候选结果默认为独立。一个可行的主训练规模是 1,500 个任务、每任务 6 个候选与 6 个验证组，约 9,000 次候选生成、54,000 次容器验证组运行和 9,000 次终端评价。网络训练预计低于 100 GPU 小时，主要资源消耗来自候选生成和容器验证。

### 立项闸门与不得声称

100 项任务的试点必须表明测试结果矩阵相对于静态补丁 verifier 提供可测的条件信息增益，并且足够多的候选池同时含正确与错误候选。试点还要检查补丁去重后的候选多样性、验证结果在候选间并非恒定以及信息价值策略相对随机、最低成本、最高不确定性和静态 verifier 的 oracle regret。若测试库主要只有回归信号，自适应验证模型不进入主论文。近邻审计还必须排除已有正式工作同时覆盖 Coding Agent 候选池、任务可见复现测试、候选集合条件的序贯信息价值以及补丁选择或放弃。该方法只改进固定候选分布下的验证与选择，不提高候选生成的 pass@K。

## 五、三篇不重叠的判定表

| 论文 | 状态输入 | 学习标签 | 核心可学习结构 | 部署动作 | 主要结果 |
|---|---|---|---|---|---|
| HERA | issue 与完整冻结仓库候选子图 | 人类三粒度证据与来源专属轨迹证据 | 层次异构图表征和粒度一致头 | 合成预算证据包 | 证据忠实度、层次一致性、下游传递 |
| 论文二待冻结 | 不沿用原 TEGRA 定义 | 必须来自公开标签或真实执行，不采用同模型自标的需求缺口 | 必须形成独立可训练工件 | 待近邻与标签闸门确定 | 不与论文一的静态证据包或论文三的补丁验证重复 |
| 自适应验证世界模型 | 候选补丁集合、测试库和部分结果矩阵 | resolved、遮蔽测试结果与成本 | 候选—测试 world model | 选择下一验证组或终止选择 | 风险覆盖、验证成本、oracle regret |

论文一学习跨粒度证据表示和最终预算包。论文二不得只是论文一的顺序版本，也不得以未经独立检验的潜变量制造表面差异。自适应验证世界模型位于补丁生成以后，不执行仓库检索，也不使用前两篇算法作为必要组件。

## 六、整系列必须先通过的试点

HERA 的试点检查固定候选子图对 ContextBench 三粒度 gold 的候选召回，并检查条件层次参数化是否改善中间表示而不只改变阈值。论文二的试点闸门将在研究对象冻结后单独定义。自适应验证模型的试点检查测试库对候选正确性的条件信息增益。任何试点失败都应缩小或停止相应研究，不以增加网络模块、数据集或提示词掩盖标签不足。
