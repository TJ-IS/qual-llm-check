# 可训练算法工件版三篇论文的重构原则与逐段双 ISR 回读协议

## 一、这一版所说的算法硬度

这一版不把模型名称、参数规模或计算花费本身视为算法硬度。算法硬度来自一个不可由提示词替代的学习问题。每篇论文必须同时说明观察单位、输入张量、监督或自监督信号、可学习参数、损失函数、训练与校准划分、冻结工件、推理规则和行动结果。若删除训练阶段以后仍可用若干提示词和云端模型完成同一核心方法，该方法不进入新版主线。

每篇论文至少产出一项能够在本地保存、加载和独立评价的算法工件。工件可以是神经网络 checkpoint、预测模型、校准器或由学习参数驱动的优化策略，不要求微调通用大语言模型。解析器、静态图、候选生成器和测试执行器可以作为冻结基础设施，但它们不能替代可学习的核心对象。

训练工作量与科学硬度分开验收。大量 Agent 调用只能说明标签取得昂贵，不能自动证明算法贡献。相反，一个参数量较小的网络若把理论要求转化为专门结构，并通过训练产生无法手工预设的中间表示、决策值或交互规律，仍可构成硬的算法工件。新版因而同时检查训练必要性、结构专属性、识别边界和结果链，而不以 GPU 小时或参数数量单独排序。

## 二、三篇必须彼此不同的训练身份

三篇不能成为同一编码器更换标签后的三个分类任务。研究一应学习仓库证据的层次表征，研究二应学习取得或组合证据的任务条件价值，研究三应学习验证反馈下的序贯行动价值。三者的观察单位分别是任务与仓库节点、任务与证据集合或信息服务、候选补丁集合与验证历史。三者的标签、网络结构、损失和部署动作必须明显不同。

三篇可以在总论中形成取得、组织和使用仓库证据的概念链条，但各篇实证必须能够独立运行。后一篇不得把前一篇的实验结果当成必要输入。若未来把三项算法串联，必须重新生成联结后的训练标签和成本记录，不能把独立实验中的 checkpoint 直接拼接后声称形成端到端系统。

## 三、从肖帅勇两篇 ISR 学习的不是表面网络

本轮以 Xiao et al. 2024 的 *Attending to Customer Attention* 为 ACAA，以 Xiao et al. 2023 的 *A Theory-Driven Deep Learning Method for Voice Chat–Based Customer Response Prediction* 为 DSDL。两篇文章的共同写法不是先选一个流行网络再寻找理论，而是先把理论对象拆成可观察要求，再让每项要求对应专门的计算构件，最后分别评价最终结果、中间表征、参数解释和构件消融。

ACAA 在原文第 89 至 116 行用过程与粒度框架导出及时性、语义多样性、投票意识和模态交互四项设计要求。第 124 至 224 行再把这些要求压入 DTV 与 AMI 两个训练构件。第 230 至 314 行依次评价预测、学习表征、机制权重和消融。其关键逻辑是理论要求先于网络命名，中间机制能够单独受检验，最终性能不是唯一证据。

DSDL 在原文第 81 至 109 行从期望确认过程导出偏好、跨视图体验和动态满意三项方法挑战。第 128 至 227 行分别构造偏好模板、跨视图注意、动态满意与联合学习。第 231 至 315 行用多数据切片、预测、表征、解释和消融检验同一条结果链。其关键逻辑是共享主问题之下存在分责明确的学习构件，而不是把多个网络模块并列成组件清单。

目标博士论文也不以三篇共享一个关键词作为系列关系。其第 281 至 300 行先用研究一识别点击与滑动模式的使用机制，再让研究二和研究三在不同决策情境中依次形成行为预测、异质效应估计和优化决策。第 2287 至 2299 行再次说明后两项研究继承共同结果目标，并因决策过程不同采用整数规划与动态规划。新版三篇因此需要共享一个仓库证据到可验证行动的结果链，同时让每篇因决策时点不同而产生不可替代的训练对象。

## 四、每段正文写完后的强制回读

每写完一个实质段落，立即在对应审计文件建立同编号记录，之后才能写下一段。记录必须同时满足以下要求。

1. 分别给出 ACAA 与 DSDL 中承担相同论文功能的原文行号和结构位置。
2. 分别列出两篇参照段每一句或每个不可再分的句群所承担的功能。
3. 列出新段每一句的功能，并检查事实、机制、转折、问题、方法和证据是否各有明确责任。
4. 写明本段每项引文负责支持的具体判断。技术事实只使用正式论文、官方数据或官方代码，IS 理论只承担其原文能够支持的构念和关系。
5. 写明回读后删除、拆分、改序或收窄的内容。只写参照文章名称、泛称再次回读或仅给一个总括判断均不计通过。
6. 若新段后来增句或改写，必须新增一份当前句表，旧句表明确标为历史版本。审计不得让多个版本同时自称当前。

## 五、正文段落的功能门

引言中的情境段只建立行动后果与信息困难，既有方案段只说明直接方案及其边界，失效机制段必须解释为什么该边界会在当前情境发生，研究问题段只集中提出一个可回答的问题。方法概述段必须完成理论对象、计算构件和训练输出的一一映射。不得在一个段落中同时铺陈检索、记忆、停止、验证和修复。

理论与方法部分不得把人类心理机制直接赋予 Agent。可以迁移的是任务适配、信息价值、取得成本、表征忠实度和行动后果等设计要求。每项迁移都要说明可观察量、算法构件和不能声称的边界。

实证部分至少形成四类互不替代的证据。第一类检验最终任务结果。第二类检验学习到的中间表示或价值。第三类检验理论导出的异质性或机制参数。第四类用消融与替代解释排除简单基线。增加数据集不能替代上述结果类型。

## 六、训练与数据的硬性防泄漏门

训练、调优、校准和最终测试以规范仓库名为基本隔离单位。任务文本、提交、补丁、测试变更和近重复 issue 另行去重。任务级随机划分不用于主要结论。同一仓库中的大量任务不能被当作同等数量的独立环境。

Gold patch、隐藏测试、成功轨迹的后续观察和 Agent 的最终结果只能按预注册角色生成标签或评价，不得反向进入部署时不可见的输入。人类标注上下文、成功轨迹读过的代码和最终补丁位置代表不同证据含义，除非有可检验的测量模型，不得合并成同一个真实必要上下文标签。

训练成本要拆成静态解析与编码、标签生成、模型拟合和在线推理四本账。公开 benchmark 只能证明任务与环境存在，不能证明本研究的派生标签已经存在。所有需要 Agent 分支、候选补丁或验证矩阵的标签都要另列生成协议和资源上界。

## 七、机械写作约束

普通中文正文不用双引号制造概念，不用冒号组织一般论述，不用分号串联多个责任。公式、集合、程序标识和正式研究问题不受此限制。正文不写内部可行性辩护，不把公开资源存在写成贡献，不预报尚未得到的实证结果，也不用唯一、现成、值得做等内部判断替代学术论证。

最终验收同时检查正文段落与审计块一一对应、两篇 ISR 双源回读、引用与书目闭合、公式定界、数据规模与官方口径、训练样本与有效独立单位、资源账、禁用短语、异常字符和历史审计降级。任一论文只有方法描述而没有可生成的数据、可拟合的参数与可执行的评价责任时，不得判为完成。
