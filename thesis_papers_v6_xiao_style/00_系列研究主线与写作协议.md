# 系列研究主线与写作协议

## 1. 共同研究问题

代码仓库和运行环境为 Coding Agent 提供了日益丰富的软件表征，但可访问的信息数量并不等于行动价值。代理需要在有限计算下取得能够反映任务相关软件状态的证据，将其组织为忠实判断，并在软件行动产生后依据运行反馈修正判断。系列研究围绕一个共同问题展开：**Coding Agent 如何把仓库与运行环境中的表征转化为支持可靠软件行动的有效证据？**

这一问题包含三个依次推进的研究层次。研究一识别证据从取得、任务表征到软件行动的转化机制；研究二面向首次修改前的静态决策，学习哪些仓库证据共同构成忠实任务表征；研究三面向初始补丁后的动态决策，学习哪项运行实验最能修正当前判断并支持提交、返修或人工转交。三篇分别承担机制诊断、行动前配置和行动后适应，形成共同理论张力下的递进研究。

## 2. 三篇论文的研究对象

### 研究一：证据有效使用机制

研究问题：仓库证据的透明取得如何形成忠实任务表征，并进一步转化为改善软件状态的知情行动？

研究单位是任务、代理、证据区域和取得尝试。核心中间量为透明取得、增量表征忠实度、任务级累积忠实度和知情行动。算法工件 EUMN 使用代码关系网络、阶段序列编码和有序机制头学习这条转化链，并以证据展示、隐去和无关替换的受控运行检验证据对行动的影响。

### 研究二：行动前的互补证据配置

研究问题：在固定上下文预算下，哪些代码、测试、配置和文档证据能够共同形成完整、有意义、清晰且正确的任务表征？

研究单位是任务、证据包和修复器运行。核心中间量为四维集合忠实度、单项贡献、成对互补与集合剩余结构。算法工件 C4 使用类型化仓库超图、集合 Transformer 和预算解码器学习证据包的响应面，并在首次修改前生成预算可行的静态证据集合。

### 研究三：行动后的自适应验证

研究问题：初始补丁产生后，Coding Agent 如何依据已观察的运行后果选择下一项验证实验，并在有限执行预算内形成提交、返修或人工转交所需的判断？

研究单位是补丁状态、运行实验和观测转移。核心中间量为终端诊断结果信念、候选实验结果分布、目标差距和风险调整行动价值。算法工件 AVEP 使用任务—补丁—测试关系编码、运行结果世界模型、Bayesian 信念更新和分布式保守价值学习形成反馈驱动的验证策略。

## 3. 理论递进与论文独立性

三篇共同采用有效使用理论关于透明交互、表征忠实度和知情行动的基本观点。研究一把三个构念转化为可观察的软件代理过程，建立证据有效使用的机制基础。研究二聚焦知情行动之前的表征配置，研究有限上下文中的集合忠实度。研究三聚焦软件行动之后的反馈适应，研究运行后果如何修正判断并引导纠正行动。

三篇拥有独立的观察单位、训练标签、模型参数和终端结果。研究二从公开任务输入和仓库候选独立训练；研究三从固定初始补丁和真实执行轨迹独立训练。研究一的 checkpoint 不作为后两篇的输入，三篇的联系由共同理论问题和不同决策时点建立。

## 4. ACAA 与 DSDL 的段落功能基准

每篇论文采用与 ACAA 和 DSDL 相近的论证次序，同时根据研究对象调整段数。

1. 摘要依次完成问题价值、直接方案、具体失效、理论对象、专门机制、数据和证据责任。
2. 引言用八至九段建立结果重要性、现实过程、直接方案、失效机制、理论桥梁、结构属性、研究问题、方法概览和贡献。
3. 文献回顾按研究能力组织已有工作，并以能够由后文机制直接回答的计算缺口收束。
4. 理论部分从构念定义推导结构属性，再为每个属性配置专门张量、运算和学习目标。
5. 方法部分先给完整输入—变换—输出流程，再按理论构件展开网络结构与训练目标。
6. 实证部分依次检验数据和标签、终端结果、中间表征、机制干预、消融与外部传导。
7. 贡献部分集中总结理论推进、算法工件和经验认识；局限集中于结尾。

## 5. 逐段双 ISR 回读要求

正文每完成一个自然段，立即在对应审计文件中建立唯一记录。每条记录包含：

1. 当前段落的唯一科学功能；
2. ACAA 中相似位置的物理行号及逐句功能；
3. DSDL 中相似位置的物理行号及逐句功能；
4. 当前段落逐句功能；
5. 三者在论证次序和效果上的比较；
6. 当前段落增加的新功能及其必要性；
7. 回读后采取的修改。

方法公式可以超出两篇来源，但公式所在段仍需遵循“理论对象—计算困难—专门运算—输出责任”的句序。实现协议、资源预算、项目门槛和近邻排除清单记录在实施备忘中。

## 6. 正文学术语气

正文以正面定义、理论推导和可检验命题组织论证。研究边界集中在文献定位和局限部分；输入可见性在方法开头统一定义；统计识别条件在实证设计中集中说明。正文避免以连续否定、审稿答辩或项目治理口径组织段落。

机械终审把否定密度作为预警指标：正文主体中“不得、不能、不主张、不称、不把、不以、只用于、仅用于”等防御性表达应接近 ACAA/DSDL 的低频水平；“冻结、预注册、门槛、退出、No-Go、资源上限”不进入理论、方法贡献或结论段。指标只负责发现异常，段落是否成立仍以双 ISR 逐句回读为准。
