# v7 实施与科学审计备忘（不进入论文正文）

## 状态

系列状态为 **Conditional-Go for research design**。当前授权撰写完整研究设计，不代表动态语料、训练支持或优效结果已经成立。KeyState、并发正确性、检索/上下文、验证矩阵、流程治理、依赖升级、主动探针、live schema migration 等候选已经淘汰，不作为本系列失败后的自动回退项。

## 系列级致命门

1. 可执行语料不少于 300 个公开许可任务，覆盖至少 3 个引擎或方言；普通 schema-only 玩具任务不得充当五维语义覆盖。
2. population、grain、join multiplicity、missingness meaning、time 五类契约各至少形成 80 个可执行正/负例；oracle 与双人复核一致率目标均不低于约 0.90。
3. 研究三的确认性评价必须取得至少 200 个相互独立的真实 upstream event clusters、覆盖至少 5 个公开源，且过半事件不是 column add/drop/rename 等 schema-only drift；同一事件下的多个 pipeline、动作或随机种子只是组内重复。若独立事件少于 200，`α=0.90` 的上尾 CVaR 只作探索性结果，主风险改报均值、q90 与严重失败率。
4. 必须出现“相同静态代码/契约，在不同 transition phase、backlog 或 uncertainty 下最优连续性动作不同”的稳定实例；否则不需要动态政策。
5. 研究三若不能同时胜过 static-best-action、runbook、MAPE-K rule policy 与 receding-horizon MPC，论文三及整套系列 No-Go。
6. 删除任一前篇 checkpoint 后，后篇仍必须能从公共底模与本篇数据独立训练；任何隐含 checkpoint、calibrator、trajectory 或 outcome 传递均视为切片。

## 研究一实施门

- 随机反馈处理须在 task×agent/model×seed 区组内以已知概率独立分派，不能只随机运行次序后声称处理随机化。
- terminal-only 反馈必须在首个端到端候选完成后、固定返修预算结束前到达，使三臂均有同等修订机会；三臂主估计量只包括 `stage-tech − terminal` 的整套制度差异，以及 `stage-semantic+provenance − stage-tech` 在相同阶段放置下的语义—来源增量，不能分别宣称识别“深度效应”和“放置效应”。
- evaluator-only shadow provenance、reason tags 与终端契约不得进入代理观察；三臂的总 token、延迟和返修机会须按制度定义并报告，不能把处理诱导的轨迹长度当处理前协变量。
- 随机化与因果单位为完整 episode，transition 只是重复测量；固定观察窗内的任务停止、失败或无响应进入吸收/竞争状态，只有行政观察窗结束才作右删失。
- 共享服务、缓存或跨 episode 记忆应隔离；无法隔离时须按服务批次随机化或显式定义 exposure mapping，不能仅靠聚类标准误修复干扰。
- 机制成立要求反馈处理在 held-out repositories 上改变 persistence、masking、time-to-correction 或 propagation hazard；仅提高 `SC-Prop` 分类 F1 不足。
- 论文一须区分当前可见 `E_t` 与当前违例 spell 的历史曝光 `O_t^m=max_{T_m^{on}<=u<=t}E_u`；同一 spell 保留历史曝光，纠正后 re-emerge 的新 spell 必须从 `O^{m+1}=0` 重新计量。单次 episode 的 `b_i` 是 realized debt，`B^a=E[b_i^a]` 才是制度均值，SOD 只定义制度均值相对实际 terminal 臂 0 的差，不生成个体反事实债务。
- Detection 使用 detect、correct-before-detect、applicability-loss、termination 四个互斥原因，correction 使用 correct、applicability-loss、termination 三个原因；只有第 12 个区间结束仍无原因才是行政删失。
- 传播若完全由 pipeline length、operator count 或基础模型能力解释，且反馈处理无额外作用，研究一停止。
- SC-Prop 只能输出测量与风险，不向论文二或三提供必需输入。

## 研究二实施门

- 训练输出不存在唯一 gold SQL；每条义务先标记 `identified / partially identified / unidentified`，并保存证据优先级、provenance-root、冲突规则与 set-valued acceptable bundles。确认性主指标只在至少一个完整 bundle 的全部 necessary leaves 均被独立识别且外部证明时记成功；bundle 交集只作歧义报告。独立于训练标注的盲 evaluator team 构造 property worlds 并报告分歧与排除率。
- 主生成域收窄为 SQL/dbt relational subset 与封闭 DataFrame DSL；`typed IR + typed slots + backend version` 必须经确定编译器返回 `Patch` 或 `Unsupported`。域外构造一律 abstain，编译器须报告 round-trip、type preservation、property tests、各登记方言中的实测语义一致性与真实 coverage；有限 differential tests 只能支持封闭域内的 tested conformance，不能写成一般跨方言 soundness。
- generation-time contract state 必须以模型预测的连续契约/义务 token 通过显式 recurrence 与 attention 进入下一 IR 节点；hard mask 只编码结构类型，不得调用完整候选才可获得的外部证明。只在 decoder hidden state 后附加预测头不算契约携带式生成。完整候选编译后，某个 bundle 的 necessary leaf 为 unknown/refuted/不可执行只使该 bundle 失败；ordinary tests 未全过或不存在任何全部 necessary leaves 均被证明的完整 bundle 时才必须 abstain，不能由经验分数覆盖。
- 完整候选上的 adapter-dropout 只报告 `\bar Z` 与原始 `s_Z`；`s_Z` 不等于后验方差或置信下界。DPO 后须在 repo-family 隔离校准集重新校准，有限样本风险门与覆盖率由 split-conformal/risk-control 程序给出。
- ELT-Bench 等既有 gold 必须经本研究 evaluator 重新验收；benchmark-attributable errors 不得当作负例或真值。
- typed grammar 只负责结构合法，不能把 grammar compliance 写成语义保证。
- 完整模型必须优于同底模 QLoRA、typed-grammar only、verifier-after-generation、classical CEGIS 与多采样 reranking；若增益仅来自更强底模、更多样本或 verifier 过滤，研究二停止。
- SC-Coder 不加载 SC-Prop；前篇初始化只能作为非必要 transfer ablation，且不能承担主结果。

## 研究三实施门

- 真实事件按 source family、transition event 与时间共同切分；同一变化的不同 window 不得跨 train/test。
- synthetic mutations 只可扩充训练，确认性测试只使用真实历史变化。
- 世界模型监督层只能从行为主路径实际到达的共同检查点分叉，并从相同可见状态执行全部预注册安全候选动作；隐藏后续窗口仅生成 action-post outcome，不进入状态。IQL 与主政策效应只使用有已知倾向的完整行为主路径；不可达的“数字孪生”或由世界模型自造的 oracle action 不得作为真实标签。
- behavior mixture 必须独立于学习世界模型，对当步 canonical enumerator 给出的每个具体安全动作保存已知 propensity。原始日志 ID 虽未见、但其冻结动作特征落入受支持 cell 且通过真实可行性检查时，可由候选条件化 actor 在直接在线政策中评分；这类 `raw-new-ID` 轨迹不得进入 IQL/OPE。动作特征 OOV、cell/邻域支持不足或可行交集为空时才回退 `escalate`；支持不足时不得用 IQL/OPE 主张政策价值。
- bounded patch-migrate 只能从结果无关的冻结候选池中选择；SC-Guard 不自由生成代码，也不调用 SC-Coder。
- 完整轨迹使用固定事件窗口的上尾损害 `CVaR^+_α`；风险权重若固定即称加权目标，只有显式风险预算与对偶更新才称约束。catastrophic semantic harm、`α` 和权重在确认性结果可见前锁定。
- 环境必须给出潜在状态、初始分布、转移核、观测核、部署可见成本回执与固定时域；策略的 `s=phi(history)` 只能称近似 information state。原始 sidecar 必须保存 `(c_receipt,timestamp,status)`，Bellman 主表则保存由该回执和可见 terminal residual 唯一派生的 `(s,a,ell,s',done,μ)`，二者以 event/step/action/checkpoint hash 一一连接。隐藏语义真值只作世界模型监督和外部语义评价，不进入回执、`ell` 或风险目标。语义恢复、故障结算或 `t=23` 后进入吸收态，标量 IQL 只从有已知支持的行为主路径学习以 `(s,z,t,eta)` 增广的终端风险价值，世界模型分支不得形成 Bellman target。确认性风险分布可包含同一真实事件下的多个受控模板，但切分、重抽样与推断始终以真实 event cluster 为最高独立单位。
- 固定 quarantine/retry 或 MPC 若在 held-out real transitions 上持平，不能靠增加网络、奖励项或 action 名称挽救论文。

## 数据候选与动态事件责任

静态骨架可来自 Snowflake-Labs `data-eng-bench`、CoDA-Bench、ELT-Bench/Verified、GovBench 和公开 dbt/SQL repositories；TPC-H/TPC-DS 只承担可控 counterexample 与 property-world 生成。动态候选包括 NYC TLC 历史发布、Citi Bike trip/GBFS 版本、UCI Electricity 的 DST/缺失含义、公开 dbt/ETL repositories 的时间戳 issues/commits。正式解封前须继续扩展到不少于 5 个源并完成事件语义复核。

## 资源粗账与先后顺序

- 研究一：目标 200–300 个 base tasks、3 feedback arms、2–3 agent/model configurations、2–3 seeds，约 2,400–8,100 agent episodes；SC-Prop 训练本身预计单卡数十 GPU 小时，执行与标注更贵。
- 研究二：7B QLoRA SFT+DPO 预计 2–4×80GB GPU、约 100–400 GPU 小时；主要成本是数千条 verified plan/patch trajectories 与 property-world 执行。
- 研究三：50 个独立事件仅用于 development；确认性目标至少 200 个独立真实 event clusters，并在可达检查点形成受控分支与行为主路径。40M 模型训练预计几十 GPU 小时，跨动作容器 replay、完整窗口 evaluator 与多源重建是主成本。
- 开工顺序采用 kill-cheap-first：契约/evaluator 小样本一致性 → 动态事件 census → 研究一 20-task 随机化 micro-pilot → 研究二 30-task generation micro-pilot → 研究三 20-event full-action replay。动态数据门未过前，不投入三篇全文实验。

任何 Full 规模必须先取得书面 GPU/CPU/存储承诺，并由 micro-pilot 的实测吞吐外推。正文不得出现这些资源门、No-Go 语言或内部治理数字。
