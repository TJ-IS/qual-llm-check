# v7 跨篇构念与测量词典

## 语义连续性

数据流水线在转换节点、代码版本和真实时间变化之间保持任务所要求业务含义的程度。它不是 syntax correctness、schema compatibility、行数稳定、测试通过或 SQL 文本相似度的同义词。

## 五类语义契约

| 家族 | 定义 | evaluator-only 基础量 | 常见静默失真 |
|---|---|---|---|
| Population | 输出所代表的实体/事件总体 | 预期与实际实体键集、provenance reach | 过滤遗漏、选择偏差、历史范围错位 |
| Grain | 每行/记录代表的分析单位 | 候选键、函数依赖、聚合层级 | 重复计数、错误聚合、身份合并 |
| Join multiplicity | 来源记录在连接后的允许复制/消失倍数 | provenance token 复制数、log q-error | fan-out、many-to-many 放大、静默丢行 |
| Missingness meaning | 缺失值形成机制与可解释状态 | observed/structural-NA/unknown/not-yet-available/imputed reason tag | 填零、删除、把未到达当真实零 |
| Time | event、valid 与 availability time 的可接受关系 | 时间戳、有效区间、可见时点依赖 | temporal leakage、as-of 错配、DST/迟到数据误读 |

## 谓词状态与不确定性

`Q[v,p,t]` 是静态节点—谓词 evaluator 给出的隐藏真值，论文三将随外生环境转移的同类动态隐藏真值记为 `Y_t[v,p]`；`A[v,p,t]` 表示该谓词在当前节点—时间是否适用，`S[v,p,t]` 表示违例严重度。`Z[v,p,t]` 是模型对谓词满足的校准概率，`U[v,p,t]` 是这一预测的不确定性；两者不得与 `Q/Y` 混写。隐藏 evaluator 的 `Q/Y/A/S` 只作为训练监督和独立评价，不进入部署前向。复杂质量要求须分解为可执行的叶谓词，再以同一单调 capacity 汇总到 ordinal quality；不同 measurement system 产生的分数不能直接比较。

`U` 是跨篇共享的构念名称，不是强制相同的数值估计器。论文一以 split-conformal 二元预测集的含混度操作化 `U`；论文二报告完整候选上 adapter-dropout 的原始 `s_Z` 并以独立 family 校准风险门，不把它冒充置信下界；论文三从可见观测预测 `\hat U` 作为 POMDP belief 的组成部分。三种量只在各自 measurement system 内评价，不能跨篇直接比较数值。

## Semantic observability debt

由于代理可见反馈不足，已经存在但尚未暴露的适用语义违例在后续转换中累积形成的风险存量。对节点—谓词的一次连续违例 spell `m`，令 `E^{a,m}[v,p,t]` 表示反馈制度 `a` 下当前证据是否在下一编辑前可见，并令 `O^{a,m}[v,p,t]=max_{T_m^{on}<=u<=t}E^{a,m}[v,p,u]` 表示该 spell 是否曾经曝光；spell 外 `E=0`，纠正后再次出现的违例构成新 spell 且 `O^{a,m+1}=0`。实现层违例负担为 `D=A(1-Q)S`。单个 episode 潜在轨迹的 realized debt sum 为

\[
b_i^{a}(H)=\sum_{t=0}^{H-1}\gamma^t\sum_{v,p}w_{vp}D^a_{ivpt}\bigl(1-O^{a,m(ivpt)}_{ivpt}\bigr),
\]

实际分配 `R_i` 后只观测 `b_i=b_i^{R_i}`；制度均值为 `B^a=E_i[b_i^a]`，制度差为 `SOD(a;0)=B^a-B^0`，其中 0 是实际执行的 terminal-feedback 臂。正文不定义个体 SOD，也不引入未执行的“最优制度”基准。这一构念不等于违例概率 `1-Z`、缺少日志的数量、网络 attention weight 或代理自述；传播事件、发现/纠正时延和终局损害是解释或验证债务的外部结果，不替代债务存量本身。

## 传播事件

每个适用的同节点—谓词 transition 先取得互斥基础状态：`stable-clean`、`emerge`、`persist` 或 `correct`。在 `persist` 内再标注严重度变化 `amplify/stable/attenuate`；当违例存在时另标注即时可见性 `visible/hidden`，其中 `mask` 专指 `E` 从 visible 转为 hidden，而同一 spell 的 `O^m` 仍保持曾曝光。谓词适用性改变单列为 `structural-NA`。跨节点传播须同时满足父 spell 先发生、冻结 provenance 图存在有向父—后代路径、子节点随后出现适用的 `emerge`，由此才建立 lineage 并标 `propagate-emerge`；其后的 `persist` 或 `amplify` 只能沿该既有 lineage 标为 `propagate-persist-nonamplifying` 或 `propagate-amplify`，不能独自建立传播关系。路径关联本身不冒充因果通道。

## Contract-carrying generation

生成过程在 typed relational IR 的每个节点显式携带模型预测的连续语义谓词状态、未决 proof obligation 与 counterexample provenance token，并把这些状态反馈到下一节点的 recurrence/attention；hard mask 只编码结构类型，生成前向不读取完整候选才可获得的外部 proof。每条义务先标记为 `identified`、`partially identified` 或 `unidentified`；冲突证据形成 set-valued acceptable bundles，`B_id` 只保留全部 necessary leaves 都有独立证据的完整 bundles，`C_common` 的 bundle 交集只报告歧义。完整候选经确定编译器返回 `Patch` 后，某个 bundle 的 terminal unknown/refuted 只使该 bundle 的证明指标为 0；确认性成功要求 ordinary tests 全部通过且至少存在一个 `C_b in B_id`，其全部 necessary leaves 均由独立外部执行器证明。不存在这样的完整 bundle、普通测试失败或域外构造时须 abstain。完整 EBNF 只约束封闭 SQL/dbt relational subset 与 DataFrame DSL，`typed IR + typed slots + backend version` 由确定编译器返回 `Patch` 或 `Unsupported`；一个任务允许多个满足不同完整可接受 bundle 的实现。

## Semantic harm

五类违例在下游使用中的累计损失。主分析报告分维度 harm；总 harm 只使用在 development 阶段锁定的单调 capacity 与风险权重。不得在看到确认性结果后改变权重以制造改进。

## Continuity actions

论文三的动作类型为 accept、contract-version route、quarantine、rollback、bounded patch-migrate、escalate；每个可执行动作以 `(kind,target_version,duration,candidate_hash,queue)` 形成参数化具体 ID，并由候选条件化 actor 在当步安全且受支持的动态集合中逐项评分。原始 ID 首次出现但其冻结动作特征落入受支持 cell 且通过真实可行性检查时可直接在线评分；这类轨迹不得进入 IQL/OPE，特征 OOV 或支持失败才回退 escalate。动作改变随后可见的数据版本、积压、延迟与可用政策，因此产生路径依赖。SC-Guard 不自由生成 SQL/代码；bounded patch 候选由结果无关的冻结公共生成器预先构造，世界模型分支只训练动作后观测/成本核，长时域标量 IQL 只读取已知 propensity 的真实行为主路径。策略的完整轨迹损害只由部署可见成本回执累计，隐藏语义真值只作世界模型监督和外部语义连续性评价；同一事件可产生多个模板结果，但切分、重抽样与推断以真实 event cluster 为最高独立单位。

## 三篇术语边界

- 论文一使用 `feedback arm`、`operator transition`、`propagation event`，不称 patch policy。
- 论文二使用 `fixed snapshot`、`typed IR`、`proof obligation`、`terminal patch`，不称 online adaptation。
- 论文三使用 `upstream transition`、`event window`、`continuity action`、`cumulative harm`，不称一般 schema-drift detection 或自由代码生成。
