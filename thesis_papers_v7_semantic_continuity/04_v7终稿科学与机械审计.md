# v7 语义连续性系列：终稿科学与机械审计

审计日期：2026-08-14。

## 一、总判断

本系列在**研究设计层**通过科学与机械终审。三篇均定义了可在本地训练、冻结和独立评价的算法工件，也形成了“机制识别—固定状态生成—外部状态转移后的动态控制”的递进关系；它们不是同一 LLM 微调任务按阶段拆成三篇，也不是提示词工程的三个版本。

当前结论仍是 **Conditional-Go for execution**：正文、标签责任、模型、损失、识别和确认性评价已经闭合，但尚未生成训练 checkpoint、held-out 中间量或确认性终端结果。因此，本文档中的“通过”只指设计可训练、可证伪、可复算，不表示任何模型已优于基线，也不表示已经达到 ACAA/DSDL 的经验完成度。

## 二、三篇究竟训练什么

| 研究 | 最高独立单位与问题 | 训练标签/监督 | 架构与 checkpoint | 主要损失 | 最终输出 |
|---|---|---|---|---|---|
| 研究一：语义可观测债务与失真传播 | 完整随机化 episode；研究三种反馈制度如何改变违例的出现、持续、掩蔽、纠正与沿来源路径传播 | 静态 evaluator `A,Q,S`，spell-local `E,O^m`，局部/传播事件，发现与纠正竞争风险，episode-level 两项制度对比 | `SC-Prop-18M`：类型适配器、四层时序关系 GNN、事件 GRU、局部/传播/风险 heads、参数独立的 nuisance 与 contrast encoders；18,017,557 参数 | `L_tr + L_surv + L_up`：Bernoulli/Huber/CE、离散竞争风险似然、OOF 正交 uplift | 测量与机制 checkpoint；不生成代码，不分配反馈，不给后篇提供必需权重 |

这里的“训练”不是同一种东西。研究一主要是**监督式时序图学习、竞争风险估计与因果异质效应学习**；研究二才是**代码模型的 SFT + DPO**；研究三是**动作后果模型 + 有支持限制的离线强化学习**。确定编译器、外部 proof executor、property worlds、容器 runner、动作枚举器和统计检验是非学习工件，它们负责产生约束、标签或评价，不能被含混地称为“模型训练”。

## 三、逐篇训练流程

### 研究一：从随机反馈实验训练机制网络

1. 对完整 task–agent–seed episode 随机分配 terminal、stage-tech、stage-semantic+provenance 三种反馈制度，并为每臂保留相同的反馈后编辑机会。
2. evaluator 在每个 operator/edit transition 上形成适用性 `A`、真值 `Q`、严重度 `S`、即时可见性 `E`、violation-spell id、局部事件、来源 lineage 和发现/纠正退出原因。`O_t^m` 只在当前 spell 内累计，纠正后 re-emerge 必须重置。
3. 把文件、操作符、数据集、字段、叶谓词、检查和反馈构造成时序异质图，联合训练契约、严重度、可见性、局部事件、传播事件和离散 competing-risk heads。
4. 在外层训练折内另做 nuisance cross-fitting，缓存并 detach OOF 结果，再训练参数独立的 contrast encoder 估计两项处理前条件制度效应；它不改变随机化 ITT 的主识别。
5. 在未见 repository families 上分别检验中间张量、风险校准、制度均值和 episode-level `tau10/tau21`，而不是只报告一个终端 F1。

这篇的 checkpoint 价值在于把“反馈是否真正使违例可见、是否及时纠正、是否沿来源传播”变成可检验的中间状态。它不是一个检索器，也不输出修复补丁。

### 研究二：训练契约状态真正进入解码的生成器

1. 在固定 snapshot 上把请求转成 set-valued acceptable bundles；只有全部 necessary leaves 都有独立证据的 bundle 才进入 `B_id`，bundle 交集 `C_common` 只描述歧义。
2. 将可支持任务规范为完整 typed relational EBNF、canonical IR 和 edit slots；确定编译器只返回 `Patch` 或 `Unsupported`。自由 SQL/Python 不直接作为训练输出。
3. SFT 阶段训练唯一 canonical IR/slot 序列，并以外部静态真值 `Q` 和 proof status 监督辅助 heads。主 2×2 比较只切换节点监督和“预测状态是否反馈到下一节点”，结构类型 mask、token 数和 task-action 学习保持一致。
4. 构造同一 snapshot 上都能编译的正负 canonical 候选；负例必须是类型保持、普通测试至少部分可过、但在隔离 property world 上触发单维语义违例的困难负例。DPO 只比较 canonical IR/slots，不让 PATCH/ABSTAIN action token 与偏好标签共变。
5. DPO 后重新执行 adapter-dropout 与 family-level conformal calibration。推理时，候选只有在 `G_test=1` 且至少一个完整 bundle 的全部 necessary leaves 均被外部 executor 证明时才能 PATCH；unknown/refuted 只使所属 bundle 失败。

这篇真正训练的是一个**受封闭关系语义约束、会输出可编译结构化程序的 7B 生成模型**。它与“让 LLM 在提示词里反思数据质量”有本质区别。

### 研究三：先学后果，再学动态政策

1. 用真实上游事件驱动四类受控下游模板，记录 24-step POMDP 轨迹。隐藏 `Y` 只给世界模型监督和外部语义评价；部署策略只能读取可见观测及带时间戳的成本回执。
2. 从行为主路径实际到达的同一检查点执行全部合法短窗分支，训练动作后观测、回执分位和语义预测 heads；分支数据只训练 world model。
3. 冻结 representation 与 world model。原始 sidecar 保存 `(c_receipt,timestamp,status)`，Bellman 主表保存由回执与可见 terminal residual 唯一派生的 `(s,a,ell,s',done,mu)`。
4. 只用已知 propensity 的完整行为主路径训练标量 IQL；状态加入累计损害 `z`、时刻 `t` 和一次选定的 Rockafellar–Uryasev 阈值 `eta`，candidate-conditioned actor 在当步动态安全支持集内逐个给具体 action ID 打分。
5. 确认性评价让 SC-Guard、static、runbook、MAPE-K 与可执行 MPC 从相同初始检查点独立跑完整窗口；至少 800 条事件—模板结果形成 CVaR 经验分布，但切分、重抽样与推断以至少 200 个真实事件 cluster 为独立单位。

这篇的动态性来自真实状态转移、队列和版本路径依赖，不是把静态模型多调用几次。world model 分支不得产生 IQL Bellman target，短窗反事实也不得冒充完整政策价值。

## 四、为什么三篇不是切片

三篇的观察单位、真值、损失、checkpoint 和行动对象全部不同：

- 研究一没有部署动作，处理是随机分配的 feedback regime，目标是识别机制。
- 研究二只有固定快照上的一次性生成与 PATCH/ABSTAIN 决策，目标是训练结构化生成器。
- 研究三不生成任意代码，目标是在外生事件到达后选择具体连续性动作并承担跨期后果。

三篇仅共享无参数的五维契约 schema、parser/resolver、container runner 与 evaluator 接口。研究二不加载研究一 checkpoint，研究三不加载前两篇 checkpoint；删除任一篇后，另两篇仍可从公共底模和本篇数据独立训练、评价和投稿。

符号也已做跨篇分层：`Q` 是静态 evaluator truth，`Y` 是论文三动态隐藏真值；`O_t^m` 是论文一 spell-local ever-exposed，论文二普通测试门改为 `G_test`；论文三原始回执 `c_receipt` 与学习损失 `ell` 分表保存并以哈希连接。

设计层的“硬度链”也已经形成：

- 研究一：表征忠实/可见性 → `A,Q,S,E,O^m` 与 lineage/risk 张量 → 多任务、竞争风险和 uplift 损失 → 随机制度与 held-out 中间机制证据。
- 研究二：契约忠实/可行动表征 → continuous Z/proof state、typed IR 与 bundles → SFT/DPO/校准 → 普通测试与完整 bundle 的可执行证明。
- 研究三：扰动—纠正行动/动态能力 → POMDP information state、回执、动作后果与累计损害 → world-model + IQL/CVaR → 完整真实轨迹、事件级推断和可达 twins。

因此，纸面设计已经不是“简单 GNN/LLM/RL 换数据集”，而是理论责任进入专用中间张量并由独立证据检验。诚实边界仍然是：ACAA/DSDL 已有 checkpoint、主结果和机制分析，而本系列目前只有设计；没有第一份可复算训练工件和 held-out 结果前，不能宣称经验完成度与其相当。
