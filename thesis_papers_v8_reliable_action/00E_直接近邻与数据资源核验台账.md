C1′ 的核心识别单元必须是 `(同一 repo, 同一 t0 feature task, 同一 t0 information set, 不同真实 boundary, 同一 t1 shock)`。若只能比较不同仓库、不同任务或不同冲击，观察到的 future remediation 差异不能归因于 agent 在 `t0` 创建了选项。

C23 也终止为 NO-GO，且其撤销同样不以训练尚未运行或数据暂缺为依据。沿 component lineage 学习共同原因潜状态，再用相关尾险约束多样化、shadow、pause、rollback 或 withdraw，仍可被动态因子图、异质图 Transformer 与 distributional CMDP 在相同谱系、轨迹、风险和动作信息下复制；把 coding-agent 工作单元替换为微服务或批处理作业后，核心张量与行动语义不变。版本化 stack BOM、exposure-set、相关损害指标、component-lineage split、共享更新压力测试、N-version/Temizkan/Koran 基线和 canary 后残留副作用记录仍可构成强外部测试层，但不能恢复独立理论论文资格。完整终审见 [01R](01R_共享Agent栈下共因失效遏制候选终审.md)。C22 只涉及单一部署单元的版本兼容、harness patch 与单实例发布，C23 只涉及多个单元共享组件造成的联合相关尾险；二者均撤销，不能相互扩大后重新占位。

上述两项撤题的历史结论继续有效，但现行系列状态已经更新。固定 pre-cutover PostgreSQL 主动缓解期权格、相关证据下的可执行分支整合和固定批准点的可信序贯取证均已通过独立设计审计，状态统一为 **DESIGN-FROZEN / RESULTS PENDING**。完整主线见 `00_总体主线与三篇论文关系.md`，独立通过证据分别见 `02W`、`02X` 与 `02V`。

## 8. 当前最重要的数据事实

- 论文一的数据不是现成日志拼接。主 substrate 固定为 PostgreSQL 17.0、pgroll 0.16.2、18 个独立 app family 与 72 个逐字段 migration contracts；训练监督必须由共同随机条件下的可执行 sibling rollouts 产生。CodeTwin 只改变公开策略/代码条件，隐藏物理条件、原始 transaction 与 candidate set 保持匹配。所有 hash 当前均是待实现字段，不得写成已生成工件。
- 论文二的任务基座只有 Vul4J 当前 natural 条目。129×6 个风险维×natural/overlay 两种来源形成 1,548 行 eligibility core，但这不是 1,548 个独立漏洞任务，也不意味着 129 个条目都进入主分析。79 个 PoV-based 与 50 个 SpotBugs-only 条目分别登记，natural eligibility 与 official-oracle preflight 决定 $N_{\mathrm{admitted}}$。Natural、overlay、NOT_APPLICABLE、UNKNOWN、运行失败和空 cell 分别计数，overlay 不能改变原生频率或主结果分母。
- 论文三没有公开数据同时包含固定绑定行动、可选择的多种行动派生证据、审核者事实 grounding 轨迹和误批因果结果。技术预训练可以使用 BSG-VA、SWT-Bench、c-CRAB、AgentLens、Consent Integrity 等资产，最终政策价值必须来自独立真人 logging cohort 与前瞻确认性 cohort；二者和 measurement/support pilot 不复用参与者。
- 原 C1 已终审撤销。严格 Novel/Partial/Resolved 与 strict Partial 构造仍可保留为数据资产，但 LoopsBench 已占据义务 DAG、ready frontier 和 persistent regression obligations；cognitive fit 又不能从人的理解—修改关系无损迁移到 agent 内部状态。该资产不得再被视为论文一题目或用 policy head 恢复。
- C1′ 已终审撤销。它没有现成两时点反事实训练集，且 Schober 状态可由 matched-state two-stage POMDP 精确复制。BUMP、PyMigBench 与 SWE-Chain 仍可为独立 benchmark 提供冲击或迁移素材，但不能恢复该题的理论算法资格。
- C1″ 故障后授权题已撤销。Agent Meltdowns、Boundary-Bench 与 noisy-container 可保留为压力测试，CapLease、Numbat、Conseca、PCAS/OAP/IGAC 等作为强基础设施或基线；这些资产不能为 `O/X/I/K` 的理论计算排他性提供证据。
- CooperBench 规模足以评价，但 feature pair 共享 base PR，随机划分会严重泄漏；现有 team logs 无法因果识别 TMS 状态。C2 已因理论所有权、时序泄漏与通用替代问题撤销；open-weight quiescent snapshot、two-world contract 与 correct/corrupt/sham content-swap 只保留为未来新候选的数据识别要求，不能恢复现题。
- AgenticFlict 的文本冲突需要执行 joint tests 才能转化为语义损害标签。
- SABER 所有配置都标为 train，必须按 repo、template 和 risk family 重新隔离。
- HiL-Bench 的大镜像与部分私有 test 限制复现；C3 不能依赖它作为训练核心。
- AIDev 已公开 PR、review、inline comment、timeline 和 commit diff 等字段，但批准与评论不是真实 defect label。C3 必须与 executable tasks 或受控人类实验结合，并按源仓库许可证筛选 patch。
- C5 已撤销为当前独立题。CodeMonitorBench、RETRACE、Terminal Wrench 与领域安全 patch benchmark 可作为今后评价资源，但普通 residual-bug verifier、generated-test monitor 或 hardening loop 不满足本系列的理论算法要求。
- C4 经最新重开复核后维持 HIGH-CONFIDENCE NO-GO / TERMINAL。DART、Cordon、Atomix、RAC、Mnemosyne、Dependency-Guided Rollback Repair、NOMS recovery-command learning、PASE 与 SRC 已覆盖语义恢复、事务、agent compensation、依赖闭包、命令学习、程序规划和有效工作保留；剩余的跨资源语法扩展缺少独立理论算子，Digital HRO 只给自动化边界且忠实下推会与 C3 重叠。完整复核见 [01Z](01Z_执行后损害补偿程序候选终审.md)。
- C10 结构侵蚀题已终审撤销。SlopCodeBench v2 可作为长期回归与结构失败数据资产，Banker–Slaughter 和 Tiwana–Safadi 可作为解释与边界文献；它们不能推出等参数时序图模型无法复制的新策略，也没有提供同前态多结构行动的未来损害真值。
- C12 审计证据捕获题已终审撤销。Auditable Agents 的五维框架继续用于评价 evidence integrity、policy checkability 和 responsibility attribution；Bajcsy 等人的记录粒度与 Shao 等人的 chain-of-evidence 继续用于约束日志结构。它们不能把未知未来查询变成可识别监督，也不能独占通用选择模型的捕获策略。
- C14 执行者—验证者分离题已终审撤销。Hua、Koran、RETRACE、Agentic Rubrics、Scaling Agentic Verifier 与 SWT-Bench 已覆盖序贯成本控制、残差相关组合、独立 patch 核验、主动测试和仓库验证。异构 verifier 的交叉运行数据仍可复用，但 warranting/SoD 不能独占下一验证动作或停止策略。
- C14A 跨所有权边界题已终审撤销。Hahn、Zaggl 与 Lindberg 已给出条件性的双空间协调、责任宽度和传播成本关系，AtomicCommitBench 已覆盖 patch 分解与选择性回退。现有 ownership、merge 与 review 数据不能给同状态替代动作的因果安全真值。
- C15 开发者恢复能力题已终审撤销。其真人延迟恢复环境可作为独立经验资产，但 `Fθ+L_dir` 不能把三类 mindful-conduction 活动变成理论专属状态；处理留下的测试、契约和不变量又使 person-skill 与 software-asset 两条恢复通道不可按当前设计分离。
- C17 验证义务积累题已终审撤销。Truth Stack 已占据 stale-evidence dependency 与 verification debt 的概念主链，连续修改 benchmark、test selection 和演化感知验证又覆盖主要状态、动作与结果。其公开资产仍可用于纵向 hidden-test、evidence invalidation 与 release-level 压力测试，但不能恢复独立理论算法题位。
- C18 普适可靠发布行动已终审撤销。CI/CD 配置修改、DevOps 行动边界、长期回归义务、canary substrate 和微服务故障注入均可复用；它们不能解决 coding-agent 可删除性、无界联合改写、理论状态约化及与迁移/C3 的系列重叠。
- C19 有限审核容量分配已终审撤销。AIDev、c-CRAB、BulkPR和OpenL2D可支持到达流、执行oracle、队列或负控制，不能给真实审核者反事实；风险审核推荐、追加专家、多专家容量、相关错误、疲劳与动态人员调度已经覆盖核心动作。隐藏oracle只改善结果效度，不能恢复独立理论算法资格。
- C21 并发仓库漂移已终审撤销。Claim Plane、CoAgent、CodeCtx、STORM、EA-Graph 与语义冲突/合并工作已经覆盖版本绑定、旧前提失效、定向通知与修复、证据新鲜度和调和；现有公开资产仍不提供同一 read/tool 前缀、外生 drift 和多个行动程序的联合执行真值。相关数据只保留为并发与状态漂移压力测试。
- C22 模型与 Scaffold 安全兼容题已终审撤销。公开资产足以重跑版本冻结的交叉设计，撤题不源于实验未运行；最强设计仍是交叉预测、约束 AutoML、可执行 harness 编辑和发布控制的组合，理论又存在单位错置或方向冲突。paired update rollout、双家族留出、隐藏安全 oracle 与版本 manifest 只保留为共同基础设施。
- C23 共享 Agent 栈共因失效题已终审撤销。公开风险任务和多 harness 工件足以严谨新建 factorial update episodes，撤题不源于实验未运行；直接 ISR 软件多样性、coding-agent N-version、低相关 monitor ensemble 与生命周期控制已覆盖主要状态和动作，剩余谱系因子与 fleet 策略可由通用模型复制。stack BOM、exposure-set、相关尾险和共享更新 stress test 只保留为外测资产。
- C24 决策适用性数据管线题已终审撤销。公开管线、语义演化、下游测试和程序修复资产足以构造可执行评价；撤题来自理论构念错置、核心图结构被 IPMAP/IPView 先占、通用策略可复制和 coding-agent 删除检验失败。consumer task 与 decision-loss oracle 只保留为跨域外测。
- C25 软件来源与许可证安全题已终审撤销。来源、条款、兼容性、修复和轨迹合规都有公开资产；撤题来自能力集成化、权威联合监督缺失、理论计算责任断裂和 agent 可删除。来源与许可证 manifest 只保留为发布前合规检查。
- C26 AI 加速漏洞协调修复与披露题已终审撤销。修复字节、patch-as-signal、披露阶段、双扩散和有限容量都能在隔离环境评价；撤题来自直接工作交集、反事实政策不可识别、通用时序策略可复制和 coding-agent 删除检验未通过。remedy-specific common-seed 回放只保留为安全系统资产。
- C27 策略性 coding subagent 委托契约题已独立终审撤销。真实 patch、contract-conditioned worker 和 hidden-harm runner 可以形成 model-organism pilot；撤题来自人工效用构造循环、Adaptive Contracts 等直接所有权、通用 Stackelberg/POMDP 可复制及连续契约构念错层。pilot 不得占论文题位。

## 9. 版本更新责任
