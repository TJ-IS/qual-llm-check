# 原候选论文一可执行状态数据构造冻结规格

## 1. 文档状态

> **状态修订（2026-08-15）：原候选论文一已经理论 NO-GO，本文件只保留为数据资产规格，不再冻结论文题目或算法贡献。** Butler–Gray mindfulness 与 digital HRO 未产生足以越过等参数 belief-state POMDP 的计算关系；终局理论判定见 `00I_候选一理论责任红队与撤题判定.md`。

本文件冻结三状态数据资产的构造、泄漏隔离和最低规模门槛。冻结不表示数据已经生成，也不表示该资产能够单独形成论文。三状态名称已由 FixedBench 使用；严格可执行状态真值、匹配状态训练和状态条件行动可继续作为未来候选的底层资源，但不能被表述为当前论文一的既定新增能力。

规格冻结日期为 2026 年 8 月 15 日。所有随时间更新的数据源必须固定 revision、哈希和容器摘要，禁止在正式方法中写成使用 latest 版本。

## 2. 数据源与职责

### 2.1 训练核心

训练优先使用 SWE-smith 的 `combine_file` 与 `combine_module` 实例。论文版报告 50,137 个任务、128 个仓库，其中组合任务 10,092 个；当前 Hugging Face 页面已显示不同的行数和镜像仓库数，说明数据会继续变化。因此，manifest 至少记录：

- Hugging Face git revision、全表行数和 SHA-256。
- SWE-smith 工具 commit 与 Docker image digest。
- 每个上游仓库及其许可证。
- 每个实例的 base commit、故障 patch、测试集合与组件哈希。
- 所有构造、验证与剔除原因。

SWE-smith 工具与数据标为 MIT，派生仓库代码仍受各上游项目许可证约束。

### 2.2 外部测试

SWE-bench Verified 只作为历史诊断集。其 500 个公开任务存在测试质量与污染问题，不能承担主要能力结论。

主要外部测试使用固定 revision 的 SWE-bench-Live `full` split，并选择完整、闭合的六个月时间窗。任务创建时间必须晚于基础模型公开日与训练数据冻结日两者中的较晚日期，同时排除训练仓库、fork network 与近重复代码。每个入选任务必须有可执行 gold patch、F2P、P2P 和固定容器摘要。

SWE-rebench V2 可抽样用于跨语言鲁棒性，不作为全量本地测试前提。其完整容器和验证成本超过本项目合理本地范围。

## 3. 严格单调的可执行状态

一个数据组必须共享同一问题文本、目标行为义务、工具接口与评价预算。令健康代码为 `H`，相互可识别的原子故障为 `B_1,...,B_k`。

训练三联体定义为：

```text
Novel:    X_N = H composed with B_1,...,B_k
Partial:  X_P(S) = H composed with a nonempty proper subset of B
Resolved: X_R = H
```

从 Novel 到 Partial 表示已经撤销至少一个真实故障，但仍保留至少一个真实故障。每个原子故障必须：

- 对应完整 AST 函数、类或依赖闭合编辑单元，禁止任意行切片。
- 单独应用后仍能构建和收集测试，并破坏至少一个原先通过的目标行为。
- 不修改测试、断言、跳过标记、超时、CI 或评价脚本。
- 能被逆补丁干净恢复至健康状态。

对每个组件执行隔离干预，构造组件与测试失败签名的因果矩阵。测试按行为失败签名聚合为至少两个行为义务，禁止按测试条数简单计分。每个组件至少需要一个不可被其他组件替代的 witness；否则合并组件或删除该组。

令 `z_j(X)=1` 表示状态 `X` 满足第 `j` 个行为义务，`r(X)=0` 表示没有新增回归。状态标签为：

- Novel 仅指规范初始故障状态，所有目标义务仍未满足。
- Partial 满足 `0 < sum(z_j(X)) < m` 且 `r(X)=0`，并且剩余修复可以干净到达 Resolved。
- Resolved 满足 `sum(z_j(X))=m` 且 `r(X)=0`。

出现以下任一情形均标为 `INVALID` 并删除：

- 补丁没有修复任何行为义务。
- 新增任意回归。
- 只改变异常形式、测试收集数量或使测试停止执行。
- 构建、导入或类型检查失败。
- 修改测试或评价设施。
- 剩余 repair patch 无法从 Partial 干净到达 Resolved。
- 三次隔离执行结果不一致。

这一定义与 FixedBench 的 Partial 构造有实质区别。后者使用弱模型任意补丁并排除完全通过 gold tests 的样本，不能保证正向进展、零回归或可完成路径。

## 4. 真实任务三联体

对于 SWE-bench 或 SWE-bench-Live，令原始仓库为 `R`，开发者 gold patch 为 `G`：

- Novel 为 `R`。
- Resolved 为 `R` 应用完整 `G` 后的状态。
- Partial 为 `R` 应用 `G` 的非空真子集 `G_S` 后的状态。

`G_S` 必须由 AST 与数据依赖闭合的编辑单元组成，并通过同样的义务进展、零回归、可组合残余修复和三次稳定性门槛。若不存在严格中间行为状态，该任务不得进入三状态测试集。不能用某个模型生成的失败 patch 替代这一过程。

构造 oracle 只负责候选选择。独立 hidden oracle 只进行一次最终确认，不能根据 hidden 结果反复修改候选。三个状态均压平为相同形式的工作树和提交元数据，删除分支名、commit message、补丁残留等标签捷径。

## 5. 构造测试与隐藏测试

每项行为义务至少保留两类相互独立的 witness：

- `T_construct` 用于构造和标签确认。
- `T_hidden` 对模型不可见，仅用于最终评价。

外部测试中，gold patch、组件划分、状态标签、test patch 与 hidden tests 均不得进入 agent context。匹配三状态使用完全相同的问题文本、公开文件集合、工具和预算。

同一问题的全部状态、全部 Partial 子集、轨迹前缀与同源复合任务共享同一 `group_id`，整体进入同一 split。依次按以下层级去重和隔离：

1. GitHub upstream 与 fork network。
2. repository。
3. base-commit ancestry。
4. 修改函数 AST hash。
5. 问题文本 MinHash。
6. 测试失败签名与 gold patch 相似度。

内部主划分在 repository-network 层完成，并额外保留至少两个未见 mutation family 作为合成 OOD 测试。

## 6. 最低规模门槛

低于任一关键门槛时继续构造；如果可确认的数据生成率不能支持下限，则撤销论文，不以预期规模替代真实计数。

- 合成三联体总数不少于 4,000 组。
- 训练不少于 3,000 组，开发集不少于 500 组，内部 repo-OOD 测试不少于 500 组。
- 覆盖不少于 80 个独立上游仓库网络。
- 每组平衡提供 Novel、Partial 和 Resolved 三个根状态。训练至少包含 9,000 个根状态；多个 Partial 变体在每轮只抽取一个。
- Verified 历史三联体不少于 150 组，并覆盖至少 8 个原始仓库。
- 新时间窗主要测试不少于 300 组三联体，并覆盖至少 40 个独立仓库网络。

SWE-smith 论文版的 10,092 个组合任务说明 4,000 组具有初步可能性。严格门槛后的真实 yield 尚未运行，正文不得写成已经获得这些规模。

## 7. 外部结果

主要结果必须同时测量修复不足与行动新增的真实损害：

- Behavioral Regression Incidence：行动前通过、行动后失败的隐藏行为义务或回归测试比例。
- Residual Defect Incidence：Novel 或 Partial 最终仍未满足目标义务的比例。
- Harm-free Task Completion：Novel 与 Partial 完全修复且无回归；Resolved 保持全部行为成立。
- Severity-weighted Harm：按行为义务的重要性汇总损害，避免参数化测试数量主导结果。

次级指标包括不必要生产代码变更率、变更规模、构建/依赖/接口回归、测试与工具调用数、token、墙钟时间，以及修复成功率—损害率 Pareto 前沿。

对能可靠移植后续上游测试的任务，可以预注册 90 日未来测试窗口并报告 Future Regression Rate。必须同时报告测试可移植率和样本选择，不能只呈现可移植子集上的有利结果。

## 8. 训练工件与强替代

首选工件为匹配三联体的 belief-option coding policy：

- 基础模型为 7B–8B 开源 code LM，使用 QLoRA。
- 输入为问题、当前代码观察、测试/构建输出和行动历史。
- 中间状态包括逐义务证据、竞争解释和当前完成状态 belief。
- 动作包括检查、检索、复现、运行测试、隔离试改、正式编辑、验证和停止。
- 损失包括状态 proper scoring、义务预测、匹配三联体对比、证据关系、状态条件动作排序和离线 advantage-weighted policy loss。

备选工件为义务—代码图 world model 加约束规划。图节点为问题义务、测试、函数、文件和当前修改，边为调用、覆盖、依赖、修改与证据关系。模型预测候选检查或编辑动作后的义务状态、回归概率与成本，并以短视 MPC 选择继续取证、执行候选编辑或停止。该方案的工程风险更高，不能与首选方案混成一个模糊主模型。

强替代至少包括：

- FixedBench 原提示、verify-before-act 与 reproduce-then-abstain。
- 直接三状态 SFT 和直接 act/abstain classifier。
- Agentic Abstention 与 Agentic Critical Training 的预算匹配适配版。
- 等参数普通 Transformer、普通 POMDP 与允许读取相同证据的通用策略。
- 相同本地 patch generator 下的义务—代码图替代。

模型只提高三状态分类而未同时降低回归与残余缺陷，不构成主要贡献。

## 9. 算力与复现

7B QLoRA 可在单张 48–80GB GPU 上训练。SWE-smith 论文版环境约占 295GB，真正的主要成本来自 CPU/Docker 状态生成和重复验证。100M–300M 图 world model 可在 24–48GB GPU 上训练。

复现包必须包含数据 revision、全表哈希、上游许可证、容器 digest、split manifest、每条状态的 obligation vector、构造/隐藏测试隔离表、所有删除原因、base model hash、adapter/checkpoint、随机种子、训练配置与完整 rollout log。

## 10. 撤题条件

- 严格质量控制后不足 4,000 个三联体或不足 80 个仓库网络。
- 无法构造至少 300 个新时间窗三联体。
- 投稿前出现等价的公开可执行三状态训练数据与学习策略。
- 等参数直接三状态 SFT、Agentic Critical Training 或通用 POMDP 复制全部收益。
- 方法只改善状态分类，不能同时降低实际回归和残余缺陷。
- 理论状态经打乱、中和或允许原始特征 bypass 后，行动和外部结果没有可观察变化。
