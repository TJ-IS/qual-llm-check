# 候选一理论责任红队与撤题判定

## 1. 当前判定

候选一的数据问题为 `CONDITIONAL GO`，Butler–Gray 可靠性—正念理论驱动的独立算法贡献为 `NO-GO`。本判定来自对 Butler 与 Gray 主文和肖帅勇老师两篇 ISR 主文的重新逐句回读，不因已经完成数据规格而降低理论门槛。

被撤销的核心主张是“个体正念五维分别产生五类算法状态”。尤其是“对差异的警觉产生可执行义务向量”没有理论原文依据。可执行义务可以定义任务真值、Partial 状态和外部结果，但不能借 mindfulness 命名。

## 2. 层级错误

Butler 与 Gray 明确区分：

- 个体 mindfulness 的五个面向是 openness to novelty、alertness to distinction、sensitivity to context、awareness of multiple perspectives 和 orientation in the present。
- collective/organizational mindfulness 的五个面向是 preoccupation with failure、reluctance to simplify、attention to operations、resilience 和 migration of decisions to expertise。

先前方案把个体五面向称为 mindful organizing，又混入组织层的失败关注和韧性，属于理论层级混用。单个 coding agent 不能在没有组织行动者、知识归属和决策权结构时直接承担 migration to expertise。

## 3. 可保留与必须撤销

| 状态或主张 | 判定 | 责任边界 |
|---|---|---|
| 历史任务叙述与当前运行证据双通道 | 可保留 | 原文支持 routines 塑造感知，以及当前状态与预期状态的区分 |
| 多个可修正的竞争解释 | 可保留 | 对应避免过早承诺、持续修正期待和不把信息呈现为确定事实 |
| 弱异常与 near-failure 独立保留 | 可保留 | 对应失败关注与避免常规成功造成过度自信 |
| 错误遏制、隔离试改和回滚能力 | 可保留 | 对应 resilience；必须用真实动作结果监督 |
| 可执行义务向量 | 仅作工程状态 | 来自测试、行为不变量和构造 oracle，不是正念状态 |
| Novel/Partial/Resolved belief | 仅作任务状态 | 是研究情境分类，不是理论构念 |
| 情境条件后果预测 | 通用技术状态 | 理论支持情境敏感，但不独占 world-model 能力 |
| 泛化 option-preservation value | 撤销理论归属 | 原文谈创建选项与恢复，没有规定一般期权价值张量 |
| 决策迁移至专长 | 当前撤销 | 现有动作空间没有专家身份、知识归属或决策权迁移 |
| 五个理论 head 或五项辅助 loss | 撤销 | 原文没有建立五个正交计算因素 |
| 固定义务集合穷尽可靠状态 | 撤销 | 固定清单自身可能形成 routine-based closure |
| 信念随取证强制单调确定 | 撤销 | 信息获取不必然增加确定性，belief 必须允许回撤与重分类 |

数据构造中的义务真值可以严格单调；推断中的义务 belief 不得被强制单调。

## 4. 若继续挽救的最低结构

理论中心只能是防止继承叙述造成过早闭合的情境化信念更新，而不是义务清单。

- `Q_t ∈ [0,1]^(m×3)`：每项行为义务满足、违反、未知的概率。它是技术状态。
- `b_hist` 与 `b_ops`：历史叙述形成的先验和当前运行证据形成的状态信念。
- `Delta_t = b_ops - b_hist`：预期—当前冲突。issue 原文不得绕过该状态直接控制 mutation policy。
- `U_t`：竞争解释对辨别性证据的未满足需求。
- `A_t`：包含来源、时间、严重度与反驳对象的异常证据表；不得被大量普通通过结果平均稀释。
- `R_t(a)`：候选动作的新增损害、可遏制性、可回滚性与成本预测。

允许的损失包括义务三态监督、belief proper scoring、证据支持/反驳关系、匹配状态对比、异常持续性、真实 rollout 后果与 constrained policy loss。禁止加入抽象的 mindfulness loss、无依据的熵最大化或五维辅助头。

若使用 resilience，动作空间必须显式包含隔离试改、checkpoint、rollback/restore 和错误遏制。只有“正式修改并暂存”不能承担该机制。

## 5. 理论方向冲突

1. 历史 issue 强烈暗示缺陷存在，当前代码和定向测试支持已解决。理论约束策略应先取得能区分解释的证据，充分后保持现态。
2. 大量常规测试通过，一个高严重度异常仍反驳 resolved。异常持续通道应触发针对性验证。
3. 固定义务全部满足，却出现集合外新异常。模型必须允许新解释或新义务进入；否则义务向量自身造成过早闭合。
4. 直接修改成功概率较高，隔离试改成本略高但显著提高恢复能力。resilience 状态应提高隔离、checkpoint 或可回滚行动的排序。
5. 额外检查不能区分任何竞争解释。策略不应把取证量等同于 mindfulness，而应停止、请求特定信息或改选另一种动作。

## 6. 通用 POMDP 反证

通用 POMDP 可以把义务真值、当前任务状态、依赖和回归设为隐状态，把 issue、代码、测试、构建和行动历史设为观测，把检查、隔离试改、编辑、请求信息、停止和回滚设为动作，再以任务完成减去回归、无谓修改和行动成本作为奖励。它在表示上可以覆盖当前全部策略。

公平反证要求：

- 相同 backbone、参数量、观测、动作、rollout、token 和工具预算。
- 通用模型获得相同义务、状态和行动后果监督。
- 另设同维度但无理论分块的 latent-state POMDP。
- 比较真实损害—任务成功—成本前沿、状态校准和方向冲突动作。
- 预注册等效区间，不能把不显著差异解释为理论胜出。

出现任一情况即撤销理论算法贡献：

- 通用 POMDP 在等效界内复制 harm-free completion、回归控制和成本。
- 打乱历史—当前配对、异常通道或恢复状态后，动作不变。
- 优势来自更多标签、规则 gate、oracle tests 或上下文预算。
- 允许 raw latent bypass 后理论状态不被使用。
- 收益只表现为三状态分类提高。
- 固定义务无法容纳新异常。
- 模型只是调用更多工具，没有改善风险—成功—成本权衡。

## 7. 与肖老师两篇 ISR 的闭合差距

肖老师两篇论文的共同标准是“现有计算动作正好系统性处理错了理论机制”，随后理论规定新的中间状态、关系方向和模型动作，并用中间状态评价与消融收回责任。

- ACAA 从一般模型偏差进入信息处理阶段和粒度，再用成对结构说明理论行为、普通 compatibility function 的错误和专用计算动作，最终落实到非冗余/互补注意、时间项、投票项及逐时点模态权重。
- DSDL 从期望不确认机制进入期望、体验和动态满意度，形成 `E`、`F`、`S=F-E` 及有方向的 contrastive loss，并验证中间状态。

C1 当前的义务向量只是任务分解。它尚未提供像 ACAA 那样的反方向计算冲突，也没有像 DSDL 的 `F-E` 那样由理论直接规定的张量关系和损失方向。因此不能进入正式正文。

## 8. Salovaara、Lyytinen 与 Penttinen 的数字高可靠组织视角

为避免在 Butler–Gray 映射失败后仓促更换几个理论术语，本轮进一步逐段回读了 Salovaara、Lyytinen 与 Penttinen（2019）的 MIS Quarterly 主文。该文确实比个体 mindfulness 更贴近自主数字行动，但它同时收紧了 C1 的理论边界。

该文的核心机制不是“五个高可靠特征分别对应五个模型模块”。作者先区分三组维度：行动主体是 human-based 还是 digital，认知形态是 mindful 还是受 frame problem 限制的 mindless，行动目的则是获取或解释信息的 epistemic operation，还是改变环境的 pragmatic operation。随后，他们在 F-Secure 情境中识别 core、improvement 与 anticipation 三层，以及层内和层间认识性行动与执行性行动的耦合。collective mindfulness 是这种社会技术组织的涌现属性，并非任何一个算法状态或辅助损失。

这一区分对 C1 产生四项硬约束：

1. 只有数字模型的仓库状态策略，不能被称为 collective mindfulness。该理论明确把数字核心视为受 frame problem 约束的 mindless pragmatic operation，并把核心之外的关键执行责任交给人类行动者。
2. “检查后修改”的普通顺序不足以实现理论。理论责任落在 epistemic 与 pragmatic operations 的职责分配、相互监控和跨层耦合，而不是给每个动作附加一个风险权重。
3. improvement 层主要处理已经可见的 known unknown，anticipation 层则以外向搜索对抗人类自身的 entrenchment。固定测试集合上的 Novel、Partial、Resolved 三联体只能支持前者，不能据此声称学习了 unknown unknown 的主动预期。
4. 该理论允许数字操作承担认识性处理和核心执行，但在数字核心之外的高影响 pragmatic decision 上强调人类责任。若算法工件把所有检查、修复、回滚与提交重新交给同一个 agent，便与理论的责任结构相冲突。

因此，Salovaara 等的理论目前只能承担两种角色。第一，它可以作为整个 thesis 的概念边界，说明 coding agent 的安全为何是社会技术的可靠行动问题。第二，若未来另行形成一个真正包含 agent core、反应性改进、主动预期和人类执行责任迁移的研究题，它可以成为该题的理论基础。它不能直接为现有 C1 的 `Q_t`、`b_hist`、`b_ops` 或义务损失提供来源。

与肖老师两篇 ISR 的标准相比，差距仍然明显。ACAA 的 reception/yielding 与四层注意粒度直接改变 compatibility function，DSDL 的期望不确认直接产生 `E`、`F`、`S=F-E` 和有方向损失。Salovaara 等给出的是社会技术行动结构；若不能把“谁执行哪一种认识性或执行性行动、哪一层监控哪一层、何时把数字核心的决定迁移给人”转化为可监督状态、结构化动作和可反证的耦合机制，强行把三层画成神经网络三层只会重复此前的理论误用。

## 9. 下一步裁决

数据构造工作可以继续，因为它独立提供严格当前状态真值与外部损害评价。正式论文写作暂停。只有在“预期—当前冲突、异常持续、解释可修正、恢复/遏制”形成紧凑且原文支持的机制，并能预先说明为何等参数 POMDP 会作出不同选择后，才重新申请 Butler–Gray 路线的理论 GO。若改用数字高可靠组织视角，还必须加入可识别的人机职责与认识性—执行性行动耦合，不能把社会技术层级压成同一 agent 的内部模块。两条路线都不闭合时，保留数据资产并替换论文题目。
