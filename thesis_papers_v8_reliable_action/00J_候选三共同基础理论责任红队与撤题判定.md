## 3. common ground 对 coding action approval 的适用边界

### 3.1 自然适用的充分条件

候选三只有同时满足以下条件，joint activity/common ground 才不是牵强迁移。

1. 人类与 coding agent 对同一个软件任务具有可识别的共同目的。人类提供执行授权并承担监督责任，agent 在授权后改变持久状态，两方行动相互依赖。
2. 研究时点固定在 escalation 已经发生之后。本文不解释为何升级，也不学习 allow、deny、ask 或权限阈值。
3. 待审核对象是 canonical action，而非 agent 自述。共同基础中的每项命题都必须绑定 action hash、repository/container identity、pre-state 和作用域。
4. 危险误批中存在一个可干预的“理解失准”路径：有效证据已经可以取得，但审核者没有正确理解行动目标、可用资源、关键风险或执行承诺，或者系统错误地把“已展示”当作“已理解”。
5. 审核者必须能通过 factual response、state prediction、clarification 或 repair 给出理解证据；只有点击、停留、信心或最终批准不能充当 grounding label。

在这些条件下，批准不是一个静态偏好点击，而是 joint action 的承诺时点。四类行动命题必须由独立任务作者从 task/action manifest 外生冻结，不能由共同基础理论或审核结果生成。Mastrogiacomo 等人的 Table 3 只提供以下稀疏关系。

- `objective←identification`：共同目的由什么任务结果识别，哪些结果不在目标内。
- `resource+risk←ability`：仓库状态、权限、测试、回滚能力和未解决后果共同决定双方是否具有完成目的的能力。
- `commitment←willingness`：人类和 agent 对 action hash、执行范围、停止与回报义务的承诺体现继续共同活动的意愿。

mutual belief 不得成为第四或第五个内容列，也不得被映射为 risk。它是围绕 objective/resource/risk/commitment 内容，经 presentation、clarification、repair、uptake 与 purpose-relative criterion 持续取得相互理解证据的过程。具体文件、调用路径、test outcome、taint flow 和 state delta 来自 task/action manifest 与技术分析，不能声称由理论产生。

### 3.2 不自然或应撤题的情境

- 风险完全来自未被任何工具发现的隐藏漏洞，而审核者对已展示事实理解无误。这里缺的是技术诊断能力，不是共同基础。
- 人类与 agent 对一个错误事实形成一致理解。common ground 可以很高，行动仍然危险；理论不能替代 evidence validity。
- 人类故意违反组织政策、存在利益冲突或根本不接受共同目标。这里不是 grounding breakdown。
- 系统只把完整 diff、告警或解释单向展示给审核者，没有可观察的 presentation–evaluation–repair–acceptance 循环。
- “双方”实际上是 agent 与一个 LLM persona 或 LLM judge。模拟对话不能承担真人共同理解或 unsafe approval 结果。

因此，理论因果链必须写成：**可信且行动绑定的证据候选 → 对当前审批目的的相互理解建立或修复 → 审核者对真实 post-state 的事实判断改善 → 危险误批下降**。不能写成“common ground 产生更真实的证据”或“common ground 直接保证安全”。

## 4. 理论状态与技术状态的强制分账

| 状态或能力 | 责任来源 | 可否作为 common-ground 理论贡献 |
| --- | --- | --- |
| canonical diff/command、tool arguments、action hash、pre/post snapshot | trusted execution infrastructure | 否，是前提 |
| test、dry-run、mutation、call/taint/scope 分析及其成本 | 软件工程与执行环境 | 否，是候选取证动作 |
| evidence validity、bug-discriminating、misleading、candidate-specific | BSG-VA 类技术监督 | 否，是技术预测任务 |
| hidden functional/security/scope/state-damage oracle | 实验构造 | 否，是结果真值 |
| `J_content` 中 objective/resource/risk/commitment 内容 | 独立 task/action manifest；理论只给 identification→objective、ability→resource+risk、willingness→commitment 的关系 | 否，是外生任务内容 |
| 对双方可访问但未被互动确认的 potential state | common-ground 理论与 Li 等人的直接证据 | 是 |
| presentation、clarification、repair、`grounding_acceptance` 的互动状态 | conversational grounding | 是，但不是 gate approval |
| 审核者对命题的解释及系统对其解释的校准信念 | 递归共同知识的可操作近似 | 是，但必须承认是概率推断而非直接读心 |
| 对当前批准目的足够的 grounding criterion 与剩余缺口 | Clark/Mastrogiacomo 的 purpose-relative sufficiency；数值由独立任务作者事前冻结 | 理论负责 purpose-relative 结构，不负责从 outcome 学阈值 |
| 行动变化后 evidence invalidation | action binding 技术规则；共同基础理论只要求重新校准 | 只能声称理论解释重新 grounding 的必要性，不能把 hash 机制归于理论 |
| unsafe approval、safe approval、review time、compute | 外部评价结果 | 否，是训练/评价目标 |

这个分账是 C3 能否成立的第一道硬门。若论文把 action–state–evidence graph、因果证据有效性或 test generation 归因于 common ground，理论责任即失真。

## 5. 外生内容与理论状态的张量、更新、约束与动作

### 5.1 张量

设一次固定审核事件含有 `P` 个行动命题、两名参与者 `H` 与 `A`、`K_p` 个命题解释候选，以及四类 grounding act。设计至少应分开一个外生内容矩阵和以下可学习理论状态。

1. **外生内容矩阵** `J_content ∈ {0,1}^{P×4}`。四列依次对应 objective、resource、risk、commitment。trusted mediator 必须先冻结 canonical action、pre-state、working-tree、permission 与 scope 的 `binding_digest`；独立任务作者随后只针对该 digest、在 participant response、approval 与 hidden outcome 之前从 task/action manifest 冻结 `J_content`。固定的 `R_joint→content∈{0,1}^{3×4}` 只记录 identification→objective、ability→resource+risk、willingness→commitment；mutual belief 不占内容列。
2. **participant-access 矩阵** `V_t ∈ [0,1]^{P×2}`。它估计命题内容是否已经对人类与 agent 可访问。由此得到 `g_pot,t ∈ [0,1]^P`。可访问只表示 potential common ground。
3. **审核者解释后验** `B_H,t ∈ ∏_p Δ^{K_p∪{UNKNOWN}}`。它表示审核者对精确行动事实的可能解释。系统不能声称观察到真实信念，只能依据 factual response、state prediction、clarification 和 repair 做校准推断；UNKNOWN 不得被折叠为正确或错误。
4. **grounding-act 状态** `C_t ∈ [0,1]^{P×4}`。四列记录 presentation、clarification、repair 和 `grounding_acceptance` 的行动绑定证据。`grounding_acceptance` 是互动阶段，不是 gate approval；schema 拒绝 approve event。它保留理解如何经互动建立，而不只保留最终一句“确认”。
5. **reciprocal-recognition 矩阵** `M_t ∈ [0,1]^{P×2}`。第一列表示系统已有独立证据认为审核者按目标含义理解命题，第二列表示审核者已有可观察证据知道系统接收并据其回答更新了行动。第二列必须对应 system-uptake event、human-exposure receipt 和 paired-confirmation item；没有人类可观察 exposure 时保持 UNKNOWN。`C` 与 `M` 不得由同一 response/event 循环定义。第二列是递归共同知识的可操作近似，也是本模型与普通 reviewer-comprehension predictor 的关键差异。
6. **established-common-ground 后验** `g_est,t ∈ [0,1]^P`。它必须同时依赖双方可访问、审核者解释、grounding phases 和 `M_t`，不能从 evidence embedding 单向计算。
7. **purpose-relative criterion 与缺口** `κ ∈ [0,1]^P`、`m_req∈{0,1}^P` 和 `r_t=m_req⊙max(0,κ−g_est,t)`。`κ/m_req` 由独立任务作者在同一 `binding_digest` 之后、任何 participant response、approval 和 hidden outcome 之前冻结，并登记 scale version、basis、required-response bank hash、threshold unit、sensitivity grid 与 upstream digest。`κ` 是外生 criterion specification，与后续 factual-grounding measurement/label 分离；它不能由 unsafe approval、harm 或 task success 反推。

技术层另有 action–state–evidence graph、证据有效性、候选取证动作后果与成本张量。它们可以与 `r_t` 交互，但不得混入 `g_est,t` 后再声称整个隐状态都来自理论。

### 5.2 更新规则

理论更新必须体现以下非对称性。

- 单向 presentation 只能提高 `g_pot`，不能自动提高 `g_est`。
- 审核者对 action-bound factual probe 的正确回答可更新 `B_H`，但不能让同一 response 同时自证 `C` 和 `M`。`M_t` 第一列需要与 phase-event 分离的 action-specific understanding evidence 或 paired confirmation。只有系统随后以 acknowledgement 或 repair 采用该回答、人确实看到这一 uptake，且完成后续 paired confirmation，`M_t` 第二列才可提高；任一环缺失时保持 UNKNOWN。错误、矛盾或“不确定”回答应降低相应后验，或触发 clarification/repair。
- clarification 本身是共同基础尚未达到 criterion 的证据；只有 repair 后的再次正确响应才能把相关命题推向 established。
- reviewer 点击 approve 不更新 established state。批准是外部结果，不是理解标签。
- action、pre-state、working-tree、permission 或 scope 任一变化时，旧 `binding_digest` 与其 proposition、`J_content`、`m_req/κ`、四个题目 bank、lattice、branch、evidence 和全部理论状态同时失效；新对象按 bind→purpose→generate→commit 全链重建。
- 已经建立的 objective 不应因出现一条新的 risk evidence 被全部清零。更新应是 proposition-specific；只有依赖该状态的命题被重新打开。

这组规则要求一个可训练的 sequential belief filter，而不是手工 if–then。监督信号来自相互分离的命题级 factual-response bank、paired-interpretation、盲态 grounding-act/uptake 标注和 repair 后 transfer items；approval、harm、task success 只作为外部回报或评价，不定义理论状态。presentation-only、answer-swap、action-swap 与 stale-evidence 样本用于反事实训练。每个 UNKNOWN 保存 time、annotator、reason 与 forbidden-source check；字段时点、event-ID 独占和 `UNKNOWN` 规则见 `00H-A`。

### 5.3 理论约束和损失

以下损失才可称为 common-ground 驱动，unsafe approval reward 或 evidence-validity loss 本身不是。

- `L_interp`：命题级审核者解释后验与 factual ground truth 的校准损失。
- `L_phase`：presentation、clarification、repair、`grounding_acceptance` 的互动阶段与观察日志的一致性损失，不读取 gate approval。
- `L_pot≠est`：potential 与 established 的反捷径对比损失。在保持静态证据内容不变、打乱互动确认历史时，`g_pot` 应稳定而 `g_est` 应改变。
- `L_reciprocal`：监督 `M_t` 的双向 recognition，并约束只有形成可观察 reciprocal evidence 的命题才可跨过 criterion；单向显示或 approve click 不能提供同等增量。
- `L_purpose`：终止前必须处理由外生 `m_req/κ` 指定的 objective/resource/risk/commitment 缺口。不同类型不可由一个总分相互抵消，损失也不能回推阈值。
- `L_effort`：在达到 criterion 的前提下减少双方总协作努力。这一项来自 least collaborative effort，必须同时计算审核者交互成本与系统取证成本，不能只惩罚 token 数。

总策略仍可采用 constrained offline POMDP，但前向状态必须显式包含外生 `J_content/κ/m_req` 与可学习的 `V,B_H,C,M,g_pot,g_est,r`。若策略可以从 raw trace 旁路这些状态直接优化 unsafe approval，理论机制无法归责。乘性或单调门只是一项理论启发且可证伪的结构假设，原文并未推出其函数形式或表达独占性。

### 5.4 理论改变的推断动作

common ground 直接支持的动作只有以下几类。

- 将某项可信、action-bound evidence 呈现给与之对应的 `J_content` 命题。
- 提出能够区分审核者解释的 factual probe，而非询问“你是否理解”。
- 当回答错误、矛盾或不确定时，针对同一命题执行 clarification 或 repair，并在 repair 后再次取得理解证据。
- 在要求命题达到 criterion 后停止增加证据；若预算耗尽仍未达到，则把事件交还外部 gate。

策略动作只允许 `acquire/present/factual_probe/clarify/repair/stop`。生成测试、运行 sandbox、寻找 counterexample、验证 rollback 等属于 `acquire` 的技术子动作；需要更换审核者时由外部 gate 处理，C3 不执行 reviewer assignment。理论只改变证据预计修复哪个 proposition-specific grounding gap，以及所需协作成本。若方法最终仅给证据打一个 expected-correction 分数并取 top-k，理论没有产生独立序贯能力。

## 6. 必须出现的冲突情境

以下情境在 raw evidence 相同的情况下，理论方法应作出与普通 selector 不同的动作。

| 冲突情境 | 普通 evidence-quality/approval 模型可能动作 | common-ground 机制的预注册动作 |
| --- | --- | --- |
| 高质量 state delta 已展示，但审核者把删除范围理解错 | 因证据充分而停止 | 保持 (g^{pot}) 高、(g^{est}) 低，提出范围 factual probe 并 repair |
| 审核者点击 approve，同时对 post-state 预测错误 | 把批准当成功标签 | 不提高 established state，继续修复或交还 gate |
| 同一解释被重复展示三次，没有新反馈 | 因 exposure/attention 累积而增加理解概率 | potential 不变或增加，established 不应只因重复展示跨过 criterion |
| 审核者已正确掌握 objective 与 commitment，但 risk 命题未建立 | 重复总摘要或选择最高风险证据 | 仅针对 risk gap 取得/呈现区分性证据 |
| action hash 或 pre-state 在对话后变化 | 复用先前高价值 evidence | 技术层失效证据，相关 established proposition 重新打开 |
| 审核者主动指出证据矛盾 | 将矛盾作为低置信噪声 | 进入 clarification/repair，更新系统对审核者解释的后验 |
| 双方共同接受一条错误测试结论 | 可能停止 | common ground 也会失败；必须由独立 evidence-validity 层阻止。这是理论边界，不得掩盖 |

若上述前五类干预不能稳定改变模型动作，common-ground 状态只是可视化标签。

## 7. 等参数通用反证

### 7.1 必须比较的通用替代

1. **Raw-POMDP**：从完整 history 学习 latent state，可读取所有外生内容和人类标签，但不强制理论分解。
2. **Human-state POMDP**：可显式预测任意审核者状态，也获得 `J_content`、factual response、phase、uptake、criterion 与 outcome labels，但不强制 potential/established 的乘性路径。
3. **Generic proposition Transformer**：读取相同 proposition/evidence graph、`J_content` 与人类反馈，以无结构 cross-attention 学习下一动作。
4. **Contextual bandit/outcome-value selector**：在相同 candidate lattice 和 logged trajectories 上直接学习各合法动作的外部价值。
5. **Generic POMDP with learned stopping**：拥有同一 belief-state 输入、信息获取和 `stop`，可以通过通用网络自行重建 C3 的中间状态。
6. **预算匹配的最强静态组合**：canonical raw action、BSG-VA 风格 discriminating evidence、PICK 信息增益、AutoSD trace 和完整 diff，在完全相同屏幕空间、取证时间和 token 预算下呈现。

前五个学习型替代必须共享 `J_content`、proposition labels、human feedback、candidate lattice、action mask、external reward、pretrained encoder、train/validation split、训练步数和随机种子数。可训练参数量控制在正负 1%，推断 FLOPs 控制在正负 5%，合法动作、interaction turns 与超参数搜索预算完全相同。理论模型唯一可以不同的是同一字段的结构使用方式；不能让基线缺少 phase、uptake 或 criterion 标签来制造优势。

### 7.2 反证性干预

- **potential-content shuffle**：保持互动历史不变，替换静态可见内容。模型应区分证据内容变化与 established 过程变化。
- **grounding-history shuffle**：保持证据与行动不变，打乱 clarification、repair 和 `grounding_acceptance` 顺序。只有 (g^{est}) 与下一 repair 动作应按预注册方向改变。
- **participant-response swap**：在相同证据下交换两个审核者的 factual response；policy 应按个体理解缺口改变。
- **purpose-type shuffle**：打乱 objective/resource/risk/commitment 类型，但保持文本 embedding。若动作不变，四类状态没有算法责任。
- **established-state clamp**：在保持 raw features 不变时，将某命题从未建立钳制为已建立；模型应减少针对该命题的重复证据，转向其他缺口。
- **action/state swap**：替换 action hash 或 pre-state；旧 interaction 不能继续支持当前 established state。
- **raw-bypass test**：允许同参数旁路后，若外部前沿相同且理论状态不再影响行为，应撤销独立理论贡献。

### 7.3 何种证据才足以越过通用反证

通用 POMDP 在表达能力上可以近似 C3 的滤波器、乘性门和策略；不存在理论模型独占的可计算函数。预测性能领先本身不够，至少需要同时出现四类结果。

1. 在未见审核者、未见仓库和未见风险类型上，理论模型以相同证据、时间和计算预算实现更低 unsafe approval，且不以 safe approval 大幅下降换取。
2. proposition-level (g^{est}) 对 factual understanding 具有可校准性，优于只预测 approval/confidence 的模型。
3. 上述 counterfactual intervention 使策略按理论预期改变，打乱理论状态则破坏行为与结果。
4. 真人实验中可观察的 acquisition、presentation/probe、clarification/repair、reciprocal uptake 与 terminal factual grounding 联合过程在策略与危险误批之间表现出预注册机制关系。神经 hidden state `g_est` 不是已识别 mediator；若只有 total effect 而完整联合过程没有相应变化，应优先解释为 evidence quality 或其他直接路径，而非 common ground。

理论贡献只能是有限数据下的样本效率、未见 repository/reviewer/risk OOD、方向明确的干预响应和更优安全—效率前沿。任何公平通用模型复制这些能力，即撤销独立理论算法贡献，不得退而把同一函数重新命名为 common ground。

机制识别合同只比较 confirmatory D 臂 C3 与 C 臂等信息 Human-state POMDP。确认性试验只按处理前 `baseline_reviewer_support` 对 `participant_id` 分层一次，四臂 `A/B/C/D` 每层概率均为 `1/4`；同一参与者的十二个计划 trial 全程同臂，不 crossover、不重新随机。D/C 子对比中的 participant-level treatment 记为 `A_i=1/0`，已知条件 propensity 均为 `1/2`。分臂使用域 `C3-CONF-ARM-20260816-v1` 与 `h_i=HMAC-SHA256(K_arm,UTF8(domain||stratum_i||salted_participant_id_i))`；`K_arm` 是首例入组前生成的 256-bit 秘密，入组前只公布真实 `SHA256(K_arm)`。取 HMAC 前 64 bit 的无符号大端整数 `u_i`，以 `floor(4u_i/2^64)` 按 `0→A,1→B,2→C,3→D` 映射。salt/ID 规则、规范化、编码、字节序、allocator/schema hash 和任务顺序在分臂前预提交，allocator 不读 trial 过程或结局。enrollment lock 后公开 key 以重放；无法重放或人工 override 记 protocol deviation，不得悄然重分配。

`T_dec=6` 个互动槽依次记录动作前 eligibility、策略动作、public execution/evidence exposure、factual response、clarification/repair/grounding-acceptance/uptake 和成本/疲劳/stop；early stop 后其余互动槽为 `NOOP_ABSORB`。第 7 槽记录 silent/no-feedback `M_obs`，第 8 槽记录 measurement 后实际允许的 safety evidence/repair `R_post`。acquisition、presentation、clarification/repair 与 factual grounding 因而都在 `Z_ir^J` 内，不能作为实际臂 `L` 被条件化掉。神经 `g_est` 不是 causal process node。

确认性 IID 单位固定为参与者 cluster `O_i=(B_i,A_i,{X_ir,Z_ir^J,C_{Y,ir},Y_ir}_{r=1}^{12})`，likelihood 唯一为 `∏_i p(O_i)`，而非 2,160 个 trial 的 IID 乘积。`p(O_i)` 内按十二个计划 trial 和每 trial 八槽继续分解；后续 trial 的 nuisance history 包含该参与者早期 `Z^J`、measurement、`R_post`、censoring、可见决策与可见结局历史。因而学习、疲劳、信任调整和 repair 属于簇内 carryover，唯一 no-interference 假设仅限不同参与者之间。

令 `X̄_i=(B_i,X_i1,…,X_i12)` 为分臂前冻结的参与者基线和十二 trial 任务序列，`G_a^{J,1:r}(dz^J_{1:r}|X̄_i)` 只按 `X̄_i` 与此前由同一 stochastic intervention 抽取的簇内过程前缀因子化。确认性目标总体是处理前合格且分入 D 或 C 的 shared-support 参与者，每人等权且人内十二 trial 等权。令 `μ_r(a,z^J_{1:r},X̄_i)=E[Y_ir|A_i=a,Z_i,1:r^J=z^J_{1:r},X̄_i,C_{Y,ir}=0]`，定义 `Ψ_J^cl(a,a*)=E_{X̄_i}[12^{-1}Σ_r∫μ_r(a,z^J_{1:r},X̄_i)G_{a*}^{J,1:r}(dz^J_{1:r}|X̄_i)]`。唯一 primary mechanism estimand 是 `IIE_JFG^cl=Ψ_J^cl(1,0)-Ψ_J^cl(1,1)`；positive value 表示把十二 trial 簇内 joint process 从通用 POMDP 分布替换为 C3 分布所减少的参与者平均 unsafe approval。这个定义与“经由取证—追问—修复建立事实锚定”的理论主张同宽，不再把 terminal score 单独冒充完整机制。首名 confirmatory participant 进入后不得增删 `X̄/Z^J`；遗漏的 treatment 后共同原因触发 `PROCESS_SCHEMA_OMISSION`，只能由新版本、新样本重建。[Wang et al. (2025)](https://doi.org/10.1515/jci-2023-0013) 的随机干预、纵向 likelihood factorization 与 general stochastic-intervention EIC 只支持 estimator；它不证明 common-ground 机制，也不规定本研究的参与者簇实施选择。

primary estimator 只能是 participant-cluster 五折 cross-fitted one-step HAL-EIC longitudinal TMLE。fold seed 为 `C3-JFG-CF-20260816-v1`；在 baseline support 各层按 `SHA256(seed||0x00||salted participant ID)` 排序并以 rank 模 5 分折，同一 participant 的全部 12 trial/row 在同一 fold，各层人数差至多 1；repository connected-component folds 作废。二元 probability 截断 `[0.01,0.99]`，多类 probability 使用 `0.98p+0.02/K`；prefix density ratio 独立裁剪到 `[1/20,20]`，ratio 允许大于 1。处理前 common-support cell 固定为 `H=(risk_stratum,baseline_reviewer_support)`；D/C 各 cell 的 participant/trial 数 `20/30` 形成 `S_h^count`，T−2 public state machine 的跨臂结构不对称形成 `B_h`，最终 `S_h=S_h^count(1-B_h)`，`P_sup^cl` 只取两臂合并的 shared-support participants，每人等权、人内十二 trial 等权。结构不合法 action 的 kernel 概率为 0，绝不以 probability floor 伪造支持。

不确定性唯一使用 2,000 次整 participant-cluster bootstrap：在 `arm×baseline_reviewer_support` 层内有放回抽完整参与者及其十二 trial，保留 multiplicity，每次完整重拟 nuisance/cross-fit/target，使用 `C3-JFG-BOOT-20260816-v1` 域下预提交的 seed/hash 和 percentile interval。失败 replicate 不重抽不补抽，失败率超过 5% 即 `MECHANISM_NOT_ESTIMABLE`。识别/support/clipping/CY 门失败但 HAL likelihood 有限且可重放时，只报预注册 cluster plug-in `standardized joint-process association`；HAL 不收敛、fold 事件不足、ratio/EIC 非有限、schema 遗漏、bootstrap 失败率超门或独立重放失败时不报机制数字。两者均仍可报告随机 total effect。`R_post` 是第 8 槽，不因出现比例而 censor；只有真实退出/decision 缺失进入 censoring。micro-randomized paired-uptake encouragement 仍只在不复用 primary participant/trial 的 secondary cohort 运行，整个实验不进入 `IIE_JFG^cl`。

### 7.4 oracle-blind 与真人支持前置门

法定时序是 `T−5 bind → T−4 purpose/criterion/bank → T−3 generate → T−2 lattice-and-branch commit → T−1 sealed evaluation`。trusted mediator 必须先把 canonical action、pre-state、working-tree、permission 与 scope 写入 immutable `binding_digest`，task authors 才能针对该 digest 冻结 `J_content/m_req/κ` 与四个题目 bank。任一绑定字段或其 hash 变化会使 proposition、purpose、criterion、bank、lattice、branch commitment/instance、evidence、response 与全部理论状态失效，随后从 T−5 起全链重建；旧 digest 下的任何对象不得进入新 trial。

candidate generator 只可读取 issue/task、已绑定 action/pre-state、`J_content/m_req/κ`、public tests 和 authorized tools。它必须在任何 logging、human response、approval 或 hidden evaluator 运行前冻结 action grammar、静态候选、mask、cost、timeout 与 ordering 的 hash manifest。T−2 还必须承诺 T1 后 `clarify/repair` 动态分支：或预枚举所有 instance bytes/hash，或冻结 branch grammar、template/slot schema、content-instantiator version/image、allowed factual source Merkle root、parent state/hash、action-bound proposition IDs、budget/cost/latency/termination、runtime input whitelist、deterministic seed 与 replay 合同。分支出现只能由 visible response、UNKNOWN 或 explicit clarification request 触发，public execution 只可填入已触发分支的预承诺 factual slot，approval 或 hidden outcome 不得触发分支；全部基线使用相同 instantiator、seed 和 branch bytes。

oracle 设计门不使用裸 AUC。成对 mirror 保持全部 B/public state、部署可见 risk signals、history/response 和 public execution 完全相同，只交换 G/hidden-oracle bytes；candidate IDs/bytes/order/mask/cost/latency、generator trace 与 action logits 必须逐字节或按预注册容差一致。条件增量 probe 先固定 public-risk strata 与可见状态，再检验 hidden-only 标识能否额外预测 availability；它只是诊断，合法 public signal 的风险可预测性不是泄漏证明。机械 noninterference 任一失败使 group 失效。

真人数据的三个 primary cohort 是互不复用的 measurement/support pilot、policy-learning logging cohort 和 prospective confirmatory cohort；次级 micro-randomized cohort 也不得与三者复用参与者或 trial。当前 treatment 前状态 `S_t^pre` 只含 risk、baseline reviewer support、pre-action grounding phase/budget、class-availability bitmask、exact eligible-set hash 与 public-history hash；当前 treatment 仅单列为 `A_t=(class,subtype,candidate_id)`，post-action trigger、response 和 outcome 另作后处理记录，均不回写 eligibility state。T−2 冻结的是 `CandidateSetFn-v4/Cap8Fn-v4/q-policy-v1` 的 executable/checkpoint，而不是尚未出现状态的数值分布。每个 opportunity 先由冻结 grammar 仅凭既往 visible response/public execution 决定性实例化全部候选；`candidate_content_hash` 是 instance bytes 的 SHA-256，`candidate_id` 是 binding、parent、class、template、slot、instance bytes 与 version 的 canonical-CBOR array SHA-256。随后按 `proposition coverage descending → expected public cost ascending → candidate content hash ascending` 的 public-only 字典序每 class 保留 8 个，`stop` 单例；retained/discarded IDs 和排序字段先于 `S_t^pre` 落盘。`q` 只能在 cap 后集合上读取 state、生成并保存归一化数值，不能反向影响实例化、排序或 cap。logging 再以 `p_cls=0.70q+0.30/|C_t|` 抽合法 class，以 `p_cand=0.60q+0.40/|K_t(c)|` 抽 class 内 candidate；exact-candidate support 只使用 cap 后的条件下界。

主要 estimand cell 为处理前 coarsening `φ(S_t^pre)=h` × 单列 class `c`。令 `W_i(h,c)=Σ_t I{φ(S_it^pre)=h,A_it.class=c}/p_cls(c|S_it^pre)`，再计算 `ESS_Kish(h,c)=(Σ_iW_i(h,c))^2/Σ_iW_i(h,c)^2`；class-wide 检查令 `W_i(c)=Σ_hW_i(h,c)` 后套用同一公式。这是唯一 ESS 算法。每个 cell 必须有至少 80 个 eligible opportunities、40 个 selected rows、30 个 selected participant clusters 和 `ESS_Kish(h,c)≥30`；每个 class 跨 cell 至少有 80 个 selected participant clusters 和 `ESS_Kish(c)≥60`。task/repository 只进入方差，不得改成替代 ESS。结构不合法 cell 不要求 positivity，但不得外推。confirmatory participant、repository 和 risk family 必须全新，且不更新任何权重、阈值或校准器。

primary unsafe approval 必须由与 C3 交互、接收 evidence 并完成联合过程第 7 槽 factual measurement 的同一审核者，对同一 canonical action 作出。外部 gate 只记录或执行决定，expert adjudicator 只定 sealed truth，二者都不替代 participant outcome；换人或 second-reviewer 试验不进入 primary estimand。样本规划与门槛以 `00H/00H-A` 为准，当前均未运行。

coding-agent deletion 必须同时比较两种删除：保留 grounding 界面却把可执行 evidence acquisition 改为静态通用解释，以及保留可执行 acquisition 却删除 reviewer-state repair。前者复制完整模型则 coding-agent 特有技术层没有贡献；后者复制则 common-ground 机制没有贡献。

### 7.5 最新真人 coding 与 agentic review 直接近邻

截至 2026 年 8 月 16 日，本轮已实际读取以下六篇主文。它们使“缺少真人协作 benchmark”“缺少 interactive feedback”与“缺少 agentic code-review conversation”三类宽泛空白全部作废。

| 主文 | 已占据对象 | 仍未占据的联合交集 |
| --- | --- | --- |
| [CentaurEval v3](https://arxiv.org/html/2512.04111) | 45 个 collaboration-necessary templates、450 个任务、45 名参与者、5 个模型、4 种 intervention conditions，直接评价 human-in-the-loop coding success | 不研究 fixed post-escalation、same-reviewer unsafe approval、oracle-blind evidence 或 factual-grounding repair；旧称 HAI-Eval 作废 |
| [RECODE-H v2](https://arxiv.org/pdf/2510.06186) | 102 个 research-code tasks、五级反馈与最多 10 轮 ReCodeAgent；反馈由 GPT-o4-mini 结合 canonical code/tests 模拟专家生成 | 模拟反馈不是同一真人的 action approval，且反馈侧可读 canonical implementation，不满足 C3 oracle-blind 人类机制 |

## 8. 撤题条件

出现任一项即判 NO-GO。

1. 主要效应来自更多证据、更多时间、颜色警告或信息显著性，而非 grounding repair。
2. Human-state POMDP 或 Raw-POMDP 在等参数、等数据、等预算条件下复制安全—效率前沿和理论干预行为。
3. 合并 potential 与 established、打乱 grounding phases 或打乱四类 proposition 后，外部行为与真人结果没有可观察下降。
4. 展示、页面停留、确认词、confidence 或 approve click 被直接当成 established common ground。
5. 无法取得命题级 factual response、repair 后复测和真人 unsafe approval，只能训练 LLM judge 或 persona。
6. 理论 state 无法校准，或者所谓 (g^{est}) 只是 evidence strength、风险分数或 reviewer propensity 的改名。
7. 策略可以绕过 theory bottleneck，直接从 raw trace 得到同样结果。
8. 论文声称 common ground 保证事实正确，或让它承担 evidence validity、test generation、harm prediction、action binding 的责任。
9. 大多数危险误批由隐藏风险未发现造成，理解失准在形成性实验中不是重要路径。
10. 方法输出退化为 top-k、普通 reranking、一次性 comprehension classifier、allow/deny 或 when-to-ask。
11. action/pre-state/working-tree/permission/scope 变化后继续复用旧 `J_content`、`m_req/κ`、bank、evidence 或 grounding，或 purpose 先于 immutable binding。
12. 无法以真实 working developers 完成序贯实验，无法排除熟悉度、学习、疲劳和任务顺序的影响。
13. `J_content`、`κ`、命题、候选 mask 或顺序由 approval、harm、task success、gold/G/hidden outcome 反向生成。
14. T−2 未承诺可重放的 `clarify/repair` 分支，或在只交换 G/hidden bytes 的 public-equivalent mirror 中，candidate IDs/bytes/order/mask/cost/latency/trace/action logits 不一致却仍保留相关 group。

18. primary unsafe approval 不是由与 C3 交互的同一审核者对同一 canonical action 产生，或 expert adjudicator 替代 participant outcome。
19. 把神经 `g_est` 当成已识别 mediator，把 acquisition/presentation/clarification/repair 条件化到随机过程之外，主分析混用 interventional/organic/natural/history-conditional effect 或多个 estimator，混淆 probability truncation 与 density-ratio clipping，忽略固定六槽、absorbing no-op、measurement reactivity 或过程内 `R_post`，或在 sequential exchangeability/overlap 不可辩护时仍作因果机制主张。
20. 仅因裸 availability AUC 高就把合法 public risk signal 判为 oracle leakage，而不作 public-state-conditioned 增量诊断与机械 noninterference。
21. confirmatory 分臂不是 `participant_id×baseline_reviewer_support` 下的预提交 HMAC 固定四臂，一名参与者在十二 trial 中 crossover/重随机，或者 likelihood、estimand、cross-fitting 或 bootstrap 把 trial 而非 participant cluster 当作独立单位。

## 12. 修订后的关键正式候选句

下列句子是可进入正式论文相应位置的候选句，不是已完成正文，也不报告任何实验结果。每句的精确肖文参照、双功能码和完整责任链均登记在 `00H-B_论文三逐句功能责任账.md`；没有同功能源句的条目已明示，不以位置相似冒充同位。

- `C3-K01`：Coding agent 不仅生成代码建议，还会通过补丁、命令和工具调用改变仓库及其运行环境的持久状态。
- `C3-K02`：当组织把这类行动交由开发者批准时，误批可能使功能破坏、越界修改或不可恢复的状态变化进入后续软件过程。
- `C3-K03`：在可信中介和完整拦截成立的范围内，行动绑定使显示对象与执行对象保持一致。这一属性并不说明审核者已经正确解释行动后果。
- `C3-K04`：可执行证据能够改善技术事实的可核验性，但证据已经展示与审核者已经形成 action-specific understanding 仍是两个不同状态。
- `C3-K05`：共同基础理论据此提示，行动相关事实从双方可访问的 potential common ground 转为 established common ground，需要针对当前目的取得可观察的相互理解证据。
- `C3-K06`：Mastrogiacomo 等人的项目转译把 identification 连到 objective，把 ability 同时连到 resource 与 risk，并把 willingness 连到 commitment。
- `C3-K07`：mutual belief 并非另一类任务内容，而是在持续对话中围绕这些内容寻找、检验和修复相互理解证据的过程。
- `C3-K08`：因此，本研究在 immutable action binding 完成后，由任务作者从 task/action manifest 冻结 objective、resource、risk 与 commitment 的外生内容矩阵 `J_content`，而不把它作为理论模型的生成结果。
- `C3-K09`：模型以 `V_t` 表示行动命题对人和 agent 的实际可访问性。`V_t` 只由 renderer access 与权限日志产生。模型以 `B_H,t` 表示审核者对 action-specific facts 的解释后验。`B_H,t` 只由独立 factual response 与可信 public execution fact 校准。`C_t` 记录 presentation、clarification、repair 与 `grounding_acceptance`。`C_t` 的标签来自不读取审批结果的盲态话轮标注。`M_t` 记录独立的人类理解证据与审核者可观察的 system uptake evidence。`M_t` 的 event ID 不得复用 `C_t` 的 response event。这些状态以可证伪的结构使用方式形成 purpose-relative established-state estimate `g_est,t`。
- `C3-K10`：批准所需的命题与阈值 `m_req/κ` 在任何审核者回答、批准和 hidden outcome 出现之前冻结，使最终结果不能循环定义共同理解。
- `C3-K11`：四路门将上述必要路径写入前向计算。乘性形式只是一项理论启发的结构假设，其经验价值需要通过校准与干预检验。
- `C3-K12`：在外部机制已经决定升级之后，策略只选择下一项 `acquire`、`present`、`factual_probe`、`clarify`、`repair` 或 `stop`。模型不决定是否启动人工审核，也不输出批准、拒绝、风险分数或审核者分配。
- `C3-K13`：为使取证动作不携带隐藏答案，候选动作、mask、成本、超时与顺序在 hidden evaluator 运行之前由仅接触部署可见字段的 generator 写入带 hash 的 lattice manifest。
- `C3-K14`：测量 pilot、策略学习 logging cohort 与前瞻检验 cohort 使用互不复用的参与者，且只有 logging cohort 的已知 propensity 轨迹用于更新策略。前瞻检验按处理前 `baseline_reviewer_support` 对 `participant_id` 分层，并以预提交 HMAC 映射把每名参与者一次性分到概率均为四分之一的 `A/B/C/D` 四臂。同一参与者的十二个计划 trial 全程保持同臂，D/C 确认性对比的条件处理概率均为二分之一。分臂 manifest 在首例入组前冻结域字符串、`seed_hash`、HMAC 输入规范、字节序和 `0→A,1→B,2→C,3→D` 映射，并在 enrollment lock 后公开 key 以供重放。机制分析把参与者 cluster 作为 IID 观测单位，在簇内纵向 likelihood 中显式纳入十二 trial 的 carryover，并仅假定不同参与者之间无干扰。shared-support 目标总体以参与者等权且人内十二 trial 等权，五折 cross-fitting 与 2,000 次 bootstrap 均以完整 participant cluster 为不可拆分单位。
- `C3-K15`：研究比较 Human-state POMDP、Raw-POMDP、generic proposition Transformer 与 contextual bandit 四类通用替代。这些替代获得相同内容矩阵、命题标签、人类反馈、候选 lattice 与动态分支实例、回报、参数、FLOPs 和搜索预算。

- `C3-K18`：所有模型效果、机制中介与比较结果将在真实实验完成后报告，当前稿件只保留研究设计、预注册检验和结果占位。

C3 的问题情境、理论责任与技术责任延续上轮通过的边界。第四轮按 `02P` 将理论所称的取证—互动—修复—事实锚定统一为纵向联合机制过程，冻结 fixed-slot process、participant folds、共同支持、density ratio、dynamic cap/q 时点与 K12 两个语法句责任，同时保留 `02M` 已通过的 treatment-free eligibility、participant-cluster Kish ESS 与 bind-first 全链失效。第五轮只按 `02T` 把 confirmatory treatment 唯一化为参与者分层的可重放固定四臂，并以 participant cluster 统一 IID 单位、十二 trial carryover likelihood、目标总体、cross-fitting 与 bootstrap。乘性门仍是可证伪结构假设，通用模型仍被承认为表达可复制。故当前状态只能是 **REPAIRED-v5 / INDEPENDENT RE-REDTEAM PENDING / RESULTS NOT RUN**，不是经验 GO，也不是修补者自行判定的设计冻结。
