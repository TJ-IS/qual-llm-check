# 总体主线与三篇论文关系

## 1. 总体研究问题

本论文研究 coding agent 如何在不完全知识下可靠地承诺一次软件状态变更。这里的“承诺”不是语言上的保证，而是一个会改变真实软件状态的决策时点。数据库迁移进入下一阶段、多个代理分支被合入仓库、开发者批准一项待执行行动，都会使此前仍可比较、补充证据或退出的方案转化为具有实际后果的状态变化。承诺过早，可能造成数据损坏、不安全代码被采纳或危险行动被误批。承诺过晚，或者一概拒绝行动，又会损害任务完成、并行效率和开发者时间。因此，本论文关注的不是如何给 coding agent 增加一个风险标签，而是如何学习何时补充信息、如何改变可选行动，以及何时进入、延后或终止状态变更。

这一总体问题属于 coding agent 的广义安全。三项研究都以可执行的软件环境为对象，以真实状态变化及其损害为结果，并要求 agent 在任务成功、安全损害、时间、计算和人工成本之间作出结构化选择。它们不以存在恶意攻击者为共同前提。风险可以来自未来运行条件、多个代理共享同一错误来源，或者审核者尚未理解候选行动的实际后果。coding agent 的特殊性在于，它同时能够读取仓库、生成代码、调用工具并推动状态变化；传统静态检查器、一般问答模型或只给建议而不能行动的代码模型都没有同样的决策位置。

总体研究问题表述如下。

> 当与一次软件状态变更有关的关键知识分布在未来环境、多个编码代理和人类审核者之间时，coding agent 如何通过可训练的状态表示与行动策略，在保持任务能力的同时减少不可靠承诺造成的实际损害？

## 2. 三种知识边界

三篇论文分别研究一种不能由同一控制器机械拆分的知识边界。

| 研究 | 承诺时点 | 行动时缺少的知识 | 主要潜在损害 | 训练工件 | 推断时的核心行动 | 主要外部结果 |
|---|---|---|---|---|---|---|
| 论文一：主动缓解期权格 | PostgreSQL 迁移进入 cutover 或放弃之前 | 后续故障、工作负载与缓解措施的联合后果 | 数据完整性破坏、服务不可用、不可恢复迁移、过度停机 | repository-conditioned 因果半马尔可夫模型与硬期权格策略 | 选择零项或多项可选缓解，延期、执行或放弃 | 严重迁移损害、迁移成功、时间与资源成本 |
| 论文二：可执行可证明性分支整合 | 多个 coding-agent 分支被整合或隔离之前 | 证据的共同来源、命题是否真正被利用、探针会怎样区分分支 | 相关错误被多数放大、不安全分支被采纳、无谓总串行 | 跨来源联合后验、实测利用算子、分支后果世界模型与受约束序贯策略 | 更新证据、运行探针、重放、隔离、整合、综合或自动停止；外部权限门可终止 episode | 不安全采纳、任务解决、错误隔离、成本与有效并行度 |
| 论文三：可信取证与共同理解 | 外部机制已要求开发者审核一项绑定行动之后 | 审核者是否已理解行动对代码和运行状态的事实后果 | 危险行动被误批、安全行动被误拒、审核负担上升 | 技术证据图、共同基础滤波器和受约束取证策略 | 获取或呈现证据、事实探查、澄清、修复理解或停止取证 | 真人不安全批准、安全批准、事实理解、时间与计算成本 |

三项研究都处理不完全知识，但缺失信息的来源、可观察信号和可执行动作不同。论文一的关键不确定性来自未来的运行过程，策略必须在物理时间推进时保留或行使选项。论文二的关键不确定性来自多个代理分支之间的共同来源与证据利用，策略必须通过可执行探针改变对各分支的后验。论文三的关键不确定性来自技术证据与审核者事实理解之间的距离，策略不能替人作批准决定，只能改变取证和理解修复过程。这些差异决定了三篇论文不能共享同一状态模型、损失函数或 checkpoint。

## 3. 论文一：主动缓解期权格下的可靠迁移行动

### 3.1 研究问题与安全结果

论文一研究 coding agent 在一个固定的 PostgreSQL 在线 schema migration 协议中，如何选择主协议之外的可选安全措施。主迁移阶段本身是完成任务所必需的动作，影子重放、语义验证、检查点保护和写入上限等措施则可能执行零项或多项。它们会消耗时间和资源，也可能减少后续损害。agent 还可以延期观察新的运行信息，在可接受条件下执行 cutover，或者在风险与收益不再匹配时放弃。本研究的风险结果来自真实数据库状态，包括数据错误、服务中断、旧客户端不兼容、不可恢复写入和迁移失败；减少全部行动不能被视为安全改善，因为迁移成功和正常服务能力同时进入评价。

### 3.2 模型、训练与动作

模型输入包括代码仓库、schema 与迁移脚本、旧新应用行为、运行合同、当前迁移状态、时间、资源、已执行缓解及可见观测。模型先估计措施冲击、运行事件、持续时间和状态转移的联合分布，再由硬期权格在二十一项参数化动作中选择下一步。训练样本来自 PostgreSQL、pgroll 和隔离的 old/new application families，通过共同随机条件下的 sibling rollouts 产生可执行状态、事件、成本和终局损害监督。最终工件包括代码与图编码器、因果半马尔可夫 kernel、校准器、策略权重、期权格实现及完整运行 manifest。

Benaroch 的主动风险缓解实物期权理论改变了算法的时间结构和行动格。理论区分主承诺、可选缓解、延后获得信息和不行使选项，使模型不能把所有步骤压缩为一次风险评分。其经验责任通过三类冲突检验体现：缓解措施的价值随状态与路径反转；有新信息到达时延期可能优于立即执行；当剩余承诺价值不足时放弃可以是合法结果而非任务失败的别名。等信息、等标签、等参数的通用物理分解 SMDP 是主要替代模型，若它在预注册等效界内复制全部结果，论文将不再主张理论带来独立算法增益。

### 3.3 独立贡献

论文一产生一个面向 live database migration 的学习型可选缓解控制器。它的独立贡献在于估计和组合多项可选措施的条件边际价值，并在时间推进、被动信息、物理事件与终局承诺之间执行统一决策。一般数据库诊断、静态 SQL 修补、固定 staged protocol、普通 canary 或事务回滚都不能直接替代这个决策对象。完整冻结规格见 [01H](01H_主动缓解期权格设计冻结规格.md)、[01H-A](01H-A_主动缓解期权格字段级任务与隔离Manifest.md)、[01H-B](01H-B_主动缓解期权格逐句主张与引文责任账.md) 和独立审计 [02W](02W_主动缓解期权格第五轮修补后独立冻结审计.md)。

## 4. 论文二：相关证据下的可执行分支整合

### 4.1 研究问题与安全结果

论文二研究多个 coding agent 为同一漏洞修复任务产生竞争分支时，如何在证据来源相关、信息被复制转述和有用证据未必进入后续行动的条件下决定下一步。六个分支可能形成表面多数，却共同继承同一错误 checkpoint、测试夹具或广播信息。一个独立分支也可能提出正确修复，但没有得到能够区分它与多数分支的可执行证据。总串行可以减少并发冲突，却牺牲并行价值；按票数、置信度或独立验证数量直接选择，又可能重复计算公共信息。本研究以不安全分支的实际采纳为主要风险结果，同时报告任务解决、错误隔离、计算成本和保留的有效并行度。

### 4.2 模型、训练与动作

模型输入是任务、仓库基线、六个候选分支、规范化命题、来源谱系、交换记录、可运行探针目录和预算。来源因子图把复制、广播和派生关系合并为共同信息因子，并以模型、支架、提示、任务文本和执行输出等公共父节点形成跨来源联合协方差；命题观测算子只更新适用且方向明确的结果维度。证据利用算子通过同前缀 correct、corrupt、sham 与 no-event 执行分叉，观察接收分支的结构化 reaction 及固定短视界行动，因而区分信息到达与信息实际进入后续行动。五成员世界模型预测探针、仓库动作和分支终局后果，保守离线 IQL 与四步悲观规划器选择处理证据、向既有分支请求信息、运行探针、重放、恢复、隔离、整合、综合或自动停止。若公开的外部权限门要求人工授权，episode 终止且答复不返回论文二策略；何时向人取证及如何吸收答复属于论文三。

训练环境以当前 Vul4J 数据集的 129 个条目为起点，其中 79 个以 proof of vulnerability 为基础，50 个是 SpotBugs-only 条目；它们不是同质的 129 个漏洞任务。预注册 eligibility、官方 oracle preflight 与运行可复现性共同确定主分析样本 $N_{\mathrm{admitted}}$。Natural official 结果与补充压力覆盖层分别保存、分别计算分母，任何不适用或未知的风险维都不能被填成安全。训练、验证和测试在 rollout 之前按仓库、时间、fork 和近重复关系隔离。保存工件包括来源编码器、命题编译器、证据利用模型、世界模型 ensemble、IQL critic/actor、规划配置和 eligibility manifest。

Qiu、Cheng 与 Pu 关于公共信息精度和重复公共信息的研究，使算法显式表示来源相关性和公共证据被过度计权的条件。Dennis 关于信息交换与信息使用的区分，使信息是否进入后续状态更新成为独立的可干预过程。两组理论都不直接规定代码探针、分支图或动作语法；这些 coding-specific 组件由本文承担。理论机制的经验责任在于多数来源相关与来源均匀时产生不同的证据价值和行动排序，并在交换量相同的条件下区分证据是否实际改变后续选择。等标签的匿名图模型和通用 POMDP 获得相同命题、来源、动作与终局监督，不能因理论命名而被削弱。

### 4.3 独立贡献

论文二产生的是多分支仓库控制器，而不是团队角色路由器、补丁投票器或单次 verifier。它联合学习公共来源去重、命题级后验更新、主动可执行探针和分支级行动，使“多数同源错误”和“独立少数但证据不足”成为可运行的安全决策情境。完整冻结规格见 [02S](02S_C29可执行可证明性分支整合设计修补规格.md)、[02S-A](02S-A_C29数据标签与Oracle隔离Manifest.md)、[02S-B](02S-B_C29逐句功能责任账.md) 和独立审计 [02X](02X_C29第二轮修补后独立冻结审计.md)。

## 5. 论文三：固定批准点的可信取证与共同理解

### 5.1 研究问题与安全结果

论文三研究一个外部机制已经决定必须由开发者审核的 coding-agent 行动。可信中介先把真实 diff、命令、参数、pre-state、snapshot 和权限范围绑定成不可替换的批准对象。研究不再决定何时升级、是否允许或是否拒绝，也不预测审核者会点击什么。它要解决的问题是，在有限时间和计算预算内，怎样取得和组织可执行后果证据，并根据审核者的事实回应修复理解，使开发者更少批准真实危险行动，同时不显著增加安全行动的误拒和审核负担。

### 5.2 模型、训练与动作

技术证据图以绑定行动、代码与状态差分、测试、静态分析、dry run、依赖与作用域分析及其成本为节点。共同基础滤波器区分审核者可能接触到的命题和已经通过事实回应、澄清与相互确认建立的理解。策略只能选择获取证据、呈现证据、提出事实探查、澄清、修复或停止取证。它不能输出批准、拒绝、风险分数、何时询问人类或第二审核者分配。

训练分为技术证据预训练、人类证据价值 logging 和前瞻确认性实验三个互不复用的阶段。确认性实验按参与者及其基线支持度一次分配到固定四臂，每位参与者完成十二个同臂任务。主要结果是同一审核者对绑定行动的不安全批准，次要结果包括安全批准、事实状态预测、信心校准、审核时间、交互次数与计算成本。最终工件包括技术图编码器、命题绑定器、共同基础滤波器、保守离线策略、可信证据 lattice、参与者级统计 pipeline 和完整的 action-binding/branch manifest。

Clark 与 Schaefer 关于 presentation、acceptance、repair 和 purpose-relative grounding criterion 的分析，以及 Clark 关于 joint activity、joint purpose 与 identification、ability、willingness、mutual belief 四项要求的论述，为互动过程提供理论责任。Mastrogiacomo、Missonier 与 Bonazzi 把这些机制适配到信息系统项目会议，并围绕 objective、resource、risk、commitment 四类内容观察理解问题、对话与修复；该研究不提出 potential common ground 与 established common ground 的术语二分。Li、Gatt 与 Poesio 的 potential/established 区分支持本文对潜在共享与已建立理解的操作化。内容 manifest 在实验前外生冻结；本文把解释后验、相互确认与修复写成可更新状态，但不把证据有效性、测试生成或行动绑定归因于共同基础理论。主要机制检验要求取证策略先改善可观察的事实 grounding，再影响不安全批准，并与获得相同人类历史和候选动作的 Human-state POMDP 公平比较。

### 5.3 独立贡献

论文三产生的是 post-escalation 的可信序贯取证策略。Consent Integrity、proof-carrying action、可执行验证、主动测试和一般 selective explanation 分别提供必要基础，但没有同时学习绑定 coding action 的下一项可执行证据、审核者事实理解修复和真人危险误批结果。完整冻结规格见 [00H](00H_论文三可信取证与真人实验冻结规格.md)、[00J](00J_候选三共同基础理论责任红队与撤题判定.md)、[00H-A](00H-A_论文三标签日志与Oracle隔离Manifest.md)、[00H-B](00H-B_论文三逐句功能责任账.md) 和独立审计 [02V](02V_C3第五轮修补后独立冻结审计.md)。

## 6. 三篇论文如何共同构成博士论文

三篇论文围绕同一因果链中的不同知识边界，而不是把一个系统拆成前后模块。

1. 论文一研究 agent 面对未来环境时怎样保留和行使行动选项。其决策对象是单个迁移 episode，核心状态随物理时间和运行事件变化。
2. 论文二研究多个 agent 的证据彼此相关时怎样取得区别性证据并整合分支。其决策对象是竞争分支集合，核心状态随来源、交换、利用和仓库探针变化。
3. 论文三研究人类获得批准权后怎样建立足够的事实理解。其决策对象是绑定行动与审核者互动，核心状态随取证、事实回应和理解修复变化。

这种安排形成“未来环境—代理群体—人机共同活动”三个边界。三个研究都在承诺前介入，但介入动作分别是缓解与延期、探针与分支控制、取证与理解修复。论文一不能用论文二的来源后验决定迁移，论文二不能依赖论文三的真人批准完成安全判断，论文三也不需要论文一的数据库 kernel 才能成立。每篇都有独立的数据生成器、训练集、模型权重、评价任务和主要结果；任一篇的负结果不会由另一篇的正结果补足。

理论上，三篇论文共同说明可靠行动并不只取决于一个模型是否“知道”某项事实。知识必须在正确的时点保留选择权，在多个来源间按其依赖关系被处理，并在人机共同活动中转化为可观察的事实理解。实物期权、公共信息精度与信息使用、共同基础分别改变上述三种转换机制。它们相互呼应，却不共享同一理论模板。

方法上，三篇可以复用容器编排、哈希 manifest、结果封存、运行日志和开放权重 code encoder 等基础设施。复用只发生在工程层。训练样本、标签服务、隐藏 oracle、策略网络、checkpoint、数据划分和主要评价均独立保存。共享基础设施不得成为跨论文信息通道。

## 7. 经验状态与写作边界

截至 2026 年 8 月 16 日，三项研究均完成研究设计冻结，尚未运行正式训练、确认性评价或真人实验。正式论文中的方法、数据构造、预注册机制和评价方案可以使用确定语气；任何性能、效应量、显著性、中介结果或模型排名都必须保留为“待运行”占位。结果表将预先给出行列、指标、统计量和判断规则，但不填入虚构数字。

三篇正式正文分别在独立子文件夹中写作。每个正文段落必须同步生成肖帅勇两篇 ISR 论文的逐句功能对照记录，每条引文必须同步进入引用核验表。写作参照采用 [00W](00W_肖帅勇两篇ISR源行句段主键Manifest.md) 的精确句段主键和 [00F](00F_逐段双ISR写作与引用审计协议.md) 的功能责任规则。参照的对象是句子在论证中的作用、引文对相邻命题的支持以及段落之间的推进关系，不复制原句，也不把位置相近误写成学术功能同位。
