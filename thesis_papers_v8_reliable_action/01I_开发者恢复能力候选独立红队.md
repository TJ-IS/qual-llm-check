# C15 开发者恢复能力保持候选独立红队

> 审查对象：`01E_开发者恢复能力保持候选终审.md` 所定义的 C15 候选  
> 文献截止：2026-08-15  
> 审查立场：不继承 01E 的结论，只判断当前题目能否冻结为一篇以 IS 理论驱动算法的独立论文  
> 终局判定：**NO-GO**

## 0. 结论先行

C15 的实验情境可以严谨构造。真实开发者可以在隔离仓库中完成 agent-assisted 变更，数日后在 agent unavailable 条件下处理隐藏事故；随机分派参与动作、测量任务成功、人时、延迟恢复和残余损害，也不存在原则上的数据障碍。因此，本次否决不以“没有公开多轮数据”“尚未训练”“尚无正结果”为理由。

当前题目不能冻结的原因发生在实验之前。Rinta-Kahila 等人提出的 activity awareness、competence maintenance 与 output assessment 是三类 mindful-conduction 活动，不是三个潜在能力，也不是三条已经识别的技能转移函数。01E 把它们保留为可观察参与类型，又另建 procedural、declarative 与 incident-recovery 三个能力状态，这避免了最直接的概念错误，却没有形成理论不可替代的计算结构。三类活动可被匿名编号、置换或由原始行为特征重新学习；三类能力可在不改变终端预测和策略的情况下旋转或重标。理论实际留下的算法约束主要是少数平均方向符号。相同数据、参数、动作和训练预算的 raw-history POMDP，或与候选等结构但匿名的状态空间模型，原则上能够复现同一状态更新与策略。

因果识别也没有闭合。随机分派某项参与动作可以识别该动作的意向处理效应，却不能自动识别“观察到的 facet 参与导致潜在技能变化，再导致延迟恢复”的中介链。实际参与是处理后的依从行为；能力是由探针推断的潜变量；延迟恢复还同时受到仓库记忆、任务迁移距离、既有经验、动机和干预产生的测试、契约或笔记等可执行资产影响。尤其是 01E 主张让开发者构造测试、约束和不变量，这些资产会直接帮助未来事故发现与恢复，即使人的能力完全未变。若保留资产，技能中介的排除限制不成立；若删除资产，处理又不再对应真实开发工作。

直接工作进一步收窄了可主张空间。Buçinca 等人已经用离线强化学习选择 AI 支持并联合优化当前表现和后续无辅助学习；Geometry 已经形式化委派、练习、技能衰减与路径依赖；HAAS 已经在软件工程中学习五档人机任务分配并显式表示 skill；SymPareto 的可核摘要已经覆盖技能保持与 AI 增长的 Pareto 调度；Agents That Teach 已直接提出 coding-agent knowledge debt、telemetry、concept map、probe 和 learning intervention；Anthropic RCT 已随机识别 AI 辅助对开发者即时技能形成的影响。更致命的是，2026 年的 AI Coaching 已经联合表示潜在技能 belief、教练动作对技能演化的因果模型、未来无辅助价值和 POMDP/RL，Proximal State Nudging 也已联合优化即时安全与未来无辅助技能。C15 剩下的是 coding-agent 延迟事故这一重要外部结果与测量环境，而不是一种由 Rinta-Kahila 理论独有地产生的算法能力。

因此，C15 按当前 MEC→MAP→ALG 主张判为 **NO-GO**。它可以另行发展为一项关于 agent-assisted development 与延迟独立恢复的随机化 HCI/软件工程研究，也可以成为构造 delayed-recovery benchmark 的经验项目；在没有新的、不可同构复制的理论机制之前，不能作为本系列三篇 ISR 级理论算法论文之一。

## 1. 红队判定口径

本审查把三个问题分开。

1. **设计可实施性。** 能否构造任务、招募参与者、收集随机轨迹并训练模型。答案是可以，至少 pilot 层面可行。
2. **设计可冻结性。** 理论构念、处理、测量、因果图、算法责任和直接工作边界是否已经清楚到足以预注册。答案是否定的。
3. **未来经验效应。** facet-matched action 是否提高能力，learned policy 是否降低延迟损害。这些是未来假设，未运行不能判真，也不应被用来掩盖设计层面的不可识别与同构问题。

判为 NO-GO 需要至少一个不依赖未来正负结果的致命条件。本候选同时触发两个：理论状态可以被等结构匿名模型同构替代；处理对延迟恢复存在无法忽略的技能之外直接通道。直接工作覆盖强化了否决，但不是唯一依据。

### 2.3 相邻 IS 理论的边界

Afiouni 与 Pinsonneault 2026 年 JAIS 的 Human-in-Control 模型讨论 AI 委派中的个人控制、偏好—情境一致性以及多条控制适应路径。该文也谈及保持技能和责任，却以概念模型解释个人控制过程，并未给出 facet-specific skill transition 或 delayed recovery policy。它支持“AI 委派中的责任、权限和技能保持是 IS 问题”，不能为 C15 的潜在状态或训练损失提供额外唯一性。

## 3. Rinta-Kahila 理论是否产生不可替代的模型状态

### 3.1 原理论实际承担的责任

Rinta-Kahila 等人研究 cognitive automation 下的技能侵蚀。他们从案例材料中归纳三类 mindful conduction。

- activity awareness 是对具体工作步骤的执行、监督或研究，主要关系到程序性知识的维持。
- competence maintenance 是取得或更新完成任务所需的领域知识，主要关系到陈述性知识。
- output assessment 是检查和验证自动化产出，需要相关陈述性知识与判断。

原文把这些 facet 作为 conscious engagement 的不同表现，也把它们视为难以直接测量技能时可能使用的 warning signs 或 proxies。它没有宣称三者是互斥处理，没有把三者建立为三个潜在能力维度，也没有给出独立的三条状态转移方程。原文能力本体只明确区分 procedural knowledge 与 declarative knowledge。所谓 incident-recovery skill 是 C15 为安全结果新增的能力，不来自原理论。

原研究的资料还不能识别微观转移。研究者通过 25 次访谈和一个会计自动化案例回顾反馈环；只有少数受访者直接经历技能侵蚀，资料没有实时纵向追踪个体在每次工作参与后的能力变化。论文自己的限制明确留下 fine-grained actions、states、interactions、timing 和 skill-erosion management mechanisms。由此可以提出待检验机制，不能把这些机制视为已由理论确定的转移真值。

### 3.2 对 01E 的 MEC→MAP→ALG 逐级判决

| 层级 | 01E 的最强表达 | 红队判决 |
|---|---|---|
| MEC | reliance 与 complacency 减少三类 mindful conduction；长期少参与使程序性、陈述性能力侵蚀；在仍有 residual responsibility 时损害未来恢复 | **部分有理论依据。** reliance—complacency—mindful conduction—skill erosion 的方向来自原文；residual responsibility 的安全边界合理。delayed executable recovery 是新外部结果，尚非原理论机制 |
| MAP | 分开表示义务图 `G`、facet participation `X`、latent capability `K`、loop state `U`、future demand `D` 与 residual responsibility `R` | **大部分来自任务工程而非理论唯一映射。** `X`/`K` 分离是概念卫生；`G,D,R` 来自 coding-safety 情境；`incident-recovery` 来自结果设计；`U` 的个体 complacency 也缺少独立在线锚定 |
| ALG | graph-temporal action-conditioned transition，加 facet-specific sign loss，再用 constrained offline POMDP/CQL/IQL 选真实参与动作 | **没有被理论唯一导出。** 图、POMDP、离线 RL 和风险约束来自通用序贯决策；三类动作名称及少数符号约束可由匿名 action embedding 和数据学习替代 |

这个映射没有满足肖老师两篇 ISR 论文所展示的核心逻辑责任：理论不仅要给构念名称，还要指出通用算法在冲突情境中会沿哪个方向系统性计算错误，并导出一个无法通过同信息重参数化获得的纠正。C15 可以说明“总参与时长会忽略参与方式差异”，却不能说明为何一个读取相同 action identity、原始轨迹和 anchor outcome 的通用 temporal model 必然处理错误。后者可以从随机数据直接学习哪类动作在何种状态下更有效。

### 3.3 同构性证明

设理论模型在节点 `v`、时间 `t` 使用三类参与表示

`X_t(v)=[x_A,x_C,x_O]`

并以动作条件转移更新能力 belief

`K_{t+1}=F_θ(K_t,X_t,H_t,G_t)`。

对任一三阶置换矩阵 `P`，令 `X'_t=P X_t`，同时把转移函数第一层对应权重改为 `W'_X=W_X P^{-1}`，策略层对应槽位也按 `P` 重排。终端能力预测、动作概率和 reward 完全不变。若 `K` 只靠联合训练的多个 head 表示，还存在可逆变换 `Q`：`K'_t=QK_t`，上下游权重分别乘 `Q^{-1}` 和 `Q` 后，终端输出仍不变。少数独立 anchor 可以固定部分尺度与方向，却不能使 facet 名称本身成为不可替代状态。

理论模型还可逐层改写为匿名等结构模型：

- 把三类 facet 名称换成 `a1/a2/a3`，保留完全相同的三槽张量。
- 让每个 action ID 的作用方向由数据学习，不加入预设语义。
- 把 procedural/declarative/recovery 换成三个由独立行为任务监督的 `z1/z2/z3`。
- 保留同一义务图、时距、responsibility mask、transition block、policy head、reward 与约束。

这个匿名模型不是较弱的“黑盒基线”，而与理论模型存在参数双射。只要训练数据包含 action assignment 和 anchor outcome，它就能表达理论模型能表达的所有策略。若理论版表现更好，差异只能来自有限样本下的手工先验或额外监督；若要把这种差异称为理论算法贡献，必须证明预设方向在跨仓库和长时距 OOD 中稳定、且不能由相同数量的 learned sign parameters 或通用 monotonic regularization复制。Rinta-Kahila 的回顾性案例不足以承担这个强先验。

### 3.4 三 facet 不是三个可分离“剂量”

真实动作经常同时触发多个 facet。开发者亲手修复一个迁移错误，既执行步骤，也更新领域知识，还可能验证输出；阅读 agent 轨迹既可能形成 activity awareness，也可能只是被动暴露；构造 property test 同时需要 competence 与 assessment。把每个动作硬分到一个 facet 会制造标签噪声，把动作表示为三维连续剂量又需要独立测量各剂量。原理论没有给出可观察行为到三维剂量的唯一编码规则。

因此，matched versus mismatched treatment 在冻结前就缺少稳定含义。若“匹配”依据研究者给动作贴的 facet 标签，而动作在内容、难度、反馈、独立性或产物价值上不同，随机比较识别的是整个动作包的差异，不是 facet 的差异。仅匹配耗时不足以排除这些替代机制。

### 3.5 `Fθ + L_dir` 是否只是通用 graph KT 加三个单调项

答案是肯定的。01E 的 `Fθ` 由 relational message passing、temporal Transformer 与 action-conditioned transition head 构成。这样的 backbone 在没有理论状态时已经能够表示任意节点历史、动作和能力结果之间的非线性关系。`L_dir` 只要求，在相关义务、行动成功和测量可靠的支持域内，activity-awareness exposure 对程序性能力的平均转移不预设为负，competence-maintenance 与 output-assessment exposure 对相应陈述性能力的平均转移不预设为负。它没有规定信息必须沿 reliance→complacency→facet participation→skill stock 传播，也没有阻止 unrestricted `Fθ` 通过其他通道直接从 raw history 预测 `K` 和 policy。

这三个约束还是几乎任何学习模型都会采用的显然先验。若一次正确、相关的真实练习被模型学成平均损害对应能力，首先应怀疑标签、选择偏差或任务失配，而不是依靠某项 IS 理论才能发现方向错误。把三项 hinge/monotonic penalty 加到通用 graph KT 上，不能满足理论改变前向计算的要求；它们至多是辅助 regularizer。

### 3.6 把反馈环升级为有向循环状态能否救援

最强救援不是再加 `L_dir`，而是把原理论反馈环实现为显式结构状态模型。令 `r_t` 表示 automation reliance，`c_t` 表示 complacency，`x_t^f` 表示三类参与，`k_t` 表示程序性与陈述性 skill stock，`p_t` 表示 agent 相对表现。模型只能按以下有向关系更新：

`p_t,k_t → r_{t+1}`，`r_t,p_t → c_{t+1}`，`c_t,Z_t → x_{t+1}`，`x_t,Δt → k_{t+1}`，`k_{t+1},p_{t+1} → r_{t+2}`。

策略通过对 `Z_t` 做干预滚动这个闭环，比较“短期 agent 表现提高但长期人类能力下降”的轨迹，而不是把 `r,c,x,k` 一次性拼接后直接预测 reward。这个版本比 01E 当前实现更忠于 vicious-circle 叙述，也能产生多步反馈和路径依赖。

它仍不能救援 C15，理由有三。

第一，闭环的计算图仍可被精确匿名化。把 `r,c,x,k` 换成 `z1,z2,z3,z4`，保留同一有向邻接、状态维数、转移族、符号和干预位置，匿名模型与理论模型存在逐层参数双射。若匿名模型连有向邻接也从数据学习，固定环只是结构先验；若匿名模型获知同一邻接但不知道名称，它与理论模型完全等价。Rinta-Kahila 理论给了这个环的解释语义，却没有产生不能被同标签匿名模型置换的运算。

第二，现有数据不能识别整条环。micro-randomization 只外生改变 `Z_t`，没有随机化 reliance 或 complacency。agent 表现、既有能力、任务难度、时间压力和组织规范会共同影响 reliance、complacency 与参与；`r_t` 和 `c_t` 若主要从同一 delegation trace 或问卷推断，二者的方向与区分依靠先验而非数据。每人 4–6 个 episode 加两个保持波次不足以从 observational segments 区分 `r→c→x`、`c→r→x`、`skill→reliance` 和共同原因。强行固定有向环会把案例理论当成已识别的 causal transition。

第三，直接工作已覆盖这种一般动态形式。Geometry 已有 skill—delegation feedback 与路径依赖，AI Coaching 已有 action-conditioned skill progression、belief state 和未来独立能力策略，HAAS 已有 skill/trust/fatigue 与 allocation co-evolution。C15 的环若不依赖三 facet，只是这些动态系统的 coding 图扩展；若依赖三 facet，又回到 facet 重叠、动作 bundle 和匿名置换问题。

因此，显式有向循环状态是比 `Fθ + L_dir` 更诚实的实现，却仍不满足理论不可替代性。它可作为一个解释性结构假设与消融对象，不能承担独立理论算法贡献。该救援失败进一步巩固 **NO-GO**。

## 4. `observable facet → latent skill → delayed executable recovery` 的因果识别

### 4.1 必须先区分 assignment、participation 与 exposure

令 `Z_t` 为随机分派的参与动作，`X_t` 为实际观察到的 facet participation，`K_t` 为潜在能力，`A_t` 为干预留下的可执行资产，`Y_{t+1}` 为延迟恢复。最小因果图应包含：

`Z_t → X_t → K_{t+1} → Y_{t+1}`

并同时包含：

`Z_t → A_t → Y_{t+1}`，`Z_t → memory/familiarity → Y_{t+1}`，`prior skill → X_t`，`prior skill → K_{t+1}`，`prior skill → Y_{t+1}`。

micro-randomization 使 `Z_t` 可外生，因而可以识别安全支持域内的 assignment ITT。`X_t` 是依从、投入和正确执行之后的处理后变量。高能力或高动机者更可能真正完成参与动作，也更可能在延迟事故中成功。用 propensity 或 doubly robust loss 不能自动消除未测量的依从混杂；它只在处理概率已知、结果模型适当和重叠成立的范围内改善估计。

### 4.2 潜在能力不是一个可直接监督的标签

无 agent probe、API 迁移题和事故任务可以作为能力 anchor，但至少需要四项证据。

1. 同一潜在构念有多个相互独立且难度校准的测量，而不是一题一个 head。
2. 不同时间、仓库、语言和处理组满足足够的 measurement invariance；否则 score change 可能是题目难度或熟悉度变化。
3. probe 不重复干预内容，也不泄露未来 incident family；否则能力提高与记忆答案无法区分。
4. recovery 不应同时被定义为潜在 skill head 和终端结果。若同一事故表现既监督 `K_recovery` 又评价 `Y_recovery`，中间状态只是在重新编码结果。

程序性与陈述性能力能否形成可分离因子，incident recovery 是独立因子还是前两者加仓库经验的形成性结果，均是待验证的测量问题。01E 目前先验地设置三种能力，超出了 Rinta-Kahila 理论责任。

### 4.3 可执行资产形成致命的直接通道

C15 最有实践价值的动作包括落实 contract、assertion、property test、migration guard、acceptance condition 和独立证据。这些动作会改变仓库本身。数日后发生事故时，更好的测试或约束可能直接暴露错误、缩小搜索空间或阻止损害，开发者也可以重用先前产物。于是，处理改善 `Y` 既可能因为人的能力提高，也可能因为软件可验证性提高。

这个问题不能靠“延迟测量”解决。可考虑 2×2 析因设计，把参与者是否接受 skill-targeted action 与 t1 是否保留其产物分别随机化；然而删除真实产物会改变仓库语义和处理真实性，保留产物又使人的能力中介不具排他性。即使析因设计估计了 asset channel 与 person channel，总效应仍属于人—软件联合干预，而不是 Rinta-Kahila facet 通过技能变化产生的独特机制。

### 4.4 `K → recovery` 的中介主张仍需强假设

随机化 `Z` 不等于随机化 `K`。若要把处理效果分解为经由能力的间接效应，需要处理后中介—结果关系不存在未测量混杂，或需要额外的可辩护工具变量与 exclusion restriction。未来恢复受到 prior expertise、repo navigation、任务迁移距离、记忆、动机、当日疲劳、incident severity 与团队背景影响；其中多项会同时影响 probe 和恢复。输出评估或恢复演练还可能直接教会 incident pattern，进一步破坏 exclusion restriction。

因此，当前设计可以诚实主张：某个随机参与动作是否改变后续独立恢复的总效果；也可以预测 latent state。它不能在没有更强设计时声称已识别 `facet → skill → recovery` 的因果中介链。理论算法若依赖该链训练 transition，得到的是带结构假设的预测模型，而不是已识别的 causal world model。

## 5. 直接工作覆盖审计

### 5.1 六项指定近邻

| 直接工作 | 已直接覆盖的核心 | C15 尚存差异 | 红队含义 |
|---|---|---|---|
| Buçinca et al., TOCHI 2026 | human state、四类支持动作、当前正确率、未来无辅助学习 reward、offline Q-learning、prospective randomized evaluation | 非 coding；后测短；没有 repo obligation 与安全事故 | “用 offline RL 在效率与未来学习间选支持”已完成。C15 不能以 POMDP/CQL 或双目标 reward 为算法贡献 |
| Geometry, 2026 | latent skill、delegation、practice、nonuse decay、path dependence、双稳态和长期干预 | 抽象任务；非真实 coding-agent 纵向数据 | “委派造成技能衰减并应保留练习”已形式化。facet 图只能算结构细化 |
| HAAS, 2026 | 软件工程任务、五档人机协作、skill/fatigue/trust、policy guard 加 contextual bandit | human dynamics 主要仿真；无 delayed recovery | 软件工程中的动态分工与 skill-aware allocation 已直接覆盖；真实人类外部效度是 C15 的差异，不是理论算法唯一性 |

### 5.2 两项比 01E 更致命的新近邻

**AI Coaching for Accelerating Human Skill Development with Reinforcement Learning。** Wang 等人把人的 latent skill 作为 coach 不可完全观察的状态，维护 belief，建立 coaching action 对 skill progression 的概率因果模型，并以 future independent competence 为目标训练 POMDP/RL coach。真人无人机研究虽然短且非 coding，却已占据 C15 想主张的核心算法组合：潜在能力、action-conditioned transition、未来无辅助结果和序贯策略。换成 repo graph 和 delayed recovery 是重要领域扩展，不能单独构成理论算法原创性。

**Proximal State Nudging。** Srivastava 等人把 assisted 与 unassisted value 差异用于估计状态 learnability，规划器联合优化当前任务表现与未来无辅助技能，并在 CARLA 人体实验中报告安全结果。它直接反驳“现有工作只优化 quiz 而没有安全后果”的宽泛空白。C15 仍有软件事故与组织责任差异，但“安全—即时表现—人类技能”联合决策已不是空白。

### 5.3 交集后的真实剩余空间

近邻尚未共同完成的是：专业开发者在 agent 完成真实 repo change 后，跨数日或数周、在 agent 不可用时处理与原义务相连但未泄露的隐藏事故，并以 containment、rollback correctness、residual harm、time-to-recovery 和 human burden 评价。

这个剩余空间足以支持一项有价值的实证研究或 benchmark。它不足以支持“Rinta-Kahila 理论产生了新的算法状态与策略”。研究情境的新颖性、结果测量的新颖性和理论算法的新颖性必须分开判断。

## 6. 公平的同数据、参数与预算反证

### 6.1 应比较的四个模型

1. **C15-theory。** 使用义务图、三类 facet、显式 procedural/declarative/recovery belief、reliance/complacency、future demand 和 residual responsibility，带理论方向损失。
2. **Anonymous-isomorphic。** 使用完全相同的块数、张量形状、transition 和 policy head；把 facet 和 skill 名称匿名化，符号与 cross-transfer 由数据学习。参数总量与 C15-theory 控制在 ±1%，而非宽松的 ±5%。
3. **Raw-history POMDP。** 直接读取相同原始 IDE/terminal/patch/test/history、义务图、time gap、action mask、anchor outcomes 和责任变量，由等参数 graph-temporal encoder 形成 belief，再训练相同 CQL/IQL 或 actor-critic policy。
4. **Direct outcome policy。** 不显式预测 skill，直接预测每项动作下 delayed recovery、residual harm、task success 和 cost 的分布，以相同约束选动作。这检验 latent theory state 是否有超出结果预测的必要性。

TOCHI offline Q-learning、HAAS、Geometry-derived policy、Agents That Teach 固定支架以及取得全文后可复现的 SymPareto，应作为外部直接基线；它们不能替代上面两个同构反证。

### 6.2 必须严格相同的资源

| 资源 | 公平约束 |
|---|---|
| 数据 | 完全相同的参与者 episode、仓库版本、随机 assignment、raw trace、graph、anchor、incident outcome 与 missingness mask |
| 信息时点 | 推断时只给 t0 已知信息；所有模型同样看不到 t1 incident、hidden tests、future patch、gold recovery 和后续 issue |
| 动作 | 同一 action mask、同一安全限制、同一人时和 agent token/tool 预算 |
| 模型容量 | trainable parameters ±1%；相同 graph depth、history length、latent width 和输出头数。若 theory model 获得额外 hand-coded labels，匿名模型获得等维 categorical IDs |
| 优化 | 相同 optimizer family、训练 step、batch、early-stop rule、OPE estimator、seed 数与超参数搜索 trial 数 |
| 策略评价 | 相同 behavior support、同一 prospective participant/repo/time split、同一 CVaR 或约束阈值 |
| 结果 | delayed hidden recovery、containment、residual harm、initial task success、human time、release delay 与 compute；不以 facet F1 或 skill AUC 决胜 |

### 6.3 决胜检验

- **名称置换。** 在每个 seed 内随机置换 facet 名称，同时一致置换动作标签。若 policy frontier 不变，名称没有理论责任。
- **结构匿名。** 保留三槽结构但删除所有语义和 sign loss。若结果不劣，贡献只是结构容量。
- **raw-history 等参数。** 允许通用模型直接使用原始行为。若其在 participant/repo/time-disjoint test 上复制安全—成本前沿，显式理论状态没有新增能力。
- **anchor rotation。** 使用多个独立任务固定能力轴，并检验 measurement invariance。若 latent slots 在等价旋转后终端结果不变，不能赋予程序、陈述和恢复的实质含义。
- **action bundle decomposition。** 在相同内容、难度、反馈、独立程度、可执行产物和耗时下只改变拟研究 facet。若无法构造这种干预，matched/mismatched 不是 facet 机制检验。
- **asset-channel factorial。** 分开随机化 person participation 与干预资产在 t1 的可用性。若主要效果来自资产保留，论文研究的是软件验证资产而非开发者能力保持。
- **loop deletion。** 删除 reliance/complacency belief，只保留最近表现与使用历史。若 policy 不变，Rinta-Kahila 反馈环没有算法责任。
- **responsibility neutralization。** 在 future demand 相同但 residual responsibility 不同的情境检查行动差异。这个机制若有效，贡献来自责任边界，而不是三 facet 理论；应重新选择更合适的责任或控制理论。

### 6.4 预期判定而非预写结果

当前不能声称匿名模型一定在数据上打平。红队能在设计阶段确定的是：匿名等结构模型与理论模型存在表达层面的参数双射，C15 尚未给出理论强制的非同构运算。未来 theory model 若因先验而样本效率更高，这是可检验结果；它不能反向证明该先验具有理论唯一性。只有在冻结前先说明哪一个不可重参数化的运算由原文强制、以及通用模型为何在某类冲突中必然算错，才有资格把未来比较当作理论算法检验。C15 尚未做到。

## 7. 最强可实现设计及其上限

为避免把可实施性误判为零，下面给出本题最强可实现版本。它说明工程路线可行，也说明 NO-GO 来自贡献与识别而非无法训练。

### 7.1 输入、张量与输出

对 batch `B`、历史步 `T`、义务节点 `N`、可观察动作类型 `A`，输入包括：

- graph node tensor `H_G ∈ R^{B×T×N×d}`，编码文件、函数、API、schema、test、build/deploy/rollback 与 invariant 节点。
- raw event tensor `H_E ∈ R^{B×T×L×e}`，编码 IDE、terminal、tool call、patch attribution、test result、参与时长和 agent visibility。
- assignment/compliance tensor `Z,X ∈ R^{B×T×N×A}`，明确区分随机分派和实际完成。
- anchor tensor `Y_K ∈ R^{B×T×N×m}` 及 missing mask，包含无 agent 程序执行、知识迁移与独立恢复任务。
- demand/responsibility tensor `D,R`、time gap、仓库状态与 action mask。

模型输出每个可行动作下的 capability belief distribution、delayed recovery survival distribution、residual-harm distribution、初始任务成功率、人时和 compute，并产生 constrained action policy。终端决策必须是执行某项真实参与、agent-only、延期演练或停止，不是只输出一个 skill score。

### 7.2 样本、标签与训练

在隔离仓库内进行 participant×episode micro-randomization。`t0` 随机分配安全支持域内的真实参与动作；7–14 日后进行 agent-unavailable hidden incident，28–42 日进行保持测试。标签来自容器执行、隐藏测试、时间戳、正确 rollback/containment、残余损害和人时，不来自 LLM 对人的主观评分。

可用 relational graph encoder 加 temporal state-space/POMDP transition，联合优化：

- anchor measurement likelihood；
- action-conditioned transition likelihood；
- delayed recovery 与 harm 的 survival/distributional loss；
- calibration loss；
- behavior-policy support 与 conservative offline RL loss；
- task-success、人时、compute 和 CVaR harm 的约束。

理论方向损失只能作为需消融的弱先验，不能把未识别路径硬编码为真。训练、验证和测试按 participant、repo family、task family、time window 与 incident family 同时隔离；同一上游 commit 的变体不能跨 split。hidden tests、future issue、incident mutation 和 gold recovery 只能在 evaluator 侧，任何由它们导出的 embedding、retrieval index、difficulty feature 或 LLM summary 都属于泄漏。

### 7.3 算力与工件

任务数据的昂贵部分是真人 longitudinal collection，不是大模型训练。图时序模型与 offline RL 可以在单机 1–4 张 24–48GB GPU 上完成多 seed 训练，具体时长需由 pilot 后的节点数、历史长度和 episode 数测算。应固定 agent checkpoint/API snapshot、container image digest、repo commit、randomization manifest、propensity、action mask、hidden evaluator digest、split manifest、配置和 seed。产生的工件包括匿名与理论状态模型 checkpoint、policy checkpoint、graph builder、containerized incidents、OPE report 和 leakage manifest。

这一版本是 design-feasible，却仍然 empirically-unproven。更重要的是，它的主体是一套通用 causal/sequential human-state learning pipeline；三 facet 没有使其中任何层成为 Rinta-Kahila 理论独有。

## 8. 设计冻结门与未来实证假设必须分开

### 8.1 设计冻结前必须已经解决的事项

| 冻结门 | 当前状态 | 判定 |
|---|---|---|
| 取得并逐节阅读 SymPareto 全文，核对状态、转移、目标、基线和资产 | 未完成 | 未冻结 |
| 把三 facet 明确为 assignment、observed compliance 还是 latent dose；给出互斥或多标签编码规则 | 01E 同时使用动作类型与参与张量，未解决重叠 | 未冻结 |
| 给出 facet-only intervention，控制内容、难度、反馈、独立性、产物和时间 | 只有 equal-time matched/mismatched，不足 | 未冻结 |
| 为 procedural/declarative 构建多题 anchor，并判断 recovery 是独立潜变量还是结果 | 尚无测量模型和 invariance 证据 | 未冻结 |
| 处理可执行资产对 t1 的直接效应 | 未建立析因或分解设计 | 未冻结 |

这些事项不是“等 pilot 看结果”的假设。处理与测量定义、direct-work 全文、信息隔离和公平反证必须在招募确证性样本前完成。尤其是非同构运算缺失不能由未来显著性补救。

### 8.2 可以留给未来数据检验的事项

- AI-agent delegation 在 7–14 日和 28–42 日是否降低独立恢复，效应是否达到预注册的实践重要阈值。
- 特定随机参与动作是否改善对应 anchor，是否比预算匹配的其他动作产生更大总效应。
- 能力变化是否预测 delayed containment、rollback correctness 与 residual harm。
- learned policy 是否在初始任务成功、人时、release delay 和 compute 约束下改善安全—效率前沿。
- 效应是否因经验、仓库、语言、incident family、future demand 和 residual responsibility 异质。
- 状态模型是否校准，long-horizon OPE 是否与 prospective trial 一致。

这些假设即使全部得到支持，也只能证明干预和策略有效。若 anonymous-isomorphic 或 raw-history model 同样有效，理论算法贡献仍不成立。

## 9. 与相邻候选的边界

| 候选边界 | C15 原定对象 | 红队后应如何处理 |
|---|---|---|
| C3 | coding-agent 行动前的风险状态、验证或后果判断 | C15 若主要靠新增 test/contract 降低事故，已经转为验证资产与后果控制，应回到 C3 类问题，而非声称人类 skill 中介 |
| C5/C14 | 人类审批、监督或信息呈现 | C15 若主要动作退化为解释、probe、概念卡或审批提示，会被 TOCHI、SHIELD 与 oversight 研究覆盖，不再是 delayed recovery policy |
| C10 | 权限、责任或 autonomy boundary | residual responsibility 若成为真正驱动动作差异的核心，理论应围绕责任—权限错配或人类控制，而不能继续由三 facet 承担算法新颖性 |
| 状态迁移/恢复候选 | agent 或软件系统在故障后的恢复、回滚与补偿 | C15 若让模型直接诊断和修复 t1 incident，研究对象变成系统恢复策略，不再是人的能力保持 |

这张边界表也说明 C15 的最佳外部结果是真实且重要的，但理论归属不稳定。不同有效机制会把题目分别拉回已有候选，三 facet 没有形成能稳定固定研究身份的算法核心。

| `ACAA-M10b/M11/M12` | 在信号冲突时给出不同于通用方法的可观察行为 | residual duty 与 future demand 能产生合理冲突；facet 匹配不能排除 raw action learner | 冲突主要来自责任约束，不来自三 facet |
| `DSDL-E11–E14b` | 中和、打乱、替代模型分别检验中间机制 | 01E 已列 permutation、rotation、mismatch 与 deletion | 检验方向正确，但理论模型与匿名模型本来同构，未来胜负不能创造理论唯一性 |
| `ACAA-P5.2` | 基线按能力层级逐步加强，最强替代必须公平 | 已含 TOCHI、HAAS、generic POMDP；遗漏 AI Coaching、PSN 和匿名同构模型 | 直接工作与最强反证未冻结 |

逐句责任的核心缺口可以压缩为一句：原理论支持“不同类型的 mindful participation 可能关系到不同知识维持过程”，但 C15 需要更强的句子——“这三类活动构成一个有固定坐标、可由行为识别、能因果更新潜在能力并决定最优安全动作的状态系统”。没有主文证据，也没有独立设计能承担后一句。

## 11. 撤题门与最终判定

### 11.1 已触发的设计层撤题门

1. 三类 facet 作为状态槽可以任意置换；理论模型可被等结构匿名模型参数重标。
2. procedural/declarative/recovery 能力坐标未由理论固定，recovery 是新增结果能力。
3. 参与动作是多机制 bundle，equal-time matched/mismatched 无法只改变 facet。
4. 可执行验证资产对 delayed recovery 存在独立直接通道，技能中介排除限制不成立。
5. AI Coaching 已直接覆盖 latent-skill belief、causal progression model、future independence 与 POMDP/RL 的组合；PSN 已覆盖即时安全与未来无辅助技能的联合规划。
6. SymPareto 全文尚未取得，直接工作内部重合度不能完成冻结。

第一至第四项均不依赖未来实验结果，其中第一项单独足以否决“Rinta-Kahila 理论驱动算法”的主张。

### 11.2 不应被误作撤题理由的事项

- 尚无现成的 6–8 周 coding-agent 人体轨迹。
- 需要自行构造 t0/t1 incident pair。
- 结果尚未运行、效应量未知。
- 确证性招募成本较高。

这些是资源与经验不确定性，不是当前 NO-GO 的依据。若题目只要求实证 HCI/SE 研究，它们可通过 pilot、功效分析和分阶段数据收集管理。

### 11.3 终局

**NO-GO。**

该结论针对当前 C15 作为“Rinta-Kahila 理论产生专用状态转移和序贯安全策略”的论文身份。delayed agent-unavailable executable recovery 仍是值得研究的现象，真人 longitudinal benchmark 也具有价值；但现有理论只提供活动分类与反馈方向，不能排除同数据、同参数、同预算的 raw-history POMDP 或等结构匿名模型。处理产生的软件资产又使 facet→skill→recovery 的中介解释无法按当前设计识别。把这两项缺口留给未来显著结果，会混淆设计冻结门与经验假设。

若未来重新立题，最低要求不是再增加一个 skill head 或更复杂的 graph encoder，而是更换或重构理论机制，使其产生一个不可通过变量重命名、槽位置换、潜变量旋转或通用 outcome modeling 复制的行动约束；同时用能够分离 person-capability 与 software-asset 两条通道的设计识别外部结果。在此之前，C15 不进入三篇 thesis 的冻结集合。
