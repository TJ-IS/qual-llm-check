### 1.1 Benaroch构念映射不再错置，但到期边界须统一

本次重新回读Benaroch（2018）主文后，修订版的option object可以保留。`01H:L16,L39,L59–L82`把对象限定为一个目标已知、固定兼容协议已推进到pre-cutover、具有600秒到期边界的release。组织拥有执行cutover的权利而无义务，`EX`是exercise，`AB`是取消本次release并回到已稳定旧服务的non-exercise。四项措施位于固定substrate之外，每项最多执行一次，省略任一项后仍存在合法`EX`或`AB`路径；它们因此是真正optional的proactive mitigations，而不是把迁移必需步骤重新命名为投资。`M_SR/M_SV`只产生证据，`M_CP`形成持续恢复能力，`M_WC`形成持续hazard与业务成本作用，给出了离散且路径条件化的不同作用通道。

`D60`也有独立行动语义。它不执行主动措施，消耗60秒和双版本维护成本，并从对agent事前隐藏的future workload接收新证据。因而它与`M_SR/M_SV`的主动取证输入机制不同，不是零成本no-op。其observation是否对latent condition有可校准信息、是否改变下一行动，仍是预注册结果门；设计不能预写value of waiting已经成立。

`AB`是合法non-exercise，因为它执行rollback、保全旧服务并承担固定release/rework机会成本，而不是把失败或全拒绝改名。但`01H:L82`规定到600秒时只允许`AB`或controlled failure，`L329`又规定到expiry时比较合法`EX`与`AB`。这两个terminal action set矛盾，会改变option value与`EXPIRED`标签。正式正文前必须二选一并同步action mask、recursion、oracle和episode terminal reason。该问题可修，不撤销`AB`构念本身。

## 2. 门一：`OptionImpactFactor` 还没有关闭非同构与旁路门

### 2.1 结构方向可以成立，匿名同构不构成否决

`01H:L287–L300` 把当前 action 的 natural parameter 写成 passive base、action main effect 与先前 actions 的 ordered pair effects 之和。若 `q_r` 真正不含 path 及其代理变量，则该结构只允许一阶 main effect 和可加的有序二阶作用，并在 primitive family 内共享 `U_r,V_r,B_r,W_r`。这不是 unrestricted ordered-history Transformer 的参数重命名。

一个严格 witness 是三阶 conjunction。固定当前 action `m`，令某个 primitive residual 只有在 `j` 和 `k` 都已先于 `m` 执行时为 1，在空 path、仅有 `j` 或仅有 `k` 时均为 0。pair-additive residual 必须写成

\[
\delta(p,m)=a_j\mathbf 1(j\in p)+a_k\mathbf 1(k\in p).
\]

两个 singleton 状态迫使 `a_j=a_k=0`，于是 joint 状态也只能为 0。等价地，pair-additive函数满足二阶混合差分 `\Delta_j\Delta_k\delta=0`，而 generic head 可用 `\operatorname{ReLU}(x_j+x_k-1)` 精确得到非零混合差分。另一个顺序 witness 是，在 matched canonical state 下，现有“先前 action 对当前 `m` 分别求和”的式子不能区分历史 `(j,k)` 与 `(k,j)`，generic ordered-history head却可以给出相反符号。只要 `q_r` path-blind 且没有其他旁路，这些结构不变量证明两个函数类不是参数置换同构。该限制是否有助于有限样本与未见组合，只能由实验回答；Benaroch 原文允许当前措施影响依赖此前完整序列，并没有规定不可约三阶作用为零。因此正文必须把pair-additive写成本文提出的“有序二阶截断归纳偏置”，不能称为Benaroch理论定理，也不能仅凭pair scalar正负就把substitution、complementarity和synergy定义为已经实现；这些关系还要由link后的primitive变化及lattice边际option value判定。

`Iso-OptionImpact` 则应当逐 batch、逐梯度和逐 action 相同。它证明实现没有把理论名称偷偷变成额外算力。一个匿名 exact clone 的存在不撤销结构贡献；决定性问题是公平 unrestricted baseline 是否也能通过同一参数图逐梯度复制。

### 2.2 当前前向图仍有八个设计缺口

1. **shared fusion 已读取 path。** `01H:L271–L272` 的 path Transformer 编码 `P`，cross-modal fusion 又明确读取 path。`L287` 随后只用文字说 `\bar h` 不含 ordered mitigation ID，却没有指定 `q_r` 来自一条独立、屏蔽 `P` 的计算支路。若 `q_r` 仍从 shared fusion 取值，`u_{r,m}` 和 `\psi_r^0` 已能直接实现任意 path function，pair term 不再承担独立责任。
2. **即使删除 `P`，path descendants 仍可旁路。** `\bar h` 继续读取 belief、recovery、write-cap、resource/cost、telemetry 与剩余时间。`r/w` 直接暴露 `M_CP/M_WC`，累计 cost 和 duration 可识别已用 action，belief 与 telemetry 可编码 `M_SR/M_SV` 的结果与顺序。于是 `No-Pair` 仍可经 `q_r(\bar h,z)` 学到 conditional impact。`L302` 与 `L436–L437` 不能把 ablation 差异唯一归因于 ordered pair。
3. **role-pair 项没有定义。** `M^{pair}_{r,\rho(j),\rho(m)}` 没有 shape、固定值、可训练性或 zero pattern。若全为 1，`learn/prevent/cope` 在 pair 计算中没有作用。若是可训练 scalar，它可吸收到 `W_r^{\rightarrow}`。若设置理论 zero，Benaroch 又没有证明哪些 role pair 必须为零。
4. **张量与 link 不足以按规格实现。** 文本只给 `q_r\in\mathbb R^{16}`、`e_m\in\mathbb R^8`，没有给每个 family 的输出维 `d_r` 及 `U/V/B/W` 的完整 shape。Bernoulli、categorical、hazard 和 quantile 的 link 也没有逐一冻结。把任意向量称为 quantile natural parameter 不能保证 19 个 quantile 单调不交叉。
5. **duration 与 terminal 存在循环或缺口。** base 读取 `d_m`，同时 `D̂` 又要预测 action duration。若 `d_m` 是行动后真实 duration，就是未来泄漏；若是 contract maximum 或 action feature，必须改名并定义。公式只对“当前 mitigation `m`”定义，尚未说明 `D60/EX/AB` 以及 `T̂` 如何获得 accumulated path effect。
6. **exercise harm probability 没有张量定义。** `T̂` 分别输出 `d` 和 `r` Bernoulli probability，planner 却需要 `\hat p(d\lor r\mid h,EX)`。两个 marginal 不能在未给 joint assumption 时唯一决定 union probability。当前 `L_cal` 的 Brier target也没有对应的显式 head。
7. **持续作用没有结构化状态。** `M_CP/M_WC`执行后的checkpoint、write-cap和风险作用要持续到后续`D60/EX/AB`，但当前公式只定义“当前`m`”的impulse。若terminal继续读取 unrestricted shared path fusion，pair责任被绕开；若完全不读path，已经执行措施的持久物理作用又会丢失。规格需要一个只由合法state transition更新的persistent impact state，而不能把raw `P`重新交给terminal head。
8. **现有role消融混入物理非法性。** `01H:L438`的`Role-Neutral`直接移除executable physical mask，使隔离取证措施可以改变生产hazard等本来不可能的通道。由此产生的退化不能归因于role tying。role实验必须保留同一hard physical mask，仅打乱`\rho`、中和role-pair tying，或用等参数neutral pair模块替代。

还有一个跨门问题。action tensor 有 8 个 replay scopes、8 个 checker sets、`M_CP/M_WC`，但公式中的 `m`、embedding `e_m` 和“四项 mitigation path”没有说明使用 operator type 还是 18 个参数化 action slot。这个选择会同时改变 pair tying、65 条枚举和 `L_lat`。

### 2.3 关闭门一所需的最小规格

正式正文前至少要把下面内容写入同一 forward manifest。

1. 明确两条 context 支路。`h_base` 与 `q_r` 给出字段 allowlist、gradient-stop 和禁止字段；不得读取 `P`、action/result tokens、cumulative cost 或可一一反推 path 的编码。`b` 只用于混合已经给定 `z` 的 primitives，不能再次作为 path proxy 输入 `q_r`。`r/w` 等真实持久状态若必须进入物理 base，应通过所有模型共享的显式 state equation进入，并在 pair 机制检验中构造 matched canonical state。
2. 先冻结action cardinality：`A_M=18`，即8个replay、8个checker、`M_CP/M_WC`；`A_N=19`再加入`D60`；`A_T=2`为`EX/AB`。候选不足八个只能padding，超过八个只能按预注册visible规则截断，analyzer不得改变universe或顺序。然后给每个family固定natural-parameter输出维`d_r`：observation为3，各event hazard为10，各event severity、duration与每类cost为19，terminal `(s,d,r)` joint logits为8，terminal `v/u/w`各为19。可实例化的最低shape契约是

   \[
   q_r\in\mathbb R^{B\times32\times16},\quad e\in\mathbb R^{B\times A_M\times8},\quad
   V_r\in\mathbb R^{16\times8},\quad U_r,B_r\in\mathbb R^{d_r\times16},\quad W_r^{\rightarrow}\in\mathbb R^{8\times8}.
   \]

   `M_r`至少要明确为`A_M×d_r`，`M_r^{pair}`若保留role维则至少明确为`3×3×d_r`，并逐项定义batch/action/latent-state广播、bias、padding与duration action mask。这样才能计算parameter/FLOP配平，而不是在实现时自由选择不等价的图。
3. 对 `M^{pair}` 二选一。若它只是冗余 scalar，删除 role 算法贡献表述。若 role 要改变计算，冻结一个有理论或 operator contract 根据的非平凡矩阵，并说明其不可被 `W` 吸收的约束。
4. 冻结 exact links。Bernoulli 使用 logit、categorical 使用 reference-logit softmax、hazard 使用离散生存参数；quantile 采用可保证非交叉的 base 加 cumulative-softplus 或等价单调参数化。
5. 用行动前可见的 contract feature `\xi_m` 替代含义不清的 `d_m`。定义结构化持久状态，例如

   \[
   g_{r,n+1}=g_{r,n}+M_{r,m_n}\odot\left[u_{r,m_n}+\sum_{j\prec m_n}M_r^{pair}v_{r,j\rightarrow m_n}\right].
   \]

   `M_CP/M_WC`只把合同允许的通道写入`g`，`M_SR/M_SV`只经observation更新belief；`D60`推进passive time而不伪造active impulse；`EX/AB` terminal head读取`g`与matched physical state，不读取raw `P`。若实际状态更新不是加法，需冻结等价的typed transition，但必须保持相同信息防火墙。
6. 把terminal改为显式joint head，例如`\hat J\in\mathbb R^{B\times2\times32\times8}`表示`EX/AB`下`(s,d,r)`八种联合状态，并由同一head求`\hat p(d\lor r)=\sum_{s,d,r:d\lor r=1}\hat P(s,d,r)`。`L_cal`、`\gamma`资格和planner都必须消费这一同一边际，不能分别拼接两个Bernoulli marginal。随后逐项冻结Bernoulli/categorical/hazard/quantile link；quantile采用base加cumulative-softplus或等价单调参数化。
7. 明确 operator-type 与 parameter-slot 的层次。若 pair 只作用于四种 operator type，candidate choice 需要独立且公平的可训练机制；若每个 slot 都有 `e_m`，枚举、path token与 baseline必须按同一 slot 语义重写。
8. 冻结四项实现前tensor tests。第一，自动微分必须得到`\partial\psi_r^0/\partial P=0`与`\partial u_{r,m}/\partial P=0`，只有允许的pair或typed persistent-state支路能响应path ID。第二，固定canonical state并把pair置零后，任意path置换不得改变primitive。第三，上述三阶mixed-difference witness中OptionImpact必须为零，而generic residual能拟合非零；ordered-history witness也要按预注册预期区分。第四，`Iso-OptionImpact`的forward、loss、逐参数gradient和action必须完全相同，`G-PhysicalFactoredSMDP`则不得存在全局参数置换同构。前两项是反旁路测试，第三项是严格函数类witness，第四项是实现与公平性测试。

这些都是可补的规格问题，所以门一当前是 `FAIL/CONDITIONAL`，不是不可修结构证明下的 `NO-GO`。

## 3. 门二：公平通用基线大体修正，但唯一差异还未隔离

### 3.1 已经通过的对等项

`01H:L364–L376` 已明确让所有 learned baselines 获得相同的 `C/G/X/P/R/τ`、candidate universe/order、action mask、physical mask、raw transitions、siblings、risk-bit labels、terminal outcomes、`ENUM-TRAIN` partial rankings和训练 split。`G-PhysicalFactoredSMDP` 保留四项 mitigation、`D60/EX/AB`、ordered path、hard SMDP recursion 与 200,000 search cap。policy-level calibration、duration/quantile nodes、utility、初始化、tokenizer、validation budget和 rollout也被列为相同。这实质修复了旧 `G-FactoredMPC` 删除合法行动和物理知识的不公平性。

### 3.2 尚未关闭的公平性

1. `G-PhysicalFactoredSMDP` 目前直接用 history Transformer 预测完整 primitive，而主模型先得到 path-independent passive base。若 base 是所有模型都应知道的 passage-of-time 与物理状态结构，baseline 也应获得同一 base，再只把 active residual替换为 unrestricted history residual。否则比较同时改变“有没有共同 base”和“有没有 main/pair tying”，不能把差异归到唯一机制。
2. baseline 只有“等容量 ordered-history Transformer”的文字，没有层数、宽度、attention mask、residual input、每个 output head和 loss 的公式。`parameter_count.json` 可以在实现时产生，但 architecture 不能等看到 primitive data 后才决定。
3. “所有 baseline 获得相同 `L_lat` 权重”还没有说明 `G-POMDP` actor–critic、`G-DirectQ` 与 primitive model各自怎样消费 partial ranking。相同 label 文件不等于相同监督强度。
4. `G-DirectQ/G-POMDP` 若也进行五个 `γ` 的 policy qualification，必须有同定义的 exercise-harm prediction接口。actor–critic没有 tree nodes，不能字面拥有相同200,000 search nodes；它应匹配训练与推断 FLOPs、wall-clock和环境 rollout，并作为次级通用替代。理论生死比较仍应由使用同一 DP/search 的 `G-PhysicalFactoredSMDP` 承担。

## 4. 门三：Bonferroni–Clopper–Pearson 核心合法，资格总体仍要补

### 4.1 固定候选和共同 worlds 下的选择证明

修订后的核心统计逻辑是合法的。令五个候选 `\pi_1,…,\pi_5` 在打开 calibration data 前完全冻结。对固定 `k`，若 worlds `W_1,…,W_N` 从同一预注册 generator 独立同分布抽取，冻结 policy 的 harm indicator `Y_{ik}` 在 `i` 上是 Bernoulli iid，则一侧 Clopper–Pearson upper bound满足

\[
\Pr\{p_k>U_k\}\le \alpha/5.
\]

union bound 给出 `\Pr\{\exists k:p_k>U_k\}\le\alpha`。因此，在这个 simultaneous event 上，用同一数据从 qualified candidates 中再按 utility、success和cost选择 `\hat k`，仍有 `p_{\hat k}\le U_{\hat k}`。五个 policies 使用共同 worlds会使 `Y_{ik}` 在 `k` 之间相关，但 Bonferroni 不要求候选间独立；它只要求每个候选在 world index 上满足自己的 binomial sampling假定。共同 worlds反而保留 paired comparison效率。

这项保证是 calibration generator 上冻结 policy 的**全 episode 边际 harm rate**，分母为全部 `N_cal` worlds，不是 exercised states 的随机子集，也不是 `Pr(harm|h,EX)`。`01H:L136,L322` 对 pointwise 与 OOD 的限定是正确的。

### 4.2 仍需修补的四个统计资格

1. `01H:L227` 说从 app、migration、risk和 workload 的离散混合“独立抽取”，但没有冻结每个因子的概率、是否有放回、snapshot/fault/action RNG的独立规则及 policy stochastic seed。顺序整数 seed 本身不是 iid 证明。必须给出完整 generator probability mass function和 RNG stream split。
2. 这里应称 **iid generator superpopulation**。若把 `{100000,…,100999}` 定义为一个固定有限总体且全部跑完，其 harm rate是已知的有限清单均值，不需要 Clopper–Pearson；若从更大的有限 frame 无放回抽样，则 binomial CP 也不是相应的 finite-population exact interval。两种口径不能混用。
3. “至少一次成功 exercise”不能阻止 1 次成功、999 次 abandon 的近退化 policy。风险上界本身仍合法，但不满足本研究“保持正常任务能力”的安全责任。必须预注册 minimum exercise/success rate `s_min`，并对它使用同时的一侧 lower bound，或把 risk qualification明确改成 harm与成功的联合可行域。用于这一门的额外 bounds要进入总 multiplicity budget。
4. 必须说明五个 model seeds是重复报告还是还会从中选择一个 deployment seed。若还要用同一 calibration data选 seed或选方法，simultaneous family不能只含五个 `γ`。utility–success–cost词典序还需冻结方向和完全平局规则。

正式引用应补入 Clopper and Pearson（1934）原文及 simultaneous selection所用的 union-bound/multiplicity依据。当前参考文献只列 feedback conformal 工作，没有给 Clopper–Pearson原始出处。综上，门三是“核心方法通过、总体与能力约束待补”，不是重新回到旧 conformal错误。

## 5. 门四：CodeTwin 的候选不泄漏，但 checker 设计内部矛盾

### 5.1 已经实质修复的通道

两文件现在要求 twins 共享 database snapshot、raw transaction bytes/order/time、absolute workload/fault seed、schema diff、pgroll plan、old repository、public fixtures、replay/checker universe、ordering与`A_mask`。source/AST/analyzer score被明确计入 code channel。candidate IDs 也被 canonicalize 为两侧相同的 opaque slots。hidden oracle在相同 raw input上应用各自可见政策。四个 full/no-source/schema-only/shuffled-source 对照及 external harm/success/cost endpoint均已写明。这些规则关闭了旧版最明显的 candidate/mask/future-input泄漏。

### 5.2 `CS04/CS05` 使任何 twin 都被判 red

`01H-A:L138` 把八个 `HALF_EVEN` checker和八个 `HALF_UP` checker放入同一个 `CS04`，`L139` 同样把 `REJECT_UNKNOWN` 与 `MAP_OTHER` 放入一个 `CS05`。`L214` 又规定 16 个 checker 中 `failure≥1` 即 red。

以正 tie `2.5` 为例，HALF_EVEN的正确结果为2，HALF_UP为3。在 HALF_EVEN twin中，至少一个 HALF_UP checker必然失败；在 HALF_UP twin中，HALF_EVEN checker必然失败。unknown的 rollback与code 99也互斥。因此，只要这些 checker真按各自政策给 pass/fail，同一 superset在任何 clean twin上都会 red。它不再是“full model从 code选择正确 checker set”，而是一个无论选择哪一 twin都报告冲突的 operator。

修补不能只忽略失败。可行做法是把两个政策假设拆成两个**同时出现在所有 twins、顺序固定且名称不含政策语义的 opaque candidate sets**。每个 set内部只有同一政策下相容的 checks；full model根据source选择，no-source看到相同两项但不知道哪一项匹配。M2与M3各需要两个 hypothesis candidates。另一种做法是让一个 set返回两个假设的likelihood而不是failure，但这会改变三值 observation schema，必须升版重审。

### 5.3 仍需锁住的非代码等值与审计字段

1. twins必须额外记录并比较 `t=0` 的 `X/P/R/τ`、visible smoke result、protocol state和所有非代码 node hashes。共享 raw stream不等于共享已经观察到的 telemetry；pre-cutover prefix若含 tie/unknown outcome，no-source可直接识别variant。
2. `No-Source` allowlist必须明确删除 repository hash、policy file path/hash、variant image digest、source-derived node hash、analyzer edge/score和任何variant-specific cache key。当前只明确删 twin/variant/oracle label仍不够。
3. hidden oracle的 sealed policy record应由 manifest中的独立常量生成，不能 import或执行new policy implementation；否则“独立重实现”会退化为同源oracle。
4. `Shuffled-Repository`造成source与world oracle故意不一致，只能作为行动敏感性干预，不能用其external outcome证明正确性。coding-agent必要性的primary held-out结论应限定在 `A11–A18` CodeTwin；train/validation app上的twins只作诊断。

门四因此仍是设计 `FAIL`，但具有直接修补路径，不构成题目级不可修泄漏。

## 6. 门五：三层隔离通过，65 条与18个mitigation槽及21个总行动仍未对齐

### 6.1 已通过的隔离

`ENUM-IDENTIFY` 使用不属于 `A01–A18` 的 D00 fixture。`ENUM-TRAIN` 只用八项 train tasks，`ENUM-TEST` 只用八个 test app tasks。用途分别为builder识别、`L_lat` partial ranking和held-out order test。修订版也明确65条不含`D60`、observation branches或中途`EX/AB`，不再称 full-policy oracle。这些修复符合 `01L` 的数据边界。

### 6.2 仍有三个行动语义缺口

1. `65=ΣP(4,k)` 只枚举四个 operator types；真实 action space却有8个 replay scope、8个 checker set、`M_CP/M_WC`共18个主动slots。不同scope/checker会产生不同observation和return。`π_ref`只说按`[M_SR,M_SV,M_CP,M_WC]`取第一个剩余action，没有说`M_SR/M_SV`采用哪个parameter slot。于是65条sequence、partial label和`e_m`目前都不是唯一可执行对象。
2. `π_cov` 的0.60也没有说明先均分给四个operator types再选parameter，还是直接均分给18个slots。两种采样产生不同coverage与labels。一次执行某个scope后，是只移除该slot还是移除全部`M_SR`slots，也须与“四项mitigation至多一次”一致。
3. `ENUM-TEST`不含`D60`，却在`01H:L447`声称检验第3.4节全部三个冲突，其中第三个正是information–expiry的`D60`冲突。lattice若保留`D60/EX/AB`再与65条mitigation-only sequences比较，也会因行动集合更大而获得机械优势。

修补需二选一。若期权格只在四个operator type层规划，就为每个world冻结一个不看outcome的candidate-selection policy，并把`L_lat`明确限定为type ranking，另用相同监督训练和评价scope/checker selector。若期权格直接规划18个参数化mitigation slots并另含`D60/EX/AB`，就按相同参数化action set重算enumeration和labels，不能再写65。任何order-regret比较都必须把lattice限制到同一action set与同一`π_ref`。`D60`冲突另用不进入训练/calibration的held-out full-policy rollout检验。

此外，`01H`要求`enumeration_split_manifest.json`，`01H-A`的九类文件却只在`split_manifest.json`中给一个`enum_tier`字段。应统一为一个有完整task/seed/template/record-hash schema的文件，并在outcome前给出确定的`EI/ETR/ETE`整数seed规则。

## 8. 门七：八个 test repo关闭了数目门，没有关闭总体推断门

八个test app与32项field-level tasks满足`01L`给出的最低扩展方案，且`01H-A`正确规定app family为最高重采样单位。world seed、risk和workload不能把八个cluster膨胀成数千个repository样本。

但两点仍不成立。

1. 低于0.20的source token Jaccard只说明文本不近重复，不能证明十八个手工合成family是从现实repository population独立抽样。它们共享作者、harness、四个motif和实验生成逻辑。AST/transaction差异审计能证明distinctness，仍不能产生概率抽样外推。
2. `01H:L458`把app与migration写成“交叉随机截距”。每个`<app>-M1..M4` task属于唯一app，所以task应nested within app；M1–M4 motif只有四个预定水平，更适合作为fixed effect。`app/migration family为最高聚类单位`也必须改成唯一的app-family最高单位。

若保留八个synthetic test clusters，primary estimand应写成“这八个预注册synthetic repository families上的有限benchmark平均paired effect”。统计上以app为八个paired units，报告leave-one-app-out、small-cluster修正或app-level randomization/wild-bootstrap敏感性；10,000次普通cluster bootstrap不会创造第九个独立cluster。若要声称对现实repository population的总体外推，需要更多具有外部provenance的独立repositories或明确抽样框，不能靠相似度阈值替代。

所以门七通过了数目和层级意识，但现有population/mixed-model表述仍是`CONDITIONAL`。

## 11. 与结果门的严格分离

下列事项没有被本次用于否决设计，也不得在真实实验前写成已经成立：

- 三类预注册冲突是否真的发生行动排序反转。
- `D60` observation是否对latent condition有信息并改变行动。
- learning/prevention/coping签名是否能从执行数据识别。
- full-code是否在held-out CodeTwin上降低harm或cost。
- pair-additive有序二阶偏置是否优于公平unrestricted residual。
- safety–success–cost Pareto改善是否达到预注册等效界限之外。

修完设计只获得`RESULTS PENDING`资格。上述任一核心结果失败，仍应按01H的撤题门撤销相应理论或整题。
