**终判：`CONDITIONAL / DESIGN NOT FROZEN / RESULTS PENDING`。**

### 2.4 中介方法原文

本轮为判断 `G_a` 与 treatment-induced `L` 的责任，另回读了方法原文，而没有只比较符号：

- VanderWeele、Vansteelandt 与 Robins 的 randomized-intervention analogue 在 exposure-induced mediator–outcome confounder 存在时，将中介抽样分布建立在 baseline covariates 上，并把“把中间混杂与原中介联合视为中介”列为另一种不同分解方案。[Epidemiology 2014, DOI 10.1097/EDE.0000000000000034](https://pmc.ncbi.nlm.nih.gov/articles/PMC4214081/)
- Hejazi、Rudolph、van der Laan 与 Díaz 明确说明 stochastic interventional mediator draw 不条件化于中间混杂 `L`，从而切断 `Z–L` 依赖；文中同时显示 estimator 所用 density ratio 是条件密度之比，并不被 1 上界约束。[Biostatistics 2023, DOI 10.1093/biostatistics/kxac002](https://academic.oup.com/biostatistics/article/24/3/686/6518842)
- Wang 等人以 random interventions 定义 longitudinal natural/interventional mediation targets，并给出对应的 iterative 与 one-step TMLE；该文明确指出更换 mediator intervention 会改变 target 的解释，因而不能在 estimand 未定时只冻结“TMLE”名称。[Journal of Causal Inference 2025, DOI 10.1515/jci-2023-0013](https://www.degruyterbrill.com/document/doi/10.1515/jci-2023-0013/pdf?licenseType=open-access)
- Valtanen 等人在 randomized longitudinal intervention 中专门处理 treatment-dependent mediator–outcome confounding，并将纵向 mediator 作为完整 trajectory/functional entity；其结果进一步说明哪些 treatment-induced history 被当作 confounder、哪些被纳入 mediator process 会改变可识别对象。[Statistical Methods in Medical Research 2026, DOI 10.1177/09622802261418211](https://journals.sagepub.com/doi/pdf/10.1177/09622802261418211)
- 纵向中介的 mediational g-formula 需要固定各时点 exposure、mediator、confounder 的先后顺序和完整因子化，而不是仅列一个 `L_1,…,L_T` 名称。[VanderWeele & Tchetgen Tchetgen 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5560424/)，[Lin et al. 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5285457/)

## 5. immutable binding 与全链失效

本项通过。

`00H` L37–47、L211–213 与 `00H-A` L15–43 规定了唯一顺序：`T−5 bind → T−4 purpose/criterion/bank → T−3 generate → T−2 lattice-and-branch commit → T−1 sealed evaluation`。`binding_digest` 覆盖 canonical action bytes/hash、repo/container、base commit、pre-state、working-tree hash、permission 和 scope。

压力测试中的以下交换均被同一规则捕获：同 diff 不同 base commit、同命令不同参数、同 bytes 不同权限、同 patch 不同 working tree、同 action hash 但 scope manifest 改变。正式实现仍需对这些 swap 做单元测试，但“尚未跑测试”不是本次 design blocker。

## 6. 唯一中介对象与纵向估计器

### 6.1 已经闭合的部分

第三轮修补已经删除了原来的 estimand/estimator 菜单：

- primary mechanism object 只剩 `IIE_FG=ψ(1,0)-ψ(1,1)`；natural、organic 和多个 direct-effect 不再并列。
- `G_0/G_1` 来自随机 D/C arms 的 observable `M_obs` 分布，不由 analyst 事后选择 shift。
- `M_obs` 是 4–8 个 action-bound required direct/transfer items 的等权 normalized Brier complement；神经 `g_est` 不冒充 causal mediator。
- 顺序明确列出 `X → A → L_1,…,L_T → M_obs → R_post → same-reviewer decision → sealed truth`，并承认 `L_t` 是 treatment-induced history。
- measurement 在两臂采用相同 silent/no-feedback bytes、顺序和时间窗；结论只解释为统一 measurement regime 下的批准。
- measurement 后新 evidence/repair 进入 `R_post`，total effect 保留，mediation 使用预注册 censoring node；不以第二次 mediator 覆盖第一次。
- primary estimator 只剩 longitudinal TMLE；g-formula 与 stabilized IPW 只作敏感性；micro-randomization 放在不复用 participant/trial 的 `micro_secondary`，`p=.5`、每 trial 最多一次、active 后一 trial washout、proximal ITT/GEE，且 micro item 不进入 `M_obs`。

这些修补足以否定“当前仍混用 organic/interventional、TMLE/g-formula 或用 micro experiment 污染主 cohort”的批评。

### 6.2 阻断 B1：`G(.|X,L)` 与所声称机制不是同一个对象

现式为：

`ψ(a,a*)=E_X E_{L|A=a,X} E_{M~G_{a*}(·|X,L)} E[Y|A=a,X,L,M]`。

并以 `IIE_FG=ψ(1,0)-ψ(1,1)` 表示在 C3 history 分布不变时，把 `M` 的条件分布从 arm C 换成 arm D。

这里的问题不是“没有唯一符号”，而是符号对应两种不同机制解释：

1. 若 `L` 只是需要控制的 post-treatment mediator–outcome confounder，history-conditional draw 可以定义一个较窄的 stochastic mediator-shift object；但它不是通常所称的、通过切断 `M–L` 依赖来处理 exposure-induced confounding 的 stochastic interventional indirect effect。
2. C3 的 `L` 不是外围 nuisance。它明确包括 evidence exposure、policy action、factual response、clarification/repair 和 trigger；这些恰是共同基础算法为改善理解而改变的过程。两项 `ψ(1,0)` 与 `ψ(1,1)` 都对 `L|A=1` 平均，因此 `A→L→M→Y` 的变化没有进入该 contrast。若 C3 通过“多做一次 repair”提高 `M_obs`，但在给定同一 repair history 后两臂的 `M` 分布相同，当前 `IIE_FG` 可以为零，即使全文所称 grounding process mechanism 很强。

Wang 等人的 longitudinal mediation/TMLE 工作说明 target 依赖所选 random mediator intervention；Valtanen 等人则说明 treatment-dependent histories 既可能构成 mediator–outcome confounder，也可能是纵向 mediator trajectory 的一部分。二者共同支持的不是“C3 尚未实施所以失败”，而是当前必须先决定 acquisition/clarification/repair history 在因果对象中究竟是被条件化的 `L`，还是 factual grounding 的联合纵向 mediator process。

这并不证明当前式“数学上不能估计”，而是证明其学术责任没有唯一冻结。必须三选一并同步改写理论命题和 TMLE：

- **完整 factual-grounding interventional effect**：使用按 baseline `X`、对 `L` 边缘化的 arm-specific mediator distribution，并明确 interventional draw 打断 `M–L` 依赖；
- **联合过程机制**：把 acquisition、presentation、factual probe、clarification/repair 与 terminal `M_obs` 定义为联合纵向 mediator process，并对其中真正的 mediator–outcome confounders另设时序节点；
- **窄条件效应**：保留 `G(m|X,L)`，但改名为 history-conditional stochastic mediator-shift effect，明确它不分解 total effect，也不测量经 evidence/repair history 发生的全部机制。

在这三种选择冻结前，不能以“唯一 IIE_FG”名称掩盖对象分叉。

### 6.3 阻断 B2：analysis manifest 尚不能产生唯一可执行 TMLE

1. **截断类型错误。** `00H-A` L317 写 `probability/density-ratio truncation [0.01,0.99]`。概率可夹到该区间；density ratio 是两个非负密度之比，可大于 1。把所有 ratio 上截为 0.99 会系统改变 clever covariate，而不是普通 positivity 防护。必须分别冻结：概率截断区间；density-ratio/clever-covariate 的有限上限、分位 cap 或其他明确稳定化规则；以及每一项应用在哪个 factor。
2. **变长 `T` 未因子化。** logging trial 有 3–6 个 opportunity，mediation 只写 `L_1,…,L_T`。须冻结固定六槽表示或其他唯一时间轴、每槽内 `history → eligibility → action → exposure → response/repair → missing/stop` 的顺序、absorbing stop、未发生槽、censoring 和 trajectory-length 节点。否则一个实现把 stop 后槽记结构缺失，另一个把它当重复吸收状态，两者得到不同 likelihood。
3. **五折可能不可构造。** “participant–repository 二部图 connected components 五折”可以防止 participant/repository 跨 fold，却没有保证图至少有五个可分 components。若共同 repositories 把参与者连接成一个 giant component，合同无法执行。须在 task allocation 前保证至少五个具有 event support 的 components，或事前冻结不可满足时的降级/终止规则；不能 outcome 后改成普通 participant folds。
4. **common support 只命名未定义。** `G_0/G_1` 的共同支持域、诊断和失败条件没有确定阈值/算法。须在解封前冻结以何种 pre-outcome feature score/density 判 support、删去的是哪些 observations、目标总体如何随 trimming 改写，以及任何一臂/任何关键 strata 的最小事件数。
5. **`R_post>5%` 分母未说明。** 需说明按合并样本、任一 arm、participant cluster 还是 opportunity 计算；建议采用“任一 arm 超过 5% 即降级”的保守规则，并把 informative censoring diagnostic 纳入同一 manifest。

cross-fitting、2,000 次 participant-cluster bootstrap、failure code、g-formula/IPW 敏感性顺序这些名称已经冻结；本节要求的是让它们在 synthetic trajectory 上只有一个可复算结果，不是要求提前知道真实效果。

## 7. `κ`、`M`、`C` 与 outcome 的 producer 隔离

本项通过。

- `J_content/m_req/κ` 由 task authors 在 binding 后、participant response/approval/harm/hidden outcome 前产生；`κ` 是 purpose-relative criterion specification，不是从 final outcome 反推的阈值。
- `criterion_measurement_t/M_obs` 来自预注册题库、公开事实 source hash 和 Brier aggregation，与 `κ` 有不同 field ID、producer 和 lineage。
- `C_t` 只记录 presentation、clarification、repair、grounding_acceptance 的盲态 phase 标签；schema 明确拒绝 gate `approve` event。
- `M[:,1]` 需要独立 understanding/paired-interpretation event；`M[:,2]` 需要 system uptake、human exposure 和更后 paired confirmation。`C` 与 `M` 的 event IDs 不得重用。
- approval、harm、task success、gold/G/hidden 不能定义 `B_H/C/M/g_est`；UNKNOWN 保留时间、责任人、reason 和 forbidden-source check。

这里已经避免“同一次回答同时自证 phase、understanding、uptake 和 criterion”的标签循环。未来标注一致性低于门而暂停训练属于预注册 failure rule，不是当前设计分叉。

## 8. oracle-blind lattice、noninterference 与同人结局

### 8.1 通过部分

`00H-A` 给出单向信息流 `trusted_mediator → binding → task_author → candidate_generator/branch_instantiator → logger/policy`，hidden evaluator 不向上游返回字段。T−2 分支只能二选一：有限预枚举 bytes/hash，或冻结 grammar、template/slot schema、image、Merkle source root、runtime whitelist、seed 和 replay executable。

非干扰测试不是只看 label AUC。三个状态 `evaluator absent / present-but-sealed / hidden-byte-swapped` 要比较 candidate/branch IDs、bytes、order、mask、cost、latency features、generator trace、syscall/file/network trace、action logits 和 selected-action distribution；任何差异使 group 与 binding 下游失效。public risk signal 合法预测真实风险不会被误判为 oracle leakage。

primary outcome 同时校验：

- `interaction_participant_id == final_approver_id`；
- `canonical_decision_action_hash == T−5 canonical_action_hash`；
- sealed expert adjudicator 只产生 safe/unsafe truth，不替代 participant approval。

因此 same reviewer、same action 和 unsafe approval 的定义已经闭合。唯一剩余问题是第 4.2 节的动态 candidate cap，而不是 hidden evaluator 本身。

## 9. 等信息基线、理论责任与 coding-agent deletion

本项通过，且没有因“通用模型表达可复制”而误判 NO-GO。

Human-state POMDP、Raw-POMDP、generic proposition Transformer 和 contextual bandit 获得相同 `J_content`、proposition labels、factual/phase/uptake human feedback、静态 lattice、动态 branch/replay contract 与实例 bytes、mask、external reward、logging propensity、splits、pretrained `E_tech`、训练步数、seed 数和搜索配置。可训练参数要求 ±1%，推断 FLOPs ±5%，wall-clock 预算匹配；结构标签也向通用多任务头开放。

这个公平性合同正确承认等参数通用 Transformer/POMDP 在表达上可能复制 C3。理论贡献只能由有限数据、未见 repository/reviewer、方向干预和安全—效率前沿的联合证据保留。结果未运行意味着这些贡献仍是待检验主张，不意味着设计应因没有胜出数字被撤题。

两种 coding-agent deletion 也具有撤销力：

1. 保留 grounding 界面，把 executable evidence acquisition 改成静态通用解释；若仍复制全模型，coding-agent 特有技术层无独立贡献。
2. 保留 executable acquisition，删除 reviewer-state repair；若仍复制全模型，common-ground 机制无独立贡献。

这比只删除一个 auxiliary head 更能检验理论和 coding-agent 情境是否 load-bearing。

## 10. 六篇近邻的联合覆盖判定

将六篇工作按能力并集组合，可以得到真人 coding、迭代反馈、部署 A/B、review dialogue、agent-review adoption 和 human handoff；再加入 SABER/constraint substrate，可以得到 stateful damage 与外部约束。然而该并集仍缺少同一研究中的四个不可替代联结：

1. fixed post-escalation 后先把 exact action/pre-state/permission/scope 做 immutable binding；
2. hidden truth 不参与 acquisition/repair candidate 的生成、mask、成本、顺序和分支；
3. 策略从同一人的 action-specific factual response 学习 `acquire/present/probe/clarify/repair/stop`，而不是只给静态反馈或停在 handoff；
4. 同一人对同一 action 的 approval 与 sealed state-damage truth 联合形成 unsafe approval，并用独立 observable factual grounding 检验机制。

因此，最新直接工作没有形成致命的“联合覆盖即等价能力”。C3 的新能力仍然可能成立，但只能在等信息通用基线与 deletion tests 未复制时成立。这里给出的是继续研究的设计新颖性边界，不是尚未取得的经验贡献结论。

唯一需要立即修正的文献身份是 RECODE-H：第三轮表格仍按 arXiv v2/under-review 口径记录，而 OpenReview 已将其列为 ICLR 2026 正式论文。出版状态更新不会改变边界判断。
