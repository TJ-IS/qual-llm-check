## 2. 联合机制对象：通过

第四轮将机制对象定义为

\[
IIE_{JFG}=\Psi_J(1,0)-\Psi_J(1,1),
\]

\[
\Psi_J(a,a^*)=
E_X\int \mu(a,z^J,X)G^J_{a^*}(dz^J\mid X).
\]

这里的 `Z^J` 不再只保留一个被条件化后的局部评分。它包含六个互动槽中依次发生的 `D→U→E→F→Cg→K`，以及第七槽的事实测量和第八槽的 `R_post`。因此，证据取得、证据呈现、probe、clarify、repair、uptake、事实测量和测量后的安全策略都进入同一个纵向联合过程分布 `G^J`。结果回归 `μ` 接收完整联合历史，处理律与过程律各自有唯一位置。

正号方向也一致。若 `Y` 是不安全批准，则 `\Psi_J(1,0)-\Psi_J(1,1)>0` 表示在结果臂固定为 1 时，把对照联合过程 `G^J_0` 替换为 C3 联合过程 `G^J_1` 会降低不安全批准。该对象可能在数值上接近 total effect，但“接近”不能成为否决机制的理由。它估计的是一整套共同基础政策过程，而非声称识别每一个节点的独立自然间接效应。

本轮专门检查了循环定义。`J_content`、`m_req`、`κ` 和 item bank 均在处理前冻结；最终批准、`Y` 和 oracle 危险标签不能成为过程节点；`g_est` 只用于估计与诊断，不是因果图中的机制变量。因此没有发现“由结果定义机制，再用机制解释结果”的循环。

理论责任与这个宽机制对象相容。Clark 系列原文支持目的相对的相互理解证据、presentation/acceptance、repair、互惠 grounding 和 least collaborative effort。Mastrogiacomo 的实际映射是 identification 对应 objective，ability 对应 resource 与 risk，willingness 对应 commitment，mutual belief 对应 conversation/process。原文不直接推出具体张量、乘法结构或 coding harm，锁定稿已把这些限定为可证伪的算法设计选择，而没有冒充理论命题。

因此，第四轮没有再次把 acquisition、presentation、probe、clarify、repair、uptake、事实测量或 `R_post` 条件化掉。联合机制门通过。

## 3. 固定时间轴、退出与观测：通过

每个 trial 的交互决策轴固定为 `T_dec=6`，完整观测轴固定为 `T_max=8`。每个交互槽内部的顺序固定为 `D→U→E→F→Cg→K`。一旦 stop，后续交互槽写入 `NOOP_ABSORB`，但第七槽的事实测量和第八槽的 `R_post` 仍按统一协议发生。

这个设计使不同表面长度的轨迹映射到同一个八槽样本空间。早停不是删去后续变量，而是确定性进入吸收状态。真正退出、日志损坏或最终决策缺失才进入 `C_Y`。`R_post` 明确属于联合过程，不能同时作为 censoring。由此，每个 trial 的 likelihood 和目标积分都有唯一长度。

事实测量可能改变后续行为，第四轮用统一、静默、无反馈的测量协议控制这种 reactivity。`Y` 只能解释为该统一测量制度下的结果。因为第八槽仍在测量之后，任何由测量触发的 `R_post` 安全响应均是处理过程的下游组成部分，既进入 total effect，也进入当前联合机制对象。只要正式执行不向不同臂提供不同测量反馈，就没有把测量反应误写成外生删失。

因此，固定轴、吸收态、事实测量、`R_post` 和 `C_Y` 的边界具有唯一解释。该门通过。

## 4. 纵向随机干预估计：方法名有原文依据，采样单位仍待唯一化

Wang 等人原文明确以 `O_1,…,O_n` 独立同分布为起点，给出完整纵向似然分解、条件密度直接更新、HAL-EIC 投影、快速 one-step TMLE、同时目标以及一般纵向随机干预。因而“one-step HAL-EIC longitudinal TMLE”这一方法名称有原文方法内容支持，不是只贴标签。

原文没有把 cross-fitting、sample splitting 或 bootstrap 作为上述方法名称的一部分。本设计增加参与者级五折 cross-fitting 和聚类重抽样是允许的实施扩展，但必须自己冻结 `O_i` 是谁、似然按谁相乘、trial 内和 trial 间历史怎样进入 nuisance，以及方差按谁重抽。不能以 Wang 论文的名称替代这些字段。

现有稿件已经冻结五折按 `participant_id` 分割、fold seed 与 manifest SHA，并把 repository OOD 留作外部敏感性分析。这个处理是正确的：repository 切分可检验迁移，不能替代随机化的因果识别。真正未关闭的是随机化单位与 `O_i` 的对应关系，详见第 7 和第 8 节。

## 5. 概率、密度比与支持域：通过

二元条件概率截断到 `[0.01,0.99]`。多分类概率采用 `0.98p+0.02/K`，仍为合法概率向量且总和为 1。密度比另行裁剪到 `[1/20,20]`；它不是概率，允许大于 1。两类处理作用于不同因子，没有把概率截断与权重裁剪混成一个操作。

任何 arm/fold 中被裁剪比例超过 5%、出现非有限值或符号异常，都触发预先规定的失败。共同支持按处理前 `H=(risk_stratum, baseline_reviewer_support)` 计数，并同时检查 cell 下限、结构不对称 `B_h`、至少 80% 保留率和风险层存活。门限在读取结局前冻结。失败时输出 `MECHANISM_NOT_ESTIMABLE`，只允许报告 association fallback，不能在看过结果后换 cell、换截断范围或改 estimand。

主对比已使 reference process 可唯一读为 `G^J_0`，结果回归臂为 1。实现时仍应在 manifest 中显式写出这一枚举值，避免程序默认值漂移；这是机械断言，不是新的设计门。

支持模拟尚未实际达到门限属于结果待定。不得把尚未达成写成已经通过，也不得因尚未运行而否决当前合同。

## 6. 动态分支与旧通过门：通过

动态 branch 的执行序列已经唯一化：先 instantiate-all，再生成 canonical CBOR 与 SHA，然后只用 public-only 字段 cap 到 8，随后把保留与丢弃集合一并落盘，计算 `S_pre`，计算 `q`，最后抽样。`q` 不能影响生成或 cap，不能读取 oracle，也不能恢复被丢弃候选。所有候选的 propensity、分母、logit、canonical bytes 和哈希均可重放。

旧通过门逐项重新检查，未发现第四轮回归：

1. bind-first 任一绑定失效会使全链失效，不允许后补绑定。
2. hidden-byte mirror 与 noninterference 仍然成立，隐藏字节不能改变在线分支。
3. producer 与 `κ/C/M` 标签生产者继续隔离，标签不能回流给行动模型。
4. primary outcome 仍是 same-reviewer、same-action 的不安全批准结果。
5. Kish ESS 按 participant cluster 计算，没有把 trial 数冒充独立人数。
6. lattice 对 oracle 保持盲态，oracle 只在封存评价路径开启。
7. 外部机制的 escalation 固定，不由被评模型自选。
8. 模型只输出六类过程动作，不输出 approve/deny、风险真值或 reviewer allocation。
9. Human-state POMDP、同信息通用替代和 coding-agent deletion 使用相同信息、标签、参数和 FLOPs 预算。

这些门均通过，但不能补偿随机化单位未冻结的问题。

## 7. 唯一可执行反例

下面两种实施都符合现有的“180 人 × 12 trials”“随机 `A=1/0`”“已知 arm propensity”和 `trial_order_block` 等文字。

**实施 I：参与者固定臂。** 180 名参与者各自在 A/B/C/D 中只随机一次，十二个 trial 始终保持同一臂。D/C 子对比的条件处理概率为 1/2。D/C 的独立单位是参与者，名义 `n` 约为 90。十二个 trial 共享同一人的学习、疲劳和风险偏好，必须作为一个 cluster 建模与重抽样。

**实施 II：trial 级随机或 crossover。** 同一参与者的十二个 trial 可以进入不同臂。D/C 的每 trial 条件概率也可以写成 1/2，所有参与者都有机会出现在两臂。先前处理会训练或疲劳 reviewer，改变后续 trial 的 probe、repair、uptake 和批准行为。此时处理律按 trial 发生，支持计数、有效样本量、carryover 假设和目标总体均与实施 I 不同。

两个实施会产生不同的 likelihood、不同的 nuisance histories、不同的标准误，也会赋予 `\Psi_J` 不同含义。现有文件没有字段能排除其中一个。因此这不是措辞润色，而是阻止实施前冻结的唯一反例。

## 8. 唯一随机化门的字段级最小修补合同

以下字段必须作为一个不可拆分的合同同步写入四份锁定稿。任何字段缺失都会重新打开第 7 节反例。

### 8.1 随机化单位、分层与臂维持

- `randomization_unit = participant_id`。
- `randomization_strata = baseline_reviewer_support`，使用锁定稿已有的三个处理前层级；分层值必须在分配前落盘。
- 四臂枚举固定为 `A/B/C/D`，每个分层内的类别概率均为 `1/4`。在只分析 D/C 的确认性对比中，条件 propensity 固定为 `P(D|D∨C,H)=P(C|D∨C,H)=1/2`。
- `arm_persistence = all_12_planned_trials`。同一参与者十二个计划 trial 保持同一臂，不 crossover、不重新随机、不以缺席 trial 替换分配。
- trial 任务及顺序属性在 arm 分配前冻结。任务顺序可以进入历史，但不能读取处理后结果再调整。

### 8.2 可重放随机化的 seed、hash 与分配函数

- 域分隔字符串固定为 `C3-CONF-ARM-20260816-v1`。
- 首位参与者入组前生成 256-bit 服务器秘密 `K_arm`，发布并写入四文件共同 manifest 的 `seed_hash = SHA256(K_arm)`。实际 64 位十六进制 hash 必须在首例入组前填入，不能保留占位符。
- 计算 `h_i = HMAC-SHA256(K_arm, UTF8(domain || stratum_i || salted_participant_id_i))`。取 `h_i` 的前 64 bit 为无符号大端整数 `u_i`，令 `j_i=floor(4u_i/2^64)`，按 `0→A, 1→B, 2→C, 3→D` 分臂。
- `salted_participant_id` 的盐、规范化规则、字符编码、字节序、arm 映射、分配脚本 SHA-256 和 schema SHA-256 均在首例入组前提交。allocator 不能读取 trial、过程或结局字段。
- `K_arm` 在 enrollment lock 后公开，以便重放；首例入组前公布的 `seed_hash` 必须与公开 key 一致。任何人工 override 均视为 protocol deviation，不得悄悄重分配。

该函数给出每个参与者的已知四臂概率 `1/4`，同时保留分配隐藏性和事后重放性。若团队选择区组随机，必须另行冻结完整区组算法并重新审计；不能在实施时把上述合同解释为区组随机。

### 8.3 独立单位、聚类似然与 carryover

独立同分布单位固定为参与者 cluster：

\[
O_i=\left(B_i,A_i,\{X_{ir},Z^J_{ir},C_{Y,ir},Y_{ir}\}_{r=1}^{12}\right),
\qquad i=1,\ldots,n.
\]

总体 likelihood 必须写成 `L(P)=∏_i p(O_i)`，不能写成 2160 个 trial 的 IID 乘积。`p(O_i)` 内部按 `r=1,…,12` 的计划顺序分解；每个 trial 再按八槽分解。第 `r` 个 trial 的 nuisance history 包含 `B_i`、`A_i`、冻结任务属性以及该参与者所有先前 trial 的完整 `Z^J`、测量、`R_post`、censoring 和可见结局历史。stop 后的 `NOOP_ABSORB` 仍按固定轴进入似然。

本合同**允许并建模参与者内 carryover**。学习、疲劳、信任调整和先前 repair 对后续 trial 的作用不是干扰违例，而是 cluster history 的组成部分。唯一的 no-interference 假设是不同参与者之间不存在结果相关的跨参与者干扰。现有“无跨参与者/trial 干扰”式表述必须删除或改成这一精确定义。

若研究者不愿建模十二个 trial 的 cluster prefix，唯一干净替代是预先把确认性因果分析限制为每人第一个 trial。不能保留十二个 trial 后把它们当作 IID。该替代会改变 estimand，采用前必须重新审计；它不是本审计推荐的默认修补。

### 8.4 聚类目标总体与 estimand

确认性 D/C 目标固定为处理前合格且被随机分配到 D 或 C 的参与者总体，以参与者等权；每名参与者的十二个计划 trial 等权。先应用既有的、读取 `Y` 前冻结的共同支持规则。repository OOD 仍是单独的外部敏感性分析，不改变确认性目标总体。

聚类联合过程目标写为

\[
\Psi_J^{cl}(a,a^*)=
E_{B_i}\left[
\frac{1}{12}\sum_{r=1}^{12}
\int \mu_r(a,z^J_{1:r},B_i)
G^{J,1:r}_{a^*}(dz^J_{1:r}\mid B_i)
\right],
\]

\[
IIE_{JFG}^{cl}=\Psi_J^{cl}(1,0)-\Psi_J^{cl}(1,1).
\]

`z^J_{1:r}` 包含当前及此前 trial 的完整八槽联合历史；计划任务属性是处理前冻结条件。缺失由已冻结的 `C_Y` 机制处理，不得通过 complete-case 删除后重新赋予参与者权重。若支持规则排除某些处理前 strata，解释边界必须写为该 shared-support 参与者总体。

### 8.5 cross-fitting、方差与失败规则

- 五折 cross-fitting 继续按 `participant_id` 分割。一个参与者的全部十二个 trial 只能进入同一 fold。
- fold seed、participant-to-fold 清单、清单 SHA-256 和 nuisance 配置 SHA-256 必须在读取确认性 `Y` 前冻结。
- 区间估计固定为 2,000 次 participant-cluster bootstrap。每次按 `arm × baseline_reviewer_support` 分层有放回抽取完整参与者 cluster，cluster multiplicity 原样保留。
- bootstrap seed 域字符串固定为 `C3-JFG-BOOT-20260816-v1`；实际 seed 与 SHA-256 在读取确认性结局前写入 manifest。
- 每个 replicate 完整重拟合 nuisance、cross-fit 预测和目标参数流水线，不能只对最终 trial 行做轻量重抽。95% 区间固定为 percentile interval。
- 失败 replicate 不重抽、不补抽。非有限值、违反截断门或流水线失败均计入失败率；失败率超过 5% 时输出 `MECHANISM_NOT_ESTIMABLE`，不临时改用另一种区间。

这些方差字段是本项目在 Wang 等人方法基础上的聚类实施选择，不能声称由该论文原样规定。

### 8.6 四文件同步位置
