## 2. 独立红队判据

本轮没有把“写得更长”或“字段出现过”当作通过依据，而是对每项合同使用以下反例判据：

1. 若两个实现都能逐字满足四份锁定稿，却会产生不同的处理分配、可见信息、行动集合、likelihood、estimand、独立单位或失败处置，则设计仍未冻结。
2. 若某个结果变量、hidden truth、批准事件或处理后变量能够改变候选可用性、标签、分臂、支持域或训练输入，则存在泄漏。
3. 若理论原文没有承担某项技术关系，而正文把它写成理论必然结论，则理论责任不合法。
4. 若同一观察被重复作为互动阶段、理解证据和最终批准，则机制对象循环定义。
5. 若未实施、未招募、未跑赢基线是唯一缺口，则只保留为结果门，不据此否决已经唯一化的设计。

## 3. `02T` 唯一剩余门的第五轮闭合

### 3.1 participant-level 分层固定四臂

四文件现在给出同一处理律：

- 唯一随机化单位是 `participant_id`。
- 唯一分层变量是处理前冻结的 `baseline_reviewer_support`，层级固定为 low、medium、high。
- 四臂枚举固定为 `A/B/C/D`，每一层中每臂设计概率均为 `1/4`。
- D/C 确认性子对比中的已知条件 propensity 为 `P(D|D∨C,H)=P(C|D∨C,H)=1/2`。
- 每名参与者的十二个计划任务及顺序属性在分臂前冻结。
- `arm_persistence=all_12_planned_trials`。一人十二 trial 全部保持同臂，不允许 crossover、trial-level rerandomization、缺席后换臂或人工 override。
- 缺席、损坏或无法完成只进入预注册 missingness/deviation 字段，不产生新分配。

因此，`02T` 的两个反例中只有“参与者固定臂”仍合法。“同一人不同 trial 进入不同臂”的实施已经被字段和失败码同时排除。

### 3.2 HMAC seed、hash、映射与重放

随机化函数的域固定为 `C3-CONF-ARM-20260816-v1`。首例入组前生成 256-bit 秘密 `K_arm`，只先公布 `seed_hash=SHA256(K_arm)`。`seed_hash` 的实现形状由 SHA-256 身份和 64 个十六进制字符检查共同确定，不存在把它实现成 64-bit 摘要的合法分支。真实 key 只能在 enrollment lock 后公开。

消息采用

`UTF8(domain || stratum_i || salted_participant_id_i)`，

其中字段长度边界、分隔符、Unicode normalization、salt、ID 规则和编码必须在首例入组前写入 `arm_randomization_protocol.yaml`。随后计算

`h_i=HMAC-SHA256(K_arm,m_i)`，

`u_i=UInt64BE(h_i[0:8])`，

`j_i=floor(4u_i/2^64)`，

并固定按 `0→A,1→B,2→C,3→D` 映射。allocator executable SHA-256、schema SHA-256 和 assignment 外键均预提交；allocator 不读取 trial 过程、人类响应或结局。每名参与者只能有一条 assignment，再把同一外键复制给十二个计划 trial。

机械复算了 `u_i∈{0,…,2^64−1}` 的四个整数区间：

| `j_i` | arm | 最小 `u_i` | 最大 `u_i` | 整数个数 |
| ---: | --- | ---: | ---: | ---: |
| 0 | A | 0 | 4,611,686,018,427,387,903 | 4,611,686,018,427,387,904 |
| 1 | B | 4,611,686,018,427,387,904 | 9,223,372,036,854,775,807 | 4,611,686,018,427,387,904 |
| 2 | C | 9,223,372,036,854,775,808 | 13,835,058,055,282,163,711 | 4,611,686,018,427,387,904 |
| 3 | D | 13,835,058,055,282,163,712 | 18,446,744,073,709,551,615 | 4,611,686,018,427,387,904 |

每个区间恰含 `2^62` 个整数，没有 modulo bias。C 与 D 的并集含 `2^63` 个整数，所以在 HMAC/PRF 随机化合同下，每层每臂为 `1/4`，条件在 D 或 C 后两臂各为 `1/2`。

enrollment lock 后，公开 key 必须与事前 `seed_hash` 相符。`00H-A` 要求两个独立实现逐参与者重放 HMAC、`u_i`、`j_i` 和 arm。key/hash 不符、任一重放不符、同一参与者出现多臂值或人工改臂都产生 protocol deviation 或 `ARM_PERSISTENCE_FAIL`，不得重抽 key、重分配或选择性保留 trial。由此，隐藏分配、事前承诺和事后可审计三项责任同时闭合。

这里冻结的是概率律与可重放算法，不承诺每层实现后四臂人数完全相等。HMAC 独立映射与区组平衡是不同设计；锁定稿明确采用前者，没有给实施者保留切换到区组随机的权限。

### 3.3 IID 单位、participant-product likelihood 与簇内 carryover

确认性分析的独立观测唯一为

\[
O_i=\left(B_i,A_i,\{X_{ir},Z^J_{ir},C_{Y,ir},Y_{ir}\}_{r=1}^{12}\right).
\]

总体 likelihood 唯一为

\[
L(P)=\prod_i p(O_i),
\]

而不是 2,160 个 trial 的 IID 乘积。每个 `p(O_i)` 先按计划顺序分解十二个 trial，再在每个 trial 内按六个决策槽、terminal measurement 和 `R_post` 八槽分解。实现可以展开 trial/slot 张量，但展开行不能被当作独立样本。

第 `r` 个 trial 的 nuisance history 包括冻结的参与者与任务基线、固定 `A_i`、该参与者此前 trial 的全部联合过程、measurement、`R_post`、censoring、可见决策和可见结局历史。它不能读取当时仍封存的 hidden safe/unsafe truth。stop 后的 `NOOP_ABSORB` 仍占据固定槽位。

学习、疲劳、信任调整、理解修正和早期 repair 对后续 trial 的作用明确属于 participant 内 carryover，并进入簇内 prefix。no-interference 只假定不同 participant cluster 之间没有结果相关的影响。四文件没有保留“跨 trial 无干扰”或 trial-IID 的正面口径；相关词只出现在禁止项和机械检查项中。

由此，固定臂处理、簇内历史和分析独立单位是一致的。实施者不能一面保留十二个 trial，一面把它们当成十二名独立参与者。

### 3.4 cluster estimand 与目标总体

确认性机制比较只取 D 臂 C3 与 C 臂等信息、等动作、等资源 Human-state POMDP。处理为参与者级固定的 `A_i=1/0`。先应用只读取结局解封前字段的共同支持合同，再把 `P_sup^cl` 定义为 D/C 两臂 shared-support 参与者的合并经验分布。目标总体按 participant 等权，每名参与者内十二个计划 trial 等权；若支持规则排除处理前 strata，解释必须收缩到该 shared-support 参与者总体。

聚类联合过程参数为

\[
\Psi_J^{cl}(a,a^*)=
E_{\bar X_i\sim P_{sup}^{cl}}\left[
\frac{1}{12}\sum_{r=1}^{12}
\int \mu_r(a,z^J_{1:r},\bar X_i)
G_{a^*}^{J,1:r}(dz^J_{1:r}\mid\bar X_i)
\right],
\]

唯一 primary mechanism estimand 为

\[
IIE_{JFG}^{cl}=\Psi_J^{cl}(1,0)-\Psi_J^{cl}(1,1).
\]

正值唯一解释为：保持 outcome arm 为 C3，把十二 trial 的完整 joint process 从 Human-state POMDP 分布替换为 C3 分布时，参与者平均 unsafe approval 减少。`z^J_{1:r}` 包括当前和此前 trial 的完整八槽历史。缺失由冻结的 `C_Y` 处理，不允许 complete-case 删除后重新改变参与者权重。

这个对象与理论主张同宽：acquisition、presentation、factual response、clarification、repair、reciprocal uptake、terminal factual measurement 和 `R_post` 均在联合过程内。D 对 C 的随机 total effect 另报。natural、organic、history-conditional、single-`M_obs`、analyst-chosen shift 和神经 `g_est` mediation 都被明确排除，没有第二个合法的 primary mechanism estimand。

### 3.5 participant 五折 cross-fitting

primary estimator 唯一为 participant-cluster 五折 cross-fitted one-step HAL-EIC longitudinal TMLE，同时 target `Ψ_J^cl(1,0)` 与 `Ψ_J^cl(1,1)`。外层 fold seed 固定为 `C3-JFG-CF-20260816-v1`。在每个 `baseline_reviewer_support` 层内，参与者按

`SHA256(UTF8(seed)||0x00||UTF8(salted_participant_id))`

升序排列，以 `fold=1+((rank-1) mod 5)` 分折。每层各折参与者数之差至多 1；同一参与者的全部十二 trial 和全部展开行必须留在同一 fold。fold seed、participant-to-fold 清单、清单 hash 和 nuisance 配置 hash 在读取确认性 `Y` 前冻结。

participant–repository connected-component folds 已明确作废。repository hash leave-group-out 只能作为 OOD 外部敏感性，不能替换 primary fold。任何另一 TMLE、g-formula、IPW 或事后 stacking 都不能替换 primary estimator。

### 3.6 2,000 次整簇 bootstrap 与失败规则

区间估计唯一使用 2,000 次 participant-cluster bootstrap。每次在 `arm×baseline_reviewer_support` 层内有放回抽取完整 participant cluster，保留抽中 multiplicity 和该参与者十二个 trial 的全部记录。bootstrap 域固定为 `C3-JFG-BOOT-20260816-v1`，实际 seed 与 SHA-256 在读取确认性 `Y` 前写入 manifest。

每个 replicate 必须完整重拟 nuisance、重新产生 cross-fit prediction 并重新 targeting。95% 区间唯一为 percentile interval。失败 replicate 不重抽、不补抽。nonfinite value、截断或 ratio 门违反、pipeline 失败都进入分母；失败率超过 5% 时固定输出 `MECHANISM_NOT_ESTIMABLE`，不能改用另一种区间方法。

失败层级也具有唯一顺序：

- identification、support、ratio 或 `C_Y` 门失败，但 cross-fitted HAL initial likelihood 仍有限且可重放时，只报告 `standardized joint-process association`，不得称为中介或间接效应。
- HAL 或 conditional-density 不收敛、任一 outer fold 的 `Y=1` 事件少于 10、ratio/EIC 非有限、`PROCESS_SCHEMA_OMISSION`、bootstrap 失败率超过 5%，或两个实现不能逐字段重放时，不报告任何机制数字。
- 两类失败都不阻止另报随机 policy total effect，但 total effect 不能替代机制门。

至此，随机化单位、处理维持、likelihood、estimand、fold、重抽样和失败输出不再彼此错位。`02T` 的唯一剩余设计门通过。

## 5. common-ground 理论责任复核

Mastrogiacomo 等人的原文将 common ground 理解为团队成员对共享知识的递归认识，并强调项目对话需要为当前协作目的取得足以建立相互理解的证据。其 Table 3 的映射为：

- identification 对应 joint objectives；
- ability 同时对应 joint resources 与 joint risks；
- willingness 对应 joint commitments；
- mutual belief 不是第五类任务内容，而是项目会议与持续对话中围绕上述内容寻找相互理解证据的过程。

原文还把 willingness 到 commitment 的连接说明为实用的研究选择，而没有把它证明成普遍心理定律。其案例研究展示了谈话式工具如何发现和修复参与者感知的共同基础破裂，但不证明 LLM 具有信念，不证明技术 evidence 正确，不推出乘性门、特定张量、coding harm 或 C3 的因果效果。

v5 对这些责任作了合法分层：

1. 理论负责指出 potential access 与 purpose-relative established understanding 的区别，要求 presentation、acceptance、repair 与 reciprocal evidence，并提供 objective/resource/risk/commitment 的内容映射。
2. `J_content` 的外生冻结、`V/B_H/C/M` 的 producer、四路门、乘性聚合、阈值、POMDP、action grammar 和随机干预估计均明确是本文可证伪的算法或识别选择。
3. 乘性门不被写成理论必然形式。等信息通用模型被承认为具有复制表达能力；若公平替代复制有限数据、OOD、方向干预和安全—效率前沿，独立理论算法贡献撤销。
4. action binding、hidden truth、same-reviewer、HMAC 分臂、participant clustering 和 bootstrap 都由实施合同承担，不借 Mastrogiacomo 或肖老师论文作伪背书。

因此，理论确实改变了中间状态、标签来源、前向结构、动作集合和机制干预，同时没有越权承担密码学、统计识别或实验效果责任。common-ground 理论门通过。
