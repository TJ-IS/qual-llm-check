### 3.1 公式链没有隐含的 duration 二次计数

对层 `B_ξ` 与 observed cell `C_d=[l,u)`，v5 先定义

\[
u_l=\max\{F_D(l),\alpha_{\xi-1}\},\qquad
u_u=\min\{F_D(u),\alpha_\xi\}.
\]

`P_phys(m|C_d,B_ξ)` 除以 `u_u-u_l`，所以它是给定层与 duration cell 后的条件 16-mask 质量。`M`中的 duration primitive只取 `(u_u-u_l)/w_ξ`。外层再乘 `w_ξ` 时得到该层 duration cell 的无条件质量，恰好一次。若把 duration mass再乘入 `P_phys`，则同一 fixture 的 joint mass会从约 `2.28096553740211e-8`变为约 `1.90080461450176e-12`；这一分叉违反 v5 明文合同和 Gold-09，不是另一个合规实现。

### 3.3 对“底层计算顺序仍可能分叉”的反证

本轮专门挑战了三个可能被误判为设计门的点。

1. 对 `g∈[-100,50]` 的 2,000,001 点 binary64 网格，直接式 `1-exp(-exp(g))` 与稳定式 `-expm1(-exp(g))` 的最大绝对差为 `1.6653345369377348e-16`。
2. 对固定 seed 生成的一百万组四因子，24 种乘法顺序相对 NumPy 基准的最大绝对差为 `2.220446049250313e-16`。
3. CDF、逆变换、分箱与 quadrature 的部署路径被要求复用同一 GL64 canonical bytes，GL128 与 MPFR-256只审计，不得另进 Bayes 或 planner。

前两项差异都比 `5e-12` 小四个数量级以上；锁定文件中也没有一个已给定 fixture 或已生成 policy 能展示它们改变动作。未来若出现真实 action-boundary 反例，应按实现审计报告并重新冻结，而不是现在凭任意接近阈值的未生成权重预设失败。pinned runtime、stable event law、MPFR 验收和同一实现复用已经满足本设计合同；要求所有平台的底层 elementary function 逐 bit 相同会超出设计责任。

## 6. Benaroch 理论责任没有被外推

Benaroch（2018）原文实际支持以下构念。

- real option是改变投资进程的权利而非义务。
- 被动 wait-and-see 与主动 act-and-see 是两种不确定性处理方式。
- 在最终投资前可以执行零项或多项 optional mitigations。
- mitigations可在离散时点产生 impulse-type effects，当前措施的成本与影响受既往措施及次序条件化。
- 关系可以是替代、互补或协同，因而价值具有 path dependence。
- learning、prevention和coping是三类 mitigation作用。
- 最终边界包含 exercise与不 exercise；附录用格结构展示多项序贯 mitigations。

v5据此引入 passive waiting、zero-or-more action lattice、ordered persistence、exercise/non-exercise和三类role。它没有声称 Benaroch 原文给出了神经 tensor、二阶截断、PostgreSQL migration、hazard head、typed codec、Bayesian belief或风险控制。`W→`、pair tensor、五 bit latent state、`kernel_measure_v1`和数据库映射均明确是作者设计。二阶 tying只有在机制分层出现预注册收缩或排序反转，并且公平 unrestricted history residual不能经验复制时，才可形成新增贡献。理论因此真实改变内部表示与行动格，同时又没有替尚待检验的算法效果背书。

固定 migration substrate也没有被冒充 optional mitigation。协议、checker、runner和oracle提供环境与后果，十八个主动 slots才是可选措施；`D60/EX/AB`分别表示等待、exercise和non-exercise边界。这个区分符合 Benaroch 的责任范围。

### 9.2 保留为 RESULTS/KILL 的经验门

- 至少两个预注册机制分层是否出现行动排序反转。
- `D60` observation是否包含 latent condition信息并改变后继动作，而不只是消耗时间。
- learning、prevention、coping的执行签名是否可识别。
- CodeTwin 的 code channel是否降低 severe harm或cost并保持success，而不只是改变 action ID。
- pair、role、path、defer与non-exercise中和是否改变实际行动和外部结果。
- 五个 `γ` 是否通过15项 simultaneous qualification，qualified set是否非空。
- 主模型相对 `G-PhysicalFactoredSMDP` 是否在 finite-data、unseen-combination与预注册切片上形成 safety-success-cost改善。
