# 论文一算法与实验规格

## 0. 文档口径

本文件是《主动缓解期权格与可靠迁移行动》的自足实施规格 v1.0。下列字段序、概率测度、行动协议、训练目标、统计程序和失败规则共同定义可复现实现；正文结果尚未运行。本文件中的数量、阈值和预期检验不代表已经生成数据、完成训练或取得经验结果。

## 1. 研究问题、单位与外部结果

研究问题是：固定 PostgreSQL 切换前兼容状态后，读取旧、新应用仓库的 coding agent 能否学习真正可选缓解的路径条件性后果，并在 defer、exercise、abandon 与零项或多项缓解之间选择，从而减少数据、语义、可用性与恢复损害，同时保持迁移成功和可接受成本。

基本研究单位是一条从 `READY_COMPATIBLE` 开始、以 `EX`、`AB` 或 `EXPIRED` 结束的 episode。起点必须同时满足：pgroll migration 已 start；old app 仍在 old version schema 上服务；new app 可在 new version schema 上运行；backfill 和 write propagation 已建立；尚未 complete。决策期限为 600 秒，terminal outcome 窗口可在合法启动后延续至 EX 的 720 秒或 AB 的 660 秒。

原始结果向量固定为

\[
Y=(s,a,x,d,v,r,u,w,t,c_{cpu},c_{io},c_{store}).
\]

| 字段 | 类型 | 唯一语义 | 来源 |
|---|---|---|---|
| `s` | binary | migration 成功且 terminal contract 满足 | sealed terminal oracle |
| `a` | binary | 选择 AB 并完成 rollback | executor + oracle |
| `x` | binary | 无合法 terminal 或 episode 到期 | protocol automaton |
| `d` | binary | 数据损害或严重业务语义损害 | hidden oracle |
| `v` | rate | 固定 `Ω_v` 业务断言的加权语义偏差率 | hidden oracle |
| `r` | binary | failback/recovery 失败 | hidden recovery oracle |
| `u` | rate/amount | availability SLO 违约 | gateway authority |
| `w` | rate/amount | write SLO 违约 | gateway authority |
| `t` | seconds | episode 终局时间 | monotonic clock |
| `c_cpu,c_io,c_store` | nonnegative | CPU、I/O、storage 累积 | cgroup/storage authority |

主要严重损害为 `d∨r`。`v/u/w` 为独立实质安全端点。终局效用 `U(Y)`只服务 Bellman recursion；主要论文结论报告原始端点、matched-success/matched-harm 比较与 Pareto 关系，不以拒绝率或单一总分替代安全结果。

终局效用及资源归一化固定为

\[
\begin{aligned}
U(Y)=&100s-25a-40x-500d-300\min(v/0.01,1)-200r\\
&-50\min(u,2)-20w-0.02t-0.001c_{cpu}-0.002c_{io}-0.01c_{store}.
\end{aligned}
\]

其中 `c_cpu=min(core_seconds/2400,1)×100`，`c_io=min((read_bytes+write_bytes)/100GiB,1)×100`，`c_store=min(GiB_minutes/1000,1)×100`。原始未截断资源值另行保存。终局语义率使用 action-invariant reference population `Ω_v(world_id,oracle_version)={(reference_tx_id_i,w_i)}_{i=1}^n`，其中 `w_i>0`，`v=Σ_iw_i1{assertion_i fails}/Σ_iw_i`；reference IDs、权重、分母、oracle version 与 deterministic CBOR hash 在任何 rollout 前封存，同一 world 的所有策略、EX、AB 和 checker coverage 必须逐字节相同，未执行的 reference transaction 仍由 sealed terminal oracle 在同一 snapshot rule 下评价。

## 2. 固定 substrate、行动目录与硬合法性

### 2.1 软件与隔离

- PostgreSQL `17.0`。
- pgroll `v0.16.2`（2026 release metadata），commit `cdbe9b0`。
- 每个 world 在 disposable 容器、独立 database snapshot 与独立 episode reset 中运行。
- 所有风险注入、破坏性测试和回滚只发生在授权隔离环境。
- substrate 固定提供 old/new schemas、backfill、write propagation、complete 与 rollback；这些不是可学习 mitigation。

schema serializer 把二十一条 operator 记录逐条展开为固定十键整数 map：`0:schema_version,1:action_rank,2:action_name,3:mitigation_type,4:d_max_us,5:protocol_preconditions,6:result_validity_bitmap,7:direct_allow_bitmap,8:persistent_decoder_id,9:terminal_flag`，按 action rank 0–20 组成 array。字符串先 UTF-8 NFC，整数使用最短无符号编码，不允许 float、indefinite length、额外 map key 或省略 null。RFC 8949 deterministic CBOR bytes 由 pinned serializer 生成，`operator_schema_hash=SHA256("OPERATOR-SCHEMA-v1"∥CBOR(records))`；decoder registry 另以 `decoder_schema_hash=SHA256("DECODER-REGISTRY-v1"∥CBOR(sorted_decoder_maps))` 固定，并与 operator bytes 一起加载到训练、全部学习基线、planner 与 executor。缺字段、额外字段、bitmap/decoder 不一致或转换后的 `p/q_n/g/t/τ/A_mask` 与从完整记录重算不相等，均使 run 失败。

路径至多包含四种 mitigation、两次 D60 和一个 terminal action，最大 decision depth 为 7。任何 nonterminal action 只有在

\[
HARD\_START_a(x)=\mathbf1\{A^{protocol}_a(x)=1,\ t+d_{max}(a)\leq600\}
\]

时可进入 kernel。到 `t=600` 后 `A_mask` 只保留 protocol-legal EX/AB；均不合法才产生 EXPIRED。started action 必须在 `d_max` 内形成 signed typed result，并按真实时长、结果和资源消耗更新状态。

### 2.3 `F_a^{v4}` 唯一运行顺序

1. wrapper 运行至多 `min(1.000s,600-t)` 的 precheck。
2. `PASSIVE-ADVANCE-v1` 把实际 elapsed interval 及事件推进为新 canonical state，并产生且只产生一条 rank-255 passive record、一次 likelihood 和一次 Bayes update。
3. 在 post-passage state 同时核验 protocol 与 hard-start；失败只写 `mask_changed`，不创建 invocation、不消耗 slot/type，但 precheck 的时间、事件与维护成本保留。
4. 合法则创建唯一 `action_invocation_id`；runner 在 `d_max` 内返回签名结果。
5. global codec 生成 `canonical_record_hash`，observable source IDs 生成 `runtime_binding_hash`，componentizer 生成 `Δℓ` identity。
6. 执行器只从 `T_a` 应用 `r_a,Δg,κ',Δℓ,Δc,t_end`，生成 `executor_state_hash`。
7. 用同一 global-cell 未重权边际 likelihood 更新 belief。
8. 按 started status 更新 `p/q_n`，重算 `τ,A_mask`。

上述八步定义主模型及普通 D60。`No-PassiveInfo` 的 rank-18 D60 是唯一例外：它先在 pre-visible state 核验 `READY_COMPATIBLE,no_active_invocation,d60_count_lt_2,hard_start`，通过后直接调用 §4.3 的 `D60-NULL-v1`，不执行第 1–3 步，也不产生普通 passive authority record；失败时不推进时钟且返回原 pre-visible mask。此分支的 decoder ID、record domain 与 hash domain 均不同于普通 D60，禁止在运行时回落到普通流程。

## 3. 状态、输入和输出

### 3.1 充分状态

\[
x=(b,x^{exec}),\qquad x^{exec}=(p,q_n,g,\kappa,\ell,c,t,\tau,A_{mask}).
\]

`p` 为已启动 mitigation type 位；`q_n∈{0,1,2}`；`g` 保存 action-valid CP/WC persistent state；`κ` 为协议自动机；`ℓ=(ℓ^{evid},ℓ^{out})` 为去重双账本；`c` 为资源累积；`t` 使用微秒整数；`τ=600-t`；`A_mask∈{0,1}^{21}`。`b∈Δ^{31}` 是五比特隐藏风险的 posterior。executor bytes 不含 belief、checkpoint、model seed 或潜在变量。

### 3.2 模型输入张量

| 符号 | shape | 内容 | 泄漏禁止 |
|---|---|---|---|
| `C` | `B×L`, `L≤32768` | old/new source、ORM、query、migration contract tokens | hidden oracle、future trace、test retrieval |
| `G` | `B×N×128`, `N≤4096` | code–schema typed nodes + sparse edges | injection identity |
| `X` | `B×120×48` | 截至决策时点的 telemetry | future timestamp |
| `P` | `B×6×64` | 最近六个 observable typed-history tokens | latent `z/h/ξ` |
| `R_phys` | `B×40` | 当前物理与 persistent state | posterior shortcut |
| `L_evt` | `B×4×12` | evidence/outcome ledger summaries | raw hidden source |
| `τ` | `B×1` | remaining time | — |
| `A_mask` | `B×21` | protocol+hard-start legality | future action success |

`Fusion_static/H_0` 只读取 `C/G`。`X/P/R_phys/L_evt/τ/A_mask` 在明确 head 接口中使用。十八个 mitigation candidates 的 universe、slot order、`d_max` 与 validity masks 对 Full-Code、No-Source 和全部公平 baseline 完全一致。

### 3.3 联合核的事件与累积字段

四个事件 bit 的固定次序为 `DAMAGE_CROSSING,PUBLIC_SEMANTIC_ALERT,SLO_BREACH,RECOVERY_GAP_PROBE`；event mask 使用这一顺序的低位到高位编码为 `0..15`。global record 的六个 accumulator 依次为 `A_u,N_w,D_w,C_cpu,C_io,C_store`，支持为 `[0,2],[0,10000],[0,10000],[0,2400],[0,100×2^30],[0,1000×2^30×60]`；模型的六个连续 primitive 轴则依次为 `A_u,N_w,r_w,C_cpu,C_io,C_store`。`r_w∈[0,1]` 只在 production write gateway 的签名 source ID 唯一、`0≤D_w≤N_w≤10000` 且 source tag 归属 passage 或 direct branch 时有效，量化步长固定为 `10^-6`；`N_w=0` 时只允许结构原子 `r_w=0,D_w=0`，否则监督值为 `round_half_even(10^6D_w/N_w)×10^-6`。每个 source branch 的 `D_w=round_half_even(N_w r_w)` 只由该 primitive pair 经 codec push-forward 产生，任何独立 `D_w` head、logit、mixture、loss 或 decoder 输入都非法；`SLO_BREACH=0` 时 `A_u=0`，为 1 时 `A_u∈(0,2]`。

### 3.4 十三个行动结果字段与全局 cell

十三个连续结果字段按下列顺序编码：`rpo_sec,rto_sec,wal_gap_bytes,storage_age_sec,admission_rate,activation_delay_sec,deferred_write_count,old_client_count,old_client_share,active_tx_count,lock_wait_p95_ms,lag_p95_ms,arrival_rate_ratio`。SR、SV 与 D60 只允许字段 8–13，CP 允许 1–4 与 8–13，WC 允许 5–13；其余字段同时写 `validity=0` 与 CBOR null。字段支持依次为 `[0,120],[0,210],[0,2^30],[0,600],[0,1],[0,20],[0,10000],[0,10000],[0,1],[0,10000],[0,1000],[0,1000],[0,4]`。

`GLOBAL-TYPED-CODEC/1.0` 在 source-authority、signature、validity 与 truth-table 检查后消费 `duration[1]+result[13]+severity[4]+accumulator[6]` 的 `numeric[24]/validity[24]`。time/latency 步长为 1 ms，bytes/count 为 1，share/rate 为 `10^-6`，SLO area 为 `10^-6 SLO-second`，CPU 为 1 ms，I/O 为 1024 bytes，storage 为 1 MiB-second；边界使用 round-half-even，溢出拒绝。`record_v1=[codec_version,action_rank,η,e,o,validity_bitmap,quantized_numeric[24]]`，`canonical_record_hash=SHA256("GLOBAL-RECORD-v1"∥CBOR(record_v1))`，`k_global=SHA256("GLOBAL-CELL-v1"∥action_rank∥η∥e∥validity∥quantized_numeric)`。`K_global` 表示该编码器在上述离散枚举和有界数值格上生成的可数 cell-key 域，而非另一个可学习类别轴；hash 命中后必须逐字节比较完整 CBOR。

`L_P(z,h)` 是唯一 prior logits。定义 `Π_joint(z,h)=softmax_{(z,h)}L_P(z,h)`、`b_0(z)=Σ_hΠ_joint(z,h)` 与 `π_H(h|z)=Π_joint(z,h)/b_0(z)`；canonical forward 分别以全 `z×h` log-sum-exp 和固定 `z` 内的 `h` log-sum-exp 计算，并断言二者的 ratio 误差不超过 `5e-12`。episode 初始 belief 唯一为 `b=b_0`，`L_risk` 只消费 `b_0`；任一后续 microbranch、observed likelihood、Bayes 与 planner 只消费当前 posterior `b` 和条件分布 `π_H`，不得再次乘 `Π_joint` 或 `b_0`。

## 4. 架构与理论进入前向计算

### 4.1 静态编码器

- code Transformer：6 layers，`d_model=384`，6 heads，FFN 1536。
- typed graph Transformer：6 layers，`d_model=384`，6 heads，使用冻结 edge types。
- static fusion：4 layers，`d_model=512`，8 heads，输出 `H_0`。
- 模型规模目标约 80M trainable parameters，实际值由实现 manifest 报告。

### 4.2 主动缓解直接作用

四个 mitigation family 的角色为 `ρ(SR)=learn`、`ρ(SV)=learn`、`ρ(WC)=prevent`、`ρ(CP)=cope`。对允许的输出 head family `h`：

\[
\psi_h(m,z,p)=M^h_m\odot u_{h,m}(H_0,z)+
\sum_{j<_{p}m}M^h_{j,m}\odot
\left[q_{h,\rho(j),\rho(m)}(H_0,z)+\lambda\widetilde v_{h,j\rightarrow m}(H_0,z)\right].
\]

可达顺序对固定为 `E={(j,m):j≠m,mitigation_type(j)≠mitigation_type(m)}`。十八槽包含八个 SR、八个 SV、一个 CP 与一个 WC，故 `|E|=8×8×2+16×1×4+1×1×2=194`。七个且仅七个非空理论组为 `learn→learn(128),prevent→learn(16),cope→learn(16),learn→prevent(16),cope→prevent(1),learn→cope(16),prevent→cope(1)`；箭头左侧是 prior role，右侧是 current role。对每个非空 `G_ab=E∩{(j,m):ρ(j)=a,ρ(m)=b}` 配置一个加性共享 `q_{h,a,b}`，不可达对在 serializer、forward、loss 与参数表中均不存在。

raw 槽位残差只为 `E` 中 194 对分配，固定为 rank-4 `r_{h,jm}=A_h(H_0,z)B_{h,jm}`。先取 `\bar r_{h,jm}=r_{h,jm}-|G_ab|^{-1}Σ_{(j',m')∈G_ab}r_{h,j'm'}`，再用组内共同尺度 `s_{h,ab}=max(1,max_{G_ab}||\bar r_{h,jm}||_2/0.25)` 定义 `\widetilde v_{h,jm}=\bar r_{h,jm}/s_{h,ab}`。每组严格满足 `Σ_{G_ab}\widetilde v=0`、`rank≤4` 与 `||\widetilde v||_2≤0.25`；两个单元素组 residual 恒为 0。主模型固定 `λ=1`，role-only 机制运行固定 `λ=0`。这一加法分解令角色对分量等于组均值，避免可吸收的乘法 `R×v`。

### 5.2 absolute-time hazard

`time_bin_edges_us=(0,60000000,120000000,180000000,240000000,300000000,360000000,420000000,480000000,540000000,600000000)`。`Λ_j` 是完整第 `j` 个 60 秒箱的 event probability，使用 complementary-log-log 整箱语义。exact duration `d` 从 action start `t` 暴露到 `t+d`，重叠微秒数 `Δ_j` 的无量纲 exposure 为

\[
\omega_j=\frac{\Delta_j}{60{,}000{,}000}.
\]

canonical binary64 forward 固定为

\[
p= -\operatorname{expm1}\left(\sum_j\omega_j\operatorname{log1p}(-\Lambda_j)\right).
\]

passage 与 direct 对同一 exact duration 分别得到四个 bit probability。令 `q_b^P(d),q_b^D(d)` 为其稳定 forward，source-mask pair 的条件质量唯一为 `P_phys(e^P,e^D|d)=∏_{b=1}^4[q_b^P]^{e_b^P}[1-q_b^P]^{1-e_b^P}[q_b^D]^{e_b^D}[1-q_b^D]^{1-e_b^D}`；canonical numeric order 先 `e^P=0..15`、再 `e^D=0..15`，observable mask 才投影为 `e=e^P∨e^D`。duration integrator 对 256 个 source pairs 各自积分，随后按 observed 16-mask 汇总并保留 `(e^P,e^D)` 给 severity/accumulator link；禁止先积分四个边际再相乘或丢失 BOTH provenance。

### 5.3 duration-cell 条件积分

\[
M_{azh\eta e^Pe^D\xi}(C_{global})=
\sum_{C^{prim}:\,Link_{codec}(C^{prim},\eta,e^P,e^D)=C_{global}}
\prod_{c\in\mathcal P_{valid}(a,\eta,e^P,e^D)}p_{c\xi}(C^{prim}_c).
\]

`Link_codec` 先对每个 primitive cell 量化，再执行 source truth table、BOTH 卷积与 support clipping；多个 primitive 原像命中同一 `C_global` 时逐项求和。observable likelihood 还对全部满足 `e^P\lor e^D=e` 的内部 source-mask pairs 求和。`P_phys` 始终是给定 `C_d,B_ξ` 的条件 event mass；完整 branch 在 `M` 外唯一乘 `p^d_ξ(C_d)`，而 duration-free 的 `M` 不再乘 duration density 或 CDF mass。训练的 primitive losses、observable NLL、给定 `z` 的 `ℓ_z(T_a)`、Bayes update 与 planner push-forward 全部调用同一 `p^d×P_phys×Γ_tool×M×O` 数值测度和 invalid-atom mask。

`MEASURE-MASS-GOLD-01` 固定一个 BOTH 分支：passage primitive cells 的质量为 `(0.25,0.75)`，direct 为 `(0.40,0.60)`，三项 resource cells 分别为 `(0.50,0.50)`、`(0.25,0.75)`、`(0.80,0.20)`，其余 valid primitive 与 invalid atoms 都是质量 1 的结构点。实现必须枚举 `2×2×2×2×2=32` 个 primitive preimages；首项贡献恰为 `0.25×0.40×0.50×0.25×0.80=0.01`，碰撞项按 global key 求和，最终 `Σ_{C_global}M(C_global)=1` 且误差不超过 `5e-12`。`MEASURE-LINK-GOLD-02` 固定 passage `(A_u,N_w,r_w,S)=(0.4,3,0.333333,0.2)`、direct `(0.8,5,0.4,0.7)`；passage-only 必须输出 `(0.4,3,1,0.2)`，direct-only 输出 `(0.8,5,2,0.7)`，BOTH 输出 `(1.2,8,3,0.7)`。再把任一支的 `r_w` validity 置 0，必须得到 invalid record，而非调用独立 `D_w` 预测。single-branch、BOTH、resource-product 与 mass-one fixtures 均由训练、Bayes、planner 三入口读取同一 runtime bytes/hash，任一入口概率差异或总质量失败即停止运行。

`PRIOR-MASS-GOLD-01` 要求 `Σ_{z,h}Π_joint(z,h)=1`、`Σ_zb_0(z)=1`、对每个 `z` 有 `Σ_hπ_H(h|z)=1`。除 `b_0` 外，再固定 `b^{edge}(0)=0.7,b^{edge}(31)=0.3` 与 `b^{uniform}(z)=1/32`；任一归一 posterior `b` 都必须满足 `Σ_zb(z)Σ_hπ_H(h|z)=1`。`KERNEL-MASS-GOLD-03` 对每个非终局 action、上述三个 beliefs 及连续和 deterministic duration 两类输入枚举完整核：

\[
\sum_z b(z)\sum_h\pi_H(h\mid z)\sum_\xi w_\xi
\sum_{C_d}p^d_\xi(C_d)\sum_{e^P,e^D}P_{phys}(e^P,e^D\mid C_d,B_\xi)
\sum_\eta\Gamma_{azh\xi\eta}\sum_{C_{global}}M_{azh\eta e^Pe^D\xi}(C_{global})
\sum_o O_{azh\eta\xi,(e^P\lor e^D),o}=1.
\]

枚举顺序固定为 `z,h,ξ,duration-cell,eP,eD,status,global-cell,observation`，每层使用 canonical numeric order；各条件分布的质量误差与整核误差均不得超过 `5e-12`。dense fixture 对三个 belief 逐一固定 `π_H=1/8`、十九个 `w_ξ=(0.075,0.05×17,0.075)`、每个 stratum 内 900 个等质量 duration cells、八个 event bits 均为 0.5 从而 256 个 source pairs 各为 `1/256`、四个 status 各为 `1/4`、两个 global cells 为 `(1/3,2/3)`、三个 observations 各为 `1/3`；其 exact factor sum 为 `(Σ_zb_z)×(8/8)×1×(900/900)×(256/256)×(4/4)×1×(3/3)=1`。deterministic-duration 版本把 900 项改为一个质量 1 与 899 个 0，其余 axes 不变。同一 fixture 必须由 `L_globalN`、Bayes likelihood 与 planner branch enumerator 三入口返回相同 binary64 bytes/hash；Gold-09 只作为其中 `P_phys` 的 conditional diagnostic，不能代替整核归一化。

规划分布是 observable push-forward：

\[
Q^a_\theta(T\mid x)=\sum_{\widetilde T:\operatorname{Canon}_a(\widetilde T)=T}
\widetilde Q^a_\theta(\widetilde T\mid x).
\]

相同 `canonical_record_hash` 的所有 `z/h/ξ` 和 cells 必须在建 chance child 前合并。key 不含 `z/h/ξ/model seed/posterior`。

给定 `z` 的 observed likelihood 记为 `ℓ_z`，与训练中的 risk-label BCE `L_risk` 区分：

\[
\ell_z(T_a)=\sum_{h,\xi}\sum_{e^P\lor e^D=e}\pi_H(h\mid z)w_\xi p^d_\xi(C_d)
P_{phys}(e^P,e^D\mid\cdot,C_d)\hat\Gamma^{tool}_{azh\xi\eta}
M_{azh\eta e^Pe^D\xi}(C_{global})\hat O_{azh\eta\xi eo}.
\]

Bayes update：

\[
b'(z)=\frac{b(z)\ell_z(T_a)}{\sum_{z'}b(z')\ell_{z'}(T_a)}.
\]

terminal branch 对 `a∈{EX,AB}`：

\[
Q^a_\theta(j,C_v,C_t,C_K,z,h,\xi\mid x)=
b(z)\hat\pi_h^T(x^{exec},a,z)w_\xi\mathrm{Cat}(j;\hat J_{azhj})
M^T_{azhj\xi}(C_v,C_t,C_K),
\]

`j=(s,d_new,r)`。EX state-level severe risk 对全部 latent/cells 积分 `1{C_d_pre=1 or d_new=1 or r=1}`。terminal 不外推 nonterminal hazard，不回写 passage interval。

## 7. Hard option lattice 与搜索

\[
V_\theta(x)=\max\{Q^{AB}_\theta,Q^{EX}_\theta,Q^{D60}_\theta,
\max_{m\in\mathcal M(x)}Q^m_\theta\}.
\]

nonterminal Bellman term：

对每个非终局 policy-visible state `x`，先定义投影行动 `a_proj(x)`：EX 合法时取 EX，否则 AB 合法时取 AB，否则取 EXPIRED。`Y_θ^{vis}(x)` 是在当前 `b,H_0,x^{exec}` 下用冻结 terminal kernel 对 `a_proj(x)` 的 `s,a,x,d,v,r,u,w,t,c_cpu,c_io,c_store` 逐分量求条件期望所得向量；已发生的公开 `u,w,t,c` 从 executor bytes 原样进入，未决分量只由 `b` 与模型预测积分，sealed oracle value、hidden risk label、future telemetry 和 test outcome 均不可读取。EXPIRED 的投影向量固定为 `(0,0,1,0,0,0,u,w,t,c_cpu,c_io,c_store)`。令 `Φ_θ(x)=U(Y_θ^{vis}(x))`，终局 `Φ(Y_T)=U(Y_T)`；这一定义既给非终局 `Y(x)` 唯一语义，也使 hidden oracle 不进入即时效用。

\[
Q^a_\theta(x)=\sum_TQ^a_\theta(T\mid x,a)
\left[\Phi_\theta(F_a^{v4}(x,T))-\Phi_\theta(x)+V_\theta(F_a^{v4}(x,T))\right].
\]

terminal term 积分 `U(Y_T)-Φ_θ(x)`；沿任一路径的 potential difference telescopes，终局只保留一次 `U(Y_T)`。训练 lattice-calibration 用 temperature `0.10` log-sum-exp；推断与外部 evaluation 用 hard max。

搜索固定 AND-OR branch-and-bound：

- depth ≤7；每 root state 最多 200,000 expanded states。
- chance node 在 observable record probability 上求期望。
- terminal node exact lower=upper。
- 未展开 lower bound：AB if legal，else EX，else EXPIRED。
- upper bound 只读 visible protocol/remainder/已发生 harm/cost，禁止 future truth。
- decision prune：child `UB≤incumbent LB`。
- chance child 不因低值删除；仅 observable record 和 bounds 均同才折叠。
- cap 前 gap 0 写 exact certificate；触 cap 选择 root LB 最大，平手用固定 action rank。
- 保存 selected LB、root UB、gap、frontier size、pruning counts。

memo key：`SHA256("LBM-1.5"||world_id||episode_reset_id||checkpoint_hash||gamma_value||utility_hash||H0_hash||candidate_universe_hash||operator_schema_hash||planner_state_bytes)`；`planner_state_bytes=CBOR(b,executor_state_bytes)`。完整 bytes collision check 必须启用。

## 8. 训练样本、loss 与优化

### 8.1 样本和标签

- raw transition：同一 observable `(η,k_global,e,o)` joint record，每条有效记录权重 1。
- risk-bit labels：只在 train world 使用，test 不输入。
- passage labels：absolute interval + production-authority sources。
- direct labels：source-authority 可归因 direct paths。
- tool labels：status、13 action-valid result fields 与 observation；duration 只在未重权的 global joint record 中监督。
- resource labels：cgroup/gateway opportunity records。
- terminal labels：统一 `Ω_v` denominator 的 `s,d,r,v,u,w,duration,cost`。
- `ENUM-TRAIN` partial ranking：固定四代表 slots、64 个非空 ordered subsets 加 1 个 empty sequence，共 65 条 fixed-continuation sequences；common seed、fixed `π_ref` continuation；不是 full oracle。

### 8.2 总损失

\[
\mathcal L=0.5L_{risk}+L_{globalN}+0.5L_{pass}+0.5L_{direct}+0.5L_{tool}
+0.5L_{resource}+L_{term}+0.2L_{lat}+0.1L_{cal}.
\]

`L_risk` 只使用 train world 的五个 sealed risk-bit labels，绝不作为 test input。令 `p_{ik}=Σ_zb_0(z|x_i)1{z_k=1}`、`m_i^R=1` 表示该 train label 可用、`B_R=5Σ_i m_i^R`，则

\[
L_{risk}=-B_R^{-1}\sum_{i,k}m_i^R\{z_{ik}\log\max(p_{ik},2^{-52})+(1-z_{ik})\log\max(1-p_{ik},2^{-52})\}.
\]

`B_R=0` 时该 batch 的 `L_risk` 权重为 0；完整 epoch `ΣB_R=0` 则训练失败。该 BCE 的唯一 prior 输入是 joint logits 的风险边际 `b_0`；§6 的 `ℓ_z(T)` 只读取 `π_H(h|z)`，二者不得共享概率因子、缓存或 reduction。

passage/direct 的监督单位是 authority 完整覆盖的 absolute-time bin。令 `y^P_{ibj},y^D_{iabj}∈{0,1}`，其中 `b=1,…,4`、`j=1,…,10`，mask `m^P_{ibj}` 仅在 passage authority 对完整 60 秒箱无缺口时为 1，`m^D_{iabj}` 还要求 direct source 唯一归因给已启动 action `a`；部分箱、重复 source、越界 timestamp 和 source 冲突的 mask 均为 0。以 `H(q,y)=-y log max(q,2^-52)-(1-y)log max(1-q,2^-52)` 定义

\[
L_{pass}=B_P^{-1}\sum_{ibj}m^P_{ibj}H(Λ^P_{ibj},y^P_{ibj}),\quad B_P=\sum m^P;
\qquad
L_{direct}=B_D^{-1}\sum_{iabj}m^D_{iabj}H(Λ^D_{iabj},y^D_{iabj}),\quad B_D=\sum m^D.
\]

tool 辅助目标只消费 schema-valid primitive。对 record `i`，`m_i^η,m_i^o` 分别表示签名 status 与 observation 有效，`m_{if}^r` 表示第 `f` 个 result field 对该 action 有效且 cell 边界完整；`P^r_{if}=F_{if}(u_{if})-F_{if}(l_{if})`。令 `B_tool=Σ_i(m_i^η+m_i^o+Σ_fm_{if}^r)`，则

\[
L_{tool}=-B_{tool}^{-1}\sum_i\left[m_i^η\log\max\{Γ_i(η_i),2^{-52}\}+m_i^o\log\max\{O_i(o_i),2^{-52}\}+\sum_{f=1}^{13}m_{if}^r\log\max\{P^r_{if},2^{-52}\}\right],
\]

其中每个 `max` 的下界均为 `2^-52`，所有概率按 canonical axis 积分 `z,h,ξ` 后取得。primitive 辅助目标的索引集固定为 `I_i={(P,A_u),(P,N_w),(P,r_w),(D,A_u),(D,N_w),(D,r_w),(R,C_cpu),(R,C_io),(R,C_store)}`；只有 source-authority、branch tag、action allowlist、support 与 quantization 同时有效的项才令 `m^c_{ib}=1`，其 cell mass 为 `P^c_{ib}=F^c_{ib}(u)-F^c_{ib}(l)`，并令 `B_C=Σ_iΣ_{(b,c)∈I_i}m^c_{ib}`：

\[
L_{resource}=-B_C^{-1}\sum_i\sum_{(b,c)\in I_i}m^c_{ib}\log\max(P^c_{ib},2^{-52}).
\]

`D_w` 不属于 `I_i`，不产生独立辅助项；它只通过 `(N_w,r_w)` 的 deterministic push-forward 进入 `L_globalN`。passage-only/direct-only record 只开放相应三项，BOTH 必须同时开放并分别计数，无法唯一绑定 source 的 primitive 只由 global joint NLL 消费。`B_P,B_D,B_tool,B_C` 任一为 0 时，相应 batch 项权重置 0 且不产生 NaN；完整 epoch 的相应 denominator 为 0 时 run 失败。mask、分母和 cell mass 均从同一 canonical record bytes 与 source binding 复算，禁止以 batch size、无效字段数或 padding 数替代分母。

令 `m_i^v` 表示 joint record 的 schema-valid mask，`B_v=Σ_i m_i^v`，则 `L_globalN=-(1/B_v)Σ_i m_i^v log max(P_θ(η_i,k_i,e_i,o_i|x_i,a_i),2^-52)`；`B_v=0` 的 batch 重抽，连续十次为空则 run 失败。初始 record 使用 `b_0`，后续 record 使用前一 observable history 得到的 current `b`，且 `P_θ(T_i|x_i,a_i)=Σ_zb_i(z)ℓ_z(T_i)`；`ℓ_z` 必须对 `h/ξ`、`e^P\lor e^D=e_i` 的 source pairs 与 `Link_codec` primitive preimages 求和，并在 duration-free `M` 外唯一乘 observed cell 的 `p^d_ξ(C_{d,i})`。不得使用 `Π_joint` 重复 prior、独立 `D_w` head、class reweight、latent-specific cell、representative-duration NLL 或四边际 surrogate。每个 epoch 必须通过 `PRIOR-MASS-GOLD-01`、`DURATION-MASS-GOLD-10` 与 `KERNEL-MASS-GOLD-03`，并断言 training、Bayes、planner 的概率 bytes/hash 相同。

对 terminal-valid mask `m_i^T` 和 `B_T=Σ_i m_i^T`，定义

\[
P^T_i=\sum_h\Pi_T(a_i,z_i,h)J(s_i,d_i,r_i\mid a_i,z_i,h)
P_{V_v}(C_{v_i})P_{D_T}(C_{d_i})P_{K_T}(C_{K_i}),\qquad
L_{term}=-B_T^{-1}\sum_i m_i^T\log\max(P^T_i,2^{-52}).
\]

`C_K` 是六个 terminal accumulator 的同一 global cell，所有 action-invalid terminal 字段令 `m_i^T=0`；`B_T=0` 时本 batch 的 `L_term` 权重为 0，epoch 级 `ΣB_T=0` 则 run 失败。`P_{K_T}` 对 valid `A_u,N_w,r_w,C_cpu,C_io,C_store` 使用 §6 的同一条件 primitive product 与 `Link_codec` 原像求和，terminal `D_w` 仍无独立 head；语义率、duration 和 accumulator cell mass 各进入一次，`J` 的八类不再拆为三个边际。

`ENUM-TRAIN` 为每个 group 冻结 65 条序列及所有可比 pair。对 pair `(u,v)`，真实 fixed-continuation return 差大于 `ε_U=10^-9` 时 `y_uv=1`，小于 `-ε_U` 时为 0，其余 ties 为 `1/2`；invalid continuation 的 mask 为 0。soft lattice 以 temperature 0.10 得到 `\widetilde V_u,\widetilde V_v`，`p_uv=sigmoid((\widetilde V_u-\widetilde V_v)/0.10)`，并定义

\[
L_{lat}=-B_{lat}^{-1}\sum_{uv}m_{uv}\{y_{uv}\log\max(p_{uv},2^{-52})+(1-y_{uv})\log\max(1-p_{uv},2^{-52})\},
\quad B_{lat}=\sum_{uv}m_{uv}.
\]

`B_lat=0` 时本 batch 权重为 0；完整 epoch 没有有效 pair 则失败。梯度只能穿过 soft recursion 回到 primitive/role/path kernel，不得建立 policy head。

令 `p_i=Σ_{c:d(c)∨r(c)=1}J_i(c)`、`y_i=d_i∨r_i`。在 `B_cal=B_T` 个 terminal-valid records 上，`L_Brier=B_cal^{-1}Σ_i m_i^T(p_i-y_i)^2`。可微校准项固定 15 个中心 `c_k=(k-0.5)/15`、带宽 `h=1/15` 与权重 `a_ik=max(0,1-|p_i-c_k|/h)`；`W_k=Σ_i m_i^Ta_ik`，空 bin 贡献 0，非空 bin 取 `\bar p_k=Σa_ikp_i/W_k,\bar y_k=Σa_iky_i/W_k`，并令 `L_sCE=Σ_k(W_k/B_cal)(\bar p_k-\bar y_k)^2`、`L_cal=L_Brier+L_sCE`。`B_cal=0` 时本 batch 权重为 0，epoch 级为空则失败。

### 8.3 优化

- AdamW；lr `2e-4`；weight decay `0.01`；gradient clip `1.0`。
- 5,000-step linear warmup 后 cosine decay。
- transition batch 64；最多 120,000 updates。
- 每 2,000 steps 在 A06–A09 的 `VAL-SELECT` 外部 transition、`VAL-ORDER` fixed-continuation pair 和 terminal records 上评价；三集合 world_id/snapshot/seed 与 train、policy calibration、ENUM-TEST、test 均不重叠。
- 固定 `ES=NLL_joint/NLL_joint(step0)+order_regret/order_regret(step0)+Brier_harm/Brier_harm(step0)`；三个 step-0 分母必须有限且大于 0。
- 改善阈值 `10^-4`，patience 8；同一最小 ES 选较早 checkpoint，任一指标非有限或来源越界则该 seed 失败。
- model seeds `{17,31,47,61,73}`；逐 seed 报告。

checkpoint 后每 seed 在 `VAL-CAL-POLICY` 1,000 个 generator worlds 上从 `γ∈{0.01,0.02,0.05,0.10,0.20}` 选择一个候选。该 generator 对 A06–A09 与 M1–M4 等权，对 W0–W2 等权，并从训练支持内的单风险与无风险配置等权抽样；world_id、snapshot、workload seed、risk seed 与 `VAL-SELECT/VAL-ORDER` 全部不重叠，`calibration_generator_hash` 在 checkpoint 训练前封存。每个候选与固定 `threshold-canary` reference 从相同 reset snapshot 独立完整运行。设 `D_i=Y^S_{i,k}-Y^S_{i,ref}∈[-1,1]`；资格化用 `α_k=0.05/15` 的 Clopper–Pearson severe-harm 上界、success 下界，以及 `L^{ΔS}=mean(D)-sqrt(2log(15/0.05)/1000)` 的 paired Hoeffding 下界。三项阈值依次为 `U_SH≤0.05,L_S≥0.20,L_ΔS≥-0.05`；通过者按 mean utility、success、总归一化 cost、较小 `γ` 的词典序选唯一值。不得更新 weight、operator、utility、reference、candidate set 或 generator。

十八个 FastAPI/SQLAlchemy apps，四项 migration：

- M1 replacement/rename。

## 10. 公平基线

### 10.1 理论生死基线 `G-PhysicalFactoredSMDP`

与主模型逐对象相同：visible bytes、raw/global/partial labels、21 actions、`d_max`、passage/direct/tool/resource/terminal heads、physical closure、codec、measure、GL64、belief、executor transition、loss、optimizer、training records、qualification worlds、hard recursion、memo/pruning/tie-break、200k cap。唯一差异：主模型的 main 加角色组均值和中心化 ordered-pair residual 被 unrestricted history residual 替换。

residual serializer 固定 18 tokens：`[CLS],H_0,e_m,a_contract,b,g,κ,ℓevid,ℓout,c,t,τ` + 6 `P` tokens。4-layer pre-LN bidirectional Transformer 永久固定 `d_model=384`、6 heads、dropout 0.10 与 learned absolute position 18；每层 FFN 恰为 `Linear(384,W,bias=True)→GELU→Linear(W,384,bias=True)`，因此 `W` 只是 FFN inner width，不改变 token width 或 head divisibility。七 family outputs 通过独立低秩 MLP，dimensions `(608,29184,152,464,1976,7528,21888)`。

`GENERIC-QUOTA-v6` 的 tuple 固定为 `q=(W,r_tool,r_obs,r_dur,r_evidence,r_persist,r_availwrite,r_resource)`，`W∈{384,385,…,3072}`，七个 rank 各在 `1..128`。令上述七个输出维度为 `d_f`、不随 `q` 变化的可训练参数为 `P_fixed`，则含 bias 的唯一参数式为 `P_G(q)=P_fixed+4(2×384W+W+384)+Σ_f{(384+1)r_f+(r_f+1)d_f}`；`W` 只进入四层 FFN inner width，所有 adapter 输入仍为 384。`generic_graph_schema_v6` 的 canonical source bundle 恰含 `graph_schema.json`、`head_registry.json`、`tensor_axes.json`、`trace_contract.json` 四个 UTF-8 NFC 文件，并按 §9.1 `SOURCE-BUNDLE-v1` 规则生成 bytes；`generic_graph_schema_hash=SHA256(ASCII("GENERIC-GRAPH-SCHEMA-v6\0")∥source_bundle_bytes)`，实现前为 `PENDING-IMPLEMENTATION`。`ConstructGraph(q)` 是纯函数：按 canonical head order 建立 18-token serializer、固定 384 维与 6-head 的四层 backbone、由 `W` 指定的 FFN、七个低秩输出 adapter 与 lattice adapter；输出 deterministic CBOR `graph_record=[schema_hash,q,sorted_nodes,sorted_edges,parameter_ids,tensor_axes,dtype]` 及其 `GENERIC-GRAPH-v6` SHA-256，再由 pinned tracer 在 batch 1 和 64 复算参数与 MAC。任何 schema hash pending、q 越界、graph build、shape inference、双进程 graph hash 或 trace 失败都把该 q 标记 infeasible。

MAC 比较使用与 label 无关的 `trace_contract.json`，21 个 action case 按 canonical ID 各出现一次，输入取 §3.2 的最大合法 shape 与固定 validity mask。对每个 `a` 定义 `M^infer_a(q)=MAC_forward(q,a,B=1)`、`M^train_a(q)=MAC_forward(q,a,B=64)+MAC_backward(q,a,B=64)`，并令 `δ^max_infer=max_a|M^infer_a(q)-M^infer_a(main)|/max(M^infer_a(main),1)`、`δ^max_train` 同理；逐行动分母为零时 `max(·,1)` 仍使非零 generic MAC 失败。总量 `δ^Σ_infer=|Σ_aM^infer_a(q)-Σ_aM^infer_a(main)|/max(Σ_aM^infer_a(main),1)` 与 `δ^Σ_train` 只作补充 tie-break，不代替逐行动门。tracer manifest 必须保存 42 个逐行动整数、四个 delta、action-order hash、graph hash 与 runtime hash；optimizer、I/O、planner 和数据库执行不计入两侧但另行等额控制。

搜索不用七维 rank 笛卡尔穷举。第一阶段对每个 `W` 与每个 action 从 graph schema 导出精确整数参数和 train/infer MAC 系数，系数不得由 label 或性能拟合。第二阶段按七个 head 顺序运行动态规划，state 为 `(k,parameter_sum,train_MAC[21],infer_MAC[21])`，从 rank 1 到 128 扩展；剩余 rank 的逐行动最小/最大可达区间、参数系数 gcd 或参数上下界若已不能到达 `P_main` 与全部 0.5% action bands，就立即剪枝，同一完整整数 state 只保留字典序最小 prefix。第三阶段只对 `parameter_sum=P_main` 且 42 个逐行动约束都满足的终态调用 `ConstructGraph` 与 tracer，symbolic/traced 任一不一致则 run 失败。DP 状态数、扩展数、逐行动剪枝原因与 frontier hash 必须落盘；20,000,000 state 上限触发 `SEARCH-INCOMPLETE`，不得从未穷尽 frontier 选择近似解。

可行集合为 `F={q:P_G(q)=P_main,δ^max_train(q)≤0.005,δ^max_infer(q)≤0.005,all_heads_active(q)=1}`，唯一选择是按 `(max{δ^max_train,δ^max_infer},δ^max_train,δ^max_infer,δ^Σ_train,δ^Σ_infer,W,r_tool,r_obs,r_dur,r_evidence,r_persist,r_availwrite,r_resource)` 取字典序最小元。`F=∅`、DP 未穷尽、任一逐行动约束失败、`ConstructGraph(q*)` 复算不符、两次空进程的 frontier hash 或 `q*` 不同、manifest 仍为 `PENDING-IMPLEMENTATION`，均使公平主比较失败。`generic_quota_manifest` 在解封 labels 前保存 schema/runtime hash、参数式与系数表、逐行动 tracer、DP frontier hash、候选终态、淘汰原因、selected tuple 与 traced graph hash；总 MAC 只用于上述 tie-break 和描述报告。

`TEST-GENERATOR/1.1.0` 是唯一 generator ID，并定义四个互斥主要切片。基础风险支持固定为 `S_base={C0,{R1},{R2},{R3},{R4},{R5}}`，组合风险支持固定为 `S_hold={C3,C4,C5,C6}`。每个 app×slice 的 `draw_index=0,…,n_s-1` 均是一次独立有放回 draw：ID 对 A00–A05 取 `n_s=216`，从 `M1–M4×W0–W2×S_base` 的均匀乘积分布抽取；Repo-OOD 对 A10–A17 取 `n_s=360` 且使用同一因素分布；Workload-OOD 对 A10–A17 取 `n_s=120`，从 `M1–M4×{W3}×S_base` 抽取；Risk-combination-OOD 对 A10–A17 取 `n_s=320`，从 `M1–M4×W0–W3×S_hold` 抽取。因而计划数仍为 `1,296+2,880+960+2,560=7,696` 个主要 world，30 个 primary app×slice cell 均有固定样本数；再加 CodeTwin 1,080 与 full-policy D60 1,152，得到每项学习策略 9,928 个外部评价 world。

令 `g=hex_to_bytes(generator_source_hash)`，切片按 `(ID,REPO_OOD,WORKLOAD_OOD,RISK_COMBINATION_OOD)` 编为 `U8BE(0..3)`，app 按 `(A00..A05,A10..A17)` 的表内次序编为 `U16BE(0..13)`。唯一 draw key 为 `HMAC-SHA256(key=g,msg=ASCII("WORLD-DRAW/1.1.0\0")∥U8BE(slice_rank)∥U16BE(app_rank)∥U64BE(draw_index))`。定义 `SubKey(k,label)=HMAC-SHA256(key=k,msg=ASCII("WORLD-SUBKEY/1.1.0\0")∥U16BE(byte_len(label))∥ASCII(label))`；label 的唯一有序表为 `FACTOR/MIGRATION,FACTOR/WORKLOAD,FACTOR/RISK,SNAPSHOT,WORKLOAD-SEED,RISK-SEED,RESET-SEED,COUNTER-STREAM`。`UniformIndex(subkey,n)` 从 `counter=0` 开始，依次取 `HMAC-SHA256(key=subkey,msg=ASCII("UNIFORM-INDEX/1.1.0\0")∥U32BE(n)∥U64BE(counter))` 的前八字节作为 unsigned big-endian 64-bit 值，拒绝 `value≥floor(2^64/n)n`，否则返回 `value mod n`；counter 溢出、`n=0` 或整数越界均使 generator run 失败。migration、workload 与 risk 各从其 canonical category array 以对应 factor subkey 取一次 index；其余五个 subkey 的完整 32 bytes 分别作为 snapshot、workload、risk、reset 与 counter stream seed，reset 与因素选择独立，任何 label、counter 或子流均不得复用。

相同 migration/workload/risk tuple 可在不同 draw_index 重复，且仍以全新 snapshot、reset seed 和无共享可变状态的数据库实例形成独立实验单位。`world_id` 必须按 §9.1 的 `WORLD-v2` 公式包含 draw_index；不同 registry 行若 world_id bytes 或 reset-seed bytes 相同，整个 generator run 在解封前失败，不进行自适应重抽，修改 source bundle/version 后才可重新生成。四个切片分别以固定 app 权重报告，不以跨切片平均替代；因素细格只作预注册描述性异质性。主要 theory contrast 是主模型 vs `G-PhysicalFactoredSMDP`；确认性 family 另含主模型 vs `G-JointSMDP`、主模型 vs `G-POMDP`，四个 slice×三个 contrasts=12，`G-LatticeNoRolePair` 只承担命题 2 机制检验。同时报告 `d∨r,s,v,u,w,wall-clock,resource,AB,EXPIRED,U`；matched success 比 harm，matched harm 比 success/cost。

### 11.1 failure-as-harm 字段映射

ordinary signed `TIMEOUT/FAILED`、合法 AB 与合法 EXPIRED 若仍能完成冻结 terminal oracle，均使用实际 `Y`，不视为缺失失败。只有模型/规划器未返回合法动作或产生 NaN/invalid probability 的 `F-MODEL`、方法专属 action/executor 使 episode 在 oracle 前不可恢复的 `F-EXEC`、方法专属容器/进程/配额崩溃的 `F-RUNTIME`，以及共享 host、snapshot、PostgreSQL、workload driver 或 oracle 故障的 `F-SHARED-INFRA` 进入下表。`F-SHARED-INFRA` 必须在相同 world/reset 上具有相同 `(stage,component,image_digest,error_code,trace_prefix_hash)`，并在中性 no-op harness replay 中复现；不满足者归到受影响方法的 `F-RUNTIME`。schema、manifest、hash、kernel mass 或配置合同失败属于整次 run invalid，停止分析，不能通过端点填补继续出结果。

定义 `unsafe=1{d=1∨r=1∨v>0∨u>0∨w>0}`、`harm=d∨r`。failure-as-harm 的唯一填补向量按 §1 字段序为 `Y_F=(s,a,x,d,v,r,u,w,t,c_cpu,c_io,c_store)=(0,0,1,1,1,1,2,1,720,100,100,100)`；由此 cost scalar `C_F=0.02×720+0.001×100+0.002×100+0.01×100=15.7`，`U(Y_F)=-1175.7`。原始实际 elapsed/core-seconds/I/O bytes/GiB-minutes 只写 sidecar，评价字段使用表列上界；实际计量缺失时 raw 字段为 canonical null，不以 0 替代。

| failure class | task/s | unsafe/harm | `d,r,v,u,w` | time | CPU/I/O/storage | AB/expired | cost/U | paired rule |
|---|---|---|---|---|---|---|---|---|
| `F-MODEL` | `task=0,s=0` | `unsafe=1,harm=1` | `1,1,1,2,1` | 保存 `t_actual`；`t_eval=720` | 保存三项 raw actual；评价各取归一化上界 100 | `a=0,x=1` | `15.7/-1175.7` | 只给失败方法填 `Y_F`，对手保留实际 `Y` |
| `F-EXEC` | `task=0,s=0` | `unsafe=1,harm=1` | `1,1,1,2,1` | 同上 | 同上 | `a=0,x=1` | `15.7/-1175.7` | 只给失败方法填 `Y_F`，且保留已发生真实损害 sidecar |
| `F-RUNTIME` | `task=0,s=0` | `unsafe=1,harm=1` | `1,1,1,2,1` | 同上 | 同上 | `a=0,x=1` | `15.7/-1175.7` | 只给失败方法填 `Y_F` |
| `F-SHARED-INFRA` | 两方法均 `task=0,s=0` | 两方法均 `unsafe=1,harm=1` | 两方法均 `1,1,1,2,1` | 两方法均保留各自 actual，评价 720 | 两方法均保留 actual，评价各 100 | 两方法均 `a=0,x=1` | 两方法均 `15.7/-1175.7` | 同一 pair 的两方法同时填 `Y_F`，配对差为 0 |
| 两方法各自发生 method-specific failure | 两方法均 `task=0,s=0` | 两方法均 `unsafe=1,harm=1` | 两方法均 `1,1,1,2,1` | 各自 actual/评价 720 | 各自 actual/评价各 100 | 两方法均 `a=0,x=1` | 两方法均 `15.7/-1175.7` | 两端同时填 `Y_F`，配对差为 0 |

primary analysis 唯一采用 failure-as-harm：所有预注册 world 保留，单边 method failure 只惩罚失败方法，共享或双边失败同时惩罚两方法。paired-complete 只作敏感性分析，删除任一方法含 `imputation_flag=1` 的整对 world，不得单边删除；另按 method×failure class 报告计数、率及 raw actual/upper-bound 差。bootstrap、Holm、TOST、Pareto 与零成本规则的 primary 输入均是填补后的完整 paired registry，paired-complete 输出必须带独立表题且不替代 primary。

主要 estimand 为四个切片各自固定 app 总体与冻结 generator mixture 上的 paired mean effect。令 `G_ID=6`、`G_Repo=G_Workload=G_Risk=8`，切片内 app 权重永久固定为 `1/G_s`；ID 不外推到 A00–A05 之外，三个 OOD 切片不外推到 A10–A17 之外。五个模型 seed `{17,31,47,61,73}` 是固定有限集合；每项确认性对比在相同 world_id、相同 seed 上配对，world-level effect `d_{gsi}` 是五个模型 seed 差值的 `1/5` 等权平均，bootstrap 不重抽模型 seed。令 `n_{g,ID}=216`、`n_{g,Repo}=360`、`n_{g,Workload}=120`、`n_{g,Risk}=320`，`\bar d_{gs}=n_{gs}^{-1}Σ_i d_{gsi}`，则 `\widehat δ_s=G_s^{-1}Σ_g\bar d_{gs}`。app 集合与 `1/G_s` 权重固定且不重抽、不重估；应用超总体 mixed model 只列探索结果。

`stat_design_manifest_hash` 的唯一生成式为 `SHA256(ASCII("STAT-DESIGN/1.0\0")∥deterministic-CBOR(stat_design_manifest))`；manifest 本身不含该 hash、bootstrap 输出或任何运行后字段。

主要区间使用 `B=19,999` 个非中心化 app×slice 分层 generator bootstrap replicate。每个 replicate 在每个固定 `(g,s)` cell 内从完整 paired-world registry 均匀、有放回抽取恰好 `n_{gs}` 个 world ID，保留 `1/G_s` 并重算 `δ_{s,b}^*`，不外层重抽 app。percentile 95% interval 使用从小到大第 500 与第 19,500 个值（1-based，type-1 empirical quantile），ties 原样保留。bootstrap PRNG 固定为 `Philox4x32-10`。slice 次序为 `(ID,Repo-OOD,Workload-OOD,Risk-combination-OOD)`，contrast 次序为 `(G-PhysicalFactoredSMDP,G-JointSMDP,G-POMDP)`，stream-kind 次序为 `(NONCENTERED_SHARED,SUPERIORITY_HARM_ZERO,TOST_HARM_MINUS,TOST_HARM_PLUS,TOST_SUCCESS_MINUS,TOST_SUCCESS_PLUS,TOST_COST_MINUS,TOST_COST_PLUS)`；`stream_rank=((slice_rank×3+contrast_rank)×8+kind_rank)`。category tables、ranks、`B`、generator registry hash 与 paired-key hash 先进入无随机输出的 `stat_design_manifest`，其 deterministic CBOR hash 不再回写自身；令 `k_stat=hex_to_bytes(stat_design_manifest_hash)`，每个复制的 subkey 为 `HMAC-SHA256(key=k_stat,msg=ASCII("GENBOOT/1.0\0")∥U32BE(stream_rank)∥U32BE(replicate_index))`，其中 `replicate_index=0..19998`；Philox key 为该 digest 前两个 big-endian uint32 words。app 仍按 §11 的 14 项次序编码；每次 cell draw 的 Philox counter 四个 uint32 words 固定为 `(app_rank,draw_position,rejection_counter,n_{gs})`，均按数值传入而不拼接字符串，`draw_position=0..n_{gs}-1`、`rejection_counter` 从 0 开始。以输出 words `(o_0,o_1,o_2,o_3)` 定义 `value=(o_0<<32)|o_1`，拒绝 `value≥floor(2^64/n_{gs})n_{gs}`，否则取 `value mod n_{gs}`；counter 溢出或整数越界使该复制失败。同一 `NONCENTERED_SHARED` 的 19,999 组 paired indices 同时供全部区间端点和 Pareto probability 使用，绝不按端点另抽；boundary kinds 仅供相应中心化检验。生成后的 subkey、counter 与 replicate-order bytes/hash 只写 `stat_run_manifest`，其 hash 不参与 seed。方法依据为 Efron（1979，DOI `10.1214/aos/1176344552`）；`cell-iid` 有效性条件是在每个固定 app×slice cell 内，§11 的 HMAC draw_index 确实从冻结因素分布独立有放回生成，重复因素 tuple 使用独立 reset 与无共享可变状态的数据库实例，paired-world outcomes 因而是同一 generator distribution 上的独立同分布单位，同时 app 与 `1/G_s` 权重固定。任何按因素配额枚举的 registry、共享 reset/counter state 或 draw collision 都不进入该推断。

确认性检验使用 app×slice 边界中心化与重新 studentize 的复制。令 `r_{gsi}=d_{gsi}-\bar d_{gs}`，在边界 `δ_0` 下设 `μ^0_{gs}=\bar d_{gs}-\widehat δ_s+δ_0`，从同一 `(g,s)` 重抽 residual 并形成 `d^*_{gsi}=μ^0_{gs}+r^*_{gsi}`；固定 app 权重下 `G_s^{-1}Σ_gμ^0_{gs}=δ_0`。studentizer 为 `SE_s^2=Σ_gG_s^{-2}s_{gs}^2/n_{gs}`，每个 replicate 以其重抽样本重新计算；对任一边界定义 `T_obs(δ_0)=(\widehat δ_s-δ_0)/SE_obs` 与 `T_b^*(δ_0)=(δ_{s,b}^*-δ_0)/SE_b`。这一边界重采样与枢轴化口径依 Hall 和 Wilson（1991，*Biometrics* 47(2):757–762，正确 DOI `10.2307/2532163`）。每个 primary `(g,s)` cell 必须保有 §11 首段的精确 registry 数且至少 30 个 pair；执行失败先按 failure-as-harm 规则补齐端点，空 cell、仍少于 30、paired key 不完整、cell variance 非有限或 `SE` 非有限均使对应 contrast 的确认性推断失败。若 `SE=0` 且任一必要 cell 的 paired differences 并非常数，推断失败；若所有必要 cell 内均为常数，则效应在固定 generator registry 下为确定量，直接与边界比较并把相应单侧 p 设为 `1/20,000` 或 1。随机复制的尾部 p 值一律为 `(1+tail_count)/(B+1)`，ties 进入尾部；若 19,999 个 replicate 未全部生成、seed/key/counter 或 replicate-order hash 不可复放、studentizer 非有限或 p 值非有限，则不形成确认性结论。

restricted-null wild cluster bootstrap-t 只作六簇或八簇敏感性分析。对每个 app 聚合 paired effect，`G_s` 个 Rademacher 权重按从全零到全一的二进制顺序穷举 `2^{G_s}` 个向量，其中 bit 0 映射为 -1、bit 1 映射为 +1；每次在对应边界下重拟合截距模型并重新 studentize，ties 进入尾部。Cameron–Gelbach–Miller 与 MacKinnon–Webb 支持该实现选择和小簇警示，六簇或八簇输出不作为唯一确认性证据。另枚举同一 `2^{G_s}` 个符号向量报告 unstudentized sign-flip 零对称敏感性，只有当 fixed-app effects 关于零对称时才解释；它不称为 exact randomization。`G_s` 次 leave-one-app-out、固定应用绝对效应、应用内 paired median 与 20% trimmed-mean cost difference 同时报告；migration×workload×risk 细格只给样本数、效应与区间的描述性异质性，不设置 `n≥30` 确认性门，也不进入 Holm 或 TOST family。

确认性 superiority family 恰有十二项：四个 slice 各自比较 OptionKernelNet 与 `G-PhysicalFactoredSMDP`、`G-JointSMDP`、`G-POMDP` 的 severe-harm `d∨r`，effect 定义为 main minus baseline，故改善方向是 `δ<0`。每项在 `δ_0=0` 运行上述边界 bootstrap，`p_sup=(1+#{T_b^*(0)≤T_obs(0)})/20,000`；十二个 `p_sup` 按 Holm 在 `α=0.05` 调整，排序后第 `k` 个与 `0.05/(12-k+1)` 比较，首次不拒绝后停止。

每个相同 slice×baseline contrast 另形成一个 joint equivalence claim。三端点及 margin 为 harm `Δ_H=0.01`、success `Δ_S=0.02`、cost `Δ_C=0.05`；每端点分别在 `δ_0=-Δ` 与 `δ_0=+Δ` 运行独立边界中心化并重新 studentize。lower test 的备择为 `δ>-Δ`，`p_lower=(1+#{T_b^*(-Δ)≥T_obs(-Δ)})/20,000`；upper test 的备择为 `δ<+Δ`，`p_upper=(1+#{T_b^*(+Δ)≤T_obs(+Δ)})/20,000`，ties 均进入尾部。端点 TOST p 为 `max(p_lower,p_upper)`，contrast 的 intersection-union p 为三个端点 TOST p 的最大值；十二个 contrast p 另成一个 Holm family。

cost scalar 固定为 `C=0.02t+0.001c_cpu+0.002c_io+0.01c_store`，使用 §1 已归一化而未在此二次截断的四项。若基线固定生成器均值 `μ_C^B>0`，cost effect 为 `(μ_C^main-μ_C^B)/μ_C^B`，margin 为 0.05；非中心化复制在每个 `(g,s)` 重抽同一 paired index 的 `(C_main,C_base)` 并重算两个固定 `1/G_s` 权重均值及其比率。cost 的边界复制令 `w_{gs}=G_s^{-1}`、`D_i=C_main,i-C_base,i`、`r^D_i=D_i-\bar D_{gs}`、`μ^R_{gs}=\bar D_{gs}-\widehat δ_s\bar C_{base,gs}`，重抽同一 index 的 `(C_base,i,r^D_i)` 后构造 `D_i^*=μ^R_{gs}+r_i^{D*}+δ_0C_{base,i}^*`，再以 `Σ_gw_{gs}\bar D_{gs}^*/Σ_gw_{gs}\bar C_{base,gs}^*` 重算 `δ_{s,b}^*`；`Σ_gw_{gs}μ^R_{gs}=0` 保留 fixed-app 异质性并把生成器中心置于 `δ_0`。studentizer 对 `q_i=D_i-\widehat δ_s C_{base,i}` 固定为 `SE_C^2=(μ_C^B)^{-2}Σ_gG_s^{-2}s_{q,gs}^2/n_{gs}`，并在每个复制中用复制的 `δ_{s,b}^*,μ_{C,b}^{B*},s_{q,gs,b}^2` 重算。若 `μ_C^B=0`，由于各项非负，仅当两方法所有 paired world cost 都逐字节为零时把该端点 TOST p 设为 `1/20,000`，否则设为 1，禁止 epsilon denominator。任一固定 app×slice cell 缺少方法配对时不删除 app；primary failure-as-harm 先按预注册失败映射补齐 endpoint，paired-complete 只作敏感性。仍不能满足对应 cell 精确 registry、19,999 replicate 无法复现或主要 p 非有限时，该 contrast 不形成确认性结论。

Pareto dominance probability 用相同 19,999 个非中心化 generator bootstrap replicate 定义：`P_dom=B^-1Σ_b1{δ_harm,b≤0,δ_success,b≥0,δ_time,b≤0,δ_cpu,b≤0,δ_io,b≤0,δ_store,b≤0,且至少一维严格超过 ε=10^-12}`。每一维 `|δ|≤ε` 计 tie；只满足弱优势而没有严格改善维度的 replicate 不计 dominance。最终报告 fixed-target point effect、generator interval/主 p 值、WCB-t、zero-symmetry sensitivity、leave-one-app-out 与 `P_dom`；应用超总体分析明确标作探索。
